## Контекст

Тикет SHOP-415. Сотрудница склада пользуется сайтом только с клавиатуры: у неё болит рука. Она жалуется: нажимает Tab и не видит, где находится. Разработчик когда-то убрал рамку вокруг выбранного элемента, потому что она «портит вид».

Видимый фокус (focus indicator) нужен всем, кто ходит по странице клавишей Tab. Требование WCAG 2.1 AA, критерий 2.4.7 «Видимый фокус» (Focus Visible).

## Цель

Верните видимый фокус всем интерактивным элементам страницы. Используйте псевдокласс `:focus-visible`: он показывает рамку при навигации с клавиатуры и не мешает при клике мышью.

## Критерии приёмки

- Ссылки меню, поле поиска, кнопка «Найти», выпадающий список сортировки и кнопка «В корзину» при фокусе имеют видимую рамку: `outline` толщиной не меньше 2px (или заметная тень `box-shadow`).
- Цвет рамки отличается от белого фона страницы не меньше чем 3 к 1 (WCAG 1.4.11).
- Стили фокуса записаны через `:focus-visible`.
- В `styles.css` не остаётся правил, которые гасят рамку (`outline: none`, `outline: 0`) для фокуса.
- Внешний вид элементов без фокуса не меняется.

## Ограничения

- Менять только `styles.css`.
- Не ставьте `tabindex` и не меняйте разметку.
