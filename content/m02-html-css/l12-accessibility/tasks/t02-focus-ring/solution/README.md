# Разбор

В `styles.css` рамка была выключена в трёх местах: общим правилом `* { outline: 0 }`, правилом `.nav a:focus` и объявлением в `.search__input`. Достаточно оставить одно из них, и часть страницы снова без фокуса. Поэтому эталон удаляет все три.

Затем добавлено одно общее правило:

```css
:focus-visible {
  outline: 3px solid #0b57d0;
  outline-offset: 2px;
}
```

- `:focus-visible` срабатывает, когда браузер считает, что фокус нужно показать: при навигации клавишей Tab и в полях ввода. После щелчка мышью по кнопке рамка не появляется.
- `outline-offset: 2px` отодвигает рамку от края, чтобы она не сливалась с тёмной кнопкой.
- Цвет `#0b57d0` на белом даёт контраст около 6,4 к 1. Для элементов интерфейса достаточно 3 к 1.

Правило с `outline` не меняет размеры элемента: рамка рисуется поверх макета и не сдвигает соседей.
