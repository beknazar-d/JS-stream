## Контекст

Тикет SHOP-431. В «Домотеке» дизайнеры меняют цвета в переменных CSS, и после каждой правки кто-то вручную проверяет контраст в сторонней программе. Нужна маленькая функция в скрипте сборки: она читает пару цветов и говорит, проходит ли пара уровень AA.

Формула из WCAG 2.1:

- Каждый канал цвета (красный, зелёный, синий) делят на 255 и получают число c от 0 до 1. Если c не больше 0,03928, то канал равен c / 12,92. Иначе канал равен ((c + 0,055) / 1,055) в степени 2,4.
- Относительная яркость (relative luminance): `0,2126 * R + 0,7152 * G + 0,0722 * B`, где R, G, B — каналы после этого пересчёта.
- Контраст: `(L1 + 0,05) / (L2 + 0,05)`, где L1 — яркость более светлого цвета, L2 — более тёмного.

## Цель

Реализуйте в `index.js` три функции: `contrastRatio(foreground, background)`, `meetsAA(foreground, background, isLarge)` и `isLargeText(fontSizePx, isBold)`.

## Критерии приёмки

- `contrastRatio('#000000', '#ffffff')` равно 21, `contrastRatio('#767676', '#ffffff')` примерно 4,54. Результат не округляется.
- Результат не зависит от порядка аргументов: `contrastRatio(a, b)` равно `contrastRatio(b, a)`.
- Цвет можно записать как `#rrggbb` или коротко `#rgb`, в любом регистре: `'#FFF'` и `'#ffffff'` дают одно и то же.
- Любая другая запись (`'red'`, `'#12'`, `'#gggggg'`, не строка) приводит к исключению `Error` с текстом «Некорректный цвет».
- `meetsAA` возвращает `true`, если контраст не меньше 4,5 для обычного текста и не меньше 3 для крупного (`isLarge` равно `true`). Сравнение по точному значению, без округления.
- `isLargeText(fontSizePx, isBold)` возвращает `true` для размера от 24px (18pt) и для жирного текста от 14pt, то есть от `14 * 96 / 72` пикселей. Размеры в пикселях CSS.

## Ограничения

- Только встроенные средства языка, без библиотек.
- Не округляйте промежуточные значения.
