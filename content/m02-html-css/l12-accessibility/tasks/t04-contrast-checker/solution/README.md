# Разбор

Решение состоит из маленьких функций, и каждая делает одно дело.

- `parseHex` проверяет запись регулярным выражением и превращает её в три числа. Короткую запись `#abc` разворачивает в `#aabbcc`. Всё остальное бросает ошибку: тихий `NaN` хуже громкого исключения.
- `channel` — формула канала из WCAG. Порог 0,03928 стоит в самом тексте стандарта; в таблицах sRGB встречается 0,04045. Для 8-битных цветов результат один и тот же.
- `luminance` складывает каналы с весами. Зелёный весит больше всего, потому что глаз к нему чувствительнее.
- `contrastRatio` берёт `Math.max` и `Math.min`, поэтому порядок аргументов не важен.
- `meetsAA` сравнивает с порогом по точному значению.
- `isLargeText`: 18pt это 24px, 14pt это около 18,67px.

Сравнение `>=` важно: ровно 4,5 проходит, а 4,48 нет.
