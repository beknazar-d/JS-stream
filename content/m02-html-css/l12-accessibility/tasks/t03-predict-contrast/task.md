## Контекст

Дизайнер «Домотеки» прислал новые цвета для подписей и кнопок. Перед правкой стилей разработчик решает, какие пары проходят проверку AA. Для этого у него есть функция расчёта контраста по формуле из WCAG 2.1. Функция печатает отношение контраста с двумя знаками и слово `true`, если пара проходит порог, либо `false`.

Порог зависит от размера текста: 4,5 к 1 для обычного текста и 3 к 1 для крупного.

## Цель

Прочитайте код из `snippet.js`. Запишите в `answer.js` в массив `output` шесть строк: ровно то, что код выведет в консоль, по одной строке на каждый вызов `report`.

## Критерии приёмки

- В массиве `output` ровно шесть строк в порядке вызовов.
- Каждый элемент — строка вида `"21.00 true"`: отношение, пробел, результат проверки.
- Ответ совпадает с реальным выводом кода построчно.

## Ограничения

- Не меняйте `snippet.js`.
- Подсказка по формуле: чем светлее цвет, тем больше его яркость; у чёрного она 0, у белого 1.
- Сначала предскажите, потом сверьтесь с проверкой. Пара `#767676` на белом лежит ровно у порога.
