# Разбор

Функция `contrast` считает отношение `(L1 + 0.05) / (L2 + 0.05)`, где `L1` — яркость более светлого цвета, `L2` — более тёмного.

1. Чёрный на белом: яркости 0 и 1, отношение `1.05 / 0.05`, то есть `21.00`. Это максимум. Порог 4,5 пройден.
2. `#767676` на белом: `4.54`. Это самый светлый серый, который проходит AA для обычного текста на белом фоне.
3. `#777777` на белом: `4.48`. Разница в один шаг цвета, но порог 4,5 не пройден: `false`.
4. Та же пара, но текст крупный. Порог 3 к 1, `4.48` его превышает: `true`.
5. Белый на белом: `1.00`. Различия нет, не проходит ни один порог.
6. Белый на тёмно-синем `#0b3d91`: `10.04`. Запас большой.

Вывод: проверять надо число, а не глаз. Серый `#777777` кажется читаемым, но стандарту не соответствует.
