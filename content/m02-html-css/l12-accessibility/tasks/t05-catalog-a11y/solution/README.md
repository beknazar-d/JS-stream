# Разбор

Каждое замечание аудитора закрыто самым простым средством.

- **Поле поиска.** `label` со скрытым текстом. Подсказка `placeholder` именем поля не считается: она исчезает при вводе.
- **Кнопки-значки.** У `button` нет текста, поэтому нужен `aria-label`. Значок `svg` получает `aria-hidden="true"`, чтобы скринридер не пытался читать его содержимое.
- **Фотографии.** `alt` отвечает на вопрос «что тут и зачем». Не «картинка» и не «чайник.jpg».
- **Декоративная линия.** `alt=""` говорит скринридеру пропустить картинку. Если убрать атрибут совсем, многие скринридеры прочитают адрес файла.
- **Кнопки «В корзину».** Настоящий `button` сразу умеет принимать фокус, нажиматься по Enter и пробелу. На `div` всё это пришлось бы дописывать руками, и всё равно получилось бы хуже. ARIA здесь не нужна: правильный элемент заменяет её.
- **tabindex.** Положительное значение вытаскивает элемент в начало порядка Tab. Порядок должен совпадать с порядком в разметке, поэтому все положительные значения убраны.
- **Ссылки «Подробнее».** Скрытое продолжение даёт уникальное имя: «Подробнее о товаре Чайник Домотека ЧЭ-17».

Внешний вид не изменился: `styles.css` тот же.
