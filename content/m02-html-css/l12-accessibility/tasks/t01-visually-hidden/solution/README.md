# Разбор

Идея: текст остаётся в дереве доступности, но для глаз его нет.

- `position: absolute` выводит элемент из потока. Он не раздвигает кнопку.
- `width: 1px; height: 1px` оставляют элемент в раскладке. Именно поэтому нельзя `display: none`: у такого элемента нет рамки, и скринридер его пропускает.
- `overflow: hidden` и `clip` не дают тексту вылезти за один пиксель.
- `margin: -1px` убирает следы от рамки в старых браузерах.
- `white-space: nowrap` запрещает перенос. Без него в колонке шириной 1px текст ломается по слову, и некоторые скринридеры читают его по буквам.

Этот класс пригодится в каждом проекте: он нужен для подписей кнопок-иконок, для заголовков полей поиска, для поясняющего текста в таблицах.
