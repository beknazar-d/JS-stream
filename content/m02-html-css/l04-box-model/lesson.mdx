## Зачем это в работе

Тикет от верстальщика «Домотеки»: «Карточки должны стоять по три в ряд, а стоят по две. Я задал ширину 300px, внутренние отступы 20px и рамку 2px. В макете карточка тоже 300, откуда 344?»

Или такой: «Между блоками должно быть 50px, а получилось 30». Обе проблемы про одно: как браузер считает размеры и отступы. Это блочная модель (box model). Без неё любая вёрстка превращается в подгонку чисел наугад.

## Объяснение

Каждый элемент на странице — прямоугольная коробка. У неё четыре слоя, изнутри наружу:

- **content** (содержимое): текст или картинка. Размер задают `width` и `height`.
- **padding** (внутренний отступ): пространство между содержимым и рамкой. Фон коробки доходит до него.
- **border** (рамка): линия вокруг.
- **margin** (внешний отступ): пустое место вокруг рамки, отталкивает соседей. Фона нет.

Представьте коробку с подарком. Подарок внутри — content. Пенопласт вокруг него — padding. Стенки коробки — border. А расстояние от коробки до соседней на полке — margin.

Теперь главная ловушка. По умолчанию `width` задаёт только размер подарка. Пенопласт и стенки добавляются сверху, и коробка получается больше, чем вы написали. Это режим `box-sizing: content-box`.

Второй режим, `box-sizing: border-box`, говорит: `width` — размер всей коробки целиком. Содержимое сожмётся, чтобы пенопласт и стенки влезли внутрь.

## Пример

Карточка из «Домотеки».

```css
.card {
  width: 300px;
  padding: 20px;
  border: 2px solid #1f6feb;
}
```

Сколько места занимает такая карточка? `300 + 20 + 20 + 2 + 2 = 344`. Не 300. А если добавить `box-sizing: border-box`, ровно 300.

<Wrong>

```css
.card {
  width: 300px;
  padding: 20px;
  border: 2px solid #1f6feb;
}
```

</Wrong>

<Right>

```css
* {
  box-sizing: border-box;
}

.card {
  width: 300px;
  padding: 20px;
  border: 2px solid #1f6feb;
}
```

</Right>

Запустите пример и сравните два режима. Он же показывает, сколько содержимого остаётся в `border-box`.

## Как это работает

Посмотрите на схему слоёв.

<Figure src="box-model.svg" alt="Вложенные прямоугольники: снаружи пунктиром margin, затем жирная рамка border, затем пунктирная граница padding, в центре закрашенное content. Справа подписи: в content-box width задаёт только content, в border-box width включает padding и border, margin в width не входит." caption="Слои коробки и два режима box-sizing." />

**Сокращённая запись.** Свойства `margin` и `padding` принимают от одного до четырёх значений.

- Одно значение: `padding: 16px` — со всех сторон.
- Два: `padding: 24px 32px` — сверху и снизу, слева и справа.
- Три: `margin: 0 0 16px` — сверху, по бокам, снизу.
- Четыре: `margin: 1px 2px 3px 4px` — сверху, справа, снизу, слева (по часовой стрелке).

Центрирование: блок с заданной шириной и `margin: 0 auto` встаёт по центру. Браузер делит свободное место поровну.

**Схлопывание отступов.** Вертикальные внешние отступы соседних блоков не складываются. Если у верхнего блока `margin-bottom: 30px`, а у нижнего `margin-top: 20px`, расстояние между ними 30, а не 50. Берётся больший.

<Playground example="margin-collapse" />

Схлопывание бывает и между родителем и первым ребёнком. Если у родителя нет рамки и внутреннего отступа, верхний отступ ребёнка выходит наружу и сдвигает родителя. Лечится рамкой, `padding` или `display: flow-root` у родителя. Горизонтальные отступы никогда не схлопываются.

**Как элемент занимает место: `display`.**

- `block`: занимает всю строку. Принимает `width`, `height`, все отступы. Так ведут себя `div`, `p`, `h1`, `section`.
- `inline`: течёт как слово в тексте. Игнорирует `width` и `height`, вертикальные отступы не двигают соседей. Так ведут себя `span`, `a`, `strong`.
- `inline-block`: течёт как слово, но принимает `width` и `height`. Подходит для кнопок и бейджей.

Пробелы между `inline-block` в HTML превращаются в небольшой зазор между элементами. Учитывайте его, когда считаете ширины.

**Переполнение.** Если содержимое не влезает в заданный размер, оно выходит за коробку. Поведение задаёт `overflow`: `visible` (по умолчанию, торчит наружу), `hidden` (обрезать), `scroll` и `auto` (прокрутка). Чтобы длинный текст обрезался многоточием, нужны три свойства вместе: `white-space: nowrap`, `overflow: hidden`, `text-overflow: ellipsis`.

## Типичные ошибки

Консоль о размерах не ругается. Проверяйте в DevTools (схема блока на вкладке Computed) или цифрами из JavaScript. Результаты ниже получены в Chromium.

**1. Блок шире, чем задано.**

<Wrong>

```css
#box { width: 300px; padding: 20px; border: 2px solid; }
```

```js
console.log(document.querySelector("#box").offsetWidth);
```

```text
344
```

</Wrong>

<Right>

```css
#box { width: 300px; padding: 20px; border: 2px solid; box-sizing: border-box; }
```

```js
console.log(document.querySelector("#box").offsetWidth);
```

```text
300
```

</Right>

**2. Отступы не складываются.** Два блока с `margin-bottom: 30px` и `margin-top: 20px`.

```js
const top = document.querySelector("#m1").getBoundingClientRect().bottom;
const bottom = document.querySelector("#m2").getBoundingClientRect().top;
console.log(bottom - top);
```

```text
30
```

Расстояние 30, а не 50.

**3. Ширина у `span` не работает.** У строчного элемента `width: 200px` записана в стилях, но на размер не влияет.

```js
const span = document.querySelector("#sp");
console.log(getComputedStyle(span).width, span.offsetWidth);
```

```text
200px 49
```

Стиль «задан», а реальная ширина 49: ширину определяет текст. Сделайте элемент `inline-block` или `block`.

**4. Протекание отступа.** Заголовок с `margin-top: 24px` в баннере без рамки и padding: фон баннера начинается выше заголовка, а отступа внутри нет. Добавьте `display: flow-root` баннеру.

**5. Горизонтальная прокрутка из-за `width: 100%`.** `width: 100%` плюс `padding` в `content-box` даёт ширину больше родителя. Решение то же: `box-sizing: border-box`.
