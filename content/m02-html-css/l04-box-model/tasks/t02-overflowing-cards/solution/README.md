# Разбор

По умолчанию у всех элементов `box-sizing: content-box`. Тогда `width: 100%` относится только к содержимому, а рамка и внутренние отступы прибавляются сверху. У карточки: `400 + 2 * 20 + 2 * 2 = 444` пикселя в панель шириной 400. У поля поиска: `400 + 2 * 8 + рамка` с лишним.

Решение — `box-sizing: border-box`. Теперь `width` задаёт всю коробку целиком: содержимое, padding и border. Карточка занимает ровно 400px, а содержимого в ней становится `400 - 44 = 356`.

Лучше задать это правило сразу для всех элементов в начале CSS:

```css
* {
  box-sizing: border-box;
}
```

Тогда ширина блока всегда равна тому, что написано в `width`, и считать отступы в уме не нужно. Почти все проекты начинают с такого правила.

`overflow: hidden` на панели прятал бы лишнее, но не исправил бы размер. Убирать `padding` и `border` нельзя: это нарушает требования дизайна.
