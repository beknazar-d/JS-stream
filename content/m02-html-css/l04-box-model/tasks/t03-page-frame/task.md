## Контекст

Тикет UI-110. Страница «Условия доставки» в «Домотеке» должна быть узкой колонкой по центру. Верстальщик помнит, что для этого нужно: задать ширину, обнулить лишнее и выровнять по центру автоматическими отступами. Заодно потренируем короткую запись свойств.

## Цель

Допишите `styles.css`.

1. Колонка `.page`: общая ширина (включая рамку и внутренние отступы) ровно 800px, по центру окна.
2. Внутренние отступы колонки: 24px сверху и снизу, 32px слева и справа. Одним свойством.
3. Рамка колонки: 1px, сплошная, цвет `#dde3ea`.
4. Заголовок `.page h1`: нулевой отступ сверху и по бокам, 16px снизу. Одним свойством.

## Критерии приёмки

- Колонка шириной 800px, её левый край на 112px от левого края окна (при ширине окна 1024px).
- `padding-top` и `padding-bottom` по 24px, `padding-left` и `padding-right` по 32px.
- Рамка 1px solid `#dde3ea`.
- У заголовка `margin-top` 0, `margin-left` и `margin-right` 0, `margin-bottom` 16px.

## Ограничения

- Менять только `styles.css`.
- Запись `margin: 0 auto` и сокращённый `padding` с двумя значениями ожидаются, но проверяется результат.
