# Разбор

- `box-sizing: border-box` делает так, что `width: 800px` включает внутренние отступы и рамку. Ширина колонки ровно 800.
- `margin: 0 auto`: ноль сверху и снизу, автоматические отступы по бокам. Браузер делит свободное место поровну, и колонка встаёт по центру: `(1024 - 800) / 2 = 112`. Центрировать так можно только блок, у которого задана ширина.
- `padding: 24px 32px`: два значения — «сверху и снизу», «слева и справа». Запись по часовой стрелке для четырёх значений: сверху, справа, снизу, слева.
- `border: 1px solid #dde3ea` — толщина, стиль, цвет. Стиль обязателен: без него рамка не появится.
- `margin: 0 0 16px` у заголовка: три значения — «сверху», «по бокам», «снизу».
