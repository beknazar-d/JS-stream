# Разбор

**Ширина блока.** Полный размер коробки по горизонтали: содержимое, внутренние отступы (padding) и рамка (border). Внешние отступы (margin) лежат снаружи, но тоже занимают место в строке.

- `content-box` (так работает браузер по умолчанию): `width` задаёт только содержимое. Размер блока: `300 + 2 * 20 + 2 * 2 = 344`. С внешними отступами `344 + 2 * 10 = 364`.
- `border-box`: `width` уже включает padding и border. Размер блока 300, с отступами `300 + 20 = 320`.

**Сколько влезет в 1000.** `1000 / 364 = 2,74`, после `Math.floor` остаётся 2. `1000 / 320 = 3,125`, остаётся 3. Вот почему карточки вставали по две: разработчик задал `width: 300px` и забыл, что рамка и отступы прибавляются сверху.

**Вертикальные отступы.** Если блок над другим имеет `margin-bottom: 24`, а нижний `margin-top: 32`, они не складываются, а схлопываются (collapse). Расстояние равно большему значению, то есть 32. Без схлопывания получилось бы 56. Сворачиваются только вертикальные отступы соседних блоков. Горизонтальные никогда не сворачиваются.
