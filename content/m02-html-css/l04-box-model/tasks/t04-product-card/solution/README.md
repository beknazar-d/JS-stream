# Разбор

- `.card`: `box-sizing: border-box` делает ширину 320 общей. Содержимое получает `320 - 2 - 32 = 286`.
- `.photo` блок, он сам занимает всю ширину содержимого, нужна только высота.
- `h2` и `p` имеют браузерные внешние отступы. Мы заменяем их одним свойством `margin` с тремя значениями: сверху, по бокам, снизу.
- Расстояние между блоками создаёт верхний отступ нижнего. Нижние отступы обнулены, поэтому схлопывание не вмешивается.
- `button` по умолчанию строчный элемент с шириной по тексту. `display: block` и `width: 100%` растягивают его. У кнопки `box-sizing` по умолчанию уже border-box, но запись явная.
- Нижний отступ карточки 17px получается сам: padding 16 и рамка 1.
