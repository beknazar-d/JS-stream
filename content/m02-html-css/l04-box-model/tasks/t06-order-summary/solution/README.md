# Разбор

1. **Каркас.** `box-sizing: border-box`, `width: 960px`, `margin: 0 auto`. Содержимое страницы получает `960 - 48 - 2 = 910`.
2. **Ячейки.** Блок `div` занимает всю строку, а `inline-block` ведёт себя как слово в строке, но принимает ширину. Три ячейки с ширинами 540, 100, 240 вместе дают 880. Между ячейками в HTML есть пробелы, и они занимают несколько пикселей. Если бы сумма была ровно 910, последняя ячейка упала бы на следующую строку.
3. **`vertical-align: top`.** У `inline-block` с `overflow` отличным от `visible` базовая линия уходит к нижнему краю. Без выравнивания по верху такая ячейка стоит выше или ниже соседей. Ставим `vertical-align: top` всем трём.
4. **Обрезка.** Три свойства вместе: `white-space: nowrap` (одна строка), `overflow: hidden` (скрыть лишнее), `text-overflow: ellipsis` (многоточие). Без любого из них обрезка не работает.
5. **Итог.** Блок с фиксированной шириной и `margin-left: auto` прижимается вправо: автоматический отступ забирает всё свободное место. Верхний отступ 24px.
