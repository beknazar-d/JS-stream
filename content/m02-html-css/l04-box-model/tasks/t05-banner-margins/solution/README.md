# Разбор

Вертикальный отступ первого ребёнка и верхний отступ родителя могут объединиться (схлопнуться), если между ними ничего нет: ни рамки, ни внутреннего отступа. Тогда отступ заголовка оказывается снаружи баннера и сдвигает весь баннер вниз, а жёлтый фон начинается там, где заканчивается отступ. То же происходит снизу с последним ребёнком.

Решение: сделать баннер новым блочным контекстом через `display: flow-root`. Внутри такого блока отступы детей остаются внутри. Других побочных эффектов у `flow-root` нет, поэтому он считается самым чистым способом. Альтернативы: рамка, `padding` (но он добавляет место), `overflow: hidden` (но он обрезает тени и выпадающие элементы).

Отступ самого баннера (`margin-on-banner`) ничего не меняет внутри: отступ заголовка всё равно протекает.
