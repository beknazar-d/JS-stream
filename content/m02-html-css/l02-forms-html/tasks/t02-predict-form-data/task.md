## Контекст

Тикет SHOP-214. Тестировщик пожаловался: из формы заказа «пропал» промокод, а количество товара при сложении превращается в «31» вместо 4. Чтобы понять, что происходит, разработчик набросал функцию `collect`, которая повторяет правило браузера: какие поля попадают в отправляемые данные и в каком виде.

## Цель

Прочитайте код из `snippet.js`. Запишите в `answer.js` в массив `output` шесть строк: именно то, что код выведет в консоль, по одной на каждый вызов `console.log`. Массив записывайте так, как его покажет консоль: `["a", "b"]`.

## Критерии приёмки

- В `output` ровно шесть строк в порядке вызовов `console.log`.
- Каждый элемент — строка, даже если код выводит число или `true`.
- Ответ совпадает с реальным выводом построчно.

## Ограничения

- Не меняйте `snippet.js`.
- Сначала предскажите, потом сверяйтесь.
