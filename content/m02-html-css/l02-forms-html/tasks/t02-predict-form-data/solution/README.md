# Разбор

Функция `collect` пропускает поле, если у него нет имени или оно выключено. Это то же правило, что у настоящей формы в браузере: поле без `name` или с `disabled` в отправляемые данные не попадает.

Из пяти полей остаются три: `email`, `qty`, `comment`. Первая строка: `["email", "qty", "comment"]`.

Значение поля — всегда строка. Поэтому `data.qty + 1` склеивает строки: `"3" + 1` даёт `"31"`. А `Number(data.qty) + 1` сначала делает из строки число, результат `4`.

Пустое поле `comment` не пропадает, оно приходит как пустая строка `""`, поэтому сравнение даёт `true`.

Промокод `promo` пропущен, потому что поле выключено: `"promo" in data` равно `false`. Если нужно показать поле, но не давать менять его, используют `readonly`: такое поле отправляется. Тип значения `data.qty` — `string`.
