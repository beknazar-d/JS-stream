## Контекст

Тикет SHOP-233. Нужна форма оформления заказа «Домотеки». Макета пока нет, поэтому верстальщик отдаёт структуру формы: группы полей, подписи, правильные типы и проверку в браузере.

## Цель

Соберите форму `form.checkout` в `index.html` по описанию. Стили не нужны.

**Группа «Контакты»** (`fieldset` с `legend`):

- «Имя»: `text`, `name="name"`, обязательное, `autocomplete="name"`;
- «Телефон»: `tel`, `name="phone"`, обязательное, `autocomplete="tel"`;
- «Email»: `email`, `name="email"`, необязательное, `autocomplete="email"`.

**Группа «Доставка»**:

- «Город»: `select`, `name="city"`, обязательный. Первый пункт «Выберите город» с пустым значением, дальше «Москва» (`msk`), «Казань» (`kzn`), «Тверь» (`tver`);
- «Адрес»: `text`, `name="address"`, обязательное, `autocomplete="street-address"`;
- «Дата доставки»: `date`, `name="date"`, обязательное;
- «Комментарий для курьера»: `textarea`, `name="comment"`, не больше 300 символов.

**Группа «Оплата»**: переключатели `name="payment"`: «Картой онлайн» (`card`, выбран по умолчанию) и «При получении» (`cash`).

В конце кнопка «Подтвердить заказ».

## Критерии приёмки

- Три `fieldset`, у каждого `legend` с названием группы: «Контакты», «Доставка», «Оплата».
- У каждого поля, переключателя и списка есть `label`, связанный через `for` и `id` (или оборачивающий поле).
- Пустая форма не проходит проверку браузера. Если заполнить имя, телефон, город, адрес и дату, проверка проходит, даже когда email пуст.
- Если в email записать `abc`, проверка не проходит.
- В списке городов по умолчанию выбран пункт «Выберите город», пока его не поменяют, поле считается незаполненным.
- Кнопка — `button` с `type="submit"`.

## Ограничения

- Не используйте `placeholder` как замену подписи.
- Значения `name` и `value` держите ровно такими, как в описании: на них рассчитан сервер.
