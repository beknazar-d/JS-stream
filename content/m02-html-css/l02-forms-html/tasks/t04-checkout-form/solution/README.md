# Разбор

**Группы.** `fieldset` объединяет связанные поля, `legend` называет группу. Скринридер при входе в группу произносит её название: «Оплата, группа, Картой онлайн, переключатель». Особенно важно это для радиокнопок: общий вопрос «Оплата» живёт в `legend`.

**Подписи.** Каждому полю соответствует `label` с парой `for` и `id`. У радиокнопок подпись стоит после кнопки, у текстовых полей до поля. Порядок внутри `p` не важен для связи, важно совпадение `for` и `id`.

**Типы и проверка.** `tel`, `email`, `date` дают нужные клавиатуры и календарь. `required` делает поле обязательным, а `email` без `required` необязателен, но если заполнен, формат проверяется.

**Список.** Первый `option` с пустым `value` играет роль подсказки. Из-за `required` на `select` он не проходит проверку: пока человек не выбрал город, форму отправить нельзя. Если бы первым стоял «Москва», проверка всегда бы проходила.

**Переключатели.** У обеих радиокнопок одинаковый `name="payment"`, так браузер знает, что выбрать можно только одну. Значения `card` и `cash` уйдут на сервер. Атрибут `checked` задаёт вариант по умолчанию.

**Текстовое поле.** `textarea` для многострочного текста, `maxlength` ограничивает длину.
