## Контекст

Баг-репорт A11Y-48 по форме «Перезвоните мне» на странице каталога. Скринридер читает все четыре поля как «поле ввода, пусто». На телефоне при вводе номера открывается обычная буквенная клавиатура, а в поле количества можно набрать «пять». Подпись «Имя» есть, но клик по ней не ставит курсор в поле.

Разработчик подписал поля через `placeholder`, а у единственного `label` перепутал `for`.

## Цель

Исправьте форму в `index.html`: у каждого поля должна быть видимая подпись, связанная с ним, и подходящий тип.

## Критерии приёмки

- Для полей `name`, `phone`, `email`, `qty` есть `label`, связанный через `for` и `id`: «Имя», «Телефон», «Email», «Количество».
- Типы: `phone` — `tel`, `email` — `email`, `qty` — `number`. Имя остаётся `text`.
- Подпись управляет своим полем: клик по ней доходит до поля (метод `label.control` возвращает это поле).
- Кнопка «Перезвоните мне» отправляет форму (`type="submit"`).
- Атрибуты `name` полей не меняются.

## Ограничения

- Не используйте `aria-label` вместо видимых подписей.
- `placeholder` можно оставить, но он не подпись.
