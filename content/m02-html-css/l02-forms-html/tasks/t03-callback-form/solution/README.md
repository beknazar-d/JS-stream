# Разбор

Три ошибки в одной форме.

**1. Подписи вместо `placeholder`.** `placeholder` — это пример ввода, а не название поля. Он пропадает, когда человек начинает печатать, и у него обычно низкий контраст. Название поля — это `label`, видимый всегда.

**2. Связь `for` и `id`.** В заготовке у `label` стоял `for="user-name"`, а у поля `id="name"`. Значения не совпали, поэтому связи нет. После исправления клик по слову «Имя» ставит курсор в поле, а скринридер читает «Имя, поле ввода».

**3. Типы.** `tel` включает на телефоне клавиатуру с цифрами, `email` проверяет формат и показывает `@`, `number` не даёт набрать буквы. Для `qty` добавлены `min="1"` и стартовое значение.

Заодно добавлен `autocomplete`: браузер подставит имя, телефон и почту, и покупателю не придётся печатать.

Кнопка без `type` внутри формы тоже отправляет её, но запись `type="submit"` показывает намерение.
