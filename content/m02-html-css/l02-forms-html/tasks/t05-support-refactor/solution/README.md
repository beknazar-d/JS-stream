# Разбор

Рефакторинг: пользователь видит ту же форму, но теперь она правильно устроена. Идём по замечаниям.

1. **Подписи.** Текст рядом с полем не связан с ним. Заменили его на `label for` и `id`. Теперь клик по тексту ставит курсор, а скринридер объявляет подпись.
2. **Тип почты.** У `input name="email"` типа не было, браузер считал его `text`. Тип `email` добавил проверку формата, нужную клавиатуру и `autocomplete`.
3. **Тема обращения.** Три радиокнопки образуют группу с общим вопросом. Для группы подходит `fieldset` с `legend`. Каждая кнопка получила свой `label`.
4. **Согласие.** Чекбокс получил `label` и `required`: без согласия форма не отправится.
5. **Кнопка.** `input type="button"` — просто кнопка, формы она не отправляет. Нужен `button type="submit"`.
6. **Не тронуто.** Все `name` и `value` на месте: это контракт с сервером. Рефакторинг меняет устройство, а не поведение.

`placeholder` оставлен как пример ввода и подписью не служит.
