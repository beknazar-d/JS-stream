# Разбор

**Группы.** Форма разбита на пять `fieldset`. Выбор времени приезда вложен в «Что устанавливаем», потому что это часть заказа. Вложенные группы допустимы, скринридер объявит обе легенды.

**Типы.** Телефон — `tel`, почта — `email`, количество — `number`, дата — `date`. Дата в формате «завтра» теперь невозможна: браузер показывает календарь.

**Ограничения HTML вместо скриптов.**

- `min="1" max="5"` на количестве: значения `0` и `6` дают ошибку `rangeUnderflow` и `rangeOverflow`.
- `pattern="[0-9]{6}"` на индексе: ровно шесть цифр. Шаблон проверяется целиком, поэтому `12345a` и `1234567` не проходят. `inputmode="numeric"` вызывает цифровую клавиатуру, `type` при этом остаётся `text`, чтобы не терять ведущие нули.
- `maxlength="500"` на комментарии.

**Список.** Первый `option` с пустым значением в обязательном `select` — незаполненное поле. Модели сгруппированы через `optgroup`.

**Радиокнопки.** `required` достаточно поставить хотя бы на одну кнопку в группе с одним `name`: браузер потребует выбрать любую из них. Ни одна не отмечена заранее, чтобы выбор был осознанным.

**Автозаполнение.** Токены `name`, `tel`, `email`, `address-level2` (город), `street-address`, `postal-code` — из стандартного списка. Браузер подставит сохранённые данные в одно касание.
