## Контекст

Тикет SHOP-260. «Домотека» запускает услугу «Установка кондиционера». Нужна форма заявки. Менеджеры жалуются на прошлые формы: люди вводили индекс из пяти цифр, заказывали «0 блоков» и «50 блоков», ставили дату в формате «завтра». Каждую заявку приходилось уточнять по телефону.

Вёрстку делает другой разработчик, вам нужна структурно правильная форма: с правильными типами, подписями, ограничениями и подсказками для автозаполнения.

## Цель

Соберите форму `form.install` в `index.html`.

**Контакты** (`fieldset`, `legend` «Контакты»):

- «ФИО» (`name="fullname"`, `text`, обязательное, `autocomplete="name"`);
- «Телефон» (`name="phone"`, `tel`, обязательное, `autocomplete="tel"`);
- «Email» (`name="email"`, `email`, необязательное, `autocomplete="email"`).

**Заказ** (`fieldset`, `legend` «Что устанавливаем»):

- «Модель» (`select`, `name="model"`, обязательный). Первый пункт «Выберите модель» с пустым значением. Дальше две группы `optgroup`: «Настенные» (пункты «Midea MSAG-09», значение `msag09`, и «Haier AS09», значение `as09`) и «Напольные» (пункт «Ballu BFL-18», значение `bfl18`);
- «Количество блоков» (`name="units"`, `number`, обязательное, от 1 до 5 включительно, шаг 1, по умолчанию 1);
- «Дата монтажа» (`name="date"`, `date`, обязательное);
- «Время приезда»: группа переключателей `name="slot"` внутри `fieldset` с `legend` «Время приезда»: «Утром» (`morning`), «Днём» (`day`), «Вечером» (`evening`). Выбор обязателен, по умолчанию не выбран.

**Адрес** (`fieldset`, `legend` «Адрес»):

- «Город» (`name="city"`, `text`, обязательное, `autocomplete="address-level2"`);
- «Улица и дом» (`name="street"`, `text`, обязательное, `autocomplete="street-address"`);
- «Индекс» (`name="zip"`, `text`, обязательное, `autocomplete="postal-code"`, ровно шесть цифр, `inputmode="numeric"`).

**Дополнительно** (`fieldset`, `legend` «Дополнительно»):

- «Комментарий» (`textarea`, `name="comment"`, до 500 символов);
- чекбокс «Согласен на обработку данных» (`name="agree"`, обязательный);

В конце формы кнопка «Отправить заявку» (`type="submit"`).

## Критерии приёмки

- Пять `fieldset` с `legend`: «Контакты», «Что устанавливаем», «Время приезда» (вложен в «Что устанавливаем»), «Адрес» и «Дополнительно» (комментарий и согласие).
- У каждого поля, списка, чекбокса и каждого переключателя есть видимая подпись `label`.
- Пустая форма не проходит проверку браузера. После правильного заполнения проходит.
- Количество блоков: `0` и `6` не проходят проверку, `1` и `5` проходят.
- Индекс: `12345` и `12345a` не проходят, `123456` проходит.
- Выбор времени приезда обязателен.
- Атрибуты `name`, `value` и `autocomplete` — как в описании.

## Ограничения

- Не используйте `placeholder` вместо подписи.
- Ограничения нужно задать атрибутами HTML. Скриптов не пишите.
