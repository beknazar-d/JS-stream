## Контекст

Тикет SHOP-205. Маркетинг просит добавить на главную «Домотеки» форму подписки на акции: одно поле для почты и кнопка. Форма короткая, поэтому её хорошо набрать по памяти.

## Цель

Впишите в `index.html` форму подписки.

## Критерии приёмки

- Тег `form` с `action="/subscribe"` и `method="post"`.
- Поле почты: `input` с типом `email`, `name="email"`, `id="email"`. Оно обязательное (`required`) и подсказывает браузеру, что это почта (`autocomplete="email"`).
- Над полем видимая подпись `label` с текстом «Ваш email», связанная с полем через `for` и `id`.
- Кнопка отправки «Подписаться» — тег `button` с типом `submit`.
- Пустое поле не проходит проверку браузера, адрес вида `a@b.ru` проходит, строка `abc` не проходит.

## Ограничения

- Не используйте `placeholder` вместо подписи. Можно добавить его как пример ввода, но подпись всё равно нужна.
- Стили писать не нужно.
