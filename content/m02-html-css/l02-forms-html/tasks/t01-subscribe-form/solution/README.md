# Разбор

Минимальная форма из четырёх частей: `form`, `label`, `input`, `button`.

- `label for="email"` и `input id="email"` связаны одинаковым значением. Теперь клик по подписи ставит курсор в поле, а скринридер читает «Ваш email, поле ввода».
- `type="email"` включает в браузере проверку формата и показывает мобильную клавиатуру с `@`. Проверка простая: она ловит `abc`, но не знает, существует ли ящик.
- `required` запрещает отправить пустое поле.
- `autocomplete="email"` позволяет браузеру подставить сохранённый адрес.
- `button type="submit"` — отправка формы. Тип `submit` у кнопки внутри формы стоит по умолчанию, но явная запись читается лучше.
- `name="email"` — имя, под которым значение уйдёт на сервер. Поле без `name` в форму не попадает.
