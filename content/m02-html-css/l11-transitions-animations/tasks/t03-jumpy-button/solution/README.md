# Разбор

Причин две.

1. **Раскладка в `:hover`.** `width` и `margin-top` — свойства, которые влияют на положение соседей. Когда они меняются, браузер заново считает геометрию страницы (reflow). Подсказка под кнопкой смещается, а на слабом телефоне такой пересчёт на каждый кадр заметно тормозит.
2. **`transition: all`.** Он анимирует всё, что изменится. Явный список честнее и безопаснее.

Решение: заменить размеры и отступы на `transform`. Функции `translateY(-4px)` и `scale(1.05)` меняют только то, как элемент рисуется. Его место в потоке остаётся прежним, поэтому соседи не двигаются. Браузер обычно может провести такую анимацию отдельным слоем (в композиторе), без пересчёта раскладки.

Дёшево анимировать два свойства: `transform` и `opacity`. Цвет фона тоже допустим для небольших элементов (он требует перерисовки, но не пересчёта раскладки). Размеры, отступы и положение (`left`, `top`) дорогие.
