# Разбор

Две задачи.

**1. Подпрыг счётчика.** `@keyframes bump` меняет только `transform: scale(...)`: 1 → 1.3 → 1. `.cart-count` подключает его строкой `animation: bump 0.5s ease-in-out 2`. Последняя цифра — число повторов. Бесконечные анимации у значка корзины отвлекают от чтения страницы, два подпрыга достаточно.

**2. Режим «уменьшить движение».** Условие `prefers-reduced-motion: reduce` истинно, когда человек включил настройку в системе. Внутри блока выключаем то, что движется:

- `animation: none` для карточек и счётчика;
- `transition: none` для кнопок.

Три правила:

- Блок пишут **в конце файла**. У правил внутри `@media` специфичность та же, что у основных. Побеждает то, что ниже.
- Анимацию **не убирают у всех**. У большинства людей настройка выключена, и им плавность помогает.
- Содержимое должно остаться видимым. У карточек в `fade-up` начальный кадр прозрачный, но при `animation: none` кадры не применяются, и карточки видны сразу.

Чего не стоит делать: ставить `animation-play-state: paused`. Анимация остановится на первом кадре, и карточки останутся невидимыми.

Проверка руками: Chrome DevTools → Rendering → «Emulate CSS media feature prefers-reduced-motion» → reduce.
