# Разбор

`left` меняет положение элемента в раскладке: браузер заново рассчитывает геометрию, а потом перерисовывает. `transform` сдвигает уже готовую картинку элемента и не трогает раскладку. Соседние блоки остаются на месте. Поэтому `translateX(-120px)` даёт тот же вид, что `left: -120px`, но дешевле.

Что изменилось:

- `left: -120px` стал `transform: translateX(-120px)`, `left: 0` стал `transform: translateX(0)`. Нужно заменить в обоих кадрах.
- `opacity` остался: прозрачность тоже дешёвая.
- `position: relative` убрали. Он нужен для работы `left`, а для `transform` не нужен.
- Остальные части `animation` (0.6 секунды, `ease-out`, `both`) не менялись.

Проверка после рефакторинга: внешний вид тот же. Если анимация вдруг не запустилась, первым делом сверьте имя в `animation` и в `@keyframes`.
