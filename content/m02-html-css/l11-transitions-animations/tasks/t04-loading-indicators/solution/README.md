# Разбор

Анимация состоит из двух частей.

1. **Кадры.** `@keyframes имя { ... }` описывают, какие значения принимают свойства в опорных точках. `from` и `to` — это 0% и 100%. Между точками браузер считает значения сам.
2. **Подключение.** Свойство `animation` у элемента называет кадры и задаёт время: `animation: spin 1s linear infinite` — имя, длительность, функция плавности, повторы. Без подключения кадры лежат без дела.

**Спиннер.** Поворот на 360 градусов за секунду с `linear`: скорость постоянная. С `ease` скорость меняется внутри каждого оборота.

**Скелетон.** Пульс идёт туда и обратно, поэтому три точки: 100%, 40% в середине и снова 100%. Запись `0%, 100% { ... }` задаёт одинаковые значения для двух точек. Функция `ease-in-out` делает пульс мягким.

**Почему только `transform` и `opacity`.** Браузер умеет обрабатывать эти два свойства без пересчёта раскладки и без перерисовки содержимого. Анимация размеров, отступов и позиции нагружает страницу на каждом кадре.

В тестах мы ставим анимацию на паузу методом `pause()` и выбираем момент через `currentTime`: так можно проверить значение в любой точке времени, не дожидаясь.
