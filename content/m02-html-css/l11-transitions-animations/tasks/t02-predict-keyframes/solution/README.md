# Разбор

**`valueAt`.** Значения между кадрами считаются по прямой.

- 25%: между кадрами 0% и 50%, ровно половина пути от 0 до 1. Результат 0,5.
- 75%: между кадрами 50% и 100%, половина пути от 1 до 0,5. Результат 0,75.
- 100%: последний кадр, значение 0,5.

**`progress`.** Время идёт, но сначала нужно отсидеть задержку.

- 500 мс: до начала ещё 500 мс. Прогресс 0.
- 2000 мс: прошло 1000 мс анимации из 2000 мс. Это 50%.
- 3000 мс: прошло 2000 мс, один полный проход. Начался второй, прогресс снова 0.
- 5000 мс: анимация идёт уже 4000 мс. Столько длятся два прохода, так что анимация закончилась. Модель возвращает 100.
- Последняя строка: на 4000 мс прошло 3000 мс анимации, второй проход, остаток 1000 мс. Прогресс 50%, значение на 50% равно 1.

Так же считает браузер: задержка, повторы и значения между кадрами складываются в один отсчёт времени. Свойство `animation-fill-mode` решает, что показывать до начала и после конца.
