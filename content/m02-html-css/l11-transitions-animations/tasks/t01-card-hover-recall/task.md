## Контекст

Задача WEB-470. Дизайнер хочет, чтобы карточка товара в каталоге «Домотеки» при наведении приподнималась и получала тень. Сейчас она меняется мгновенно, будто мигает.

Приподнимать нужно через `transform`, а не через отступы: тогда соседние блоки не дёргаются, а браузер анимирует движение без пересчёта всей страницы.

## Цель

Допишите `styles.css` по памяти, без подглядывания в конспект.

## Критерии приёмки

- У `.card` объявлен `transition` для двух свойств: `transform` и `box-shadow`. Длительность каждого 0.2 секунды.
- Правило `.card:hover` сдвигает карточку на 4 px вверх через `transform` и добавляет `box-shadow`.
- При наведении подпись `.note` под карточкой остаётся на месте.
- В `transition` не используется значение `all`.

## Ограничения

- Менять только `styles.css`.
- Для движения не используйте `margin`, `top` и `padding`.
- Тест не может навести курсор. Он применяет правила из `.card:hover` к карточке через временный класс, как будто курсор над ней.
