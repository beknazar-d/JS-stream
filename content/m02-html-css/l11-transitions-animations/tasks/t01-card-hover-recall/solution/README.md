# Разбор

`transition` не двигает карточку сам. Он говорит браузеру: «когда значение этого свойства изменится, не прыгай, а плавно дойди за 0,2 секунды». Значение меняет правило `:hover`.

Поэтому два места:

- `.card { transition: transform 0.2s ease, box-shadow 0.2s ease; }` — какие свойства и как долго;
- `.card:hover { transform: translateY(-4px); box-shadow: ...; }` — к чему приходить при наведении.

Переход пишут у исходного состояния, а не у `:hover`. Тогда он работает в обе стороны: когда курсор уходит, карточка так же плавно опускается.

`transform` не двигает соседей и не заставляет браузер заново раскладывать страницу. Если бы карточка поднималась через `margin-top: -4px`, подпись `.note` под ней прыгала бы вверх-вниз.

Запись `transition: all` работает, но анимирует всё подряд. Явный список безопаснее.
