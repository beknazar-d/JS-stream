# Разбор

Причина: `width: 800px` задаёт жёсткую ширину. Экран у́же 800 px, блок вылезает за край.

Исправление из двух строк:

- `max-width: 100%` — ширина фото не больше ширины родителя. На широком экране фото остаётся своего размера 800 px.
- `height: auto` — высота считается по ширине и пропорциям картинки. Без неё атрибут `height="400"` остаётся в силе, и фото на телефоне сжимается только по ширине.

`display: block` убирает лишний зазор под строчной картинкой. Для приёмки он не обязателен, но это привычка.

Почему не `width: 100%`: так фото тянется и на большом экране, а растянутый растр размывается.
