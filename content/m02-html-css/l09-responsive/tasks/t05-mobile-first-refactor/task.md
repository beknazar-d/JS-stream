## Контекст

Код-ревью. Стили главной страницы «Домотеки» написаны «сверху вниз»: сначала макет для компьютера, а в конце блок `@media (max-width: 767px)`, который отменяет почти всё сделанное выше. На телефоне браузер читает правила для компьютера и тут же перебивает их. Тимлид просит переписать так, чтобы базовыми были стили телефона, а запросы добавляли широкую раскладку.

Внешний вид на экранах 375, 767, 768 и 1024 px должен остаться прежним.

## Цель

Перепишите `styles.css` в подходе «сначала телефон» (mobile-first): базовые правила для телефона, дополнения в `@media (min-width: 768px)`.

## Критерии приёмки

- На 375 и 767 px меню идёт в столбик (зазор 8 px), три преимущества стоят в одну колонку.
- На 768 и 1024 px меню в строку (зазор 16 px), три преимущества в одном ряду, зазор между ними 16 px.
- В стилях не осталось медиазапросов с `max-width`.
- Есть медиазапрос с `min-width`.

## Ограничения

- Разметку (`index.html`) менять не нужно.
- Внешний вид кроме раскладки не меняйте: цвета, шрифты, рамки остаются.
