# Разбор

Значения для телефона (`column`, `gap: 8px`, `1fr`) стали базовыми. Всё, что нужно только на широких экранах, лежит в одном блоке `@media (min-width: 768px)` в конце файла.

Граница сохранена: старый запрос `max-width: 767px` и новый `min-width: 768px` делят оси ровно на 767 и 768. Ни одна ширина не осталась без правила и не попала под оба.

Порядок важен. У базовых правил и правил из запроса одинаковая специфичность (один класс). Поэтому запрос должен стоять после базовых правил, иначе базовые победят.

Выигрыш: на телефоне браузер читает правила один раз и ничего не отменяет.
