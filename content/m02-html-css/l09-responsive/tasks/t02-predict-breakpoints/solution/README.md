# Разбор

Заголовок: предпочтительное значение `8 + 3vw`.

- 320 px: `8 + 9,6 = 17,6`. Это меньше минимума 20, поэтому результат 20.
- 600 px: `8 + 18 = 26`. Внутри границ, результат 26.
- 1200 px: `8 + 36 = 44`. Больше максимума 32, поэтому 32.

Колонки: подход «сначала телефон». Результат 1, потом условия перезаписывают его.

- 375 px и 767 px: ни одно условие не выполнено, остаётся 1.
- 768 px: выполнено `>= 768`, получаем 2 (граница включена).
- 1024 px: выполнены оба условия, последнее даёт 3.

Это та же логика, что у каскада CSS: правило, которое подошло позже, побеждает.
