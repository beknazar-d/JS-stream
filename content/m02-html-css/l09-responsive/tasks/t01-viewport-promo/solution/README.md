# Разбор

Две вещи, которые нужны каждой адаптивной странице.

1. `<meta name="viewport" content="width=device-width, initial-scale=1">`. Без него мобильный браузер считает окно шириной около 980 px и сжимает страницу, а медиазапросы работают на «виртуальной» ширине. С ним ширина окна равна ширине экрана.
2. `@media (min-width: 768px) { ... }`. Базовые стили написаны для телефона, а запрос добавляет изменения для широких экранов. `min-width: 768px` включает ширину 768 px.

Подход «сначала телефон» (mobile-first) удобен тем, что у телефона самый простой макет и меньше всего правил. Запросы только добавляют, а не отменяют.
