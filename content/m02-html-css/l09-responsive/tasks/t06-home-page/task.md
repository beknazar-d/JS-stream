## Контекст

Задача WEB-340: адаптивная главная страница «Домотеки». Дизайнер прислал макет для двух экранов, телефона (375 px) и компьютера (1024 px и шире). Заказчик сказал: «Планшеты и большие мониторы должны выглядеть нормально без отдельных макетов».

В `styles.css` лежат только базовые стили карточек и сброс. В `index.html` пока нет метатега `viewport`, а контент не ограничен по ширине.

## Цель

Сделайте страницу адаптивной по макету. Работайте от телефона к широким экранам.

## Критерии приёмки

- В `head` есть метатег `viewport` (`width=device-width, initial-scale=1`).
- Страница не прокручивается вбок на ширинах 375, 768, 1024 и 1440 px.
- Контент (класс `.page`) не шире 960 px и стоит по центру. Отступы от краёв по 16 px.
- Заголовок `.hero__title`: 24 px на телефоне, 40 px на 1024 px и шире, на 768 px между 32 и 38 px. Размер растёт плавно, без скачков.
- Картинка `.hero__image` занимает ширину контента, сохраняет пропорции 2 к 1 и не растягивается шире своего размера.
- Шапка: на телефоне логотип, меню и корзина друг под другом; от 768 px в одну строку, корзина у правого отступа.
- Товары: по два в ряду на телефоне (зазор 12 px), по четыре в ряду от 768 px (зазор 16 px).

## Ограничения

- Менять `index.html` можно только для метатега. Остальная разметка остаётся.
- Контрольные точки только через `min-width`. Размер заголовка без медиазапросов.
