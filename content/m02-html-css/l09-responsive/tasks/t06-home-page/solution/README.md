# Разбор

Порядок работы: сначала метатег, потом база для телефона, потом одна точка 768 px.

- **Контент.** `.page { max-width: 960px; margin: 0 auto; padding: 0 16px }`. На 1440 px он сжимается до колонки по центру, на телефоне занимает всё доступное место.
- **Заголовок.** `clamp(1.5rem, 0.75rem + 3vw, 2.5rem)`: нижняя граница 24 px, верхняя 40 px, посередине 12 px плюс 3% ширины окна. На 768 px это около 35 px, а упирается в потолок примерно с 933 px. Медиазапросы тут не нужны: размер меняется плавно.
- **Картинка.** `max-width: 100%` не даёт ей выйти за контейнер, `height: auto` сохраняет пропорции. Атрибуты `width` и `height` в разметке остаются: по ним браузер резервирует место до загрузки.
- **Шапка.** Телефон: flex-столбец с зазором 8 px. С 768 px: строка, `justify-content: space-between` разносит логотип, меню и корзину.
- **Товары.** Две колонки по умолчанию, четыре с 768 px. Единица `fr` сама делит ширину.

Всего один медиазапрос, потому что макет менялся в одном месте. Контрольную точку выбирают по контенту: 768 px взяты потому, что на этой ширине четыре карточки ещё читаются.
