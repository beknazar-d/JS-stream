# Разбор

Базовые стили описывают телефон: список становится сеткой с одной колонкой (`1fr`) и зазором 16 px. Отступ 16 px от края даёт `padding` самого списка.

Дальше два медиазапроса `min-width`. Они меняют только число колонок: `repeat(2, 1fr)` от 768 px и `repeat(4, 1fr)` от 1024 px. Зазор и отступы остаются от базовых стилей, их не нужно повторять.

Блоки идут по возрастанию ширины. Так при ширине 1024 px подходят оба запроса, и побеждает последний, потому что правила одинаковой специфичности решает порядок.

Единица `fr` делит свободное место поровну, поэтому ширину карточек не нужно считать самому. Контрольные точки 768 и 1024 взяты из макета. Это не «ширины устройств», а места, где макет начинает смотреться хуже: об этом подробнее в уроке.
