## Зачем это в работе

Тикет от поддержки «Домотеки»: «Покупатель открыл каталог с телефона. Карточки торчат за правый край, кнопка „В корзину“ не видна, страницу приходится двигать пальцем вбок».

На компьютере всё в порядке. Но большинство покупателей заходит с телефона, и для них страница сломана. Разработчик, который делает макет только под свой монитор, получает такие тикеты каждую неделю.

В этом уроке вы научитесь делать так, чтобы одна страница работала на экранах от 320 px до больших мониторов. Это называется адаптивная вёрстка (responsive design).

## Объяснение

Страница в браузере похожа на воду: она принимает форму сосуда. Окно узкое, страница узкая. Окно широкое, страница широкая. Задача верстальщика — решить, как именно вода перераспределится, когда сосуд меняет форму.

Три инструмента.

**1. Метатег viewport.** Область просмотра (viewport) — это видимая часть страницы. Телефон по умолчанию «делает вид», что экран шире, примерно 980 px, и уменьшает страницу. Метатег отключает эту хитрость:

```html
<meta name="viewport" content="width=device-width, initial-scale=1">
```

**2. Медиазапрос (media query).** Это условие для блока стилей. Блок применяется, только если условие верно:

```css
@media (min-width: 768px) {
  .catalog { grid-template-columns: repeat(2, 1fr); }
}
```

Читается так: «если окно не меньше 768 px, применить эти правила». Число, где условие меняется, называется контрольной точкой (breakpoint).

**3. Гибкие значения.** Картинки и размеры шрифта подстраиваются плавно, без скачков: `max-width: 100%` и функция `clamp()`.

Главный приём называется «сначала телефон» (mobile-first). Базовые стили пишутся для самого узкого экрана. Они простые: одна колонка, ничего лишнего. Затем запросы `min-width` добавляют правила для экранов пошире. Слой лежит на слое, как на схеме ниже.

## Пример

Запустите модель: сколько колонок будет на каких ширинах. Измените массив контрольных точек и посмотрите, как меняется результат.

<Playground example="breakpoints" />

Теперь то же самое в CSS. Базовые стили описывают телефон, а запросы добавляют колонки:

```css
.catalog {
  display: grid;
  gap: 16px;
  grid-template-columns: 1fr;
}

@media (min-width: 768px) {
  .catalog { grid-template-columns: repeat(2, 1fr); }
}

@media (min-width: 1024px) {
  .catalog { grid-template-columns: repeat(4, 1fr); }
}
```

На 375 px сработал только базовый блок. На 768 px — базовый и первый запрос. На 1024 px — все три. Поэтому порядок такой: от меньшего к большему, и запросы идут после базовых правил.

Сравните два подхода.

<Wrong>

```css
/* сверху вниз: сначала компьютер, потом отмены */
.catalog { grid-template-columns: repeat(4, 1fr); }

@media (max-width: 1023px) {
  .catalog { grid-template-columns: repeat(2, 1fr); }
}

@media (max-width: 767px) {
  .catalog { grid-template-columns: 1fr; }
}
```

</Wrong>

<Right>

```css
/* сначала телефон, потом дополнения */
.catalog { grid-template-columns: 1fr; }

@media (min-width: 768px) {
  .catalog { grid-template-columns: repeat(2, 1fr); }
}

@media (min-width: 1024px) {
  .catalog { grid-template-columns: repeat(4, 1fr); }
}
```

</Right>

Результат одинаковый. Но слева на телефоне браузер читает правила для компьютера и тут же отменяет их. Справа телефон получает только то, что ему нужно.

## Как это работает

<Figure src="min-width-layers.svg" alt="Горизонтальная ось ширины окна от 0 до 1440 пикселей. Первая полоса — базовые стили на всей оси. Вторая полоса начинается на отметке 768 и тянется вправо: две колонки. Третья начинается на отметке 1024: четыре колонки. На отметке 1024 действуют все три слоя, и побеждает верхний." caption="Слои min-width. Чем шире окно, тем больше слоёв включено. Верхний подходящий слой побеждает." />

Из схемы следуют правила.

1. **Выбирайте точки по контенту, а не по устройствам.** Модели телефонов меняются каждый год. Расширяйте окно в режиме адаптивного просмотра DevTools. Когда макет начинает выглядеть плохо, поставьте точку. Значения 768 и 1024 в курсе — отправная точка, а не закон.
2. **Запрос пишут с единицей.** `(min-width: 768px)`, а не `(min-width: 768)`. Без единицы условие недействительно и не сработает никогда. Мы проверили это в Chromium: правило внутри такого запроса не применилось даже при ширине 1024 px.
3. **Размер шрифта плавно.** Функция `clamp(минимум, предпочтительное, максимум)` выбирает среднее по величине из трёх значений. Например, `clamp(1rem, 0.5rem + 2vw, 1.75rem)`: на узком экране 1rem, на широком 1.75rem, посередине растёт вместе с окном. Единица `vw` — это 1% ширины окна. В предпочтительное значение добавляйте `rem`: размер, заданный только в `vw`, не меняется, когда человек увеличивает масштаб в настройках браузера.

<Playground example="clamp-model" />

4. **Картинка не шире родителя.** `max-width: 100%` не даёт ей вылезти за край, `height: auto` сохраняет пропорции. Атрибуты `width` и `height` в разметке оставьте: по ним браузер резервирует место до загрузки.

```html
<img src="kettle-800.jpg" alt="Чайник Domo K-17" width="800" height="400">
```

```css
img { max-width: 100%; height: auto; }
```

5. **Несколько файлов для одной картинки.** Атрибут `srcset` перечисляет файлы с их шириной в пикселях. Браузер сам выбирает подходящий по размеру места и плотности экрана:

```html
<img
  src="kettle-800.jpg"
  srcset="kettle-400.jpg 400w, kettle-800.jpg 800w, kettle-1200.jpg 1200w"
  sizes="(min-width: 1024px) 25vw, 50vw"
  alt="Чайник Domo K-17"
  width="800" height="400">
```

Атрибут `sizes` сообщает, сколько места займёт картинка на экране. Без него браузер считает, что на всю ширину окна. Это только введение: так телефон не скачивает тяжёлый файл для компьютера.

<Playground example="srcset-pick" />

<Note>

Горизонтальная прокрутка на телефоне — почти всегда следствие элемента, который шире экрана: картинка, таблица, длинное слово или блок с `width` в пикселях. Откройте DevTools, включите эмуляцию 375 px и найдите элемент, у которого правый край дальше окна.

</Note>

## Типичные ошибки

У CSS нет «ошибок в консоли»: браузер молча пропускает то, чего не понял. Поэтому все четыре ошибки ниже мы проверили запуском в Chromium и записали, что он показал на самом деле.

**1. Нет метатега viewport.** На эмуляции телефона шириной 375 px (при вставленном метатеге) окно равно 375 px. Без метатега ширина окна равна 980 px, и все ваши запросы `max-width: 600px` не срабатывают. Страница выглядит как уменьшенная копия компьютерной.

<Wrong>

```html
<head>
  <meta charset="utf-8">
  <title>Домотека</title>
</head>
```

</Wrong>

<Right>

```html
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Домотека</title>
</head>
```

</Right>

**2. Запрос без единицы.** Условие `(min-width: 768)` не равно ни одной ширине. Chromium оставил красный цвет, хотя окно было 1024 px, а `matchMedia` вернул `false`. Ошибки в консоли нет.

<Wrong>

```css
@media (min-width: 768) {
  .promo { display: block; }
}
```

</Wrong>

<Right>

```css
@media (min-width: 768px) {
  .promo { display: block; }
}
```

</Right>

**3. Запрос выше базовых правил.** Правила одинаковой специфичности решает порядок. Если блок `@media` стоит выше, то базовое правило ниже перебивает его. В задании этого урока именно так «ломается» раскладка на компьютере.

<Wrong>

```css
@media (min-width: 768px) {
  .nav { flex-direction: row; }
}

.nav { flex-direction: column; }
```

</Wrong>

<Right>

```css
.nav { flex-direction: column; }

@media (min-width: 768px) {
  .nav { flex-direction: row; }
}
```

</Right>

**4. Картинка с `max-width: 100%`, но без `height: auto`.** Ширина ограничена, а атрибут `height="400"` остался. Фото на телефоне сплющено по ширине, но высокое.

<Wrong>

```css
img { max-width: 100%; }
```

</Wrong>

<Right>

```css
img { max-width: 100%; height: auto; }
```

</Right>

## Итог

Что вы теперь умеете:

- включать метатег viewport и объяснять, зачем он нужен;
- писать страницу «сначала телефон» и добавлять правила через `@media (min-width: ...)`;
- выбирать контрольные точки по контенту;
- делать размер шрифта плавным через `clamp()`;
- не давать картинкам вылезать за экран и подсказывать браузеру нужный файл через `srcset`.

Адаптивность — это не только размеры. Тема, которую выбрал человек, тоже должна работать на любой странице. В следующем уроке вы вынесете цвета и отступы в переменные CSS и сделаете тёмную тему одним переключателем.
