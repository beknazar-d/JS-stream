# Разбор

Причина в том, что `em` считается от размера шрифта родителя. Первый `li` получает `0.875 × 16 = 14px`. Второй `li` вложен в первый, поэтому берёт `0.875 × 14 = 12.25px`. Третий — `0.875 × 12.25 = 10.7px`.

Исправление: заменить `em` на `rem`. Он всегда считается от корня, и вложенность ничего не меняет. Все три уровня получают 14px.

Есть и второй способ: оставить `em` только на первом уровне, а у вложенных написать `font-size: 1em`. Но тогда придётся помнить об особом правиле. Единица, которая не зависит от места в дереве, надёжнее.
