## Контекст

В каталоге «Домотеки» меню категорий состоит из трёх уровней: раздел, подраздел, товарная группа. Дизайнер заложил один размер для всех пунктов: 14px. На странице же третий уровень еле виден. Покупатели жалуются, что не могут прочитать «Двухкамерные».

## Цель

Исправьте `styles.css` так, чтобы пункты всех трёх уровней имели одинаковый размер шрифта, равный `0.875rem`.

## Критерии приёмки

- Пункты первого, второго и третьего уровня имеют размер 14px при корне 16px.
- Размер зависит от настройки браузера: при корне 20px все три уровня получают 17.5px.
- Разметку менять не нужно.

## Ограничения

- Не меняйте `index.html`.
- Не задавайте размер шрифта у `html`.
