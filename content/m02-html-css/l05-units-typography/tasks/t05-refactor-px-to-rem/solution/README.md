# Разбор

Правило перевода: пиксели делим на 16.

- Шрифт, отступы и ширина карточки должны расти вместе с текстом, поэтому они в `rem`: `24px` → `1.5rem`, `20px` → `1.25rem`, `320px` → `20rem`, `12px` → `0.75rem`.
- Рамка `1px` остаётся в пикселях. Тонкая линия, которая растёт, выглядит грубо.
- Межстрочье переводим в число: `30px / 24px = 1.25`, `24px / 16px = 1.5`. Тогда оно умножается на размер шрифта своего элемента.
- Радиусы скругления оставлены в пикселях: они маленькие и тоже могут оставаться неизменными.

После правок внешний вид при 16px не изменился, а при увеличенном корне карточка вырастает целиком, как картинка.

Проверьте вручную: поставьте `html { font-size: 125% }` временно в DevTools и посмотрите на карточку. Потом уберите.
