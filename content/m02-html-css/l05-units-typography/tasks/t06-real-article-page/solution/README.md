# Разбор

1. **База.** На `body` задан стек шрифтов и `line-height: 1.6` числом. Все потомки умножают его на свой размер.
2. **Первый экран.** `min-height: 40vh` берёт высоту от окна, а не от родителя. Внутри `.hero` включён `display: flex` с `align-items: center`, поэтому `h1` встал посередине по вертикали. Мы использовали `min-height`, а не `height`: если заголовок вырастет, блок вырастет вместе с ним.
3. **Колонка.** `max-width: 65ch` у `.article` ограничивает всю колонку, `margin: 0 auto` ставит её по центру. Колонка уже окна, поэтому поля по бокам задаёт `padding` в `rem`: на 375px колонка занимает ширину окна минус отступы.
4. **Размеры.** Все шрифты в `rem`: при увеличенном шрифте браузера страница вырастает целиком.
5. **Цитата.** Левая рамка и отступ выделяют цитату без лишних элементов.

Проверка при корне 20px: `ch` измеряется в шрифте элемента, поэтому колонка вырастает вместе с текстом, а число символов в строке остаётся тем же.
