## Контекст

Сайт «Домотеки» выглядит по-разному в разных браузерах: у одних крупные буквы, у других мелкие, межстрочье слипается. Нужна общая база типографики, которую подключают на все страницы. Набирайте её по памяти, без шпаргалки.

## Цель

Допишите `styles.css` для страницы с карточкой чайника: задайте шрифт, межстрочное расстояние и размеры текста.

## Критерии приёмки

- У `body` задан `font-family`: стек не меньше чем из трёх шрифтов, последний — `sans-serif`.
- У `body` задан `line-height: 1.5` числом без единиц: у основного текста при шрифте 16px получается 24px, а при другом размере шрифта значение пересчитывается.
- Заголовок `h1` — `2rem` (32px), `.lead` — `1.25rem` (20px), `.text` — `1rem` (16px), `.note` — `0.875rem` (14px).
- Размеры растут вместе с размером шрифта в браузере: при корне 20px заголовок получает 40px.

## Ограничения

- Не меняйте `index.html`.
- Не задавайте размер шрифта у `html`: пользовательская настройка не должна сбрасываться.
- Все размеры шрифта — в `rem`.
