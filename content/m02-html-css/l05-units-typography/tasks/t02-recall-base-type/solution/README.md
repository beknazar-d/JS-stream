# Разбор

Всего три идеи.

1. Стек шрифтов `system-ui, "Segoe UI", Arial, sans-serif`: браузер берёт первый доступный, а `sans-serif` гарантирует, что текст не окажется шрифтом с засечками.
2. `line-height: 1.5` без единиц. Каждый элемент умножает 1.5 на свой размер шрифта: основной текст получает 24px, а `.lead` — 30px.
3. Размеры в `rem`. Корень остаётся 16px, поэтому `2rem` — это 32px, а при увеличенном шрифте браузера всё растёт вместе.

Обратите внимание: шрифт и межстрочье задаются один раз на `body` и наследуются. Размеры задаются у тех элементов, у которых они отличаются.
