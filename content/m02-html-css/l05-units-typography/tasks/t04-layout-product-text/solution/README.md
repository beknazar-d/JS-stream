# Разбор

1. Шрифт и межстрочье задаются на `body`: `line-height: 1.6` числом. Все абзацы умножат его на свой размер.
2. Размеры у `h1`, `.price`, `.lead`, `.text` записаны в `rem`.
3. Колонка `.product`: `max-width: 48rem` ограничивает ширину, `margin: 0 auto` центрирует блок, `padding` по бокам даёт воздух на узком экране. Пока окно уже 48rem, колонка занимает ширину окна минус поля.
4. Строка текста ограничена в `ch`: `max-width: 65ch` у `.text`. При шрифте 16px это около 520px и около 65 символов. При корне 20px `ch` тоже вырастает, и число символов остаётся тем же.

Почему не `width: 520px`? Число символов в строке зависит от шрифта. `ch` переводит «сколько символов» в ширину именно для вашего шрифта.
