# Разбор

1. `24 / 16` — `1.5`.
2. `14 / 16` — `0.875`.
3. `40 / 16` — `2.5`, в шаблонной строке добавляется `rem`: `2.5rem`.
4. `"20px" / 16` — из строки с единицей число не получается, это `NaN`.
5. `Number.parseFloat("20px")` читает число из начала строки: `20`. `20 / 16` — `1.25`.
6. Вложенные блоки с `em`: `16 × 1.5 = 24`, затем `24 × 1.5 = 36`.
7. `rem` всегда считается от корня: `1.5 × 16 = 24`.
8. `520 / 8 = 65` символов. Это середина удобного диапазона 60–75.
