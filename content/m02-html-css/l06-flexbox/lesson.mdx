## Зачем это в работе

Шапка «Домотеки»: логотип слева, меню посередине, корзина справа. Всё должно стоять в одну линию и выровняться по высоте. Раньше такое делали через `float` и `inline-block`, с хитрыми отступами. Сегодня это три строки Flexbox.

Ещё задача. В каталоге три карточки в ряд, и описания у них разной длины. Кнопки «В корзину» стоят на разной высоте и выглядят неряшливо. Менеджер просит: пусть все кнопки лежат на одной линии внизу карточек.

Flexbox (flexible box, «гибкий контейнер») решает обе задачи. Он выстраивает элементы в ряд или колонку, делит свободное место и выравнивает их. В этом уроке разберём основные свойства и одну ловушку с `order`.

## Объяснение

Включите `display: flex` у родителя, и его прямые потомки станут гибкими элементами (flex items). Родитель называется контейнером (flex container).

В контейнере всегда две оси:

- главная ось (main axis) — направление, в котором идут элементы. По умолчанию слева направо;
- поперечная ось (cross axis) — перпендикулярная ей.

Направление главной оси задаёт `flex-direction`: `row` (по умолчанию) или `column`. Если выбрать `column`, оси меняются местами: главная идёт сверху вниз, поперечная слева направо.

Основные свойства контейнера:

- `justify-content` — как расположить элементы вдоль главной оси: `flex-start`, `center`, `flex-end`, `space-between`, `space-around`;
- `align-items` — как расположить элементы поперёк: `stretch` (по умолчанию), `center`, `flex-start`, `flex-end`;
- `gap` — расстояние между элементами;
- `flex-wrap: wrap` — разрешает переносить элементы на новую строку.

Свойства самого элемента:

- `flex: 1` — взять свою долю свободного места;
- `flex-shrink: 0` — не сжиматься;
- `margin-top: auto` — прижаться вниз, забрав всё свободное место сверху;
- `order` — поменять порядок показа. О нём ниже.

Аналогия: полка и книги. Полка — это контейнер. Книги выстраиваются вдоль неё (главная ось). `justify-content` решает, где они стоят вдоль полки: слева, по центру, с промежутками. `align-items` решает, как они стоят по высоте: прижатые к нижней доске или по центру.

## Пример

Шапка сайта целиком.

```html
<header class="site-header">
  <a class="logo" href="/">Домотека</a>
  <nav>
    <ul class="nav">
      <li><a href="/catalog">Каталог</a></li>
      <li><a href="/delivery">Доставка</a></li>
    </ul>
  </nav>
  <a class="cart" href="/cart">Корзина</a>
</header>
```

```css
.site-header {
  display: flex;
  justify-content: space-between;
  align-items: center;
}

.nav {
  display: flex;
  gap: 24px;
  list-style: none;
}
```

Контейнер `.site-header` расставляет три элемента вдоль главной оси так, что свободное место делится между ними: логотип слева, корзина справа. `align-items: center` ставит всех посередине по высоте. Вложенный `.nav` — тоже контейнер, но для пунктов меню.

Сравните два способа оформить промежуток между пунктами.

<Wrong>

```css
.nav li {
  margin-left: 24px; /* у первого пункта тоже есть лишний отступ */
}
```

</Wrong>

<Right>

```css
.nav {
  display: flex;
  gap: 24px; /* промежуток только между пунктами */
}
```

</Right>

## Как это работает

Схема показывает оси для двух направлений.

<Figure src="flex-axes.svg" alt="Две схемы контейнера с тремя блоками. Слева flex-direction row: главная ось идёт слева направо, поперечная сверху вниз; justify-content двигает блоки вдоль главной оси, align-items вдоль поперечной. Справа flex-direction column: главная ось идёт сверху вниз, поперечная слева направо, поэтому justify-content теперь отвечает за вертикаль, а align-items за горизонталь." caption="Оси меняются местами при flex-direction: column. Тогда justify-content работает по вертикали." />

Правила, которые стоит запомнить.

1. **Оси зависят от `flex-direction`.** `justify-content` всегда про главную ось, `align-items` — про поперечную. В колонке главная ось вертикальна.
2. **`flex: 1` — это три свойства сразу.** Короткая запись `flex: 1` означает `flex-grow: 1`, `flex-shrink: 1`, `flex-basis: 0%`. Элемент начинает с нуля и берёт равную долю свободного места. Поэтому три карточки с `flex: 1` получаются одной ширины, как бы ни был длинен их текст.
3. **`flex: auto` — другое.** Здесь начальная ширина берётся из содержимого, и карточки с длинным текстом получаются шире.
4. **Элементы сжимаются сами.** Если в строке не хватает места, по умолчанию все элементы уменьшаются (`flex-shrink: 1`). Кнопке это обычно не нужно: пишите `flex-shrink: 0`.
5. **`margin-top: auto` прижимает вниз.** В колонке автоматический отступ забирает всё свободное место. Так делают кнопки внизу карточек.

Теперь про `order`. Свойство меняет порядок показа, но не меняет порядок в разметке. Экранный диктор и клавиша Tab идут по порядку в HTML. Если на экране кнопка стоит первой, а в разметке последней, человек с клавиатурой попадёт на неё в последнюю очередь. Это нарушает требования доступности WCAG: порядок фокуса должен соответствовать видимому порядку.

<Wrong>

```html
<div class="item">
  <button class="btn">Купить</button>
  <a class="title" href="/p/1">Чайник</a>
</div>
```

```css
.item { display: flex; }
.title { order: 1; } /* на экране название раньше кнопки */
```

</Wrong>

<Right>

```html
<div class="item">
  <a class="title" href="/p/1">Чайник</a>
  <button class="btn">Купить</button>
</div>
```

```css
.item { display: flex; }
```

</Right>

Если порядок на экране нужно поменять, меняйте разметку. `order` годится для редких случаев, где порядок в HTML и так логичен, а на экране мелкая правка.

<Note>

В DevTools Chrome и Firefox рядом с элементом-контейнером есть значок flex. Нажмите на него: браузер нарисует оси, свободное место и промежутки поверх страницы.

</Note>

## Типичные ошибки

В CSS нет сообщений в консоли. Вот что бывает на практике.

**1. Забыли `display: flex` у родителя.** Остальные свойства (`justify-content`, `gap`) молча не работают. Это самая частая ошибка: проверяйте, что стили стоят на контейнере.

**2. Перепутали оси.** После `flex-direction: column` вместо `justify-content` берут `align-items`, чтобы выровнять по вертикали. Помните: `justify-content` — всегда по главной оси.

**3. Центр по вертикали не работает.** `align-items: center` в контейнере без высоты не даст эффекта: места по высоте больше нет. Нужна высота: `min-height`.

**4. Кнопка сжимается и текст в ней переносится.** У элемента по умолчанию `flex-shrink: 1`. Пишите `flex-shrink: 0` для кнопок и иконок.

**5. Карточки разной ширины.** Записали `flex: auto` или `flex: 1 1 auto`. Ширина берётся из текста. Нужен `flex: 1`.

**6. `order` вместо правки разметки.** На экране всё хорошо, но Tab идёт не по порядку.

В JavaScript аналог ошибки «забыли родителя»: вызов метода у `null` падает с реальным сообщением Node.js 22.

```text
TypeError: Cannot read properties of null (reading 'x')
```

В вёрстке такая ошибка молчит: просто ничего не происходит.

## Итог

Что вы теперь умеете:

- включать `display: flex` и объяснять главную и поперечную оси;
- выравнивать элементы через `justify-content`, `align-items`, `gap`;
- переносить строки через `flex-wrap`, делить место через `flex: 1`;
- прижимать кнопки вниз через `margin-top: auto`;
- не использовать `order` там, где можно поменять разметку.

Flexbox хорош для одной оси: ряд или колонка. Но каталог — это сетка из рядов и колонок сразу. В следующем уроке мы познакомимся с Grid: он раскладывает элементы по двум осям и позволяет описать всю страницу как таблицу областей.
