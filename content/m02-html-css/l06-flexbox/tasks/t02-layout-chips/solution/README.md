# Разбор

Трёх свойств на контейнере достаточно.

- `display: flex` выстраивает `li` в ряд.
- `flex-wrap: wrap` разрешает переносить плитки: когда следующая не помещается, она уходит на новую строку.
- `gap: 8px 12px` — сокращённая запись `row-gap` и `column-gap`: 8px между строками и 12px между плитками.

Текст внутри плиток не переносится благодаря `white-space: nowrap`, который уже есть в заготовке. Без `flex-wrap` элементы сжимались бы (`flex-shrink: 1`), и плитки ломали бы текст.
