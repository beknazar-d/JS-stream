## Контекст

Перед версткой каталога вы проверяете расчёт на скрипте, который повторяет алгоритм Flexbox: делит свободное место по `flex-grow` и делит нехватку по `flex-shrink`. Нужно предсказать размеры в пяти ситуациях: три карточки с `flex: 1`, неравные доли, фиксированные блоки, нехватка места и блок, которому запретили сжиматься.

## Цель

Прочитайте код из `snippet.js`. Запишите в `answer.js` в массив `output` ровно то, что код выведет в консоль, по одной строке на каждый вызов `console.log`.

## Критерии приёмки

- В массиве `output` ровно пять строк в порядке вызовов `console.log`.
- Каждый элемент — строка с размерами через запятую и пробел, например `"100, 200"`.
- Ответ совпадает с реальным выводом построчно.

## Ограничения

- Не меняйте `snippet.js`.
- Сначала предскажите, потом сверяйтесь.
