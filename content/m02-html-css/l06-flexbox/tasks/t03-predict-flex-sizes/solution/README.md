# Разбор

1. `flex: 1` у трёх карточек даёт базу 0 и равные доли: 600 делится на три, `200, 200, 200`.
2. Базы 200 и 100 занимают 300 из 500, свободных 200. Доли grow 1 и 3: первому 50, второму 150. Итог `250, 250`.
3. У всех `grow: 0`: свободные 300px остаются пустыми, размеры не меняются: `100, 100, 100`.
4. Базы 300, 200, 100 дают 600 при контейнере 450. Нехватка 150 делится пропорционально базам (300:200:100): минус 75, 50, 25. Итог `225, 150, 75`.
5. У первого `shrink: 0`, он остаётся 300. Нехватку 150 делят только два других с весами 200 и 100: минус 100 и 50. Итог `300, 100, 50`.
