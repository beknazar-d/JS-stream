# Разбор

Две пары свойств.

1. Шапка: `display: flex` включает Flexbox, `justify-content: space-between` отодвигает крайние элементы к краям (логотип влево, корзина вправо, меню посередине), `align-items: center` ставит всех по центру высоты шапки.
2. Меню: `display: flex` превращает список в ряд, `gap: 24px` ставит промежутки только между пунктами.

Заметьте: `.site-header` управляет тремя своими прямыми детьми, `.nav` — пунктами `li`. Внуки не получают гибкость автоматически.
