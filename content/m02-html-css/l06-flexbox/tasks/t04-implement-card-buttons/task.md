## Контекст

В каталоге «Домотеки» три карточки стоят в ряд. У блендера описание длинное, у чайника короткое. Кнопки «В корзину» оказались на разной высоте: у чайника сразу под ценой, у блендера гораздо ниже. Менеджер просит выровнять их по нижней линии.

## Цель

Допишите `styles.css`: расставьте карточки в ряд одной ширины и прижмите кнопки к низу карточек.

## Критерии приёмки

- Три карточки стоят в один ряд, ширины равны (разница не больше 2px), промежуток между карточками 16px.
- Карточки одной высоты.
- Нижние края кнопок совпадают, а сами кнопки отстоят от нижнего края карточки на её внутренний отступ.
- Если описание сделать очень длинным, кнопки остаются на одной линии и не налезают на цену.
- Если добавить четвёртую карточку с длинным названием, ширины всех четырёх остаются равными.

## Ограничения

- Не меняйте `index.html`.
- Не задавайте карточкам фиксированную высоту.
- Не используйте `position: absolute`.
