# Разбор

Нужно два уровня Flexbox.

1. `.cards { display: flex; gap: 16px; }` ставит карточки в ряд. По умолчанию `align-items: stretch`, поэтому все карточки одной высоты: самая высокая задаёт линию.
2. `.card { flex: 1; }` делит ширину поровну. `flex: 1` означает базу 0, поэтому длинный текст не делает карточку шире.
3. `.card` сама становится колонкой: `display: flex; flex-direction: column`.
4. `.btn { margin-top: auto; }` забирает всё свободное место сверху и прижимает кнопку вниз.

Почему решение не ломается при длинном тексте: высота карточек определяется содержимым, а кнопка всегда идёт после цены, свободного места нет, `margin-top: auto` превращается в ноль.
