## Контекст

Это первая настоящая страница каталога «Домотеки». Менеджер прислал макет: сверху панель с поиском и корзиной, ниже сетка карточек по четыре в ряд. Шесть товаров, поэтому второй ряд неполный. Он должен выглядеть так, как будто для всех карточек есть место, а не растягиваться на всю ширину. Корзина не должна сжиматься, когда поле поиска занимает место.

## Цель

Допишите `styles.css` и добейтесь вида по макету `mockup.svg`.

## Критерии приёмки

- Панель: логотип, поле поиска и корзина стоят в одной линии, центры совпадают. Поиск шире 400px, корзина у правого края колонки.
- Корзина в одну строку, высота не больше 44px, даже если логотип станет длиннее.
- Карточки: четыре в первом ряду, две во втором. Все шириной 228px (±2px), промежутки 16px по горизонтали и по вертикали.
- Второй ряд начинается у левого края.
- Кнопки в каждом ряду лежат на одной линии у нижних краёв карточек.
- Если товаров четыре, карточки остаются шириной 228px; если добавить седьмую, она встанет во второй ряд той же ширины.

## Ограничения

- Не меняйте `index.html`.
- Не используйте `position: absolute` и фиксированную высоту карточек.
- Промежутки только через `gap`.
