# Разбор

**Панель.** `.toolbar` — ряд: `display: flex`, `align-items: center` для общей оси по вертикали, `gap: 16px` для промежутков. Полю поиска достаётся всё свободное место через `flex: 1`. Корзине запрещено сжиматься (`flex-shrink: 0`) и переносить текст (`white-space: nowrap`). Тогда при длинном логотипе страдает поиск, а не корзина.

**Карточки.** Это ряд с переносом: `display: flex; flex-wrap: wrap; gap: 16px`. Ширину карточки считаем по формуле: контейнер 100%, три промежутка по 16px, итого `(100% - 48px) / 4`. Запись `flex: 0 0 calc(...)` означает: не расти, не сжиматься, база — четверть. Поэтому две карточки второго ряда не растягиваются.

**Кнопки.** Каждая карточка — колонка (`flex-direction: column`), кнопке задан `margin-top: auto`. Карточки в одном ряду одной высоты (по умолчанию `align-items: stretch`), кнопки лежат на нижней линии.

Если нужна сетка из строк и столбцов, где можно управлять обеими осями сразу, Grid подходит лучше. Следующий урок покажет, как та же страница выглядит на Grid.
