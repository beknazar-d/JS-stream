# Разбор

Свойство `order` меняет только картинку. Порядок для Tab, экранного диктора и поиска по странице определяется порядком в разметке (DOM order). Поэтому приём «разметка в одном порядке, экран в другом» создаёт расхождение, которое видно только тем, кто не пользуется мышью.

Рефакторинг в два шага.

1. В `index.html` переставили элементы в порядке «название, цена, кнопка» для обеих строк.
2. Из `styles.css` убрали три `order`. Остальное осталось: `display: flex`, `gap`, `flex: 1` у названия.

Результат на экране тот же, а Tab идёт по тому, что человек видит: сначала ссылка, потом кнопка. Это пример правила WCAG: порядок фокуса должен быть осмысленным и соответствовать визуальному порядку.
