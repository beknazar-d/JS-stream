## Контекст

Список товаров в панели менеджера получил жалобу. Сотрудница, которая работает с клавиатуры, нажимает Tab и сначала попадает на кнопку «Купить», а название, куда она идёт, стоит только третьим. Экранный диктор тоже читает сначала кнопку и цену. Причина: разработчик расставил элементы свойством `order`, а в разметке они лежат в обратном порядке.

## Цель

Перепишите страницу так, чтобы порядок в разметке совпал с порядком на экране, а свойств `order` не осталось. Внешний вид не должен измениться.

## Критерии приёмки

- На экране слева направо: название, цена, кнопка (как сейчас).
- Дети каждого `li` в разметке идут в том же порядке: `title`, `price`, `btn`.
- Порядок Tab: сначала ссылка, потом кнопка.
- В `styles.css` нет свойства `order`, вычисленное значение у всех трёх элементов равно 0.
- Название по-прежнему занимает всё свободное место, кнопка прижата к правому краю.

## Ограничения

- Менять нужно `index.html` и `styles.css`.
- Не используйте `flex-direction: row-reverse`.
- Не удаляйте элементы и не меняйте их текст.
