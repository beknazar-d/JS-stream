## Контекст

Код-ревью страницы товара «Домотеки». Фирменный зелёный `#0b6e4f` записан в стилях дважды, так же дважды повторяются тёмно-синий текст `#1d2733` и серая рамка `#d5dbe1`, а белый встречается четыре раза. Отступ 16 px тоже повторяется. К осени запланирован ребрендинг, и тимлид просит заранее собрать значения в одном месте.

Внешний вид страницы после правок не должен измениться ни на пиксель.

## Цель

Вынесите значения в переменные (дизайн-токены, design tokens) в `:root` и замените ими все места использования.

## Критерии приёмки

- В `:root` объявлены: `--color-brand` (#0b6e4f), `--color-on-brand` (#ffffff), `--color-text` (#1d2733), `--color-surface` (#ffffff), `--color-border` (#d5dbe1) и `--space-md` (16px).
- Во всех правилах, кроме `:root`, нет цветов в виде `#...`, `rgb(...)`, `hsl(...)`. Только `var(--color-...)`.
- Внешний вид прежний: те же цвета и те же отступы на шапке, карточке, кнопке и подвале.
- Горизонтальные отступы шапки, карточки, кнопки и подвала берутся из `--space-md`: смена значения меняет все четыре блока.

## Ограничения

- Менять только `styles.css`.
- Имена переменных и их значения заданы в критериях: тест обращается к ним по имени.
- Вертикальный отступ кнопки (8 px) остаётся значением: это другой размер.
