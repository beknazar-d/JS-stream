# Разбор

1. Выписаны все значения: зелёный (бренд), тёмно-синий (текст), серый (рамка), белый, отступ 16 px.
2. Каждому дано имя по роли. Белый встречается в двух ролях, и они могут разойтись при ребрендинге: `--color-surface` (фон поверхностей) и `--color-on-brand` (текст на брендовом фоне). Токены называют по назначению, а не по цвету: `--color-white` потеряет смысл, когда поверхность станет тёмной.
3. Все токены в `:root`: так их видит вся страница, и их можно переопределить на самом верхнем уровне.
4. Вертикальный отступ кнопки 8 px остался значением. Это другая величина, а токен нужен там, где значение повторяется по смыслу.

Проверка после рефакторинга: вид страницы не изменился, а смена каждого токена меняет все места использования. Именно это проверяют тесты.
