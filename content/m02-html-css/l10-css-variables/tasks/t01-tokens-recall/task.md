## Контекст

Задача WEB-401. В «Домотеке» меняется фирменный зелёный цвет, а кнопки и плашки раскрашены по всему сайту «вручную». Перед редизайном нужно собрать значения в переменные, чтобы цвет менялся в одном месте. Начните с карточки заказа.

## Цель

Допишите `styles.css` по памяти, не подглядывая в конспект.

## Критерии приёмки

- В `:root` объявлены `--color-brand: #0b6e4f` и `--space-md: 16px`.
- Фон `.button` берётся из `--color-brand`. Если сменить значение на `:root`, кнопка перекрасится.
- Боковые отступы `.button` (padding слева и справа) равны `--space-md`, вертикальные остаются 8 px.
- Отступ вокруг `.order` равен `--space-md`.
- Цвет текста `.badge` берётся из `--badge-color` с запасным значением `#b42318`. Пока `--badge-color` не задана, плашка красная.

## Ограничения

- Менять только `styles.css`.
- Имена переменных важны: тест обращается к ним по имени.
