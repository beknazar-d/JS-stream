# Разбор

Пользовательское свойство (custom property) начинается с `--` и объявляется как обычное: `--color-brand: #0b6e4f`. Чтобы его видела вся страница, его объявляют в `:root`. Это корневой элемент `html`, а свойства наследуются вниз по дереву.

Читают значение функцией `var(--имя)`. Второй аргумент `var(--имя, запасное)` работает, когда переменная не объявлена. Запасное значение можно переопределить: на плашке `--badge-color` задаётся локально, и она перекрасится, а остальные останутся красными.

Одинарная запись цвета в `:root` вместо десятка копий означает один переключатель на весь сайт.
