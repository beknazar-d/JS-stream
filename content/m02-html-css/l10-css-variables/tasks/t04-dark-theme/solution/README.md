# Разбор

Компоненты уже читают переменные, поэтому тёмная тема — это только новые значения тех же шести переменных.

Два блока:

1. `[data-theme="dark"]` — тема, выбранная человеком. Атрибут стоит на `html`. У `:root` и у `[data-theme="dark"]` одинаковая специфичность (псевдокласс и атрибут весят как класс), поэтому побеждает тот блок, что ниже в файле: тёмный должен идти после `:root`.
2. `@media (prefers-color-scheme: dark) { :root:not([data-theme]) { ... } }` — тема системы. Часть `:not([data-theme])` означает «только если человек ничего не выбирал». Поэтому `data-theme="light"` останется светлой даже при тёмной системе.

Тёмные значения подбирают по контрасту: светлый текст на тёмной поверхности. Фон карточки (`--color-surface`) делают чуть светлее фона страницы, чтобы карточку было видно. Текст на кнопке: тёмный на светлом брендовом цвете, а не белый на светло-зелёном.

Недостаток: тёмные значения записаны дважды. CSS пока не умеет подключить один блок к двум условиям. В реальных проектах это либо терпят, либо генерируют из токенов, либо оставляют только `data-theme` и выставляют его скриптом по настройке системы.
