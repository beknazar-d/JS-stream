## Контекст

Задача WEB-433: тёмная тема для корзины «Домотеки». Страница уже использует переменные цветов, значения светлой темы лежат в `:root`. Нужно добавить тёмные значения и подключить их двумя способами:

- человек сам выбрал тему: атрибут `data-theme="dark"` на `html` (позже его будет ставить переключатель);
- человек не выбирал, а система работает в тёмном режиме: `prefers-color-scheme: dark`.

Выбор человека важнее настройки системы: если на `html` стоит `data-theme="light"`, страница остаётся светлой, даже когда система тёмная.

## Цель

Допишите `styles.css`: определите значения шести переменных для тёмной темы и подключите их двумя способами. Компоненты (`body`, `.card`, `.button`) менять не нужно: они уже читают переменные.

## Критерии приёмки

- Без `data-theme` страница светлая.
- При `data-theme="dark"` на `html`: фон страницы тёмный, текст светлый, фон карточки тоже тёмный.
- Контраст текста к фону не ниже 4.5 : 1 на карточке и на кнопке в тёмной теме.
- Есть блок `@media (prefers-color-scheme: dark)`, который включает те же тёмные значения, но только когда `data-theme` не задан.
- Тест не может переключить браузер на тёмную системную тему. Поэтому он берёт правила из вашего блока `@media` и применяет их так, как будто условие выполнено. Всё остальное проверяется честно.

## Ограничения

- Не используйте `!important`.
- Не меняйте правила `body`, `.card`, `.button`.
- Значения цветов подбирайте сами: тест проверяет яркость и контраст, а не конкретные цвета.
