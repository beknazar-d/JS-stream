# Разбор

Три причины, ни одна не пишет ошибку в консоль.

1. **Область видимости.** `--gap` и `--color-accent` объявлены на `.catalog-section`. Переменные наследуются только вниз, а `.site-footer` — сосед секции, а не потомок. Для него переменных нет. Общие переменные объявляют в `:root`.
2. **Опечатка.** В объявлении `--color-accent`, в `var(--color-acent)` буквы `c` не хватает. Такой переменной не существует, значение недействительно, и свойство `color` работает как будто не указано: цена наследует чёрный цвет.
3. **Единица после скобки.** `var(--gap)px` не дописывает `px`. Подстановка происходит как замена текста: получается `16pxpx`, значение недействительно, и `margin-bottom` сбрасывается в 0. Единица уже хранится в переменной. Если нужно число без единицы, его пишут в переменной как `16` и перемножают: `calc(var(--space) * 1px)`.

Совет на будущее: в панели Styles (DevTools) такое свойство отображается зачёркнутым или с предупреждающим значком. Начинайте поиск с него.
