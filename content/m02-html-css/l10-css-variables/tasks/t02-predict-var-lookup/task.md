## Контекст

В стилях «Домотеки» переменные объявлены в разных местах: что-то на странице, что-то на карточке, что-то в боковой колонке. Нужно понимать заранее, какое значение увидит каждый элемент. Модель на JavaScript повторяет правила поиска, которые использует браузер: свой элемент, потом родители вверх по дереву.

Элементы связаны так: `page` — корень; `sidebar`, `card` и `footer` — его дети; `badge` лежит внутри `card`.

## Цель

Прочитайте `snippet.js`. Запишите в `answer.js` в массив `output` семь строк: то, что код выведет в консоль, по одной на каждый вызов `console.log`.

## Критерии приёмки

- В массиве `output` ровно семь строк в порядке вызовов `console.log`.
- Каждый элемент — строка, например `"16px"` или `"invalid"`.
- Ответ совпадает с реальным выводом кода построчно.

## Ограничения

- Не меняйте `snippet.js`.
- Не запускайте код до ответа: сначала подумайте, потом сверьтесь.
