# Разбор

Правило одно: браузер ищет переменную у самого элемента, потом у родителя, дальше вверх. Побеждает ближайшая.

1. `badge`: у него нет `--color`, у родителя `card` есть `darkgreen`. Ближайшее значение побеждает значение корня `navy`.
2. `badge`, `--gap`: нет ни у него, ни у `card`, находим у `page`: `16px`.
3. `footer`, `--gap`: своё значение `8px` перекрывает значение корня.
4. `footer`, `--color`: своего нет, берётся у `page`: `navy`.
5. `card`, `--accent`: переменная объявлена у `sidebar`. Это сосед, а не предок, цепочка `card → page` её не содержит. Результат `invalid`, то есть значение недействительно.
6. `footer`, `--shadow`: нигде нет, поэтому берётся запасное значение `none`.
7. `page`, `--gap` с запасным `4px`: переменная есть, запасное значение игнорируется.

В CSS это работает так же благодаря наследованию: переменные наследуются от родителя к детям.
