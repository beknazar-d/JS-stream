## Зачем это в работе

Пятница, правки перед запуском акции. За день пришло шесть жалоб на вёрстку:

- кнопка «Распродажа» должна быть красной, но она серая, хотя правило в стилях есть;
- заголовок блока вплотную прижат к краю, хотя отступ сверху задан;
- у заказа с длинным названием цена уехала за правый край и выпала из строки;
- в чате поддержки покупатель вставил длинную ссылку, и страница получила горизонтальную прокрутку;
- всплывающее уведомление «Товар добавлен» спрятано под баннером, хотя у него `z-index: 100`;
- боковое меню заканчивается посреди страницы, хотя в стилях написано `height: 100%`.

В консоли тихо. Ошибок нет, предупреждений нет. Все шесть случаев — классические ловушки CSS. После этого урока вы будете узнавать их с первого взгляда и знать, что править.

## Объяснение

Ловушка (trap) в CSS — это правило, которое выглядит верным, но не срабатывает из-за скрытого устройства браузера. Вот шесть главных.

1. **Специфичность (specificity).** Из двух правил для одного элемента побеждает то, у которого селектор «тяжелее». Вес считают тройкой чисел: сколько идентификаторов, сколько классов, сколько тегов. Идентификатор весит больше любого числа классов. Побеждает большая тройка, а при равенстве — правило, написанное позже. Спасение: держите селекторы лёгкими, без `#` и без `!important`.
2. **Схлопывание отступов (margin collapsing).** Вертикальные отступы соседних блоков не складываются, а объединяются в больший. А отступ первого ребёнка может «вытечь» наружу через родителя, если у родителя нет рамки и внутреннего отступа.
3. **Flex-элемент не сжимается.** Гибкий элемент по умолчанию не может стать уже своего содержимого. Длинное слово расталкивает соседей. Спасение: `min-width: 0` у элемента.
4. **Переполнение длинным словом.** Слово без пробелов не умеет переноситься. Спасение: `overflow-wrap: anywhere` или обрезание с многоточием.
5. **`z-index` без позиционирования.** Порядок слоёв работает у элементов с `position`, отличным от `static`, и у элементов flex и grid. У обычного блока в потоке `z-index` ничего не делает.
6. **`height: 100%` без высоты родителя.** Процент считается от высоты родителя. Если у родителя высота `auto`, процент превращается в `auto`. Спасение: `min-height: 100vh` на корне или высота родителю.

Аналогия: правила дорожного движения. Знак «стоп» (идентификатор) важнее обычного знака (класса), и никакое число обычных знаков его не перебьёт. Что-то похожее есть у всех шести ловушек: в каждой действует внутреннее правило, которого не видно глазом.

## Пример

Сначала специфичность. Посчитаем вес селекторов кодом, как это делает браузер.

Селектор `#promo` весит `1,0,0`, а `.card.sale.hit` — `0,3,0`. Идентификатор побеждает, даже если классов в десять раз больше.

<Wrong>

```css
.card .price { color: #222; }
.sale { color: #c0261b; }   /* вес 0,1,0 проигрывает 0,2,0 */
```

</Wrong>

<Right>

```css
.price { color: #222; }
.price.sale { color: #c0261b; }   /* вес 0,2,0 побеждает 0,1,0 */
```

</Right>

Теперь схлопывание отступов.

<Playground example="collapse" />

Два соседних блока с отступами 24 и 16 дают расстояние 24, а не 40. Если один из отступов отрицательный, они складываются: 24 и −8 дают 16.

Отступ первого ребёнка и родителя:

<Wrong>

```css
.summary { background: #fff1c2; }
.summary h1 { margin-top: 32px; }   /* уйдёт наружу, над блоком */
```

</Wrong>

<Right>

```css
.summary { background: #fff1c2; display: flow-root; }  /* отступ остаётся внутри */
.summary h1 { margin-top: 32px; }
```

</Right>

Значение `display: flow-root` создаёт отдельный контекст форматирования, и отступы детей остаются внутри. Тот же эффект даёт `padding-top: 1px` или рамка, но это грубее.

Теперь flex-элемент и длинное слово.

<Playground example="min-content" />

Элемент не станет уже самого длинного слова, поэтому для длинного слова нужны две правки.

<Wrong>

```css
.order-name { flex: 1; }   /* длинное слово раздвигает строку */
```

</Wrong>

<Right>

```css
.order-name {
  flex: 1;
  min-width: 0;                /* разрешили сжиматься */
  overflow-wrap: anywhere;     /* разрешили переносить */
}
```

</Right>

## Как это работает

Все шесть ловушек на одной карте.

Схлопывание отступов: отступ уходит наружу, нужен display flow-root. Flex-элемент: длинное слово расталкивает строку, нужен min-width ноль. Теперь подробнее о трёх ловушках, которые труднее всего заметить.

**Специфичность и порядок.** Браузер сравнивает тройки слева направо. `1,0,0` больше любого `0,N,N`. Если тройки равны, побеждает правило ниже по тексту. Правило с `!important` побеждает любое правило без него, но обращается с ним как с гранатой: следующему, кто захочет переопределить, придётся писать ещё один `!important`. Это «война важностей». Выход: понизить вес исходного правила, а не повышать вес нового.

**`z-index`.** Свойство работает только у элементов, для которых создан слой: позиционированных (`relative`, `absolute`, `fixed`, `sticky`) и дочерних элементов flex и grid. Если слой есть у соседа, а у вашего блока нет, значение вашего `z-index` не участвует в сравнении.

**Процент высоты.** `height: 100%` спрашивает: «а какая высота у родителя?» Если родитель сам по содержимому, ответа нет, и процент превращается в `auto`. Для высоты окна используйте `vh`, а `min-height` вместо `height`, чтобы блок не обрезал содержимое.

<Note>

Привычка отладки: открыть DevTools, выбрать элемент и вкладку Styles. Перечёркнутые строки — проигравшие правила. Вкладка Computed показывает итоговое значение и «победителя».

</Note>

## Типичные ошибки

Ловушки CSS молчат. Вот симптомы и первое, что стоит проверить.

**1. Стиль не применяется.** Найдите элемент в DevTools. Правило зачёркнуто? Значит, его перебило другое. Посмотрите, какое именно, и сравните вес.

**2. Отступ «исчез».** Заголовок вплотную к краю блока. Родитель без рамки и padding. Добавьте `display: flow-root`.

**3. Строка сломалась от одного слова.** В строке из flex-элементов один выбивается. Поставьте ему `min-width: 0`.

**4. Прокрутка вбок на телефоне.** Где-то длинное слово, URL или широкая картинка. Найдите элемент, у которого ширина больше экрана, и задайте `overflow-wrap: anywhere` или `max-width: 100%`.

**5. `z-index` не помогает.** Проверьте `position` у элемента.

**6. Блок не растягивается на высоту окна.** Проверьте высоту всех родителей вверх до `html` или задайте `min-height: 100vh`.

В JavaScript есть своя «тихая ловушка» с похожим характером. Сравнение строк вместо чисел молчит так же. Реальный вывод Node.js 22:

```text
"10" < "9"  → true
```

Смысл тот же: язык делает не то, что показывает глаз, а ошибки при этом нет.

## Итог

Что вы теперь умеете:

- считать вес селектора и чинить конфликт без `!important`;
- возвращать отступ внутрь блока через `display: flow-root`;
- разрешать flex-элементу сжиматься (`min-width: 0`) и тексту переноситься (`overflow-wrap`);
- помнить, что `z-index` требует позиционирования, а процент высоты — высоты родителя.
