# Разбор

1. `p` — один тег: `0,0,1`.
2. `.card .price` — два класса: `0,2,0`.
3. `ul li a:hover` — три тега и один псевдокласс: `0,1,3`.
4. `#app .card.sale` — идентификатор и два класса: `1,2,0`.
5. `button[disabled]` — атрибут считается как класс, плюс тег: `0,1,1`.
6. `.price` (0,1,0) против `.card .price` (0,2,0): второй тяжелее.
7. `.sale` и `.price` весят одинаково `0,1,0`: побеждает тот, что ниже по тексту, то есть второй — `.price`.
8. `#promo` (1,0,0) против `.card.sale.hit.new` (0,4,0): идентификатор побеждает по первому числу.
9. `main p` — два тега `0,0,2`, `.note` — один класс `0,1,0`. Один класс тяжелее любого числа тегов.
