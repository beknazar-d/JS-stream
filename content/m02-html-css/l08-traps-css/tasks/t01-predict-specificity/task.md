## Контекст

В стилях «Домотеки» накопились правила с разными селекторами, и никто не помнит, какое побеждает. Перед ревью вы разбираете их на скрипте, который считает вес селектора так же, как браузер: идентификаторы, классы и теги.

## Цель

Прочитайте код из `snippet.js`. Запишите в `answer.js` в массив `output` ровно то, что код выведет в консоль, по одной строке на каждый вызов `console.log`.

## Критерии приёмки

- В массиве `output` ровно девять строк в порядке вызовов `console.log`.
- Каждый элемент — строка, например `"0,2,0"`.
- Ответ совпадает с реальным выводом построчно.

## Ограничения

- Не меняйте `snippet.js`.
- Сначала предскажите, потом сверяйтесь.
