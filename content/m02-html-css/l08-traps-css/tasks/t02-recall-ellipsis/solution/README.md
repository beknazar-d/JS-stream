# Разбор

Рецепт из трёх свойств всегда один и тот же:

1. `white-space: nowrap` запрещает перенос, поэтому строка остаётся одной.
2. `overflow: hidden` скрывает всё, что не поместилось.
3. `text-overflow: ellipsis` заменяет скрытый хвост на «…».

Без любого из трёх результат ломается: без первого текст переносится, без второго вылезает за границу, без третьего обрывается без знака. Полный текст остаётся в разметке, поэтому его читает экранный диктор, а при желании можно показать целиком в подсказке `title`.
