## Контекст

В списке заказов в панели менеджера карточка шириной 280px. Название товара бывает очень длинным: «Холодильник Nord NR-120 двухкамерный, 340 литров, белый, доставка в четверг». Сейчас оно переносится на три строки и ломает ряд. По задаче дизайнера название должно занимать одну строку и заканчиваться многоточием.

## Цель

Допишите правило `.order-title` в `styles.css` по памяти.

## Критерии приёмки

- Длинное название занимает одну строку (высота меньше 30px) и не выходит за границы карточки.
- В конце видно многоточие: `text-overflow: ellipsis`.
- Полный текст остаётся в разметке.
- Короткое название «Чайник K-200» остаётся целым.
- Новое длинное название, подставленное позже, тоже обрезается.

## Ограничения

- Не меняйте `index.html`.
- Не задавайте названию фиксированную высоту и не обрезайте текст в разметке.
