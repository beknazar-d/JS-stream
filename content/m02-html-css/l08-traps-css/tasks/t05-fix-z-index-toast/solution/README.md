# Разбор

Свойство `z-index` управляет порядком слоёв только у элементов, которые участвуют в наложении: позиционированных (`position` не `static`) и дочерних элементов flex и grid. У `.toast` позиционирования нет, поэтому `z-index: 100`, `right` и `bottom` игнорируются, а блок остаётся обычным блоком внизу страницы. Слайдер же позиционирован (`relative`, `z-index: 1`) и лежит выше потока.

Исправление: `position: fixed`. Теперь элемент привязан к окну (`right` и `bottom` работают), выпадает из потока, а `z-index: 100` выигрывает у слайдера со значением 1.

Почему не `absolute`? Он привязан к странице: при прокрутке уведомление уедет вместе с контентом. Почему не `relative`? Он оставляет элемент в потоке: слой поднимется, но в угол окна уведомление не попадёт.
