# Разбор

Гибкий элемент по умолчанию имеет `min-width: auto`, то есть не может стать уже своего минимального содержимого. Для текста это ширина самого длинного слова. Название из 70 символов без пробелов шире свободного места, поэтому `flex: 1` не сжимает его, а сумму выдавливает за край.

Исправление из двух частей:

1. `min-width: 0` снимает ограничение: элемент может стать уже слова.
2. `overflow-wrap: anywhere` разрешает переносить слово в любом месте. Значение `anywhere` учитывается при расчёте минимальной ширины, а `break-word` нет: поэтому оно нам подходит, а `break-word` в одиночку не помогает.

Если название нужно показать в одну строку с троеточием, то решение другое (см. прошлое задание), но тогда часть текста скрыта. Здесь по условию название должно быть видно целиком.
