## Контекст

В панели менеджера строка заказа состоит из названия и суммы. Когда товар называется длинно и без пробелов (например, «Холодильник_двухкамерный_Nord_NR120_белый_артикул_4821_серия_Комфорт»), сумма вылетает за правый край карточки, а у страницы появляется прокрутка вбок. Менеджеры жалуются, что не видят цену.

## Цель

Исправьте `styles.css`: строка заказа не должна ломаться при длинном названии.

## Критерии приёмки

- Сумма находится внутри строки, название заканчивается левее суммы.
- Строка остаётся шириной 480px, у страницы нет горизонтальной прокрутки.
- Название переносится на несколько строк и видно целиком: оно не скрыто и не обрезано.
- Сумма остаётся в одну строку.
- Короткая строка «Чайник K-200» выглядит как раньше.
- Другое очень длинное слово ведёт себя так же.

## Ограничения

- Не меняйте `index.html`.
- Не используйте `overflow: hidden` для названия.
