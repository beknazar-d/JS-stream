# Разбор

Причина всех `!important` — вес `#catalog .card .price`, равный `1,2,0`. Исключение `.price.sale` весит `0,2,0` и проигрывало, поэтому его усилили вручную.

Решение — снизить вес базовых правил, а не повышать вес исключений:

1. Убрали `#catalog` из селекторов: оставили `.card`, `.price`, `.badge`.
2. Теперь база весит `0,1,0`, а исключения `.price.sale` и `.badge.hit` — `0,2,0`. Они побеждают по весу, а не по порядку в файле.
3. `!important` больше не нужны.

Правило на будущее: исключение (модификатор) должно быть на один класс тяжелее базового правила. Тогда порядок строк не важен и новый разработчик может безопасно добавлять варианты.
