## Контекст

В стилях каталога «Домотеки» живёт «война важностей». Когда-то дизайнер попросил сделать цену со скидкой красной, а правило с `#catalog` перебивало красный цвет. Разработчик поставил `!important`. Потом понадобилась зелёная плашка «Хит продаж», и появился ещё один `!important`. Теперь любое изменение цвета требует нового `!important`.

## Цель

Перепишите `styles.css` так, чтобы внешний вид остался тем же, но в стилях не было ни `!important`, ни идентификаторов в селекторах.

## Критерии приёмки

- Цвет обычной цены `#222222`, цены со скидкой `#c0261b`, плашки `#1b5fd1` с белым текстом, плашки хита `#1b7a3a`; размер цены 20px; ширина карточки 220px.
- В `styles.css` нет `!important`.
- В селекторах нет `#`.
- В селекторах не больше двух классов.
- Новая карточка с классами `price sale` и `badge hit` получает те же цвета.
- Цвет не зависит от порядка правил: исключение тяжелее базового правила.

## Ограничения

- Не меняйте `index.html`: идентификатор `catalog` в разметке остаётся.
- Не добавляйте новые классы в разметку.
