## Контекст

Тикет UI-80. Дизайнер передал правила оформления карточек каталога «Домотеки». В проекте уже есть базовые стили, и некоторые из них мешают: цена в карточках всё время остаётся чёрной, хотя в новых правилах она красная.

## Цель

Допишите `styles.css` так, чтобы выполнялись все правила. Разметку менять не нужно, базовые стили не удаляйте.

1. Цена (`.price`) красно-коричневая `#b32d00`.
2. Старая цена (`.old-price`) серая `#6b7280` и зачёркнутая (`line-through`).
3. Новая цена, которая стоит сразу после старой, крупнее: `font-size: 20px`. У остальных цен остаётся 16px.
4. Карточка с атрибутом `data-stock="0"` полупрозрачная: `opacity: 0.5`.
5. Выключенная кнопка `.buy` внутри карточки: фон `#cbd2d9`, текст `#5a6572`.
6. Бейдж (`.badge`), который стоит первым ребёнком карточки, пишется заглавными (`text-transform: uppercase`). Бейдж на другом месте не меняется.
7. Каждая третья карточка в списке получает рамку `1px solid #1f6feb`. Остальные остаются с рамкой `1px solid #dde3ea`.

## Критерии приёмки

- Цена без старой: цвет `#b32d00`, размер 16px.
- Цена после старой: цвет `#b32d00`, размер 20px.
- Старая цена: цвет `rgb(107, 114, 128)` и зачёркивание.
- Карточка без остатка: `opacity: 0.5`. Остальные карточки с `opacity: 1`.
- Выключенная кнопка серая, доступная кнопка синяя `#1f6feb` с белым текстом.
- Первый бейдж заглавными, второй как написан.
- В `styles.css` нет `!important`.

## Ограничения

- Не используйте `!important` и селекторы по `id`.
- Базовые правила `.catalog .price`, `.buy`, `.card` оставьте, они нужны по ТЗ.
