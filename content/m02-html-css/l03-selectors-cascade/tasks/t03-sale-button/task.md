## Контекст

Баг-репорт UI-72. Кнопки со скидкой («Акция» в панели над каталогом и «Купить со скидкой» в карточке товара) должны быть красными. На деле в панели красная кнопка серая, а в карточке синяя. Правило `.btn-sale` в CSS есть, но «не работает».

## Цель

Исправьте `styles.css`, чтобы обе кнопки со скидкой были красными (`#dd0000`) с белым текстом. Обычные кнопки не должны измениться: в панели серые, в карточке товара синие.

## Критерии приёмки

- Кнопки с классом `btn-sale` в панели и в карточке: фон `#dd0000`, текст `#ffffff`.
- Обычная кнопка в панели: фон `#e8ecef`, текст `#222222`.
- Обычная кнопка в карточке товара: фон `#1f6feb`, текст `#ffffff`.
- В `styles.css` нет `!important`.

## Ограничения

- Менять только `styles.css`.
- HTML не меняйте: классы уже расставлены.
