## Контекст

Тикет ADMIN-12. Для панели менеджера «Домотеки» подключена готовая библиотека таблиц. Её стили лежат в `index.html` в теге `style` с идентификатором `vendor`. Править их нельзя: библиотека обновляется, и правки пропадут. Нужно оформить таблицу заказов поверх этих стилей так, как просит отдел продаж, и не использовать `!important`.

Библиотека задаёт, среди прочего, такие правила:

```css
table.grid td, table.grid th { padding: 4px 8px; text-align: left; }
table.grid td { color: #333333; }
table.grid tbody tr:nth-child(even) td { background: #f5f5f5; }
```

## Цель

Допишите `styles.css` так, чтобы таблица выглядела по ТЗ. Правила библиотеки не меняйте, а перебивайте своими, более весомыми.

1. Ячейки сумм (`td.num`) и заголовок столбца сумм (`th.num`) выровнены по правому краю.
2. Строки со статусом «отменён» (`tr[data-status="cancelled"]`): текст серый `#888888`, зачёркнутый (`line-through`).
3. Строки со статусом «новый» (`tr[data-status="new"]`): фон `#e7f1ff`, причём и в нечётных, и в чётных строках (чётные библиотека красит в серый).
4. Строка с классом `urgent`: у первой ячейки слева красная полоса `4px solid #dd0000`.
5. Остальные ячейки сохраняют стиль библиотеки: цвет текста `#333333`, чётные строки серые `#f5f5f5`.

## Критерии приёмки

- Все пять пунктов выполнены в обеих позициях строк (чётной и нечётной), где это применимо.
- Стили библиотеки в `index.html` не изменены.
- В вашем `styles.css` нет `!important` и нет селекторов по `id`.

## Ограничения

- Менять только `styles.css`.
- Не используйте `!important` и `id`.
