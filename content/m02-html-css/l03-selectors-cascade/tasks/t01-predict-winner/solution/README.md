# Разбор

Вес селектора — тройка `[идентификаторы, классы, теги]`. Тройки сравниваются слева направо. Более высокое число в ранней позиции побеждает, сколько бы ни было в поздних: один идентификатор сильнее любого числа классов.

Идём по шагам. Победитель шага участвует в следующем сравнении.

1. `.btn` `[0,1,0]` против `.card .btn` `[0,2,0]`: классов больше, побеждает `.card .btn`.
2. `.card .btn` против `button.btn` `[0,1,1]`: классов 2 против 1, `.card .btn` остаётся.
3. `.card .btn` против `.product .btn` `[0,2,0]`: веса равны. Побеждает позднее правило, то есть `.product .btn`.
4. `.product .btn` против `#cart .btn` `[1,1,0]`: в первой позиции 0 против 1, побеждает `#cart .btn`.
5. `#cart .btn` против `a.btn:hover` `[0,2,1]`: у `#cart .btn` первая позиция больше, он остаётся.
6. Вес победителя `1-1-0`.

Вывод для CSS: «последнее правило выигрывает» верно только при равном весе. Если кнопка не меняет цвет, сравните вес двух селекторов.
