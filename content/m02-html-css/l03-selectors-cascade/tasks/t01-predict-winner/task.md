## Контекст

Тикет UI-58. Кнопка «В корзину» в «Домотеке» не меняет цвет, хотя правило для неё написано. Дизайнер уверен, что «последнее правило всегда выигрывает». Разработчик набросал функцию `stronger`, которая выбирает победителя между двумя правилами по весу селектора. Вес записан тройкой чисел: сколько в селекторе идентификаторов, классов и тегов.

## Цель

Прочитайте код из `snippet.js`. Запишите в `answer.js` в массив `output` шесть строк: именно то, что код выведет в консоль, по одной на каждый вызов `console.log`.

## Критерии приёмки

- В `output` ровно шесть строк в порядке вызовов `console.log`.
- Каждый элемент — строка.
- Ответ совпадает с реальным выводом построчно.

## Ограничения

- Не меняйте `snippet.js`.
- Сначала предскажите, потом сверяйтесь.
