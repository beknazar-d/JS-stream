## Контекст

Тикет UI-61. На странице каталога «Домотеки» нужно оформить карточки. Разметка готова и не меняется, остались стили. Это задание на память: все нужные селекторы разобраны в уроке.

## Цель

Допишите `styles.css`. В нём пока пусто. Нужны шесть правил:

| Какие элементы | Что задать |
|---|---|
| Заголовки карточек, класс `card-title` | `font-size: 18px` |
| Цены, класс `price` | `color: #b32d00` |
| Цены внутри карточки с классом `card-sale` | `color: #d00000` |
| Чётные карточки в списке (2-я, 4-я) | `background-color: #f3f5f7` |
| Ссылки, адрес которых начинается с `https` | `color: #0066cc` |
| Ссылка, которая идёт сразу после цены | `margin-top: 8px` |

## Критерии приёмки

- Цена обычной карточки `#b32d00`, цена карточки со скидкой `#d00000`.
- Фон `#f3f5f7` только у второй и четвёртой карточки, у остальных фона нет.
- Синяя ссылка `#0066cc` только внешняя («Сайт производителя»). Внутренняя ссылка «Подробнее» остаётся цветом по умолчанию.
- Отступ сверху 8px только у ссылки, идущей сразу после цены.

## Ограничения

- Менять только `styles.css`.
- Не используйте `!important` и селекторы по `id`.
