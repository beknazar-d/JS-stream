# Разбор

Шесть правил, шесть видов селекторов.

- `.card-title` — селектор класса.
- `.price` — селектор класса.
- `.card-sale .price` — потомок: цена, которая лежит внутри карточки со скидкой. Вес у него `[0,2,0]`, у `.price` `[0,1,0]`, поэтому красный цвет скидки побеждает независимо от порядка в файле.
- `.card:nth-child(even)` — псевдокласс: чётные дети. Считаются дети родителя `ul`, а не карточки по порядку класса. Фон получат вторая и четвёртая.
- `a[href^="https"]` — селектор атрибута: значение `href` начинается с `https`. Внутренняя ссылка `/catalog/...` не подходит.
- `.price + a` — соседний комбинатор: ссылка, идущая сразу после цены. Вторая ссылка идёт после первой ссылки, а не после цены, поэтому её не затрагивает.

Ловушка: `:nth-child(even)` и `:nth-child(2n)` равны. `odd` и `2n+1` дают первую, третью, пятую.
