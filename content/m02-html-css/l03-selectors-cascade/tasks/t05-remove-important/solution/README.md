# Разбор

**Что было не так.** Идентификатор весит `[1,0,0]`, класс `[0,1,0]`. Каждое правило `#menu a` сильнее любого классового правила, поэтому его невозможно переопределить без нового идентификатора или `!important`. Вместе они создали гонку вооружений: чтобы победить, приходилось добавлять ещё.

**Что сделали.**

1. Идентификаторы заменили классами. Меню получило класс `menu`, остальные правила привязаны к `.note` и `.btn` без родителя.
2. Базовое правило и вариант разнесли по весу: `.note` против `.note.warning`, `.btn` против `.btn.danger`, `.menu a` против `.menu a.active`. У варианта вес больше, поэтому порядок в файле не имеет значения.
3. Убрали все `!important`.

Внешний вид не изменился: сверьтесь по критериям приёмки.

**Почему так лучше.** Новая кнопка `.btn.success` теперь пишется одной короткой строкой, и ничего не нужно пробивать. Правило читается без поиска идентификатора по всему HTML.

Идентификаторы по-прежнему нужны HTML: для `label for`, якорных ссылок и скриптов. Но для стилей их стоит избегать.
