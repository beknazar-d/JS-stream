## Контекст

Тикет TECH-35. Стили панели «Домотеки» писались в спешке: для победы над чужими правилами в каждую строку добавляли `!important`, а селекторы привязали к идентификаторам. Теперь добавить новую кнопку невозможно: любое новое правило проигрывает. Тимлид просит привести CSS в порядок, не меняя того, как страница выглядит.

## Цель

Перепишите `styles.css` без `!important` и без селекторов по `id`. Если нужно, добавьте классы в `index.html`. Внешний вид должен остаться прежним.

## Критерии приёмки

- Ссылки меню: цвет `#333333`. Активная ссылка (класс `active`): цвет `#dd0000` и жирный шрифт (700).
- Заметки (`.note`): фон `#eeeeff`, внутренний отступ 8px. Предупреждение (`.note.warning`): фон `#ffeeee`.
- Кнопки (`.btn`): фон `#1f6feb`, текст белый. Опасная кнопка (`.btn.danger`): фон `#dd0000`.
- В `styles.css` нет `!important` и нет селекторов, в которых есть `#` (идентификатор).
- Новая кнопка с классом `btn` (и `btn danger`), добавленная в `main`, получает тот же вид без дополнительных правил.

## Ограничения

- Не используйте `!important` и `id` в CSS.
- Тексты и порядок элементов в HTML не меняйте.
