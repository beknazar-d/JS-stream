## Зачем это в работе

В прошлом уроке мы собрали каталог на Flexbox. Четыре карточки в ряд работают, но чтобы вторая строка не растягивалась, пришлось вычислять ширину карточки формулой `calc`. Менеджер просит новое: баннер акции на всю ширину каталога, а в конце списка пусть карточки сами подстраиваются под окно. На широком мониторе пять в ряд, на планшете три, на телефоне одна. Без медиазапросов.

Для задач, где важны и строки, и столбцы, есть Grid (сетка). Flexbox раскладывает элементы вдоль одной оси. Grid раскладывает их по клеткам, как таблицу, но без таблицы в разметке. В этом уроке: колонки и строки, единица `fr`, функции `repeat` и `minmax`, разница между `auto-fill` и `auto-fit`, а ещё именованные области страницы.

## Объяснение

Включите `display: grid` у родителя. Он станет контейнером сетки (grid container), а его прямые потомки — элементами сетки (grid items). Дальше вы описываете колонки и строки:

- `grid-template-columns` — сколько колонок и какой они ширины;
- `grid-template-rows` — сколько строк и какой они высоты (часто не нужно, строки создаются сами);
- `gap` — промежутки между клетками.

Новая единица `fr` (fraction, «доля») делит свободное место. `1fr 2fr` — две колонки, вторая вдвое шире первой. Можно смешивать с пикселями: `200px 1fr` — левая колонка 200px, правая забирает остальное.

Функция `repeat(3, 1fr)` — сокращение для `1fr 1fr 1fr`. Функция `minmax(220px, 1fr)` задаёт диапазон: не меньше 220px, не больше доли свободного места.

Слово `span` растягивает элемент на несколько клеток: `grid-column: span 2` — на две колонки.

Аналогия: разлинованный лист. Вы сами чертите линии и говорите, в какие клетки попадёт каждый элемент. Flexbox — это полка, Grid — шахматная доска.

## Пример

Каталог из шести карточек в три колонки.

```css
.catalog {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 16px;
}
```

Три колонки одной ширины, шесть карточек лягут в две строки. Теперь баннер на всю ширину:

```css
.promo {
  grid-column: 1 / -1;
}
```

Запись `1 / -1` читается так: от первой линии сетки до последней. Линия — это граница между колонками, а не сама колонка. Для трёх колонок линий четыре: 1, 2, 3 и 4. Число `-1` — последняя линия, поэтому баннер займёт всю строку при любом числе колонок.

<Wrong>

```css
.promo {
  grid-column: 1 / 4; /* в сетке из 4 колонок это только три колонки */
}
```

</Wrong>

<Right>

```css
.promo {
  grid-column: 1 / -1; /* от первой до последней линии */
}
```

</Right>

Посмотрим, как браузер делит место между `fr` и пикселями.

Теперь самое полезное: колонки, которые сами подстраиваются под ширину окна.

```css
.catalog {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(220px, 1fr));
  gap: 16px;
}
```

Читается так: «столько колонок, сколько поместится, каждая не уже 220px и не шире доли свободного места». Проверим на числах.

## Как это работает

Схема показывает линии и области на примере страницы панели.

<Figure src="grid-areas.svg" alt="Страница панели менеджера в виде сетки из трёх колонок и трёх рядов. Сверху шапка на три колонки. В среднем ряду слева меню, в центре основная часть, справа боковая панель. Внизу подвал на три колонки. Подписаны названия областей header, nav, main, aside, footer и размеры колонок 200 пикселей, 1fr, 240 пикселей." caption="Именованные области: страницу можно нарисовать словами, прямо в CSS." />

Эту схему можно записать словами:

```css
.app {
  display: grid;
  grid-template-columns: 200px 1fr 240px;
  grid-template-rows: auto 1fr auto;
  grid-template-areas:
    "header header header"
    "nav    main   aside"
    "footer footer footer";
  gap: 16px;
  min-height: 100vh;
}

.app > header { grid-area: header; }
.app > nav    { grid-area: nav; }
.app > main   { grid-area: main; }
.app > aside  { grid-area: aside; }
.app > footer { grid-area: footer; }
```

Каждая строка в `grid-template-areas` — ряд сетки, каждое слово — клетка. Одинаковые имена подряд объединяются в одну область. Область должна быть прямоугольной: буква «Г» не получится.

Теперь `auto-fill` против `auto-fit`. Оба создают столько колонок, сколько помещается. Разница видна, когда элементов меньше, чем колонок.

- `auto-fill` оставляет пустые колонки: они занимают место, а карточки сохраняют обычную ширину и прижимаются влево;
- `auto-fit` схлопывает пустые колонки в ноль, и оставшиеся карточки растягиваются на всю строку.

Для каталога обычно нужен `auto-fill`: две карточки не должны разрастаться в огромные плитки. Для ряда «Хиты продаж» из двух-трёх элементов иногда удобнее `auto-fit`.

Ещё три правила.

1. **`fr` и длинное содержимое.** По умолчанию колонка `1fr` не уже содержимого. Длинное слово раздвинет её. Если нужна колонка, которая может сжаться, пишите `minmax(0, 1fr)`.
2. **Линии, а не колонки.** В записи `grid-column: 1 / 3` числа — номера линий. Это колонки 1 и 2, а не 1–3.
3. **Flexbox или Grid?** Один ряд или колонка, размер определяется содержимым: Flexbox. Расклад по строкам и столбцам, размер определяется сеткой: Grid. На практике страница — Grid, а внутри ячеек — Flexbox.

## Типичные ошибки

В CSS нет сообщений в консоли: недопустимое значение браузер отбрасывает молча. В DevTools такая строка зачёркнута. Вот что случается чаще всего.

**1. `display: grid` не на том элементе.** Колонки пишут у карточки, а не у списка. Сетка применяется только к прямым потомкам контейнера.

**2. Перепутали линии и колонки.** `grid-column: 1 / 4` в сетке из четырёх колонок занимает три. Для «до конца» берите `-1` или `span`.

**3. Области не прямоугольные.** Если в `grid-template-areas` одно и то же имя образует букву «Г», всё свойство считается недопустимым и игнорируется. Страница разваливается без объяснений.

**4. Забыли `grid-area` у элементов.** Области в `grid-template-areas` описаны, но элементам имена не присвоены. Они ложатся в порядке разметки, по клеткам.

**5. `repeat(auto-fill, 1fr)`.** Такая запись недопустима: браузеру нужна минимальная ширина. Пишите `repeat(auto-fill, minmax(220px, 1fr))`.

**6. Длинное слово раздвинуло колонку.** `1fr` не позволяет колонке стать уже содержимого. Используйте `minmax(0, 1fr)` и `overflow-wrap: anywhere`.

В JavaScript аналог ошибок с линиями — выход за границу массива. Реальный вывод Node.js 22:

```text
const cols = [1, 2, 3, 4]
cols[4]  → undefined
cols.at(-1)  → 4
```

Индексы тоже считаются с нуля, а `-1` у `at` означает «последний», как `-1` у линии сетки.
