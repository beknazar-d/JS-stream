# Разбор

1. **Колонки и ряды.** `200px 1fr 240px` — меню, основная часть, сводка. `auto 1fr auto` — шапка и подвал по содержимому, средний ряд забирает остаток.
2. **Области.** Три строки `grid-template-areas` — это буквально рисунок страницы. Повторяющееся имя `header header header` объединяет три клетки в одну область.
3. **Привязка.** `grid-area: header` и остальные говорят каждому блоку, в какую область встать. Без этого области остаются пустыми.
4. **Высота.** `min-height: 100vh` растягивает страницу до окна, средний ряд (`1fr`) занимает свободное место, подвал оказывается внизу. Если контента больше, страница растёт, потому что именно `min-height`, а не `height`.
