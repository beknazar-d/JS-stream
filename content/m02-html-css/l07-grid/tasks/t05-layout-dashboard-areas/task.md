## Контекст

Панель менеджера «Домотеки» состоит из пяти блоков: шапка, меню разделов, основная часть, сводка справа и подвал. Сейчас блоки идут друг под другом, и менеджеру приходится прокручивать страницу, чтобы увидеть сводку. Дизайнер нарисовал макет `mockup.svg`: классическая схема «шапка, три колонки, подвал».

## Цель

Допишите `styles.css`: опишите сетку `.app` по макету через области.

## Критерии приёмки

- Шапка и подвал занимают всю ширину окна 1024px. Шапка вверху, подвал внизу.
- Средний ряд: меню шириной 200px слева, сводка шириной 240px справа, основная часть между ними.
- Промежутки между блоками 16px.
- Подвал прижат к нижнему краю окна 768px, средний ряд занимает всё свободное место, все три блока ряда одной высоты.
- Если основная часть вырастет, подвал уходит вниз вместе с ней.

## Ограничения

- Не меняйте `index.html`.
- Используйте `grid-template-areas` и `grid-area`.
- Высоту задавайте в `vh`, не в пикселях.
