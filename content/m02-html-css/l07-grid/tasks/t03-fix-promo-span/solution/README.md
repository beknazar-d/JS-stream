# Разбор

В `grid-column: 1 / 4` числа — это номера линий сетки, а не колонок. У сетки из четырёх колонок пять линий: 1, 2, 3, 4, 5. Запись `1 / 4` идёт от первой линии до четвёртой, то есть занимает три колонки. Четвёртая колонка осталась пустой, и карточка заняла её.

Исправление `grid-column: 1 / -1`. Число `-1` — последняя линия явной сетки. Поэтому баннер займёт весь ряд при любом числе колонок.

Запись `span 4` тоже исправит баннер, но привязывает его к числу колонок. Если колонок станет три, получится лишняя неявная колонка.
