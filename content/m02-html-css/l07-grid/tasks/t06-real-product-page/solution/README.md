# Разбор

1. **Колонки.** `1.2fr 1fr` делит остаток после промежутка в пропорции 1.2 к 1. Промежуток 24px приходит из `gap`.
2. **Фото через три ряда.** `grid-row: 1 / span 3` растягивает фото на ряды 1–3. Три блока справа лежат в этих же рядах и задают их высоту.
3. **Правая колонка.** `grid-column: 2` и номера рядов явно ставят заголовок, цену и кнопку. Кнопке добавлено `align-self: end`, чтобы она прижималась к низу фото.
4. **Описание.** `grid-column: 1 / -1` растягивает его на обе колонки, и оно естественно попадает в следующий свободный ряд.
5. **Характеристики и отзывы.** Идут по порядку разметки: первый берёт левую клетку, второй правую.

Почему здесь Grid, а не Flexbox: блоки привязаны сразу к строкам и к колонкам. Фото должно доходить до конкретного ряда, описание — занимать обе колонки. Для такого расклада сетка проще: вы говорите, какая клетка чья.
