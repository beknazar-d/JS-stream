## Контекст

Каталог «Домотеки» пока выводит карточки списком в одну колонку. Нужно сделать три колонки: на широком мониторе так читать и сравнивать товары легче. Это базовый приём Grid, поэтому наберите его по памяти.

## Цель

Допишите `styles.css`: превратите `.catalog` в сетку из трёх колонок.

## Критерии приёмки

- Шесть карточек лежат в два ряда по три.
- Колонки одной ширины (разница не больше 2px), сетка заполняет всю ширину колонки `main`.
- Промежутки между карточками 16px и по горизонтали, и по вертикали.
- Для сетки использован `display: grid`, колонок три.

## Ограничения

- Не меняйте `index.html`.
- Ширину колонок не задавайте в пикселях.
