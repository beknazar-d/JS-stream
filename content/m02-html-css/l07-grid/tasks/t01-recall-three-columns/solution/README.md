# Разбор

Три свойства:

1. `display: grid` превращает список в контейнер сетки.
2. `grid-template-columns: repeat(3, 1fr)` создаёт три колонки по доле свободного места.
3. `gap: 16px` ставит промежутки и между колонками, и между рядами.

Ряды создавать не нужно: браузер добавляет их сам, когда карточек больше, чем клеток в первом ряду. Это называется неявной сеткой.
