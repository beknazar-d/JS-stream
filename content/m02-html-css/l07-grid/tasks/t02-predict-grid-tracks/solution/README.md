# Разбор

1. Три колонки по `1fr`, контейнер 960px, два промежутка по 30px. Свободно 960 − 60 = 900px, на колонку 300px.
2. `200px 1fr 1fr`: свободно 940 − 200 − 40 = 700px, на каждую долю по 350px. Итог `200, 350, 350`.
3. `1fr 2fr`: свободно 620 − 20 = 600px. Одна доля 200px, две доли 400px.
4. `auto-fill` при 1000px: колонок `floor((1000 + 20) / (200 + 20)) = floor(4.63) = 4`. Ширина `(1000 − 60) / 4 = 235`.
5. При 400px: `floor(420 / 220) = 1` колонка. Она занимает все 400px.
6. Элемент на две колонки: 235 + 235 + промежуток 20 = 490.
