## Контекст

Перед версткой нового каталога вы проверяете расчёты на скрипте, который повторяет, как Grid делит ширину: колонки в долях `fr`, `auto-fill` с минимальной шириной и элемент, растянутый на две колонки. Нужно предсказать числа.

## Цель

Прочитайте код из `snippet.js`. Запишите в `answer.js` в массив `output` ровно то, что код выведет в консоль, по одной строке на каждый вызов `console.log`.

## Критерии приёмки

- В массиве `output` ровно шесть строк в порядке вызовов `console.log`.
- Каждый элемент — строка, например `"300, 300, 300"`.
- Ответ совпадает с реальным выводом построчно.

## Ограничения

- Не меняйте `snippet.js`.
- Сначала предскажите, потом сверяйтесь.
