# Разбор

Нужна одна строка: `grid-template-columns: repeat(auto-fill, minmax(200px, 1fr))`.

- `minmax(200px, 1fr)` — колонка не уже 200px и делит остаток поровну.
- `auto-fill` — создать столько колонок, сколько помещается с учётом `gap`.

Для 928px (окно 1024 минус поля `main`) помещается четыре колонки: `floor((928 + 16) / (200 + 16)) = 4`. Для 668px — три, для 343px — одна.

Если карточек меньше, чем колонок, `auto-fill` оставляет пустые колонки, и две карточки сохраняют ширину колонки. `auto-fit` схлопнул бы пустые колонки, и карточки растянулись бы.
