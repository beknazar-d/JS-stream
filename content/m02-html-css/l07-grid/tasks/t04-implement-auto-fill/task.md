## Контекст

Каталог «Домотеки» читают с мониторов, планшетов и телефонов. Медиазапросов пока в проекте нет, а карточки на телефоне должны идти одна под другой, на планшете по три, на мониторе по четыре. Менеджер просит сделать это одним правилом.

## Цель

Допишите `styles.css`: сетка должна сама подбирать число колонок по ширине окна.

## Критерии приёмки

- В окне 1024px — четыре колонки, в окне 700px — три, в окне 375px — одна.
- Ширина карточки не меньше 200px, карточки не выходят за правый край окна ни на ширине 320, 480, 700 или 900px.
- Карточки заполняют колонку `main` до правого края.
- Если в каталоге всего две карточки, они не растягиваются: ширина не больше 260px.
- Промежутки между карточками 16px.

## Ограничения

- Не меняйте `index.html`.
- Не используйте `@media`.
- Число колонок в CSS не указывайте.
