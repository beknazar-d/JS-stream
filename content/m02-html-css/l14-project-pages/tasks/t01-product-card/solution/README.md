# Разбор

**Разметка.** Страница получила настоящие элементы. `main` помечает основное содержимое, `article` — самостоятельный блок «товар», `h1` — заголовок, который должен быть один. Кнопка стала `button`: она принимает фокус, нажимается по Enter и пробелу и называется кнопкой. Характеристики — это пары «название и значение», для них есть `dl`, `dt`, `dd`. У каждой картинки свой `alt`.

**Раскладка.** `.product` — сетка с колонками `480px 1fr` и зазором 32. Её ширина 960, а `margin: 32px auto` ставит карточку по центру. `align-items: start` не даёт правой колонке растягиваться по высоте левой. Миниатюры — вторая сетка из трёх колонок по 96.

**Мелочи, которые проверяют.** Заголовку обнулён верхний отступ (`h1` по умолчанию его имеет), чтобы верх текста совпал с верхом картинки. У `dd` обнулён отступ слева (по умолчанию 40px), иначе значения уедут. Картинки имеют `display: block`, иначе под ними остаётся зазор для строки текста.

**Цвета.** Тёмный текст на белом, белый на `#0b3d91` (около 10 к 1), серый `#4b5563` на белом (около 7,6 к 1), серый `#6b7280` (около 4,8 к 1). Всё выше порога 4,5.
