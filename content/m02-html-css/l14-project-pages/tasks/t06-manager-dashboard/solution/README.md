# Разбор

Решение собирает всё, чему учил модуль.

**Mobile-first.** Базовые правила описывают телефон: сводка и фильтры в колонку, всё на всю ширину. Один блок `@media (min-width: 600px)` включает ряды. Так на узком экране не приходится «отменять» десктопные значения.

**Сетка и flex.** Сводка — Grid: три равные колонки с зазором 16 одной строкой. Фильтры — Flex: поиск получает `flex: 1`, список фиксированные 200, а `align-items: center` ставит все по центру строки. Пейджер — Flex с `justify-content: space-between`: на любой ширине слева, по центру и справа.

**Таблица.** Из прошлого этапа: настоящий `table`, `table-layout: fixed`, ширины колонок у `th`, `min-width: 640px`, контейнер с `overflow-x: auto`, `tabindex="0"` и `role="region"`. На телефоне прокручивается контейнер, а не страница.

**Изменение требований.** Два новых куска: `.kpi--warning` (рамка слева 4 px) и `.status--backorder`. Они добавлены как новые правила, остальное не тронуто. В БЭМ это обычная практика: новый вариант это новый модификатор.

**Доступность.** Один общий `:focus-visible` с синей рамкой 3 px (около 6,4 к 1 на белом). Рамки полей `#6b7280` (около 4,8 к 1). Бейдж `#9a3412` на `#ffedd5` около 6,4 к 1. Текст кнопок белый на `#0b3d91`, около 10 к 1. Отключённая кнопка «Назад» серая: для неактивных элементов контраст не требуется.

**Самопроверка проекта** есть в чек-листе урока: семантика, адаптив на 375, 768 и 1024, доступность и валидатор HTML.
