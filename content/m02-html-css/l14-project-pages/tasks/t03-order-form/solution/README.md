# Разбор

**Разметка.**
- `form` вместо `div` даёт отправку по Enter, проверку `required` и правильную роль.
- `fieldset` с `legend` объединяет связанные поля. Скринридер произносит название группы перед каждым полем: «Доставка, Курьером».
- `label` с `for` и `id` даёт полю имя, а ещё увеличивает область щелчка: щёлкнув по подписи, вы попадёте в поле.
- `type="tel"` и `type="email"` включают нужную клавиатуру на телефоне. `autocomplete` позволяет браузеру подставить сохранённые данные. Значения берутся из списка в стандарте HTML.
- Радиокнопка внутри `label` кликается по всей подписи.

**Раскладка.** Строка — `display: grid` с двумя равными колонками. Модификатор `--single` оставляет одну колонку, `--address` задаёт `2fr 1fr`. Подпись и поле лежат во flex-колонке с зазором 4. `box-sizing: border-box` и `width: 100%` делают поле ровно по ширине колонки с учётом рамки.

**Подвал.** Flex с `space-between` разводит итог и кнопку по краям строки. Кнопка получает правый край группы автоматически.

**Доступность.** Рамка поля `#6b7280` даёт около 4,8 к 1, она контрастна с белым фоном. Фокус показан синей рамкой 3 px.
