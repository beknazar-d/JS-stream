# Разбор

**Принцип.** Новое состояние добавляется модификатором: всё, что отличается, записано под `.product--sold-out`. Правила блока не тронуты, поэтому без модификатора страница остаётся прежней. Это называется «открыто для расширения, закрыто для изменения».

**Как модификатор побеждает.** Базовые `.product__badge` и `.product__notify` скрыты (`display: none`, вес `0-1-0`). Правило `.product--sold-out .product__badge` весит `0-2-0` и включает бейдж. Тяжелее соседей оно не стало: просто чуть тяжелее одного базового правила.

**Ссылка вместо кнопки.** «Сообщить о поступлении» ведёт на другую страницу, поэтому это ссылка (`a`). Внешне она оформлена как вторичная кнопка: рамка, цвет текста. `display: flex` ставит текст по центру и позволяет задать высоту 48.

**Адаптив.** Ссылка по умолчанию занимает всю ширину (телефон), а с 600 px сужается до 200, как кнопка «В корзину».

**Контраст.** Бейдж `#9b1c1c` на `#fde8e8` даёт около 6,9 к 1. Серая цена `#4b5563` на белом около 7,6 к 1. Пересчитайте их функцией из урока про доступность, если захотите изменить цвета.

**Регрессия.** Проверки без модификатора доказывают, что старый вид цел. Такой набор проверок стоит держать всегда, когда расширяете готовый компонент.
