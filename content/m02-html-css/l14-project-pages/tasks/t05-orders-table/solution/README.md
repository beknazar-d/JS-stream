# Разбор

**Что делает настоящая таблица.** Элемент `table` и его части (`thead`, `tbody`, `th`, `td`) передают браузеру структуру: у ячейки есть строка и колонка, а у колонки заголовок. Скринридер читает ячейку вместе с заголовком: «Сумма, 12 480 ₽». Скрытый `caption` называет таблицу целиком. Атрибут `scope` указывает, к чему относится заголовок: `col` к колонке, `row` к строке.

**Как сохранён вид.**
- `table-layout: fixed` берёт ширины колонок из ячеек первой строки, как это делал `grid-template-columns`. Колонка клиента получает остаток.
- `border-collapse: collapse` склеивает рамки ячеек. Без него между ними остаются зазоры, и линии разорваны.
- Высоту строки задаёт `height` у ячеек: у `tr` она работает хуже.
- Ширина колонки задана вместе с отступами (`box-sizing: border-box`): иначе колонка шире на 24 px.
- `th` по умолчанию жирный и выровнен по центру, поэтому `font-weight` и `text-align` заданы явно.

**Прокрутка.** Контейнеру нужен `tabindex="0"`: без него клавиатурный пользователь не сможет прокрутить таблицу стрелками. `role="region"` и `aria-label` называют область. Таблице нужна собственная минимальная ширина, иначе она сожмётся вместо прокрутки.

**Работа над рефакторингом.** Структура поменялась полностью, а проверки внешнего вида остались теми же и всё время были зелёными. Это и есть критерий: поведение прежнее, устройство лучше.
