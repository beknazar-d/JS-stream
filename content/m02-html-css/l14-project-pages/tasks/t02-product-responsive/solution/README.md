# Разбор

Фиксированные размеры заменены на гибкие, десктопная раскладка вынесена в медиазапрос.

- Ширина `min(960px, calc(100% - 32px))`: на широком экране 960, на узком окно минус по 16 с краёв.
- Картинка `width: 100%` с `aspect-ratio: 4 / 3`: высота выводится из ширины. На 1024 колонка 480 даёт 360, как раньше.
- Подход mobile-first: базовые правила описывают телефон, а `@media (min-width: ...)` добавляют возможности для широких экранов. Так проще: на узких экранах работает то, что написано без условий.
- `min-width: 900px` включает две колонки ровно с 900, а `min-width: 600px` возвращает крупный заголовок и узкую кнопку.

`overflow-x: hidden` не лечит проблему: он лишь прячет полосу прокрутки, а часть содержимого пользователь больше не увидит.
