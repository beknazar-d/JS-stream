## Контекст

Тикет SHOP-492. Стили каталога «Домотеки» писались быстро. Селекторы вроде `#catalog .grid .card.hot .t` длинные и жёсткие: чтобы поменять цвет названия, приходится искать, где ещё этот селектор переопределяется. Новый разработчик боится что-либо менять. Нужно переписать их по БЭМ, а внешний вид оставить как есть.

Это рефакторинг (refactor): поведение и вид не меняются, меняется только устройство кода. Проверки внешнего вида в задании уже есть и проходят на заготовке. После вашей правки они обязаны проходить так же.

## Цель

Перепишите разметку и стили каталога по БЭМ: блок `product-card` с элементами и модификатором скидки. Внешний вид не должен измениться.

## Критерии приёмки

- Каждая карточка — блок `product-card`. Элементы: `product-card__image`, `product-card__title`, `product-card__price`, `product-card__button`.
- Старая цена — `product-card__price product-card__price--old`.
- Карточка со скидкой — `product-card product-card--sale`: модификатор добавляется к блоку, а не заменяет его.
- Каждый селектор в `styles.css` — один класс (вид `.блок`, `.блок__элемент`, `.блок--модификатор`), без идентификаторов, без вложенных цепочек и без `!important`. Допустимо также правило для `body`.
- Модификатор скидки не требует отдельных правил для вложенных элементов: цвет названия и кнопки зависит от модификатора через переменные CSS.
- Атрибуты `data-card`, `data-image`, `data-title`, `data-price`, `data-old-price` и `data-button` остаются: по ним тесты находят элементы.
- Прежние проверки внешнего вида проходят: раскладка в три колонки с зазором 16px, шрифты, цвета, отступы, зачёркнутая старая цена.

## Ограничения

- Классы-обёртки для сетки и страницы называйте тоже по БЭМ (например, `catalog` и `catalog__list`).
- Не добавляйте inline-стили.
- Не меняйте значения свойств, только устройство селекторов.
