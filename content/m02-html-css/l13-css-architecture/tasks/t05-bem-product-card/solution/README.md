# Разбор

**Что было не так.** Каждое правило начиналось с `#catalog .grid .card`. Такой селектор привязан к месту в разметке и весит `1-2-0` или больше. Чтобы переопределить его, нужен ещё более тяжёлый селектор. Состояние «скидка» размазано по четырём правилам с цепочками `.card.hot .t`, `.card.hot a.b`.

**Как устроено после.**

- Блок `product-card` самостоятелен: он не знает, где лежит на странице. Его можно переместить в другой каталог, и он выглядит так же.
- Элементы называются `product-card__image`, `__title`, `__price`, `__button`. Имя говорит, чья это часть.
- Вариант «скидка» это модификатор блока: `product-card--sale`. В разметке он дополняет блок, а не заменяет его.
- Правила состоят из одного класса, поэтому у них одинаковый вес `0-1-0`, и порядок в файле читается как порядок приоритета.

**Как модификатор меняет вложенные элементы без вложенных селекторов.** Блок задаёт переменные `--product-card-accent` и `--product-card-title`. Модификатор `--sale` меняет их значения. Элементы читают переменные через `var()`. Правило для кнопки одно, цвет приходит из блока. Переменные CSS наследуются, поэтому вложенные элементы получают значение от ближайшего родителя.

**Порядок работы при рефакторинге.**

1. Убедитесь, что проверки внешнего вида проходят до правок.
2. Меняйте по одному блоку и запускайте проверки после каждого шага.
3. Не меняйте значения свойств и разметку одновременно.

Если после правки проверка внешнего вида упала, значит, вы потеряли правило или изменили вид. Верните последний рабочий шаг.
