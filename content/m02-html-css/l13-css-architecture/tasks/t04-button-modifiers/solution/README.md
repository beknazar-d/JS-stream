# Разбор

Причина всех трёх симптомов одна: селектор `#catalog .btn` весит `1-1-0`. Любой класс весит `0-1-0`, поэтому модификаторы проигрывают базовому правилу, что бы в них ни было написано.

`!important` у `.btn--small` лишь прикрывал проблему. Он заставил одно свойство работать, но теперь `.btn--wide` не может его переопределить: правила с `!important` побеждают обычные при любой специфичности.

Исправление:

1. `#catalog .btn` становится `.btn`. Теперь у базового класса и у модификаторов одинаковый вес `0-1-0`.
2. `!important` убран.
3. Порядок в файле: сначала `.btn`, потом модификаторы. При равных весах побеждает более поздний, поэтому модификатор перекрывает базу, а `.btn--wide` (после `.btn--small`) перекрывает маленькие отступы.

Общее правило БЭМ: все селекторы компонентов состоят из одного класса. Тогда стили предсказуемы, а порядок в файле читается сверху вниз: сначала общее, потом частное.

Идентификатор `id="catalog"` в разметке можно оставить: он нужен для якорей и скриптов. В стилях он не нужен.
