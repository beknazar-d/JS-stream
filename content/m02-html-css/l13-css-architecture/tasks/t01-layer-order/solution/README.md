# Разбор

Порядок слоёв задаётся одной строкой, и дальше правила получают приоритет по слою, а не по специфичности:

```css
@layer reset, components, utilities;
```

Слой справа побеждает слой слева. Поэтому:

- сброс (`reset`) идёт первым: любой компонент его перекроет, даже если селектор у сброса точнее;
- компоненты идут вторыми;
- утилиты (`utilities`) идут последними: простой селектор `.u-hidden` побеждает громоздкий `.card .btn.btn--primary`.

Что важно знать:

- Внутри одного слоя работают обычные правила: специфичность, затем порядок в файле.
- Правила вне слоёв (unlayered) побеждают любые слои. Поэтому в проектах со слоями в слои кладут всё.
- Объявление `@layer reset, components, utilities;` в первой строке фиксирует порядок один раз. Блоки ниже можно писать в любом порядке и даже в разных файлах.

Слои заменяют `!important` в самой частой его роли: «эта утилита должна победить любой компонент».
