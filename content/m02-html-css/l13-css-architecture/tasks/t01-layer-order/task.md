## Контекст

Тикет SHOP-471. В карточке товара «Домотеки» кнопка «Сообщить о поступлении» должна скрываться служебным классом `.u-hidden`. Класс не работает: правило компонента `.card .btn.btn--primary` точнее и перебивает утилиту `display: none`. Раньше такое чинили словом `!important`. Теперь команда решила использовать слои каскада (cascade layers).

Слой — это именованная группа правил. Слои идут в заданном порядке, и последний слой побеждает предыдущий независимо от специфичности селекторов.

## Цель

Разложите правила в `styles.css` по трём слоям: сброс (`reset`), компоненты (`components`) и утилиты (`utilities`). Объявите порядок слоёв одной строкой в начале файла.

## Критерии приёмки

- В начале `styles.css` одно объявление порядка слоёв: `@layer reset, components, utilities;`.
- Каждая группа правил обёрнута в свой слой: `@layer имя { ... }`.
- Кнопка с классами `btn btn--primary u-hidden` скрыта (`display: none`).
- Заголовок с классами `card__title u-mt-16` имеет верхний отступ 16px, хотя в компоненте у него `margin: 0 0 8px`.
- Кнопка `.btn` сохраняет отступы `8px 16px`, хотя в сбросе для `button` стоит `padding: 0`.
- В файле нет `!important`.

## Ограничения

- Менять нужно только `styles.css`, значения свойств оставьте как есть.
- Не повышайте специфичность и не используйте `!important`: задача решается только порядком слоёв.
