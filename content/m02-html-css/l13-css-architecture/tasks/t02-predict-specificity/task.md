## Контекст

В стилях «Домотеки» накопились селекторы вроде `#catalog .card .btn:hover`. Новый разработчик не понимает, почему кнопка не меняет цвет. Прежде чем разбирать стили, нужно уметь взвешивать селекторы вручную. Код в `snippet.js` делает это по правилам CSS: считает веса и выбирает победителя.

Вес записывается тройкой: сколько в селекторе идентификаторов (id), классов (с атрибутами и псевдоклассами) и тегов. Сравнивают слева направо.

## Цель

Прочитайте код из `snippet.js`. Запишите в `answer.js` в массив `output` шесть строк: ровно то, что код выведет в консоль, по одной строке на каждый вызов `console.log`.

## Критерии приёмки

- В массиве `output` ровно шесть строк в порядке вызовов.
- Каждый элемент — строка, например `"0-1-0"` или `".btn"`.
- Ответ совпадает с реальным выводом кода построчно.

## Ограничения

- Не меняйте `snippet.js`.
- Сначала предскажите, потом сверьтесь с проверкой.
- Помните: один id весит больше любого числа классов, а при равных весах побеждает правило, которое объявлено позже.
