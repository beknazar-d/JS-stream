# Разбор

1. `.btn`: один класс, вес `0-1-0`.
2. `#catalog .card .btn:hover`: один id, три класса (`.card`, `.btn` и псевдокласс `:hover`), тегов нет. Вес `1-3-0`.
3. `ul li a`: три тега, вес `0-0-3`.
4. `#catalog .btn` против `.card .btn.btn--primary`: у первого `1-1-0`, у второго `0-3-0`. Сравнение идёт слева направо: 1 больше 0, второй селектор даже не рассматривают. Побеждает `#catalog .btn`. Именно так id в селекторах ломают модификаторы.
5. `.btn.btn--accent` и `.btn.btn--ghost`: оба `0-2-0`. Веса равны, побеждает объявленный позже: `.btn.btn--ghost`.
6. `a.link` весит `0-1-1`, `.link:hover` весит `0-2-0`. Второй сильнее по числу классов, хотя у первого есть тег.

Вывод: тройку не складывают в одно число. Один id весит больше любого количества классов, а один класс больше любого количества тегов.
