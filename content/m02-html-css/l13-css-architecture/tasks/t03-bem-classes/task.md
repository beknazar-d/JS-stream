## Контекст

Тикет SHOP-478. В «Домотеке» карточки товаров, кнопки и бейджи собираются из шаблонов, и классы по БЭМ каждый пишет вручную: `product-card product-card--sale`. Одни забывают базовый класс, другие путают `--` и `__`. Нужна функция, которая строит строку классов по правилам БЭМ.

БЭМ (BEM) расшифровывается как блок, элемент, модификатор: `блок__элемент--модификатор`. Блок самостоятельный (`product-card`). Элемент — часть блока (`product-card__title`). Модификатор — вариант внешнего вида или состояние (`product-card--sale`).

## Цель

Реализуйте в `index.js` функцию `bem(block, element, modifiers)`. Она возвращает строку классов для HTML-атрибута `class`.

## Критерии приёмки

- `bem('product-card')` возвращает `'product-card'`.
- `bem('product-card', 'title')` возвращает `'product-card__title'`.
- Пустой элемент (`null`, `undefined`, `''`) означает «сам блок»: `bem('btn', null)` возвращает `'btn'`.
- Модификатор со значением `true` добавляет класс `блок--имя`, а базовый класс остаётся первым: `bem('product-card', null, { sale: true })` возвращает `'product-card product-card--sale'`.
- Модификатор со строкой или числом добавляет `блок--имя-значение`: `bem('btn', null, { size: 'small' })` возвращает `'btn btn--size-small'`. Значение `0` допустимо: `{ quantity: 0 }` даёт `btn--quantity-0`.
- Модификаторы со значением `false`, `null`, `undefined` и `''` пропускаются.
- Для элемента модификатор строится от имени элемента: `bem('product-card', 'price', { old: true })` возвращает `'product-card__price product-card__price--old'`.
- Порядок модификаторов в результате совпадает с порядком в объекте. Классы разделены одним пробелом, пробелов в начале и в конце нет.
- Пустое имя блока (не строка или пустая строка) приводит к исключению `Error` с текстом «Нужно имя блока».

## Ограничения

- Только встроенные средства языка.
- Имена не преобразуются: функция не меняет регистр и не вычищает символы.
