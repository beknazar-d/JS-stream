# Разбор

Функция в три шага.

1. Проверка входа: имя блока обязательно. Ошибку лучше бросить сразу, чем получить класс `undefined--sale` в разметке.
2. Базовое имя: `block` или `block__element`. Пустой элемент (`null`, `undefined`, `''`) ложен, поэтому условие `element ? ... : block` работает для всех трёх.
3. Модификаторы: `Object.entries` отдаёт пары «имя, значение» в порядке объекта. Пропускаем четыре значения явно, а не через проверку на истинность: иначе число `0` исчезнет, а оно допустимое значение.

Базовый класс всегда первый. Модификатор в БЭМ дополняет блок: в разметке нужны оба класса, `product-card product-card--sale`. Стили модификатора переопределяют только отличия.

Запись `modifiers ?? {}` позволяет не передавать третий аргумент.
