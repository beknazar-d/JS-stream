# Разбор

**Подход.** Рефакторинг делают маленькими шагами с зелёными проверками. Здесь проверки внешнего вида работают на трёх ширинах. Любая потерянная строка CSS проявится как упавший тест, а не как жалоба пользователя.

**Слои.** Порядок `reset`, `base`, `components`, `utilities` читается как «от общего к частному». Сброс самый слабый, утилиты самые сильные. Благодаря этому не нужны `!important` и тяжёлые селекторы: `.u-hidden` побеждает `display: flex` у карточки только потому, что лежит в более позднем слое.

**Адаптив внутри слоя.** Медиазапросы лежат внутри `@layer components`, рядом с блоками. Если вынести их наружу, они окажутся вне слоёв и победят всё. Правило запоминается так: в проекте со слоями вне слоёв лежит только объявление их порядка.

**БЭМ.** Один блок — одна ответственность: `site-header`, `catalog`, `product-card`, `site-footer`. Селекторы плоские. Состояние «скидка» выражено модификатором и переменными, поэтому у кнопки и названия нет собственных правил для скидки.

**Утилиты вместо `style` и `!important`.** `u-mt-24` и `u-mt-32` — маленькие одноцелевые классы. Они лежат в последнем слое, и им не нужно усиление.

**Что не менялось.** Значения свойств остались теми же. Поэтому визуальные проверки прошли без правок, а это и есть признак корректного рефакторинга.
