# Разбор

Список уровней: `1, 2, 4, 2, 3, 1, 3`. В нём семь заголовков.

`findJumps` сравнивает соседние уровни и записывает переход, только если уровень вырос больше чем на 1:

- от 1 к 2: рост на 1, это нормально;
- от 2 к 4: рост на 2, пропущен `h3`, запись `"h2 -> h4"`;
- от 4 к 2 и от 3 к 1: спуск, пропуском не считается;
- от 2 к 3: рост на 1;
- от 1 к 3: рост на 2, запись `"h1 -> h3"`.

Поэтому массив пропусков содержит две записи, а его длина равна `2`.

Единиц в списке две, значит лишний `h1` один. Для списка `[1, 2, 3]` лишних нет, и результат `0`.

Практический вывод: возврат на уровень выше (с `h4` на `h2`) допустим, а вот прыжок вглубь через уровень делает структуру страницы дырявой для скринридера.
