## Контекст

Для проверки страниц каталога в «Домотеке» написана небольшая функция. Она получает уровни заголовков страницы в порядке появления (`1` значит `h1`, `2` значит `h2`) и находит два типичных дефекта: пропуск уровня и лишние `h1`. Прежде чем доверять ей, надо понять, что она выводит.

## Цель

Прочитайте код из `snippet.js`. Запишите в `answer.js` в массив `output` пять строк: именно то, что код выведет в консоль, по одной на каждый вызов `console.log`.

## Критерии приёмки

- В `output` ровно пять строк в порядке вызовов `console.log`.
- Каждый элемент — строка. Массив, который выводит код, записывайте так, как его покажет консоль: `["h1 -> h3"]`.
- Ответ совпадает с реальным выводом построчно.

## Ограничения

- Не меняйте `snippet.js`.
- Сначала предскажите, потом сверяйтесь.
