# Разбор

Карта страницы:

- `body` содержит три ориентира: `header`, `main`, `footer`.
- В `main` лежат два независимых по смыслу блока: `article` с товаром и `aside` с похожими товарами. Товар можно вынуть из страницы и он сохранит смысл, поэтому это `article`. Похожие товары без товара бессмысленны, поэтому это `aside`.
- Внутри товара `figure` и `figcaption` связывают фото с подписью. `alt` описывает картинку для тех, кто её не видит, а `figcaption` — подпись для всех. Тексты у них разные.
- Характеристики — список, потому что это набор равноправных пунктов.
- Отзывы — вложенные `article`: каждый отзыв самостоятелен. Автор — `h3`, потому что отзывы лежат внутри раздела `h2`.
- Дата в `time` с `datetime="2026-03-14"`: человек видит «14 марта 2026», а программа получает дату в машинном формате ISO.
- Цена в абзаце: отдельного тега для цены в HTML нет, и это нормально.

Заголовки образуют план: h1 «Холодильник», h2 «Описание», h2 «Отзывы», h3 «Марина К.», h3 «Игорь С.», h2 «Похожие товары». Пропусков нет.
