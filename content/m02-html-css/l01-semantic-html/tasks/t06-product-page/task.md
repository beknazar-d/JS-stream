## Контекст

Тикет SHOP-171. Нужна разметка страницы товара «Холодильник Atlant XM 4421». Дизайнер ещё рисует макет, поэтому сначала верстальщик отдаёт чистую семантическую разметку без стилей. Позже на неё повесят оформление.

Содержимое страницы передал контент-менеджер.

**Шапка.** Название магазина «Домотека» (ссылка на `/`). Меню: «Каталог» (`/catalog`), «Корзина» (`/cart`), «Контакты» (`/contacts`).

**Товар.** Название «Холодильник Atlant XM 4421». Фото `fridge.jpg` с подписью «Atlant XM 4421, вид спереди». Цена «41 990 ₽». Характеристики: «Объём 312 л», «Класс A+», «Высота 186 см», «No Frost». Кнопка «Добавить в корзину».

**Раздел «Описание».** Абзац: «Двухкамерный холодильник с системой No Frost. Не требует разморозки, тихо работает».

**Раздел «Отзывы».** Два отзыва: автор «Марина К.», дата 14 марта 2026, текст «Тихий, вместительный, доставили вовремя»; автор «Игорь С.», дата 2 апреля 2026, текст «Дверь пришлось перевесить, в остальном без нареканий».

**Рядом с товаром.** Блок «Похожие товары» со ссылками: «Atlant XM 4424» (`/catalog/4424`), «Indesit DF 4180» (`/catalog/4180`), «LG GA-B419» (`/catalog/b419`).

**Подвал.** Строка «© Домотека, 2026» и ссылка «Политика конфиденциальности» (`/privacy`).

## Цель

Разметьте страницу в `index.html` семантическими тегами. Стили писать не нужно.

## Критерии приёмки

- Структура: `header` с `nav`, один `main`, `footer`; блок «Похожие товары» — `aside` внутри `main`.
- Товар — один `article` с заголовком `h1`. Фото лежит в `figure` с подписью `figcaption`, у картинки есть `alt`.
- Характеристики — список `ul` из четырёх пунктов. Кнопка — `button` с `type="button"`.
- «Описание» и «Отзывы» — `section` с заголовками `h2`. Каждый отзыв — отдельный `article` с заголовком `h3` (автор), датой в теге `time` с атрибутом `datetime` и текстом в абзаце.
- «Похожие товары» — заголовок `h2` и список ссылок.
- Заголовки идут без пропусков, `h1` на странице один.
- Все ссылки ведут по указанным адресам, нет ссылок на `#`.
- У меню есть имя через `aria-label`.
- Все тексты из описания присутствуют.

## Ограничения

- Только `index.html`.
- `div` использовать не нужно.
