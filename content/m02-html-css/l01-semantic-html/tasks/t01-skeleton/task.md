## Контекст

Тикет SHOP-110. Команда начинает новую страницу каталога «Домотеки» и просит заранее набрать каркас страницы. Вёрстка и стили будут потом, сейчас нужен только правильный скелет из семантических тегов.

## Цель

Впишите в `index.html` внутрь `body` разметку страницы по памяти. Содержимое такое:

- шапка сайта с названием «Домотека» и главным меню из трёх ссылок: «Каталог» (`/catalog`), «Доставка» (`/delivery`), «Контакты» (`/contacts`);
- основная часть с заголовком первого уровня «Холодильники» и одним абзацем текста;
- подвал со строкой «© Домотека».

## Критерии приёмки

- Шапка, основная часть и подвал размечены тегами `header`, `main` и `footer` и лежат прямо в `body`.
- Меню — тег `nav` внутри шапки. У меню есть имя через `aria-label`, например «Основное меню».
- Три ссылки меню лежат в списке `ul`, каждая в своём `li`, и ведут по указанным адресам.
- На странице ровно один `h1`, он лежит в `main` и содержит текст «Холодильники».
- Порядок в документе: шапка, основная часть, подвал.

## Ограничения

- Теги `div` и `span` не нужны.
- Стили писать не требуется.
