# Разбор

Каркас страницы — три тега прямо в `body`: `header`, `main`, `footer`. Каждый из них — ориентир (landmark): скринридер даёт перейти к нему одной клавишей.

Меню — это `nav`. Внутри него ссылки лежат в списке `ul`: скринридер объявит «список, 3 пункта», и человек сразу поймёт размер меню. `aria-label` даёт меню имя. Когда на странице одно меню, имя необязательно, но когда появится второе (например, в подвале), без имён их не различить.

`h1` на странице один, он называет страницу и лежит в `main`. Название магазина в шапке — обычный абзац или ссылка на главную, не заголовок.

Дополнительного оформления не нужно: теги уже несут смысл без единой строки CSS.
