# Разбор

Правило выбора: если элемент **делает что-то на этой странице** (кладёт в корзину, раскрывает блок), это `button`. Если он **ведёт на другой адрес**, это `a` с настоящим `href`.

- `.buy` стал `button type="button"`. Тип `button` нужен, чтобы кнопка не отправляла форму, если когда-нибудь окажется внутри неё.
- `.specs-toggle` был ссылкой `href="#"`. Такая ссылка никуда не ведёт, а при клике прыгает наверх страницы. Это действие, значит кнопка.
- `.back` стал `a href="/catalog"`: появились открытие в новой вкладке, копирование адреса и фокус с клавиатуры.
- `alt` описывает, что на фото: покупатель со скринридером узнаёт, что он выбирает.

Стили не менялись, потому что они привязаны к классам. Для `button` в CSS уже стоят `border: 0` и `font: inherit`, поэтому выглядит кнопка так же, как раньше `div`.

Почему не `role="button"` и `tabindex="0"`: так придётся самому добавлять обработку Enter и Пробела. Тег `button` получает фокус и реакцию на клавиши бесплатно.
