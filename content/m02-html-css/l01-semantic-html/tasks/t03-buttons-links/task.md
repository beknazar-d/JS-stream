## Контекст

Баг-репорт A11Y-31 по карточке товара «Чайник Домотека T-200». Покупатель, который ходит по сайту только с клавиатуры, не может добавить товар в корзину: по Tab фокус перескакивает через «Добавить в корзину». Скринридер читает «Вернуться в каталог» как обычный текст, а картинку чайника не описывает вовсе.

Разработчик собрал страницу из `div` и `span` и там, где не хватало тега, нарисовал нужное стилями.

## Цель

Исправьте разметку в `index.html`: у каждого элемента должен быть тег, который соответствует его работе. Классы менять нельзя, стили в `styles.css` рассчитаны на них.

## Критерии приёмки

- Элемент `.buy` («Добавить в корзину») — `button` с `type="button"`.
- Элемент `.back` («Вернуться в каталог») — ссылка `a` с адресом `/catalog`.
- Элемент `.specs-toggle` («Показать характеристики») — `button` с `type="button"`: он только раскрывает блок на странице и никуда не ведёт.
- У картинки `.photo` есть описание в `alt`, не короче пяти символов.
- Тексты элементов не изменились.
- На странице нет ссылок с адресом `#` и нет элементов с атрибутом `data-href`.

## Ограничения

- Не добавляйте `tabindex` и `role`: для этого есть правильные теги.
- Классы элементов сохраните.
