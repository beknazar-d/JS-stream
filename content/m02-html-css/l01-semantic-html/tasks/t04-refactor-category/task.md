## Контекст

Тикет SHOP-142. Страницу категории «Стиральные машины» когда-то собрали целиком из `div`. Она выглядит нормально, но поисковик не понимает, где у неё главное содержимое, а скринридер читает её как сплошную простыню без ориентиров.

## Цель

Перепишите разметку в `index.html` на семантические теги. Текст на странице должен остаться тем же, а внешний вид не важен: стили в `styles.css` в этом задании не проверяются.

## Критерии приёмки

- Шапка — `header`, внутри неё `nav` со списком из трёх ссылок (`ul` и `li`).
- Основная часть — один `main`. В нём заголовок `h1` «Стиральные машины».
- Три товара лежат в списке `ul`, каждый товар в `li`, внутри `li` — `article` с заголовком `h2` (название модели) и абзацами для описания и цены.
- Совет «Как выбрать» — `aside` с заголовком `h2` и абзацами.
- Подвал — `footer`.
- Все исходные тексты страницы остались на месте.
- В разметке остаётся не больше одного `div`.

## Ограничения

- Менять только `index.html`.
- Названия моделей, цены и ссылки не менять.
