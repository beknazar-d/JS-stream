# Разбор

Идея рефакторинга: содержимое страницы не меняется, меняются только теги. Работаем сверху вниз.

- Верхний блок стал `header`, меню — `nav` со списком `ul`: меню — это список ссылок.
- `content` стал `main`. Заголовок страницы — `h1`.
- Товары — список независимых карточек. Каждую карточку можно вынуть и показать отдельно (в поиске, в рассылке), поэтому это `article` в `li` внутри `ul`.
- Название модели — `h2`, потому что оно на уровень ниже названия страницы. Абзацы описания и цены — `p`.
- «Как выбрать» — побочный совет, не основное содержимое: `aside`.
- Нижний блок стал `footer`.

Классы оставлены, и стили продолжают работать. Размер заголовка `h1` задан классом `big-title`, поэтому внешний вид не поменялся. Заметьте: уровень заголовка выбирается по месту в структуре, а не по размеру шрифта.

Сколько `div` осталось: ни одного. Если бы для вёрстки понадобилась обёртка, один `div` разрешён.
