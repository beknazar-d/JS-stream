## Контекст

Баг-репорт SEO-17. Страница «Посудомоечные машины» плохо ранжируется. Аудит показал: на странице нет нормальной структуры заголовков. Логотип в шапке оформлен как `h1`, а название страницы — как `h3`, потому что «так получался нужный размер шрифта». Дальше уровни идут вперемешку: после `h3` сразу `h5`, потом `h4`.

## Цель

Исправьте уровни заголовков в `index.html` так, чтобы они отражали структуру страницы. Внешний вид должен остаться прежним: размеры шрифтов, которые сейчас получаются, нужно сохранить. Для этого размеры придётся перенести из селекторов по тегам в селекторы по классам.

## Критерии приёмки

- На странице один `h1`: название страницы «Посудомоечные машины».
- Логотип «Домотека» больше не заголовок.
- Разделы «Популярные модели» и «Встраиваемые» — `h2`, названия моделей внутри разделов — `h3`.
- Заголовки идут без пропусков уровней: после `h1` идёт `h2`, после `h2` идёт `h3` или следующий `h2`.
- Размеры шрифта прежние: `.logo` — 14px, `.page-title` — 28px, `.section-title` — 20px, `.product-title` — 16px.
- Тексты заголовков не менялись.

## Ограничения

- Классы `logo`, `page-title`, `section-title`, `product-title` сохранить.
- Размеры шрифта должны задаваться по классам, не по тегам `h1`–`h6`.
