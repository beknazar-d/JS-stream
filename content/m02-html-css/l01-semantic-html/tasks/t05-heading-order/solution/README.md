# Разбор

Причина бага: уровень заголовка выбрали по размеру шрифта, потому что стили писались на теги (`h1 { font-size: 14px }`). Чтобы получить нужный размер, подставляли подходящий тег.

Правильный порядок: сначала план страницы, потом теги.

1. Название страницы — `h1`.
2. Разделы — `h2`.
3. Модели внутри разделов — `h3`.
4. Логотип — не заголовок, он не называет раздел страницы. Он стал обычным абзацем.

После смены тегов селекторы `h1`, `h3`, `h4`, `h5` вешали бы размеры не на те элементы. Поэтому размеры переехали на классы: `.page-title`, `.section-title`, `.product-title`, `.logo`. Теперь внешний вид от тега не зависит, и уровень можно менять, не трогая дизайн.

Отступы у `h1`, `h2`, `h3` и `p` в браузере по умолчанию свои. Строка `h1, h2, h3, p { margin: 0 }` их сбрасывает, а нужные отступы задают классы.
