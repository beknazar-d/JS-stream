# Разбор

Идея: один проход по очереди раскладывает заказы в два новых списка. Исходные `queue` и `urgent` только читаются.

1. Дубли. Перед раскладкой проверяем, не лежит ли номер уже в одном из списков. Так остаётся первое вхождение. Проверка стоит в начале, поэтому она работает и для срочных, и для обычных.
2. Срочные номера, которых нет в очереди, не попадают в план сами: мы идём по очереди, а `urgent` используем только как справочник через `includes`.
3. Порядок: срочные идут в порядке очереди, потому что цикл идёт по очереди. Потом в тот же список добавляются обычные.
4. Смена. `slice(0, capacity)` берёт первые заказы, `slice(capacity)` — остаток. Для `capacity` равного `0` первый кусок пустой, для большого — второй. Исключений для этих случаев писать не нужно.

Метод `includes` сравнивает через `===`, поэтому номера должны быть строками одного формата.
