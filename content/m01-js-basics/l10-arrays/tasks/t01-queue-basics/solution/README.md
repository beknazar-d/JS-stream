# Разбор

- `push` добавляет элемент в конец и сразу возвращает новую длину массива, поэтому отдельный `return queue.length` не нужен.
- `shift` убирает первый элемент и возвращает его. Для пустого массива он вернёт `undefined`, а по условию нужен `null`. Оператор `??` подменяет `undefined` (и `null`) значением справа.
- `at(-1)` читает последний элемент и ничего не меняет. Для пустого массива тоже даёт `undefined`, поэтому снова `?? null`.

Как это связано с прошлым: `null` здесь означает «заказа нет, и это нормально», а `undefined` — «ничего не положили». Для вызывающего кода единый `null` проще проверять.
