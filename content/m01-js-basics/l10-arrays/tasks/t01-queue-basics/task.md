## Контекст

Склад интернет-магазина собирает заказы по очереди: первым пришёл, первым собран. Очередь хранится массивом номеров заказов, например `["A-101", "A-102"]`. Сборщику нужны три простых действия, и вы напишете их по памяти, без подсказок в тексте урока.

## Цель

Допишите в `index.js` три функции:

- `addOrder(queue, orderId)` ставит заказ в конец очереди и возвращает новую длину очереди;
- `takeNextOrder(queue)` убирает из очереди первый заказ и возвращает его;
- `lastOrder(queue)` возвращает последний заказ, не убирая его из очереди.

## Критерии приёмки

- `addOrder(["A-101"], "A-102")` возвращает `2`, а сама очередь становится `["A-101", "A-102"]`.
- `takeNextOrder(["A-101", "A-102"])` возвращает `"A-101"`, а в очереди остаётся `["A-102"]`.
- `lastOrder(["A-101", "A-102"])` возвращает `"A-102"`, очередь не меняется.
- Для пустой очереди `takeNextOrder` и `lastOrder` возвращают `null`.
- Функции работают с переданным массивом, а не с его копией: `addOrder` и `takeNextOrder` меняют очередь на месте.

## Ограничения

- Менять только тела функций.
- Не создавайте новых массивов: очередь общая, её видят другие части системы.
