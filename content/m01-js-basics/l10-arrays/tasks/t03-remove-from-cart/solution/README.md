# Разбор

Причина бага: `indexOf` не нашёл `GLOVE-03` и вернул `-1`. Первый аргумент `splice` может быть отрицательным, тогда он считается с конца, поэтому `splice(-1, 1)` удалил последний элемент. Ошибки не было, и баг остался тихим.

Исправление: проверить индекс до удаления. Для `-1` возвращаем `false` и ничего не трогаем.

Заметьте, что проверять нужно именно `-1`, а не «индекс больше нуля»: первый элемент имеет индекс `0`, и это правильный результат поиска.
