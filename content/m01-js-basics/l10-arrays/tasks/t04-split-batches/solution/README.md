# Разбор

Цикл идёт не по элементам, а по начальным индексам: `0`, `size`, `2 * size` и так далее, пока начало партии не вышло за конец очереди.

На каждом шаге `slice(start, start + size)` копирует кусок. Если до конца осталось меньше `size` элементов, `slice` просто возвращает всё, что есть: ошибки за границей массива не будет. Поэтому последняя неполная партия получается сама.

Для пустой очереди условие `0 < 0` сразу ложно, цикл не выполняется, результат `[]`.

`slice` не меняет оригинал. Это то, чего не гарантирует `splice`.
