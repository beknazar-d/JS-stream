# Разбор

1. `picked.slice(1, 3)` копирует элементы с индексами 1 и 2: `["A-2", "A-3"]`. Элемент с индексом 3 не входит. Массив не меняется.
2. `picked.length` равно `4`: после `slice` ничего не убавилось.
3. `picked.splice(1, 2)` вырезает два элемента с индекса 1 и возвращает их: `["A-2", "A-3"]`.
4. Теперь в `picked` остались `["A-1", "A-4"]`. Именно здесь `splice` отличается от `slice`.
5. `A-3` уже вырезан, поэтому `indexOf` возвращает `-1`.
6. `push("A-9")` добавляет элемент и возвращает новую длину: было 2, стало `3`.
7. `at(-1)` читает последний элемент: `A-9`.
