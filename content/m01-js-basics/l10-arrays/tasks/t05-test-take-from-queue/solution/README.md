# Разбор

Хорошие тесты проверяют места, где функция может сломаться. Здесь их три.

1. **Остаток.** Если проверять только `taken`, потерянный элемент в `rest` останется незамеченным. Нужен тест, который сверяет `rest` целиком.
2. **Отрицательное количество.** `slice(0, -2)` не пустой набор, а «все, кроме двух последних». Поэтому нужен тест на `-2`, а не только на `0`.
3. **Исходная очередь.** Функция, вырезающая заказы через `splice`, возвращает правильные `taken` и `rest`. Единственный способ её поймать — после вызова посмотреть на саму очередь.

Тесты проверяют только результат и состояние очереди и не зависят от того, как функция написана внутри.
