## Зачем это в работе

Тикет от склада интернет-магазина. Сборщик нажал «убрать из корзины» на товаре, которого в корзине не было. Система молча удалила последний товар. Покупатель потерял кепку, а в логах ни одной ошибки.

Другой тикет: на складе очередь заказов. Менеджеру нужно показать первые два заказа, не трогая саму очередь. После его кода очередь стала короче, и два заказа пропали.

Оба случая про массивы. Массив (array) — самая частая структура данных: корзина, очередь, список заказов, остатки по дням. В этом уроке вы научитесь создавать массивы, читать и менять их элементы и не путать методы, которые копируют, с методами, которые портят оригинал.

```js
const cart = ["кроссовки", "носки", "кепка"];
console.log(cart.length);
```

```text
3
```

## Объяснение

Массив — это пронумерованный список значений. Значения лежат в порядке, в котором вы их положили. Каждое значение называется элементом (element), а его номер — индексом (index).

Аналогия: ряд почтовых ящиков в подъезде. Ящики стоят подряд, и у каждого есть номер. Чтобы достать письмо, нужно знать номер. Важная странность: нумерация начинается с нуля. Первый ящик — номер 0, второй — номер 1.

Массив создают квадратными скобками: `["кроссовки", "носки", "кепка"]`. Пустой массив — `[]`. В массиве могут лежать значения любых типов, но в работе в одном массиве обычно хранят однотипные значения.

Что нужно знать сначала:

- `cart[0]` — элемент с индексом 0, то есть первый.
- `cart.length` — длина (length), сколько в массиве элементов. Это свойство, а не вызов: скобки после `length` не нужны.
- Последний элемент лежит по индексу `cart.length - 1`. Короче: `cart.at(-1)`. Отрицательный индекс метода `at` считается с конца.
- Если индекса нет, JavaScript не падает, а возвращает `undefined`.

Четыре метода меняют массив на месте. Говорят, что они мутируют (mutate) массив, то есть изменяют сам массив, а не создают новый:

- `push(x)` добавляет элемент в конец и возвращает новую длину;
- `pop()` убирает последний элемент и возвращает его;
- `shift()` убирает первый элемент и возвращает его;
- `unshift(x)` добавляет элемент в начало и возвращает новую длину.

Запомнить просто: очередь заказов. Новый заказ встаёт в конец (`push`), а сборщик берёт заказ с начала (`shift`).

Кстати, слово `const` не запрещает менять содержимое массива. Оно запрещает только присвоить переменной другой массив. `cart.push("шапка")` с `const` работает, а `cart = []` — нет.

## Пример

Теперь самое важное различие урока. У массивов есть два похожих метода: `slice` и `splice`. Названия отличаются одной буквой, а поведение — принципиально.

- `slice(от, до)` копирует кусок. Исходный массив не меняется. Элемент с индексом `до` в кусок не входит.
- `splice(от, сколько)` вырезает кусок из самого массива. Массив становится короче.

Запустите пример и посмотрите на очередь после каждого вызова.

<Playground example="slice-vs-splice" />

После `slice` очередь осталась из четырёх заказов. После `splice` в ней осталось два. Вырезанные заказы вернулись в `removed`, но из очереди они пропали.

Правило: если нужен кусок, а оригинал должен остаться целым, берите `slice`.

<Wrong>

```js
// Показать первые два заказа
const preview = queue.splice(0, 2);
// queue теперь короче на два заказа
```

</Wrong>

<Right>

```js
// Показать первые два заказа
const preview = queue.slice(0, 2);
// queue не изменилась
```

</Right>

## Как это работает

Посмотрите на схему. Над ячейками стоят обычные индексы, под ячейками — отрицательные для `at`.

<Figure src="array-indexes.svg" alt="Массив из трёх ячеек: кроссовки, носки, кепка. Над ячейками индексы 0, 1, 2. Под ячейками индексы для метода at: минус 3, минус 2, минус 1. За последней ячейкой пунктиром показан индекс 3: там пусто, результат undefined." caption="Нумерация с нуля. Последний индекс на единицу меньше длины. Индекс за границей даёт undefined, а не ошибку." />

Теперь поиск и перебор.

- `includes(x)` отвечает на вопрос «есть ли такой элемент»: `true` или `false`.
- `indexOf(x)` возвращает индекс первого найденного элемента. Если элемента нет, вернёт `-1`.
- `for (const item of cart)` обходит все элементы по очереди. Индекс при этом не нужен.

<Playground example="search-and-loop" />

Число `-1` — это особый сигнал «не найдено». Это важно для `splice`. У `splice` первый аргумент тоже может быть отрицательным: он считается с конца. Поэтому `cart.splice(-1, 1)` удаляет последний элемент. Если передать в `splice` результат `indexOf` и ничего не проверить, то при ненайденном товаре удалится последний. Это ровно баг из начала урока.

```js
const cart = ["кроссовки", "носки", "кепка"];
const index = cart.indexOf("шарф"); // -1
cart.splice(index, 1);              // удалил «кепку»
```

Всегда проверяйте `index === -1` до вызова `splice`.

<Note>

Копировать массив целиком можно так: `cart.slice()`. Без аргументов `slice` возвращает копию всего массива. Присваивание `const other = cart` копию не создаёт: обе переменные указывают на один и тот же массив. Подробно про это в уроке про объекты.

</Note>

Ещё две мелочи. `includes` и `indexOf` сравнивают через `===`, как в первом уроке. Поэтому в массиве чисел `[1, 2, 3].includes("2")` даёт `false`: строка `"2"` — не число `2`. И длину можно читать после изменения: `cart.length` всегда актуальна.

## Типичные ошибки

Все сообщения ниже получены запуском в Node.js 22. Браузер на движке V8 (Chrome, Edge) пишет их так же.

**1. Массива нет, а метод вызвали.**

<Wrong>

```js
let cart;
cart.push("кепка");
```

</Wrong>

```text
TypeError: Cannot read properties of undefined (reading 'push')
```

Переменная `cart` пуста (`undefined`), у неё нет методов. Создайте массив: `let cart = [];`.

**2. Взяли элемент из пустого массива и сразу обратились к его свойству.**

<Wrong>

```js
const cart = [];
console.log(cart[0].name);
```

</Wrong>

```text
TypeError: Cannot read properties of undefined (reading 'name')
```

`cart[0]` для пустого массива равно `undefined`, а у `undefined` нет свойства `name`. Сначала проверьте `cart.length`.

**3. Присвоили `const`-переменной новый массив.**

<Wrong>

```js
const cart = ["кепка"];
cart = [];
```

</Wrong>

```text
TypeError: Assignment to constant variable.
```

Чтобы очистить корзину, не нужно новое присваивание. Либо объявите `let`, либо используйте `cart.length = 0`.

**4. Метод массива вызвали у строки.**

<Wrong>

```js
const cart = "кепка";
cart.push("носки");
```

</Wrong>

```text
TypeError: cart.push is not a function
```

Так бывает, когда из формы пришла строка вместо массива. Проверьте, что в переменной лежит: `Array.isArray(cart)` вернёт `true` только для массива.

**5. Тихая ошибка: `splice(-1, 1)`.** Сообщения нет, удалился не тот товар.

<Wrong>

```js
const cart = ["кроссовки", "носки", "кепка"];
cart.splice(cart.indexOf("шарф"), 1);
console.log(cart);
```

</Wrong>

```text
["кроссовки", "носки"]
```

<Right>

```js
const index = cart.indexOf("шарф");
if (index !== -1) {
  cart.splice(index, 1);
}
```

</Right>

## Итог

Что вы теперь умеете:

- создавать массив и читать элементы по индексу, включая `at(-1)`;
- менять массив через `push`, `pop`, `shift`, `unshift` и помнить, что они мутируют его;

- искать через `includes` и `indexOf` и проверять `-1`;
- обходить массив через `for...of`.

Массив хранит значения по номеру. Но заказ — это не просто строка. У него есть номер, статус, сумма и клиент. В следующем уроке мы познакомимся с объектами: они хранят значения не по номеру, а по имени.
