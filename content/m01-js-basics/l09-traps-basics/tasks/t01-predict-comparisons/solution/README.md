# Разбор

1. `0 == ""` — двойное равно приводит оба значения к числу: `""` становится `0`. Результат `true`.
2. `null == undefined` — особое правило двойного равно: эти два значения равны только друг другу. Результат `true`.
3. `null === undefined` — строгое равенство не приводит типы, а типы разные. Результат `false`.
4. `"5" + 3 + 2` — плюс идёт слева направо. `"5" + 3` даёт строку `"53"`, затем `"53" + 2` даёт `"532"`.
5. `5 + 3 + "2"` — сначала `5 + 3` складывает числа в `8`, затем `8 + "2"` склеивает: `"82"`.
6. `"10" < "9"` — две строки сравниваются как текст по первому различающемуся символу. `"1"` меньше `"9"`, поэтому `true`.
7. `NaN == NaN` — `NaN` не равен ничему, даже самому себе. Результат `false`.
8. `Number("12px") + 1` — из `"12px"` число не получается, `Number` даёт `NaN`, а арифметика с `NaN` снова даёт `NaN`.
