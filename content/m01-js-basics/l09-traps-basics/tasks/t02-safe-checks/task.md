## Контекст

После недели багов команда договорилась завести общие маленькие функции-проверки без ловушек и пользоваться только ими. Сейчас нужны три: запасное количество для пустого поля, строгое сравнение и проверка на `NaN`. Это те самые строки из шпаргалки, которые надо знать наизусть.

## Цель

В `index.js` объявите и экспортируйте три функции.

- `quantityOrOne(value)` возвращает `value`, а если значения нет (`null` или `undefined`), то `1`. Ноль и пустая строка — настоящие значения и остаются.
- `sameValue(a, b)` возвращает `true`, только если значения равны без приведения типов.
- `isNotANumber(value)` возвращает `true`, только если `value` — это `NaN`.

## Критерии приёмки

- `quantityOrOne(undefined)` и `quantityOrOne(null)` возвращают `1`; `quantityOrOne(0)` возвращает `0`; `quantityOrOne("")` возвращает `""`.
- `sameValue(5, 5)` возвращает `true`; `sameValue("5", 5)` и `sameValue(0, "")` возвращают `false`.
- `isNotANumber(NaN)` возвращает `true`; `isNotANumber("abc")`, `isNotANumber(undefined)` и `isNotANumber(5)` возвращают `false`.

## Ограничения

- Не используйте `==` и `||` для запасного значения.
- Заготовка пустая: объявите функции с `export` сами.
