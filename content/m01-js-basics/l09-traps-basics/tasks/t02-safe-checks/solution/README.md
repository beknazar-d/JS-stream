# Разбор

1. `value ?? 1` заменяет значение только когда оно `null` или `undefined`. Ноль, пустая строка и `false` остаются. Оператор `||` заменил бы и их.
2. `a === b` сравнивает без приведения типов. Тройное равно честно отвечает, что `0` и `""` разные значения.
3. `Number.isNaN(value)` — единственный надёжный способ проверить `NaN`. Выражение `value === NaN` всегда ложно, потому что `NaN` не равен самому себе. В отличие от глобальной функции `isNaN`, `Number.isNaN` не превращает строку в число: для `"abc"` он вернёт `false`.
