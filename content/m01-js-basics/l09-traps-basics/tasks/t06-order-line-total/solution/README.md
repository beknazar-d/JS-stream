# Разбор

1. Цена и количество превращаются в числа через `Number()`. Пустая строка и `null` дают `0`, поэтому условия `price <= 0` и `quantity < 1` отсеивают и пустые поля. `Number.isFinite` ловит `NaN` и `Infinity`, `Number.isInteger` ловит дроби и `NaN`.
2. Скидка: сначала решаем, заполнено ли поле. Пустое поле — это `undefined`, `null` или строка из пробелов. Именно этот случай нельзя отдать `Number()`: `Number("")` равно `0`, и пустое поле стало бы скидкой 0%. Явное «0» заполнено, поэтому остаётся нулём. Оператор `||` здесь сломал бы ноль.
3. Скидку проверяем после превращения: конечное число от 0 до 100.
4. Остаток: `undefined` и `null` означают «ограничения нет». Остальное — число, целое, не меньше нуля, и количество не должно его превышать. Пустую строку отсеиваем отдельно, иначе она стала бы нулём.
5. Формула считает в конце, когда все данные проверены. `NaN` наружу выйти не может.
