## Контекст

Три функции из модуля цен возвращают не то, что ждёт покупатель, но ошибок в консоли нет. Тикеты от поддержки:

1. «В корзине сумма строки показывается как undefined».
2. «Итого с доставкой тоже undefined, а должно быть сумма плюс 350 рублей, если доставка не указана».
3. «Карточка товара падает: ReferenceError на строке с остатком».

Три разных ловушки в одном файле.

## Цель

Исправьте `index.js` так, чтобы все три функции работали.

- `lineTotal(price, quantity)` возвращает `price * quantity`.
- `withShipping(amount, shipping = 350)` возвращает `amount + shipping`. Если доставку передали нулём, добавляется 0.
- `stockLabel(stock)` возвращает строку вида `Остаток: 5 шт.`.

## Критерии приёмки

- `lineTotal(100, 3)` возвращает `300`.
- `withShipping(1000)` возвращает `1350`, `withShipping(1000, 0)` возвращает `1000`.
- `stockLabel(5)` возвращает `"Остаток: 5 шт."`, `stockLabel(0)` возвращает `"Остаток: 0 шт."`.
- Ни одна из функций не падает с ошибкой и не возвращает `undefined`.

## Ограничения

- Не меняйте имена функций, порядок параметров и значение по умолчанию.
- Не переписывайте функции целиком: в каждой нужно исправить ровно одну ловушку.
