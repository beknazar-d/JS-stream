# Разбор

Три функции, три разных ловушки.

1. `lineTotal`: после `return` стоял перенос строки. JavaScript сам вставил точку с запятой, и функция вернула `undefined`, а `price * quantity` стало отдельным недостижимым выражением. Решение: значение пишется на той же строке, что и `return`.
2. `withShipping`: стрелка с фигурными скобками требует явного `return`. Без него результат вычисляется и теряется. Решение: дописать `return`. Можно было убрать скобки и записать `(amount, shipping = 350) => amount + shipping`. Значение по умолчанию мы не трогали: оно не заменяет ноль, поэтому `withShipping(1000, 0)` даёт 1000.
3. `stockLabel`: константа `unit` объявлена ниже строки, которая её читает. Это временная мёртвая зона, и язык бросает `ReferenceError`. Решение: объявить `unit` до использования, сразу с значением.

В каждом случае ошибка была одна, и общей чертой всех трёх было то, что код выглядел разумно.
