# Разбор

1. `0 || 10` — ноль ложный, оператор `||` берёт правую часть: `10`.
2. `0 ?? 10` — ноль не `null` и не `undefined`, оператор `??` оставляет его: `0`.
3. `"" || "нет заметки"` — пустая строка ложная, берётся `"нет заметки"`.
4. `"" ?? "нет заметки"` — пустая строка остаётся. Шаблонная строка превращает её в пустое место между скобками: `[]`.
5. `discount` не получила значения, это `undefined`. Оператор `??` подставляет `15`.
6. `null ?? undefined ?? 7` — оба первых значения пустые, цепочка доходит до `7`.
7. `NaN ?? 1` — `NaN` не `null` и не `undefined`, поэтому остаётся `NaN`. Оператор `||` заменил бы его.
8. `false || null || "запасной"` — `false` ложный, `null` ложный, берётся последнее значение: `"запасной"`.
