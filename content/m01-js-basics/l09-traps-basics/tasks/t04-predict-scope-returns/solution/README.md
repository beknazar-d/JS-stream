# Разбор

1. Внутри `priceWithMargin` объявлена своя `rate`, равная `0.5`. `1000 * 1.5` даёт `1500`.
2. Внешняя `rate` не изменилась: `0.2`.
3. `lineTotal`: после `return` перенос строки. JavaScript вставляет `;`, функция возвращает `undefined`.
4. `lineTotalArrow` написана с фигурными скобками без `return`: результат потерян, `undefined`.
5. `lineTotalShort` без скобок возвращает выражение сама: `100 * 3` равно `300`.
6. Внутри блока объявлена новая `count`. Она живёт только в блоке и меняется там до 3, а внешняя остаётся `1`.
7. Параметр `status` внутри `changeStatus` — отдельная переменная, в неё скопировано значение внешней. Присваивание меняет только её. Внешняя остаётся `"новый"`.
8. `makeAdder(10)` возвращает функцию, которая помнит `step`, равный 10. Вызов `addTen(5)` даёт `15`.
