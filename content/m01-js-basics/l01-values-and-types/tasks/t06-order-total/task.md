## Контекст

Тикет SHOP-402. Страница оформления заказа считает итог по трём полям формы: цена, количество и скидка по промокоду. Все три поля отдают строки. Сейчас итог считается прямо в обработчике кнопки и иногда показывает `NaN` или склеенные числа. Касса принимает суммы только в копейках целым числом, потому что дробные рубли дают ошибки округления.

## Цель

Реализуйте `calcOrderTotal(form)` в `index.js`. Функция получает объект с полями формы:

```js
{ price: "499.90", quantity: "3", discountPercent: "10" }
```

и возвращает итог заказа в копейках целым числом, либо `null`, если форма заполнена некорректно.

## Критерии приёмки

- Итог для `price: "499.90"`, `quantity: "3"`, `discountPercent: "10"` равен `134973` (1349,73 рубля).
- Итог считается как цена в копейках, умноженная на количество, минус скидка, с округлением до целой копейки по правилам `Math.round`.
- `price`: число больше нуля с точкой как разделителем, не более двух знаков после точки. Пробелы по краям допустимы. `""`, `"0"`, `"-5"`, `"abc"`, `"499,90"` и `"Infinity"` дают `null`.
- `quantity`: целое число не меньше 1. `""`, `"0"`, `"1.5"`, `"-1"`, `"abc"` дают `null`.
- `discountPercent`: целое число от 0 до 100. Пустая строка, строка из пробелов и отсутствующее поле (`undefined`) означают «скидки нет». Значения `"101"`, `"-1"`, `"10.5"`, `"abc"` дают `null`.
- Скидка 100 процентов даёт итог `0`, а не `null`.
- Результат — либо целое число, либо `null`. Значение `NaN` не возвращается ни при каких входных данных.

## Ограничения

- Только встроенные средства языка, без внешних библиотек.
- Результат считается в копейках: сначала переведите цену в копейки и округлите, потому что `19.99 * 100` не равно `1999` (получится `1998.9999999999998`). Для округления используйте `Math.round`.
- Функции подробно разберём дальше в модуле. Объявление уже есть в заготовке, пишите её тело.
