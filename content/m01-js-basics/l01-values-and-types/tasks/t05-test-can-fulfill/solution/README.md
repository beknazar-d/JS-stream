# Разбор

Хорошие тесты проверяют не «функция работает», а места, где она может сломаться. Для `canFulfill` таких мест три.

1. **Граница.** Запрос ровно на весь остаток должен проходить. Ошибка `<` вместо `<=` ловится только тестом `canFulfill(10, 10)`.
2. **Целое количество.** Тесты с `0`, отрицательными числами и дробями (`1.5`, `"2.5"`) ловят потерянную проверку `Number.isInteger`.
3. **Типы.** Данные приходят строками. Два значения `"9"` и `"10"` как текст идут в другом порядке, чем как числа. Только тест `canFulfill("9", "10")` выдаёт ошибку, если сравнение забыло превратить строки в числа.

Тесты проверяют результат функции и не лезут в её устройство, поэтому переживут переписывание реализации.
