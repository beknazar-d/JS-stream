## Контекст

Перед оформлением заказа сайт проверяет, хватает ли товара на складе. Это делает функция `canFulfill(requested, available)`. Количество в заказе и остаток склада приходят из разных источников: иногда числами, иногда строками из форм и выгрузок. Тестов у функции нет, а перед следующим релизом её будут переписывать.

Ваша задача — написать тесты, которые защитят функцию от поломки.

## Цель

Напишите тесты в `index.test.js` для функции `canFulfill` из файла `subject/index.js` (код показан под описанием). Функция работает так:

- возвращает `true`, если запрошено целое число не меньше 1 и оно не больше остатка;
- иначе возвращает `false`;
- количество и остаток могут быть числами или строками с числом.

## Критерии приёмки

- Все ваши тесты проходят на показанной реализации.
- Проверка находит каждую из трёх реализаций с ошибкой: тесты должны падать на каждой.
- В тестах нет ни одной проверки, которая зависит от того, как функция написана внутри: проверяется только результат для входных данных.
- Названия тестов описывают случай на русском языке, например `it('отказывает, если запрошено больше остатка', ...)`.

## Ограничения

- Пишите тесты только в `index.test.js`. Код функции менять нельзя.
- Используйте `describe`, `it` и `expect` без импорта. Из `index.js` импортируйте только `canFulfill`.
- Подумайте о границах (ровно весь остаток), о нулях и дробях, о строках и о нечисловом вводе.
