# Разбор

`Number(value)` и `String(value)` — явные преобразования: вы сами говорите, какой тип нужен. Они ведут себя предсказуемо: `Number("")` даёт `0`, `Number("abc")` даёт `NaN`, `String(null)` даёт `"null"`.

`Number.isNaN(value)` возвращает `true` только для самого значения `NaN` и не приводит тип. Поэтому `Number.isNaN("abc")` даёт `false`. Сравнение `value === NaN` не работает: `NaN` не равен даже себе.

Частые промахи: `parseInt` вместо `Number` (теряет дробную часть, по-другому разбирает пустую строку) и сравнение с `NaN` через `===`.
