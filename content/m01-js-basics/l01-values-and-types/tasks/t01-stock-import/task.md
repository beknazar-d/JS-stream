## Контекст

Склад выгружает остатки в файл, а сайт читает их из текстовых полей. Значения приходят строками: `"40"`, `" 7 "`, `""`. Для подписи на этикетке нужны обратные превращения: артикул, который хранится числом, надо вывести как текст.

Это разминка: наберите три маленькие функции по памяти, без подсказок из урока.

## Цель

Напишите в `index.js` тела трёх функций:

- `toNumber(value)` превращает значение в число явным преобразованием;
- `toText(value)` превращает значение в строку явным преобразованием;
- `isNotANumber(value)` проверяет, что значение — это именно `NaN`.

## Критерии приёмки

- `toNumber("15")` возвращает число `15`, а `toNumber(" 7 ")` возвращает `7`.
- `toNumber("12.5")` возвращает `12.5`.
- `toNumber("")` возвращает `0`, `toNumber("abc")` возвращает `NaN`.
- `toText(1042)` возвращает строку `"1042"`, `toText(null)` возвращает строку `"null"`.
- `isNotANumber(NaN)` возвращает `true`, `isNotANumber(5)` возвращает `false`.
- `isNotANumber("abc")` возвращает `false`: строка не является значением `NaN`.

## Ограничения

- Только встроенные функции `Number`, `String` и `Number.isNaN`.
- Файл `index.js` экспортирует три функции с этими именами. Сами функции подробно разберём дальше в модуле, сейчас пишите только то, что внутри.
