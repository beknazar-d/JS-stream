# Разбор

Причина бага: `line.quantity` — строка. Оператор `+` видит строку и склеивает: `0 + "12"` даёт `"012"`, потом `"012" + "3"` даёт `"0123"`.

Исправление: превратить количество в число до сложения, `Number(line.quantity)`. Затем проверить результат: `Number.isNaN(quantity)`. Если ввод некорректный, строку пропускаем, и `NaN` не попадает в итог.

Почему нельзя обернуть итог в `Number(units)`: к концу цикла строки уже склеены в `"0123"`, и число из неё получается 123, а не 15. Преобразовывать надо до сложения.

Пустая строка `""` превращается в `0`, поэтому отдельная проверка на пустоту не нужна. Пробелы по краям `Number()` отбрасывает сам.
