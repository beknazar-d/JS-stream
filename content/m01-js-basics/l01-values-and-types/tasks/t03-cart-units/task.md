## Контекст

Баг-репорт BUG-2041 от службы поддержки интернет-магазина.

Шаги:

1. Открыть корзину, в которой две строки: кроссовки, количество `12`, и носки, количество `3`.
2. Посмотреть на значок в шапке сайта «Товаров в корзине».

Ожидалось: `15`.

Фактически: `0123`.

Количество в строках корзины приходит из полей формы, поэтому это строки. Функция `countUnits` складывает их и склеивает. Кроме того, пользователи иногда оставляют поле пустым или вводят текст, и такая строка не должна ломать общий счёт.

## Цель

Исправьте `countUnits(lines)` в `index.js`: функция принимает массив строк корзины вида `{ sku: "RUN-42", quantity: "12" }` и возвращает общее число единиц товара.

## Критерии приёмки

- Для строк с количеством `"12"` и `"3"` результат — число `15`, а не строка `"0123"`.
- Результат всегда имеет тип `number`.
- Количество может быть строкой (`"3"`) или числом (`3`). Оба варианта считаются.
- Пустая корзина даёт `0`.
- Пустое поле (`""`) считается как `0`.
- Нечисловой ввод (`"abc"`, `"12 шт"`) не учитывается: строка считается как `0`, итог не превращается в `NaN`.
- Пробелы по краям (`" 4 "`) не мешают.

## Ограничения

- Менять только тело `countUnits`.
- Результат не должен проходить через `Number()` только в самом конце: исправление нужно там, где происходит сложение.
