# Разбор

1. `"40" - 15` даёт `25`. Минус работает только с числами, поэтому строка `"40"` превращается в число.
2. `"40" + 15` даёт `"4015"`. У плюса особое правило: если есть строка, значения склеиваются.
3. `typeof ("40" * 1)` даёт `"number"`. Умножение превращает строку в число, а `typeof` называет тип результата.
4. `Number("12 шт")` даёт `NaN`: в строке есть буквы, число из неё не получить.
5. `Number("")` даёт `0`. Пустая строка превращается в ноль, а не в `NaN`. Это ловушка: пустое поле формы выглядит как нулевой остаток.
6. `"10" === 10` даёт `false`. Строгое сравнение не приводит типы, а тип у значений разный.
