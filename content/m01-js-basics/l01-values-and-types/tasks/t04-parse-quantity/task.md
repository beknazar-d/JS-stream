## Контекст

Тикет SHOP-318. В карточке товара есть поле «Количество». Что бы ни ввёл покупатель, оно отдаёт строку. Сейчас разные части сайта разбирают её по-своему: одни пропускают `"3abc"`, другие превращают пустое поле в `0`. Нужна одна функция, которой будут пользоваться все.

## Цель

Реализуйте `parseQuantity(input)` в `index.js`. Она принимает значение поля и возвращает количество товара целым числом либо `null`, если ввод некорректен.

## Критерии приёмки

- `parseQuantity("3")` возвращает число `3`.
- Пробелы по краям отбрасываются: `parseQuantity("  12 ")` возвращает `12`.
- Ноль допустим: `parseQuantity("0")` возвращает `0` (так покупатель убирает товар из корзины).
- Ведущие нули допустимы: `parseQuantity("007")` возвращает `7`.
- Пустая строка и строка из одних пробелов дают `null`.
- Текст и числа с посторонними символами дают `null`: `"abc"`, `"3abc"`, `"12 шт"`, `"1 2"`.
- Дробные числа дают `null`: `"2.5"`. Запятая как разделитель тоже не поддерживается: `"2,5"` даёт `null`.
- Отрицательные числа дают `null`: `"-3"`.
- Если пришла не строка (`null`, `undefined`, число, объект), результат `null`.
- Результат — либо `number`, либо `null`. Значение `NaN` возвращать нельзя.

## Ограничения

- Допустимые записи: целое число в десятичной записи, например `"15"`. Записи вроде `"1e3"` и `"0x10"` в проверках не участвуют.
- Только встроенные функции языка, без внешних библиотек.
- Функции подробно разберём дальше в модуле. Сейчас достаточно написать тело готовой функции.
