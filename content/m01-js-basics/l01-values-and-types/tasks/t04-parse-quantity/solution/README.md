# Разбор

Решение — цепочка проверок, от самой грубой к самой тонкой.

1. `typeof input !== 'string'`: всё, что не строка, отсеиваем сразу. Без этого `null` превратился бы в `0` через `Number(null)`, а число `5` случайно прошло бы.
2. `input.trim()` и проверка на пустоту. Это обязательно: `Number("")` и `Number("   ")` равны `0`, и пустое поле стало бы нулевым количеством.
3. `Number(text)` разбирает строку целиком. Для `"3abc"` и `"1 2"` получится `NaN`. Именно поэтому не подходит `parseInt`: он берёт число из начала строки и молча игнорирует остаток.
4. `Number.isInteger(quantity)` отсеивает дробные значения. Он же вернёт `false` для `NaN` и `Infinity`, поэтому проверка `Number.isNaN` здесь запасная, но делает намерение явным.
5. `quantity < 0` отсеивает отрицательные.

Результат либо число, либо `null`, и `NaN` наружу не выходит.
