# Разбор

Три функции, три разные причины. Ни одна не даёт сообщения об ошибке.

1. `if (stock = 0)` присваивает ноль, а не сравнивает. Условие всегда ложно, потому что результатом присваивания стал ноль. Нужен `===`.
2. В `statusText` нет `break`. После нужного `case` выполнение идёт вниз по всем оставшимся, и в `text` остаётся последнее присвоенное значение. Для `"new"` это «Неизвестный статус». Поставьте `break` после каждого варианта.
3. `if (stock)` считает ноль «пустым значением». Остаток 0 — настоящее число. Сначала явно отделяем отсутствие данных (`undefined` или `null`), потом ноль, потом всё остальное.
