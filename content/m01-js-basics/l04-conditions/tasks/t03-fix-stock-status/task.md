## Контекст

Баг-репорт BUG-2311 по трём местам карточки заказа:

1. Для распроданного товара отметка «Распродано» не показывается никогда.
2. Статус заказа `new` показывается как «Отправлен». Остальные статусы тоже съехали.
3. Товар с остатком `0` подписан «Нет данных» вместо «Нет в наличии».

В консоли ошибок нет, во всех трёх случаях работает не та ветка.

## Цель

Исправьте функции в `index.js`:

- `isSoldOut(stock)` возвращает `true`, если остаток равен нулю, иначе `false`;
- `statusText(status)` возвращает подпись статуса: `"new"` даёт `"Новый"`, `"paid"` даёт `"Оплачен"`, `"shipped"` даёт `"Отправлен"`, любой другой даёт `"Неизвестный статус"`;
- `describeStock(stock)` возвращает подпись остатка: `undefined` и `null` дают `"Нет данных"`, `0` даёт `"Нет в наличии"`, положительное число даёт `"В наличии: "` и число.

## Критерии приёмки

- `isSoldOut(0)` возвращает `true`, `isSoldOut(7)` возвращает `false`.
- `statusText("new")` возвращает `"Новый"`, `statusText("paid")` возвращает `"Оплачен"`.
- `describeStock(5)` возвращает `"В наличии: 5"`, `describeStock(undefined)` возвращает `"Нет данных"`.
- `describeStock(0)` возвращает `"Нет в наличии"`, `describeStock(null)` возвращает `"Нет данных"`.

## Ограничения

- Менять нужно только тела функций.
- Структуру `switch` в `statusText` сохраните.
