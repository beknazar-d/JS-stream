# Разбор

**`validateBooking`.** Сначала значения из формы превращаются в числа. Дальше проверки идут в порядке из тикета, и каждая заканчивается ранним выходом. Благодаря этому из нескольких ошибок возвращается первая, и вложенности нет.

- `Number.isInteger(guestCount)` ложно и для `NaN` (из `"abc"`), и для `1.5`. Пустая строка превращается в `0` и отсекается условием `guestCount < 1`.
- Ночи проверяются диапазоном 1–30 тоже вместе с целостностью.
- `"Максимум гостей: " + capacity`: плюс со строкой склеивает.
- `daysUntilCheckIn < 0`: ноль (заезд сегодня) допустим.
- Если ни одна проверка не сработала, возвращается `"ok"`.

**`bookingTotal`.** Скидка выбирается цепочкой `if`, `else if`: сначала более узкий и более выгодный случай (14 ночей), потом 7. Если бы порядок был обратным, условие «от 7» сработало бы и для 14 ночей, и скидка 15 процентов никогда бы не применилась. Результат округляется один раз в конце.
