# Разбор

Порядок проверок повторяет порядок правил из тикета, и каждая проверка заканчивается ранним выходом.

1. `!(weightKg > 0)`: сравнение с `NaN` и `undefined` всегда ложно, поэтому запись `!(...)` отсекает и ноль, и отрицательные числа, и «не число». Запись `weightKg <= 0` пропустила бы `NaN`.
2. `switch` выбирает базовую цену. Каждый `case` заканчивается `break`, а `default` сразу возвращает `null`: неизвестная зона отсекается до проверки суммы.
3. `orderSum >= 5000` возвращает `0`. Граница включена (`>=`), потому что в тикете «не меньше 5000».
4. Надбавка за вес выбирается цепочкой `if`, `else if`. Сначала самый узкий случай (свыше 25 кг), потом свыше 10. Границы строгие (`>`), потому что «свыше».
5. Результат — базовая цена плюс надбавка.
