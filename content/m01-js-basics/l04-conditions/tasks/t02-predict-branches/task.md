## Контекст

Стажёр написал две маленькие функции: одна подписывает значения, пришедшие из формы, другая считает срок доставки по зоне. Он запускал код только с «удобными» значениями. Вам нужно предсказать поведение на трудных: нуле, строке `"0"`, пустой строке и зоне без `break`.

## Цель

Прочитайте код из `snippet.js`. Запишите в `answer.js` в массив `output` восемь строк: ровно то, что код выведет в консоль, по одной строке на каждый вызов `console.log`.

## Критерии приёмки

- В массиве `output` ровно восемь строк в порядке вызовов `console.log`.
- Каждый элемент — строка, например `"ложь"` или `"2"`, а не число.
- Ответ совпадает с реальным выводом кода построчно.

## Ограничения

- Не меняйте `snippet.js`.
- Не пытайтесь вычислить ответ запуском: сначала предскажите, потом сверьтесь с проверкой.
