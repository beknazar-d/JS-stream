# Разбор

1. `label(0)`: ноль ложный, условие не срабатывает, функция доходит до последнего `return`. Ответ `ложь`.
2. `label("0")`: строка с символом нуля непустая, а значит истинная. Ответ `истина`.
3. `label("")`: пустая строка ложная. Ответ `ложь`.
4. `label(NaN)`: `NaN` ложный. Ответ `ложь`.
5. `zoneDays("A")`: `days` становится `1`, но `break` нет, и выполнение проваливается в `case "B"`, где `days` становится `2`. Там `break`. Ответ `2`.
6. `zoneDays("B")`: сразу `days = 2` и `break`. Ответ `2`.
7. `zoneDays("Z")`: ни один `case` не подошёл, срабатывает `default`. Ответ `9`.
8. `5 > 3` истинно, поэтому тернарный оператор берёт значение «да». Ответ `много`.
