## Контекст

В карточке товара три мелких выбора: срок доставки по зоне, подпись по остатку и название тарифа. Каждый удобнее записать своей формой условия.

Это разминка: наберите три функции по памяти, без подсказок из урока.

## Цель

Напишите в `index.js` тела трёх функций:

- `deliveryDays(zone)` возвращает срок доставки в днях по коду зоны. Используйте `switch`: зона `"A"` даёт `1`, `"B"` даёт `2`, `"C"` даёт `4`, любая другая даёт `7`;
- `stockLabel(stock)` возвращает подпись по остатку. Используйте `if`, `else if` и `else`: остаток `0` даёт `"Нет в наличии"`, от `1` до `5` включительно даёт `"Мало"`, больше `5` даёт `"В наличии"`;
- `serviceName(isExpress)` возвращает `"Экспресс"` для `true` и `"Обычная"` для `false`. Используйте тернарный оператор.

## Критерии приёмки

- `deliveryDays("A")` возвращает `1`, `deliveryDays("B")` возвращает `2`, `deliveryDays("C")` возвращает `4`, `deliveryDays("X")` возвращает `7`.
- `stockLabel(0)` возвращает `"Нет в наличии"`, `stockLabel(5)` возвращает `"Мало"`, `stockLabel(6)` возвращает `"В наличии"`.
- `serviceName(true)` возвращает `"Экспресс"`, `serviceName(false)` возвращает `"Обычная"`.

## Ограничения

- Другие формы условий вместо указанных не используйте: цель разминки в том, чтобы набрать каждую по памяти.
