# Разбор

1. `switch` подходит для готового набора кодов. Каждый `case` заканчивается `return`, поэтому провала в следующий вариант нет. `default` ловит все остальные коды.
2. `if`, `else if`, `else` подходит для диапазонов. Порядок важен: сначала самый узкий случай (`0`), потом «до 5 включительно», в `else` остаётся всё остальное. Граница `<= 5` включает пятёрку.
3. Тернарный оператор `условие ? значение1 : значение2` выбирает из двух значений и сам является выражением, поэтому его можно сразу вернуть.
