# Разбор

**Проверка входа первой.** Условие `!Number.isInteger(days) || days < 0` отсекает дроби, `NaN`, строки и минус. Без неё цикл с отрицательным числом просто не выполнится, и функция вернёт дату без ошибки.

**Копия.** `new Date(start)` создаёт независимую дату. Цикл двигает копию, а `start` остаётся нетронутым.

**Счёт по одному дню.** Цикл сдвигает дату на сутки и считает только подходящие дни. Так выходные в середине срока и праздники пропускаются сами, а специальных формул для недель не нужно. Цикл конечный: каждые семь дней добавляется хотя бы один рабочий день, если только `holidays` не содержит все дни подряд.

**День недели.** `getUTCDay()` возвращает 0 для воскресенья и 6 для субботы. Праздники сравниваются строками `YYYY-MM-DD`: у дат нет надёжного оператора равенства, а у строк есть.

**Старт на выходной.** Суббота плюс один рабочий день: воскресенье не считается, понедельник считается. Получается понедельник, правило особого случая не нужно.
