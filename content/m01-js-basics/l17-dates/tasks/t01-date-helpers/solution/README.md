# Разбор

`Date.UTC(year, month - 1, day)` возвращает метку времени (число миллисекунд с 1 января 1970 года по UTC). Вычитание единицы нужно потому, что в `Date` январь равен `0`. День месяца при этом считается с единицы.

`toISOString()` всегда даёт запись в UTC вида `2025-03-05T00:00:00.000Z`. Первые десять символов и есть день.

В `addDays` сначала делается копия: `new Date(date)`. Затем `setUTCDate` с суммой переходит через границу месяца и года сам: 31 января плюс один день даёт 1 февраля. Копия нужна, потому что `Date` изменяемый, и метод `set...` правит объект на месте.
