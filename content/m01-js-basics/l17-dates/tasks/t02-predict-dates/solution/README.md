# Разбор

1. Январь в `Date` — это `0`, поэтому `getUTCMonth()` вернёт `0`.
2. `toISOString()` печатает дату в UTC с буквой `Z` на конце.
3. `setUTCDate(32)` для января переходит на 1 февраля. Копия `next` изменилась, а `d` нет.
4. В 2025 году в феврале 28 дней, поэтому «29 февраля» превращается в `2025-03-01`. Именно так клиент из тикета получил курьера 1 марта.
5. Вычитание двух дат даёт разницу в миллисекундах: сутки — `86400000`.
6. Две отдельные даты — это два объекта. Оператор `===` сравнивает ссылки и даёт `false`, даже если время одинаковое.
7. Сравнение чисел `getTime()` даёт `true`: время совпадает.
8. Строка `'abc'` даёт Invalid Date, у которого `getTime()` равно `NaN`. Проверка `Number.isNaN` даёт `true`.
