# Разбор

Исходный код делал три ошибки.

1. Части текста оставались строками, и `new Date(год, месяц, день)` получал месяц «03» как номер 3, то есть апрель.
2. Конструктор с тремя числами работает в местном часовом поясе компьютера. На компьютере в другом поясе полночь «5 марта» получится другим моментом времени. Для дат без времени используют `Date.UTC`.
3. Не было проверки. `Date` не отказывает на несуществующих датах, а переносит их: `31.04.2025` превращается в 1 мая.

Решение: разобрать части в числа, собрать дату через `Date.UTC(year, month - 1, day)` и проверить, что год, месяц и день в результате совпадают с введёнными. Если дата «съехала», значит, исходная была несуществующей.

Пустая строка даёт одну часть, а `abc` — число `NaN`: оба случая отсекаются раньше. `Number('')` даёт `0`, но `''.split('.')` не даёт трёх частей.
