# Разбор

Ошибки в датах живут на границах, поэтому тесты берут пары моментов, которые отличаются на одну миллисекунду.

1. **Начало последнего дня** (`T00:00:00.000Z`) и **конец последнего дня** (`T23:59:59.999Z`): оба должны дать `false`. Мутант `exclusive-end` ломается на первом.
2. **Начало следующего дня** (`T00:00:00.000Z`): должно дать `true`. Мутант `extra-day` держит код ещё сутки и ломается на этой проверке.
3. **Плохой формат.** Текст, пустая строка и дата в формате `ДД.ММ.ГГГГ` дают ошибку. Без проверки `NaN` в сравнении всегда даёт `false`, то есть «не истёк», и мутант `invalid-ignored` молча принимает мусор.

Время во всех тестах задано строками с буквой `Z`, то есть в UTC. Поэтому результат не зависит ни от часового пояса компьютера, ни от текущего момента. Тест, который берёт `new Date()`, нельзя ни воспроизвести, ни довести до границы суток.
