## Контекст

Диспетчер службы доставки каждое утро открывает список «Что нужно доставить». Для каждого заказа он хочет видеть крайнюю дату доставки по-русски («пятница, 14 марта 2025 г.»), сколько дней осталось и не просрочен ли заказ. Список должен идти от самых срочных заказов. Заказы приходят из разных систем, и в некоторых дата создания испорчена. Один такой заказ не должен ломать весь список: его нужно показать в отдельной таблице ошибок.

В файле `calendar.js` лежат готовые `isWeekend` и `addWorkingDays` из предыдущей задачи (с проверкой срока и праздниками). Пользуйтесь ими.

## Цель

Реализуйте в `index.js` функцию `buildSchedule(orders, today, holidays = [])`.

Заказ: `{ id, createdAt, days }`, где `createdAt` — строка вида `2025-03-06T15:20:00Z`, а `days` — срок в рабочих днях. Срок считается от дня создания (по UTC), время суток не учитывается.

Функция возвращает `{ items, errors }`.

`items` — массив для хороших заказов:

- `id` — номер заказа;
- `deliverBy` — крайний день доставки строкой `YYYY-MM-DD`;
- `label` — тот же день по-русски, через `Intl.DateTimeFormat('ru-RU', { timeZone: 'UTC', weekday: 'long', day: 'numeric', month: 'long', year: 'numeric' })`, например `пятница, 14 марта 2025 г.`;
- `daysLeft` — целое число календарных дней от дня `today` (по UTC, время суток игнорируется) до `deliverBy`; для просроченных оно отрицательное;
- `late` — `true`, если `daysLeft` меньше нуля.

Порядок в `items`: по возрастанию `deliverBy`, при равенстве по возрастанию `id`.

`errors` — массив `{ id, message }` для плохих заказов: `Некорректная дата заказа`, если `createdAt` не строка или не разбирается в дату; для плохого срока — сообщение ошибки из `addWorkingDays`.

## Критерии приёмки

- Заказ, у которого крайний день совпадает с сегодняшним, не считается просроченным, в какое бы время суток ни вызывали функцию.
- Праздники из `holidays` учитываются при расчёте.
- Плохие заказы попадают в `errors` и не мешают остальным.
- Входные данные (`orders`, `today`, `holidays`) не меняются.

## Ограничения

- Не используйте `Date.now()` и `new Date()` без аргументов: текущая дата приходит параметром `today`.
- Не используйте методы без `UTC` в названии (`getDate`, `getHours` и подобные): результат не должен зависеть от часового пояса.
