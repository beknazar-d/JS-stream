# Разбор

1. Шаблон перехода: `function имя(параметры) { return выражение; }` превращается в `const имя = (параметры) => выражение;`. Слово `return` и фигурные скобки исчезают, потому что значение выражения возвращается само.
2. `parcelKind` содержала `if` с двумя `return`. Тернарный оператор из урока 1.4 заменяет их одним выражением, которое можно поставить после стрелки. Скобки вокруг тернарного выражения необязательны, но так читать проще.
3. Значение по умолчанию `percent = 0` остаётся в списке параметров без изменений: стрелки поддерживают его так же, как обычные функции.
4. Проверка `'prototype' in fn` отличает стрелки от `function`: у стрелочных функций такого свойства нет. Это техническая проверка стиля, поведение функций проверяют остальные тесты.
