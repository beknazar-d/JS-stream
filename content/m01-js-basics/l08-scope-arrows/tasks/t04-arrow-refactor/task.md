## Контекст

В файле утилит магазина пять функций написаны по-старому, через `function`. Команда договорилась, что короткие расчёты пишутся стрелками, а там, где в теле одно выражение, используется неявный возврат. Правка должна быть чисто стилистической: результаты функций не меняются.

## Цель

Перепишите все пять функций из `index.js` как стрелочные: `export const имя = (параметры) => ...`. Сохраните имена, порядок параметров и значения по умолчанию.

## Критерии приёмки

- Каждая из пяти функций — стрелочная.
- Результаты не изменились: `vat(500)` даёт `600`, `lineTotal(300, 4)` даёт `1200`, `parcelKind(5)` даёт «Тяжёлая», `orderNumber(42)` даёт «№00042», `discounted(2000)` даёт `2000`, а `discounted(2000, 10)` даёт `1800`.
- Значение по умолчанию у `discounted` сохранено: процент равен 0, если не передан.
- Для `parcelKind` вместо `if` используйте тернарный оператор, чтобы тело стало одним выражением.

## Ограничения

- Не меняйте имена функций и порядок параметров.
- Не добавляйте новых функций.
