# Разбор

1. Внутри `priceFor` объявлена своя `discount`, равная 25. Она закрывает внешнюю. Скидка 25% от 1000 даёт `750`.
2. Внешняя `discount` не менялась: `10`.
3. В блоке `if` объявлена новая `let stock = 100`. Она живёт только внутри блока. Вычитаем 1, получаем `99`.
4. После блока видна внешняя `stock`. Блок её не менял: `5`.
5. `a()` в первый раз: `count` увеличивается с 0 до 1, возвращается `1`.
6. Второй вызов `a()` помнит значение: `2`.
7. `b` создана отдельным вызовом `makeCounter`, у неё своя `count`. Первый вызов даёт `1`.
8. `broken` написана с фигурными скобками без `return`, поэтому результат `undefined`.
9. `works` без скобок возвращает выражение сама: `4 * 2` даёт `8`.
