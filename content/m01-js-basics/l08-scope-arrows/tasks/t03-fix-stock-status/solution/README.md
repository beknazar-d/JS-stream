# Разбор

В исходной функции `const status` объявлялась отдельно в каждой ветке. Ветки `if` — это блоки, и переменная, объявленная в блоке, существует только в нём. Строка `return status` находится снаружи блоков и ищет `status` в области функции. Там её нет, отсюда `ReferenceError: status is not defined`.

Исправление: объявить `let status;` до `if`, в области функции. Тогда блоки видят её как внешнюю и только присваивают значение, а `return` читает ту же переменную. Вместо `const` нужен `let`: значение присваивается позже, после объявления.

Типичная ошибка при исправлении: оставить `const status = ...` в ветках. Тогда внутри блоков снова создаются новые переменные, которые закрывают внешнюю, и внешняя остаётся пустой.
