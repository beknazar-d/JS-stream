# Разбор

Запись `export const имя = (параметры) => выражение;` состоит из четырёх частей: `export const` создаёт и экспортирует переменную, `(параметры)` задают входные значения, стрелка `=>` отделяет параметры от результата, выражение после стрелки возвращается само (неявный возврат).

- `toRubles` — один параметр, результат деление на 100. Копейки сохраняются, потому что деление не округляет.
- `orderTotal` — два параметра, скобки обязательны.
- `freeShipping` — параметров нет, поэтому скобки пустые: `() => 0`.

Если бы мы поставили фигурные скобки, пришлось бы писать `return` самим.
