## Контекст

В утилитах магазина три маленьких расчёта: перевод копеек в рубли для вывода цены, стоимость строки заказа и бесплатная доставка для подарочных сертификатов. Все три принято писать стрелочными функциями.

## Цель

В `index.js` объявите и экспортируйте три стрелочные функции.

- `toRubles(kopecks)` переводит копейки в рубли: `1999` превращается в `19.99`.
- `orderTotal(price, quantity)` возвращает `price * quantity`.
- `freeShipping()` без параметров всегда возвращает `0`.

## Критерии приёмки

- `toRubles(1999)` возвращает `19.99`, `toRubles(500)` возвращает `5`.
- `orderTotal(300, 4)` возвращает `1200`.
- `freeShipping()` возвращает `0`.
- Все три — стрелочные функции (записаны через `=>`).

## Ограничения

- Используйте неявный возврат, где это возможно (без фигурных скобок и `return`).
- Заготовка пустая: объявите функции с `export const` сами.
