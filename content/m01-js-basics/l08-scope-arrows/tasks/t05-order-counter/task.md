## Контекст

Тикет: «Нумерация заказов». Онлайн-магазин начинает нумерацию с 1000, касса в офлайн-точке с 5000. Номера каждой системы идут по порядку, и системы друг на друга не влияют. Сейчас номера хранятся в двух глобальных переменных, и в одном месте кто-то случайно присвоил в них строку. Нужно спрятать счётчик так, чтобы изменить его можно было только вызовом функции.

## Цель

В `index.js` объявите и экспортируйте функцию `createOrderCounter(startFrom = 1)`. Она возвращает новую функцию без параметров. Каждый вызов возвращённой функции возвращает следующий номер заказа. Первый вызов возвращает `startFrom`.

```js
const nextWebOrder = createOrderCounter(1000);
nextWebOrder(); // 1000
nextWebOrder(); // 1001
```

## Критерии приёмки

- Первый вызов возвращает `startFrom`, второй `startFrom + 1`, и так далее.
- Если `startFrom` не передан, нумерация начинается с 1.
- Два счётчика независимы: вызовы одного не меняют другой.
- Текущий номер хранится внутри замыкания: в файле нет переменной на уровне модуля, которая хранит текущий номер.
- Возвращённая функция не принимает аргументов и ничего не печатает.

## Ограничения

- Используйте стрелочную функцию для возвращаемой функции.
- Не используйте глобальные переменные.
