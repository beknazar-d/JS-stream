# Разбор

1. `createOrderCounter(startFrom = 1)` — внешняя функция. Её параметр имеет значение по умолчанию, поэтому без аргумента нумерация идёт с 1.
2. `let current = startFrom - 1` объявлена внутри `createOrderCounter`. Каждый вызов `createOrderCounter` создаёт свою `current`, и два счётчика независимы.
3. Возвращается стрелочная функция без параметров. Она видит `current` из внешней области, потому что вложенная функция видит внешние переменные.
4. Внутри возвращённой функции `current++` увеличивает значение, `return current` отдаёт его. Мы начали с `startFrom - 1`, поэтому после первого увеличения получаем ровно `startFrom`.
5. Когда `createOrderCounter` завершилась, `current` не исчезла: на неё ссылается возвращённая функция. Это замыкание. Снаружи изменить `current` нельзя.
