## Контекст

Тикет: «Акция для постоянных покупателей». Маркетинг запускает две кампании.

1. Купоны: каждой кампании выдаются коды вида `WINTER-0001`, `WINTER-0002`, ... Свой префикс и своя нумерация у каждой кампании, и кампании не должны влиять друг на друга.
2. Бонус за крупный заказ: у каждой кампании свой порог суммы и свой процент скидки. Заказы от порога получают скидку. Сумма приходит из поля формы строкой.

Обе функции нужны как «фабрики»: вы настраиваете кампанию один раз и дальше пользуетесь готовой функцией.

## Цель

В `index.js` объявите и экспортируйте две стрелочные функции.

- `createVoucherIssuer(prefix, startFrom = 1)` возвращает функцию без параметров. Каждый её вызов выдаёт следующий код: префикс, дефис, номер с ведущими нулями до четырёх цифр. Например, `WINTER-0001`.
- `createLoyaltyCalculator(threshold, percent)` возвращает функцию `(amountText)`. Она превращает строку в число и возвращает сумму к оплате: если сумма не меньше `threshold`, применяется скидка `percent` процентов, иначе сумма остаётся прежней. Для неподходящей суммы возвращает `null`.

## Критерии приёмки

- `createVoucherIssuer("WINTER")` выдаёт `"WINTER-0001"`, затем `"WINTER-0002"`.
- `createVoucherIssuer("SPRING", 15)` начинает с `"SPRING-0015"`. Номер длиннее четырёх цифр не обрезается.
- Два выдавателя независимы: выдача кодов одной кампании не сдвигает нумерацию другой.
- `createLoyaltyCalculator(5000, 10)("6000")` возвращает `5400`; `("4999")` возвращает `4999`; `("5000")` возвращает `4500` (порог включительно).
- Сумма с пробелами по краям допустима: `(" 6000 ")`. Числа вместо строк тоже допустимы.
- Для пустой строки, нуля, отрицательного числа, текста и `NaN` возвращается `null`, а не `NaN`.
- Обе экспортируемые функции и обе возвращаемые функции записаны стрелками.

## Ограничения

- Никаких переменных на уровне модуля для хранения номеров.
- Функции ничего не печатают в консоль.
