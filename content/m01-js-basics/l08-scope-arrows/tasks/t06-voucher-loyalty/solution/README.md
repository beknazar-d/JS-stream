# Разбор

1. `createVoucherIssuer` — фабрика: она настраивает кампанию (`prefix`, `startFrom`) и возвращает рабочую функцию. Переменная `next` создаётся при каждом вызове фабрики, поэтому у каждой кампании свой счётчик. Это замыкание.
2. Код формируется до увеличения: сначала запоминаем `code`, потом `next++`. Так первый выданный код соответствует `startFrom`.
3. `padStart(4, '0')` дополняет номер нулями слева. Если номер длиннее, строка не обрезается: `12345` остаётся `12345`.
4. `createLoyaltyCalculator` возвращает стрелку, которая запоминает `threshold` и `percent`. Запись `(a) => (b) => ...` значит «функция, возвращающая функцию». Здесь она выглядит так: настройки принимает первая, ввод — вторая.
5. Внутри вторая функция проверяет ввод так же, как в уроке 1.1: `Number()` и `Number.isNaN`. Пустая строка превращается в `0`, и условие `amount <= 0` отсеивает её вместе с нулём и отрицательными числами.
6. Порог включительный: `amount >= threshold`. Результат либо сумма со скидкой, либо исходная сумма.
