# Разбор

Три функции, три причины. Ни одна не даёт сообщения об ошибке.

1. `raw.trim();` и `raw.toUpperCase();` вернули новые строки, но результат никуда не записан. Исходная строка `raw` не меняется, и функция возвращает её же. Решение: вернуть результат цепочки.
2. `replace` заменяет только первое вхождение. В телефоне пробелов несколько, и дефисов тоже. Нужен `replaceAll`.
3. Подстановка `${id}` работает только в обратных кавычках. В двойных кавычках это обычный текст.
