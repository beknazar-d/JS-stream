## Контекст

Баг-репорт BUG-2402 по трём вспомогательным функциям сайта. Ошибок в консоли нет, но результаты не те:

1. Артикул из формы остаётся строчным и с пробелами, поиск по базе не находит товар.
2. Телефон после «очистки» всё ещё содержит скобки и пробелы, служба доставки не может позвонить.
3. В подписи заказа вместо номера выводится текст `${id}`.

## Цель

Исправьте функции в `index.js`:

- `cleanSku(raw)` возвращает артикул без пробелов по краям и в верхнем регистре;
- `compactPhone(phone)` возвращает телефон без пробелов, дефисов и круглых скобок;
- `orderLabel(id)` возвращает подпись вида `"Заказ №42"`.

## Критерии приёмки

- `cleanSku(" rn-4521-blk")` возвращает `"RN-4521-BLK"`, пробелы справа тоже убираются.
- `compactPhone("+7 (999) 123-45-67")` возвращает `"+79991234567"`.
- `orderLabel(42)` возвращает `"Заказ №42"`.
- Строки, не требующие правки, остаются как есть: `compactPhone("+79991234567")` возвращает то же самое.

## Ограничения

- Менять нужно только тела функций.
- Обратите внимание на то, что методы строк возвращают новую строку.
