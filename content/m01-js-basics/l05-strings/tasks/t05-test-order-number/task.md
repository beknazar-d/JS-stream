## Контекст

Две функции работают с номерами заказов. `formatOrderNumber(sequence, year)` собирает номер вида `ORD-2024-0042` из порядкового номера в течение года и года. `parseOrderNumber(text)` достаёт из номера порядковый номер числом. Тестов нет, а в следующем квартале порядковые номера впервые перевалят за 9999.

Ваша задача — написать тесты, которые защитят обе функции от поломки.

## Цель

Напишите тесты в `index.test.js` для функций из файла `subject/index.js` (код показан под описанием). Функции работают так:

- `formatOrderNumber(7, 2024)` возвращает `"ORD-2024-0007"`: порядковый номер дополняется нулями слева до четырёх цифр. Если цифр больше четырёх, номер не обрезается;
- `parseOrderNumber("ORD-2024-0042")` возвращает число `42`.

## Критерии приёмки

- Все ваши тесты проходят на показанной реализации.
- Тесты падают на каждой из трёх реализаций с ошибкой.
- Тесты проверяют только результат для входных данных, а не устройство функции.
- Названия тестов описывают случай по-русски.

## Ограничения

- Пишите тесты только в `index.test.js`. Код функций менять нельзя.
- Используйте `describe`, `it` и `expect` без импорта. Из `index.js` импортируйте `formatOrderNumber` и `parseOrderNumber`.
- Подумайте о коротких номерах, о номерах длиннее четырёх цифр и о типе, который возвращает `parseOrderNumber`.
