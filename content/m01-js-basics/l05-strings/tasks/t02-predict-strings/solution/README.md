# Разбор

Индексы строки `"RN-4521-BLK"`: `R`=0, `N`=1, `-`=2, `4`=3, `5`=4, `2`=5, `1`=6, `-`=7, `B`=8, `L`=9, `K`=10.

1. `code.length` равен `11`.
2. `code[3]` — символ с индексом 3, то есть `4`.
3. `code.slice(3, 7)` — индексы 3, 4, 5, 6, то есть `4521`. Индекс 7 (дефис) не входит.
4. `code.slice(-3)` — последние три символа, `BLK`.
5. `code.includes("blk")` даёт `false`: в коде заглавные буквы, а поиск различает регистр.
6. После `toLowerCase()` строка стала `"rn-4521-blk"`, и `includes("blk")` даёт `true`.
7. `"7".padStart(3, "0")` — дополнить слева нулями до длины 3, получится `007`.
8. `"a b c".replace(" ", "")` убирает только первый пробел, получается `ab c`.
9. В шаблонной строке сначала вычисляется `5 + 3` равное `8`, затем подставляется: `Итого: 8`.
