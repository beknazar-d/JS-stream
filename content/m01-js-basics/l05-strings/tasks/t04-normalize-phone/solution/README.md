# Разбор

1. Чистка: `trim` убирает края, затем четыре `replaceAll` убирают пробелы, дефисы и обе скобки. Нужен именно `replaceAll`: у `replace` замена одна.
2. Приведение начала. `phone.slice(1)` отбрасывает первую цифру `8`, а `"+7"` ставится вместо неё. Если номер начинается с `7`, достаточно добавить плюс. Номер, который уже начинается с `+7`, не меняется.
3. Проверка. Строка должна начинаться с `+7` и иметь длину 12: плюс, семёрка и десять цифр. Иначе возвращается пустая строка. Номер с кодом `+1` или пустая строка не проходят первое условие, а короткие и длинные номера не проходят второе.
