# Разбор

**`formatPhone`.** Сначала проверка формата ранним выходом: телефон должен начинаться с `+7` и иметь 12 символов. Иначе `"не указан"`. Дальше `slice` режет номер на части по индексам: `+7` (0–1), код (2–4), три цифры (5–7), две (8–9) и последние две (от 10 до конца). Части собираются шаблонной строкой.

**`shippingLabel`.** У каждой строки этикетки своя переменная, это делает код читаемым.

- номер заказа сначала превращается в строку (`String`), потому что `padStart` есть только у строк. Если число длиннее шести символов, `padStart` его не меняет;
- имя очищается `trim()` и поднимается `toUpperCase()`;
- адрес собирается шаблонной строкой, город и улица очищаются `trim()` по отдельности;
- в конце четыре строки склеиваются шаблонной строкой через `\n`.
