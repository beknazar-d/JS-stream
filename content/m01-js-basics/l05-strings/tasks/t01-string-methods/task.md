## Контекст

Четыре мелких функции для склада и службы доставки: привести артикул к виду из базы, подписать заказ шестизначным номером, определить российский телефон и достать год из номера заказа.

Это разминка: наберите функции по памяти, без подсказок из урока.

## Цель

Напишите в `index.js` тела четырёх функций:

- `normalizeSku(raw)` убирает пробелы по краям и делает все буквы заглавными: `" rn-4521-blk "` превращается в `"RN-4521-BLK"`;
- `orderLabel(orderNumber)` возвращает `"№"` и номер заказа, дополненный нулями слева до шести символов: `42` превращается в `"№000042"`;
- `isRussianPhone(phone)` возвращает `true`, если телефон начинается с `+7`, иначе `false`;
- `orderYear(orderNumber)` возвращает год из номера вида `"ORD-2024-0042"`: строку из четырёх символов `"2024"`.

## Критерии приёмки

- `normalizeSku(" rn-4521-blk ")` возвращает `"RN-4521-BLK"`.
- `orderLabel(42)` возвращает `"№000042"`, `orderLabel(123456)` возвращает `"№123456"`.
- `isRussianPhone("+79991234567")` возвращает `true`, `isRussianPhone("+13105550123")` возвращает `false`.
- `orderYear("ORD-2024-0042")` возвращает `"2024"`.

## Ограничения

- Используйте методы строк из урока: `trim`, `toUpperCase`, `padStart`, `startsWith`, `slice`.
- Номер заказа в `orderLabel` приходит числом, а `padStart` есть только у строк.
