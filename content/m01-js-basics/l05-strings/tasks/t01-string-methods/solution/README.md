# Разбор

1. `raw.trim().toUpperCase()`: методы идут цепочкой, каждый получает строку от предыдущего. Результат нужно вернуть, потому что исходная строка не меняется.
2. `String(orderNumber).padStart(6, "0")`: `padStart` есть только у строк, поэтому число сначала превращается в строку. Первый аргумент — итоговая длина, а не количество нулей. Длинный номер не обрезается.
3. `phone.startsWith("+7")` уже возвращает `true` или `false`, `if` не нужен.
4. `orderNumber.slice(4, 8)`: в `"ORD-2024-0042"` год занимает индексы 4, 5, 6, 7. Индекс 8 в кусок не входит.
