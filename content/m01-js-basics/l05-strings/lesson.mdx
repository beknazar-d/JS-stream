## Зачем это в работе

Тикет от склада: «Кладовщик ввёл артикул `rn-4521-blk` с пробелом в конце, а система ответила “Товар не найден”. В базе он лежит как `RN-4521-BLK`».

Для человека это один и тот же артикул. Для программы разные строки:

```js
const typed = " rn-4521-blk ";
const stored = "RN-4521-BLK";
console.log(typed === stored);
console.log(typed.trim().toUpperCase() === stored);
```

```text
false
true
```

Данные из форм почти всегда неаккуратные: лишние пробелы, регистр, скобки в телефоне. Прежде чем сравнивать или искать, текст приводят к единому виду. Для этого и нужны методы строк.

## Объяснение

Строка (string) — это текст в кавычках. Представьте стеллаж с ячейками в один ряд, и в каждой ячейке по одному символу. Ячейки пронумерованы с нуля. Этот номер называется индексом (index). В строке `"RN-45"` символ `R` имеет индекс 0, `N` — индекс 1, `-` — индекс 2.

Кавычки бывают тремя видами: `"двойные"`, `'одинарные'` и `` `обратные` ``. Двойные и одинарные одинаковы. Обратные нужны для шаблонных строк, о них чуть дальше. Спецсимвол `\n` внутри любой строки — переход на новую строку. Чтобы вставить кавычку внутрь такой же, перед ней ставят обратную косую черту: `"Он сказал \"да\""`.

Что можно узнать о строке:

- `text.length` — число символов. Скобок после `length` нет: это свойство, а не вызов;
- `text[0]` — первый символ, `text[text.length - 1]` — последний. Если индекс слишком большой, получится `undefined`;
- `text.includes("abc")` — есть ли внутри такой кусок, `text.startsWith("ORD")` и `text.endsWith("42")` — начинается или заканчивается ли строка им;
- `text.indexOf("-")` — индекс первого найденного куска или `-1`, если его нет.

Как вырезать и менять. Метод (method) — это функция, которая принадлежит значению, её вызывают через точку:

- `text.slice(начало, конец)` — вырезать кусок. Символ с индексом `конец` в кусок не входит. Отрицательное число отсчитывается от конца: `slice(-4)` даёт последние четыре символа;
- `text.trim()` — убрать пробелы по краям;
- `text.toUpperCase()` и `text.toLowerCase()` — заглавные и строчные буквы;
- `text.replaceAll("что", "чем")` — заменить все вхождения;
- `text.padStart(длина, "чем")` — добавить символы слева до нужной длины. Так делают номера вида `000042`.

Главное правило. Строки неизменяемы (immutable). Метод никогда не меняет исходную строку. Он возвращает новую. Если результат не сохранить или не вернуть, он потеряется.

Сборка текста. Шаблонная строка (template literal) пишется в обратных кавычках. Внутри `${выражение}` подставляется значение выражения:

```js
const id = 42;
console.log(`Заказ №${id}`);
```

```text
Заказ №42
```

Она короче и надёжнее, чем склейка плюсом: `"Заказ №" + id`.

Ещё два метода показываем коротко. `text.split(", ")` режет строку по разделителю и возвращает список кусков (массив). `list.join("-")` собирает список обратно в строку. Массивы мы разберём подробно позже, пока важно знать, что эта пара превращает текст в части и обратно.

## Как это работает

Схема показывает, как индексы связаны с `slice`.

<Figure src="string-slice.svg" alt="Строка ORD-2024-0042 разложена по ячейкам с номерами от 0 до 12. Ячейки с номерами от 4 до 7 выделены и подписаны: slice(4, 8) возвращает 2024. Ячейки с номерами от 9 до 12 подписаны: slice(-4) возвращает 0042. Внизу сказано: length равен 13, а последний индекс равен 12." caption="slice(начало, конец): начало входит, конец не входит. Отрицательное число отсчитывается от конца." />

Правила, которые стоит запомнить.

1. Индексы начинаются с нуля. Последний индекс равен `length - 1`.
2. В `slice(a, b)` символ `a` входит, символ `b` нет. Длина куска равна `b - a`.
3. Любой метод строки возвращает новую строку и оставляет старую.
4. `includes`, `startsWith` и `replaceAll` различают регистр: `"ORD".includes("ord")` даёт `false`. Если регистр не важен, сначала приведите обе строки к одному через `toLowerCase()`.
5. Сравнение через `===` тоже различает регистр и пробелы.

Заметка про `replace` и `replaceAll`. Метод `replace` заменяет только первое найденное вхождение, `replaceAll` заменяет все. Для чистки телефона нужен именно `replaceAll`.

<Note>

Строки в JavaScript хранятся в кодировке UTF-16, поэтому для эмодзи и редких символов `length` может быть больше, чем число символов на экране. Для артикулов, номеров заказов и русских слов это не проблема, но помните об этом при подсчёте длины пользовательского текста.

</Note>

## Типичные ошибки

Сообщения получены запуском в Node.js 22.

**1. Скобки после `length`.**

<Wrong>

```js
const sku = "RN-4521";
console.log(sku.length());
```

</Wrong>

```text
TypeError: sku.length is not a function
```

`length` — число, а не функция. Пишите `sku.length` без скобок.

**2. Метод строки вызвали у числа.**

<Wrong>

```js
const n = 42;
console.log(n.padStart(6, "0"));
```

</Wrong>

```text
TypeError: n.padStart is not a function
```

Как и в уроке 1.1: `n` — число, а метод есть у строк. Сначала `String(n)`.

**3. Результат метода потерялся.** Ошибки нет, строка осталась прежней.

<Wrong>

```js
const sku = "rn-4521";
sku.toUpperCase();
console.log(sku);
```

</Wrong>

```text
rn-4521
```

Метод вернул новую строку, а мы её нигде не сохранили. Правильно: `const upper = sku.toUpperCase();` или сразу `return sku.toUpperCase();`.

**4. `replace` вместо `replaceAll`.**

<Wrong>

```js
console.log("8 999 123 45 67".replace(" ", ""));
```

</Wrong>

```text
8999 123 45 67
```

Убран только первый пробел. Остальные остались. Для всех нужен `replaceAll`.

**5. Регистр в поиске.**

<Wrong>

```js
console.log("ORD-2024-0042".includes("ord"));
```

</Wrong>

```text
false
```

Поиск различает регистр. Приведите обе строки к одному виду: `text.toLowerCase().includes("ord")`.

**6. Подстановка в обычных кавычках.**

<Wrong>

```js
const id = 42;
console.log("Заказ №${id}");
```

</Wrong>

```text
Заказ №${id}
```

Подстановка `${...}` работает только в обратных кавычках. В обычных кавычках это просто текст.

**7. Незакрытая кавычка.**

<Wrong>

```js
const city = "Казань;
```

</Wrong>

```text
SyntaxError: Invalid or unexpected token
```

Строка не закрыта, значит, кавычка потерялась. Редактор подсвечивает строку цветом до самого конца: так видно, где она «расползлась».

**8. Кавычки внутри кавычек.**

<Wrong>

```js
const note = "Он сказал "да"";
```

</Wrong>

```text
SyntaxError: Unexpected identifier 'да'
```

Вторая двойная кавычка закрыла строку. Либо экранируйте: `"Он сказал \"да\""`, либо возьмите другие внешние кавычки: `'Он сказал "да"'`.

## Итог

Что вы теперь умеете:

- читать символы по индексу и вырезать куски через `slice`;
- чистить текст через `trim`, менять регистр и заменять куски через `replaceAll`;

До сих пор каждый кусок кода выполнялся один раз. Но склад обрабатывает не один артикул, а тысячи. В следующем уроке разберём циклы: как повторять действие, не копируя код, и как не зациклить программу навсегда.
