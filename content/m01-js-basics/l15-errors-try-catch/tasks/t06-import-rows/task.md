## Контекст

Оптовый партнёр присылает выгрузку заказа: список строк `{ sku, qty }`, где всё записано текстом, потому что файл собран из таблицы. Менеджеру нужен отчёт: какие строки приняты и какие отклонены, причём не по одной ошибке за раз. Сейчас импорт останавливается на первой плохой строке, и менеджер по десять раз перезапускает его.

Есть и вторая сторона. Если справочник товаров недоступен, это уже не «плохая строка», а поломка. Её нельзя записывать в отчёт как «ошибка в строке 3», иначе настоящая причина потеряется.

## Цель

В `index.js` уже есть класс `ValidationError`. Напишите две функции.

`parseRow(row, findProduct)` превращает одну строку выгрузки в позицию. Функция `findProduct(sku)` возвращает товар `{ sku, price }` или `undefined`, если такого артикула нет. Проверки идут по порядку, первая найденная проблема выбрасывает `ValidationError`.

| Проблема | Сообщение |
| --- | --- |
| артикул пустой или состоит из пробелов | `Не указан артикул` |
| количество (текст) не целое число больше нуля | `Количество должно быть целым числом больше нуля` |
| товара с таким артикулом нет | `Неизвестный артикул: A-100` |

Артикул перед использованием очищается от пробелов по краям. Результат успешного разбора: `{ sku, qty, total }`, где `qty` — число, а `total` равен `qty`, умноженному на цену.

`importRows(rows, findProduct)` разбирает все строки и возвращает `{ valid, errors }`:

- `valid` — массив результатов `parseRow` в порядке строк;
- `errors` — массив `{ row, message }`, где `row` — номер строки с единицы, а `message` — сообщение ошибки.

## Критерии приёмки

- Плохие строки не мешают разбору остальных: обрабатываются все строки.
- Количество `'3'`, `' 3 '` принимается, `''`, `'0'`, `'-1'`, `'2.5'`, `'abc'` отклоняется.
- Если `findProduct` выбрасывает не `ValidationError` (например `Error('База товаров недоступна')`), `importRows` пробрасывает эту ошибку дальше, а не записывает в `errors`.
- Строка `null` (баг вызывающего кода) тоже не превращается в запись отчёта: ошибка пробрасывается.
- Пустой список строк даёт `{ valid: [], errors: [] }`.

## Ограничения

- Только `index.js`. Класс `ValidationError` не меняйте.
- Ловите только `ValidationError`: проверяйте тип через `instanceof` и пробрасывайте остальное через `throw error`.
