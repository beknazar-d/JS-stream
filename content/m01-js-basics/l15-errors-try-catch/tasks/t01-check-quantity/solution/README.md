# Разбор

`Number.isInteger(quantity)` возвращает `false` для строки, для `NaN` и для дроби, поэтому одного условия хватает на все плохие входы кроме нуля и отрицательных. Для них добавлено `quantity <= 0`. Обратите внимание: условие описывает *плохой* вход, а `throw` стоит прямо внутри `if`. Так остановка происходит сразу, а «хороший путь» идёт без вложенности.

`throw` прерывает функцию на месте. Строка `return quantity` выполнится, только если ошибки не было.

В `tryQuantity` строка из формы превращается в число через `Number()`, как в первом уроке. Пустая строка даёт `0`, а текст даёт `NaN`: оба случая отсеиваются в `checkQuantity`. Блок `catch` получает объект ошибки, а читаемый текст лежит в `error.message`.

Ловим мы здесь потому, что знаем, что делать: показать сообщение покупателю. Если бы не знали, ошибку лучше пропустить выше.
