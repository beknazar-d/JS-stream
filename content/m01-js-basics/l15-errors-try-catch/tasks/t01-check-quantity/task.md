## Контекст

Форма корзины отдаёт количество товара, и дальше оно идёт в расчёты. Если там `0`, `-3` или `1.5`, сумма заказа получится бессмысленной. Правильное место для проверки — одна функция на входе. Она либо пропускает число, либо останавливает работу с понятным сообщением. Рядом нужна обёртка для формы, которая превращает остановку в сообщение для покупателя.

## Цель

Напишите по памяти два тела в `index.js`.

- `checkQuantity(quantity)`: если `quantity` — целое число больше нуля, возвращает его. Иначе выбрасывает ошибку `Error` с текстом `Количество должно быть целым числом больше нуля`.
- `tryQuantity(text)`: принимает строку из поля формы, превращает её в число и вызывает `checkQuantity`. Возвращает `{ ok: true, value }`, если проверка прошла, и `{ ok: false, error }`, если нет. В `error` лежит текст сообщения ошибки.

## Критерии приёмки

- `checkQuantity(3)` возвращает `3`.
- `checkQuantity(0)`, `checkQuantity(-2)`, `checkQuantity(1.5)` выбрасывают ошибку с текстом из задания, а не возвращают `false`.
- `checkQuantity('3')` (строка) тоже выбрасывает ошибку: функция принимает только числа.
- `tryQuantity('4')` возвращает `{ ok: true, value: 4 }`, `tryQuantity('abc')` и `tryQuantity('')` — `{ ok: false, error: '...' }`.

## Ограничения

- Только `index.js`. В `tryQuantity` используйте `try/catch`.
- Не используйте внешние функции проверки: пишите `throw` сами.
