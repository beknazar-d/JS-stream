## Контекст

В магазине действуют два промокода. `SALE10` даёт скидку 10% с округлением до целого рубля. `MINUS500` уменьшает сумму на 500 рублей, но итог не может уйти ниже нуля. Функция `applyCoupon(total, code)` считает сумму со скидкой и должна ругаться на неизвестный код и на странную сумму. Прошлой весной промокод с опечаткой молча «сработал» без скидки, и клиенты написали больше сотни писем. Тестов нет, а функцию собираются переписывать.

## Цель

Напишите тесты в `index.test.js` для `applyCoupon` из `subject/index.js` (код показан под описанием).

## Критерии приёмки

- Все ваши тесты проходят на показанной реализации.
- Тесты падают на каждой из трёх версий с ошибкой.
- Ошибки проверяются через `expect(() => ...).toThrow(...)` с текстом сообщения.
- Тесты проверяют только результат и ошибки, не устройство функции.
- Названия тестов описывают случай по-русски.

## Ограничения

- Пишите тесты только в `index.test.js`. Код функции менять нельзя.
- Из `index.js` импортируйте только `applyCoupon`.
- Помните: тест на ошибку должен падать, если ошибки *не было*.
