# Разбор

Тесты на ошибки пишутся иначе, чем тесты на значения. Нужно передать функцию в `expect`: `expect(() => applyCoupon(...)).toThrow('текст')`. Тогда проверка сама вызывает код и ловит ошибку. Если ошибки нет, тест падает, и это то, что нам нужно.

Три группы поведения и три мутанта:

1. **Неизвестный код.** Отказ проверяется для опечатки, пустого кода и регистра. Мутант `unknown-code-ignored` возвращает сумму без скидки, и тест на `toThrow` его ловит.
2. **Нижняя граница.** `MINUS500` на `300` и на `500` ровно. Мутант `goes-below-zero` даст `-200`.
3. **Плохая сумма.** Отрицательная, строка и `NaN`. Мутант `accepts-bad-total` пропустит их.

Ошибка теста, которую часто делают: писать `try { код } catch (e) { expect(...) }`. Если код *не* выбросит ошибку, `catch` пропустится, внутри не проверится ничего, и тест останется зелёным. `toThrow` такого не допускает.
