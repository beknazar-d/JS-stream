# Разбор

Выводов в коде больше, чем в ответе: строка `не выведется` не появится. Но по порядку.

1. `старт`: вход в `try`.
2. `reserve(10, 3)` возвращает `7`.
3. `reserve(10, 30)` выбрасывает `StockError`. Выполнение блока `try` прерывается на этой строке. Последний `console.log` в `try` не вызывается.
4. В `catch` попадает объект ошибки. Его `name` равен `StockError` (имя задано в конструкторе), а `message` равен `На складе только 10`.
5. `error instanceof StockError` и `error instanceof Error` оба `true`: свой класс наследует от `Error`. `console.log(true, true)` выводит значения через пробел.
6. `finally` выполняется всегда: и после успеха, и после ошибки. Здесь он печатает `готово`.
7. `String(new Error('x'))` склеивает имя и сообщение: `Error: x`.
