## Контекст

Лог склада: «Резерв списал 7 штук, потом упал на запросе 30, а вот строка „готово“ в консоли всё равно появилась, зато следующая строка исчезла». Новый сотрудник не понимает, почему часть кода выполнилась, а часть нет. Чтобы разобраться, надо проследить, куда идёт управление после `throw`.

## Цель

Прочитайте код из `snippet.js`. Запишите в `answer.js` в массив `output` ровно то, что код выведет в консоль, по одной строке на каждый `console.log`. Значения, которые не строки, записывайте так, как их показывает консоль, например `true true`.

## Критерии приёмки

- В массиве `output` ровно семь строк в порядке вызовов `console.log`.
- Каждый элемент — строка.
- Ответ совпадает с реальным выводом кода построчно.

## Ограничения

- Не меняйте `snippet.js`.
- Не запускайте код до ответа: сначала предскажите, потом сверьтесь с проверкой.
