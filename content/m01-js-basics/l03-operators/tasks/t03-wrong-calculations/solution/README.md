# Разбор

Три разные ловушки, и ни одна не даёт сообщения об ошибке.

1. `discountPercent || 10`. Оператор `||` считает `0` ложным и подставляет 10. Скидка 0 законна, значит, нужен `??`: он подставляет значение по умолчанию только при `null` и `undefined`.
2. `orderSum > 5000`. Знак `>` исключает границу. В акции «от 5000» сама граница входит, поэтому `>=`.
3. `first + second / 2`. Деление выполняется раньше сложения, и выходит `first + (second / 2)`. Для 10 и 20 это `10 + 10 = 20`. Сумму нужно взять в скобки: `(first + second) / 2`.
