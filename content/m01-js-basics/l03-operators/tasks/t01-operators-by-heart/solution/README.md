# Разбор

1. `orderNumber % 2 === 0`. Остаток от деления на 2 равен нулю у чётных чисел и единице у нечётных. Результат сравнения уже `true` или `false`, лишний `if` не нужен.
2. `side ** 3`. Двойная звёздочка — степень. Символ `^` здесь не подходит: в JavaScript это побитовая операция, `3 ^ 3` даёт `0`.
3. `total += Number(delivered)` равносильно `total = total + Number(delivered)`. Значения из формы — строки, поэтому до прибавления они проходят через `Number()`, как в уроке 1.1.
