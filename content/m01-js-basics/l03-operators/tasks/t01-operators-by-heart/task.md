## Контекст

Три мелочи из разных тикетов склада: проверить чётность номера заказа (чётные идут на левый конвейер), посчитать объём коробки-куба и увеличить остаток после поставки. Для каждой нужен свой оператор.

Это разминка: наберите функции по памяти, без подсказок из урока.

## Цель

Напишите в `index.js` тела трёх функций:

- `isEvenOrder(orderNumber)` возвращает `true`, если номер заказа чётный, иначе `false`. Используйте оператор остатка;
- `boxVolume(side)` возвращает объём куба со стороной `side`. Используйте оператор возведения в степень;
- `restock(stock, delivered)` возвращает остаток после поставки. Прибавьте поставку к остатку оператором `+=`.

## Критерии приёмки

- `isEvenOrder(1042)` возвращает `true`, `isEvenOrder(1043)` возвращает `false`.
- `boxVolume(3)` возвращает `27`, `boxVolume(2)` возвращает `8`.
- `restock(40, 5)` возвращает `45`.
- Остаток и поставка могут прийти строками: `restock("40", "5")` возвращает число `45`.

## Ограничения

- Только операторы и `Number()`. Готовые функции вроде `Math.pow` не нужны.
