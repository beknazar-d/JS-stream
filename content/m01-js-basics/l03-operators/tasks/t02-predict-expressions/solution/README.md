# Разбор

1. `47 % 12` даёт `11`: в 47 три раза по 12 (это 36), остаётся 11.
2. `2 + 3 * 4 ** 2`: сначала степень (`4 ** 2` равно 16), потом умножение (`3 * 16` равно 48), потом сложение (`2 + 48`). Итог `50`.
3. `0 || 10` даёт `10`: ноль считается ложным, поэтому берётся правая часть.
4. `0 ?? 10` даёт `0`: оператор `??` подставляет правую часть только при `null` и `undefined`.
5. `"9" > "10"` даёт `true`. Это две строки, они сравниваются по символам: первый символ `"9"` больше первого символа `"1"`. Если бы это были числа, ответ был бы `false`.
6. `null ?? "нет данных"` даёт `"нет данных"`: слева `null`.
7. `stock` было 10, после `+= 5` стало 15, после `*= 2` стало 30.
