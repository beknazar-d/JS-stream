# Разбор

Все четыре функции — по одному выражению.

- `Math.floor(items / perBox)`: деление даёт 3.9166..., `floor` отбрасывает дробную часть вниз и оставляет 3 полные коробки.
- `items % perBox`: остаток от деления — это ровно штуки, которые не поместились в полные коробки.
- `Math.ceil(items / perBox)`: округление вверх. Для 47 и 12 это 4, для 48 и 12 это 4, для 0 это 0. Запись `floor(...) + 1` дала бы лишнюю коробку при ровном делении.
- `items % perBox === 0`: если остатка нет, россыпи нет и последняя коробка полная. Результат сравнения уже `true` или `false`.
