# Разбор

**`sellerPayout`.**

- `commissionPercent ?? 10`: значение по умолчанию подставляется только при `null` и `undefined`. Ноль процентов остаётся нулём. С оператором `||` партнёры без комиссии стали бы платить 10 процентов, потому что ноль «ложный».
- `bonusKopecks ?? 0`: если премия не передана, считаем её нулём. Иначе `undefined` в сложении даст `NaN`.
- Комиссия считается от выручки и сразу округляется до целой копейки через `Math.round`, потому что деньги в копейках не бывают дробными.
- Итог: выручка минус комиссия плюс премия.

**`canPayOut`.** Три условия соединены `&&`: сумма не меньше порога, не выходной, не заблокирован. Отрицание `!` превращает «выходной» в «не выходной». Граница `>=` важна: ровно 100000 копеек выплачивается.
