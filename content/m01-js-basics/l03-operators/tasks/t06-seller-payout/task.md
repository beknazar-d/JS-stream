## Контекст

Тикет MP-58. Маркетплейс выплачивает продавцам деньги за проданные товары. Суммы хранятся в копейках целыми числами. Из выручки удерживается комиссия площадки. Продавцам с хорошим рейтингом добавляется премия.

Правила:

- комиссия в процентах приходит из настроек продавца. Если она не задана (`undefined` или `null`), берётся стандартная: 10 процентов. Ноль процентов задан намеренно (партнёры без комиссии) и должен остаться нулём;
- премия в копейках. Если не задана, она равна нулю;
- выплата равна выручке минус комиссия плюс премия;
- комиссия считается от выручки и округляется до целой копейки через `Math.round`;
- выплата уходит продавцу, только если она не меньше 1000 рублей (100000 копеек), сегодня не выходной и продавец не заблокирован.

## Цель

Реализуйте в `index.js` две функции:

- `sellerPayout(saleKopecks, commissionPercent, bonusKopecks)` возвращает сумму выплаты в копейках;
- `canPayOut(payoutKopecks, isWeekend, isBlocked)` возвращает `true`, если выплату можно отправить сегодня, иначе `false`.

## Критерии приёмки

- `sellerPayout(100000, 10, 5000)` возвращает `95000`.
- Нулевая комиссия остаётся нулём: `sellerPayout(100000, 0, 0)` возвращает `100000`.
- Комиссия по умолчанию: `sellerPayout(100000)` и `sellerPayout(100000, null, null)` возвращают `90000`.
- Дробная комиссия округляется: `sellerPayout(999, 2.5)` возвращает `974` (комиссия 24,975 копейки округляется до 25).
- `canPayOut(100000, false, false)` возвращает `true`.
- `canPayOut(99999, false, false)` возвращает `false`: выплата меньше порога.
- В выходной или для заблокированного продавца `canPayOut` возвращает `false`.

## Ограничения

- Только операторы, `Math.round` и значения по умолчанию через `??`.
- Не используйте `||` для значений по умолчанию: он съест законный ноль.
