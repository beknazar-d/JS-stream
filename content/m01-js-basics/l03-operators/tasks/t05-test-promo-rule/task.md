## Контекст

Функция `canApplyPromo(orderSum, isMember, usedBefore)` решает, можно ли применить промокод «ВЕСНА». Правило из тикета маркетинга:

- сумма заказа не меньше 3000 рублей;
- покупатель состоит в клубе, либо сумма заказа не меньше 10000 рублей;
- этот покупатель ещё не использовал промокод.

Тестов у функции нет, а перед следующим релизом её будут переписывать.

## Цель

Напишите тесты в `index.test.js` для функции `canApplyPromo` из файла `subject/index.js` (код показан под описанием). Функция возвращает `true` или `false` по правилу выше.

## Критерии приёмки

- Все ваши тесты проходят на показанной реализации.
- Тесты падают на каждой из трёх реализаций с ошибкой.
- Тесты проверяют только результат для входных данных, а не устройство функции.
- Названия тестов описывают случай по-русски, например `it('не применяется, если промокод уже использован', ...)`.

## Ограничения

- Пишите тесты только в `index.test.js`. Код функции менять нельзя.
- Используйте `describe`, `it` и `expect` без импорта. Из `index.js` импортируйте только `canApplyPromo`.
- Подумайте о границе ровно в 3000, о покупателе без клуба и о повторном использовании.
