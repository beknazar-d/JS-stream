# Разбор

Правило состоит из трёх условий, соединённых `&&`. Хороший тест проверяет каждое условие отдельно: все остальные выполнены, а проверяемое решает исход.

1. **Граница.** Ошибка «строго больше» видна только на сумме ровно 3000. Значения 2999 и 5000 её не замечают.
2. **Клуб или крупный заказ.** Нужны два случая: не член клуба с суммой между 3000 и 10000 (отказ) и не член клуба с суммой 10000 (согласие). Ошибка «и» вместо «или» замечается тестом на члена клуба со средней суммой: `canApplyPromo(3000, true, false)`.
3. **Повторное использование.** Все остальные условия выполнены, а `usedBefore` равен `true`. Если такого теста нет, удалённую проверку не заметить.

Тесты проверяют результат, а не устройство, поэтому переживут переписывание функции.
