## Зачем это в работе

Тикет от маркетинга: «Покупатель оформил заказ ровно на 5000 рублей, а скидка 10 процентов не применилась. В акции написано: скидка от 5000».

Разработчик открыл код и нашёл одну строку:

```js
const orderSum = 5000;
console.log(orderSum > 5000);
console.log(orderSum >= 5000);
```

```text
false
true
```

Знак `>` означает «строго больше», а `>=` означает «больше или равно». Одна лишняя буква в условии, и граница заказа выпала из акции. Консоль молчала: код был корректный, просто делал не то.

Такие тикеты приходят постоянно: комиссии, остатки, пороги бесплатной доставки. Поэтому операторы нужно знать точно.

## Объяснение

Оператор (operator) — это знак, который делает что-то со значениями. Значения, с которыми он работает, называются операндами (operands). В выражении `2 + 3` знак `+` — оператор, а `2` и `3` — операнды.

Представьте кассу. На ней кнопки: сложить, вычесть, сравнить с порогом. Операторы — это такие же кнопки. Их немного, и они делятся на четыре группы.

**1. Арифметика.** Шесть операторов:

- `+`, `-`, `*`, `/`: сложение, вычитание, умножение, деление;
- `%`: остаток от деления. `47 % 12` даёт `11`, потому что в 47 помещается три раза по 12, и остаётся 11;
- `**`: возведение в степень. `2 ** 3` даёт `8`.

Остаток нужен чаще, чем кажется. Заказали 47 штук, в коробку влезает 12. Полных коробок получится `Math.floor(47 / 12)`, то есть 3. Функция `Math.floor` отбрасывает дробную часть вниз. Штук, которые не поместились, будет `47 % 12`, то есть 11.

**2. Сокращённое присваивание.** Запись `stock += 5` значит `stock = stock + 5`. Так же работают `-=`, `*=` и `/=`. Увеличить на единицу можно ещё короче: `stock++`. Все они работают только с переменными, объявленными через `let`.

**3. Сравнение.** Результат всегда логическое значение: `true` или `false`.

- `>`, `<`, `>=`, `<=`: больше, меньше, не меньше, не больше;
- `===` и `!==`: равно и не равно, без приведения типов (как в уроке 1.1).

**4. Логические операторы** соединяют условия:

- `&&` («И»): истина, только если истинны обе части;
- `||` («ИЛИ»): истина, если истинна хотя бы одна часть;
- `!` («НЕ»): меняет истину на ложь и наоборот.

Теперь запустите пример со всеми четырьмя группами.

## Пример

<Playground example="arithmetic" />

Что произошло. Деление `47 / 12` дало дробное число, поэтому для числа полных коробок мы взяли `Math.floor`. Остаток `47 % 12` дал 11. Строка `stock += 5` увеличила остаток, а `stock *= 2` удвоила его.

Теперь про логику. Оператор `&&` вычисляет левую часть. Если она ложна, правую он не трогает вовсе. Оператор `||` делает обратное: если левая часть истинна, правую он пропускает. Это называется коротким вычислением (short-circuit).

<Playground example="logic" />

Из-за короткого вычисления операторы `&&` и `||` на самом деле возвращают не `true` или `false`, а одну из своих частей. Выражение `0 || 10` даёт `10`: левая часть ложна, значит, берётся правая. Этим пользуются, чтобы подставить значение по умолчанию.

Здесь есть ловушка. Для `||` «ложными» считаются `0`, пустая строка `""`, `NaN`, `null`, `undefined` и `false`. Скидка `0` процентов совершенно законна, но `||` примет её за «значения нет». Для таких случаев есть оператор `??` (nullish coalescing, «объединение с null»). Он подставляет правую часть только если слева `null` или `undefined`. Ноль и пустая строка он оставляет как есть.

<Wrong>

```js
const percent = discountFromForm || 10; // 0 превратится в 10
```

</Wrong>

<Right>

```js
const percent = discountFromForm ?? 10; // 0 останется 0
```

</Right>

<Playground example="nullish" />

## Как это работает

Когда в выражении несколько операторов, JavaScript выполняет их не слева направо, а по приоритету (precedence). Как в школе: умножение раньше сложения. Схема показывает порядок.

<Figure src="precedence.svg" alt="Лесенка приоритетов сверху вниз: скобки, затем не и степень, затем умножение деление и остаток, затем сложение и вычитание, затем сравнения, затем И, затем ИЛИ и двойной вопрос. Справа пример: 2 плюс 3 умножить на 4 в степени 2. Шаги: сначала степень, получается 16, потом умножение, получается 48, потом сложение, получается 50." caption="Что выше на лесенке, то считается раньше. Скобки всегда первые." />

Три правила, которые стоит запомнить:

1. Арифметика считается раньше сравнения, а сравнение раньше `&&` и `||`. Поэтому `price * quantity >= 5000 && isMember` читается именно так, как задумано.
2. `&&` сильнее `||`: выражение `a || b && c` значит `a || (b && c)`.
3. Не надеясь на память, ставьте скобки. `(a + b) / 2` короче и надёжнее комментария «тут сначала сложение».

Ещё одна особенность: `??` нельзя смешивать с `||` или `&&` без скобок. Это синтаксическая ошибка, и язык заставляет вас явно показать порядок.

<Note>

Деньги в дробных числах считать нельзя. `0.1 + 0.2` даёт `0.30000000000000004`: компьютер хранит дроби приблизительно. Поэтому суммы считают в копейках целыми числами, как в уроке 1.1, а округляют через `Math.round`.

</Note>

## Типичные ошибки

Сообщения и результаты получены запуском в Node.js 22.

**1. Строгое сравнение вместо нестрогого на границе.** Ошибки нет, программа просто считает неверно.

<Wrong>

```js
console.log(5000 > 5000);
```

</Wrong>

```text
false
```

Если в тикете «от 5000», нужен `>=`. Ставьте тест ровно на границе: 4999, 5000, 5001.

**2. Цепочка сравнений.** В математике запись `1 < stock < 100` значит «между 1 и 100». В JavaScript она работает иначе.

<Wrong>

```js
const stock = 500;
console.log(1 < stock < 100);
```

</Wrong>

```text
true
```

Сначала считается `1 < stock`, получается `true`. Потом `true < 100`, а `true` превращается в `1`. Выходит `1 < 100`, то есть снова `true`. Правильно соединять условия через `&&`.

<Right>

```js
const stock = 500;
console.log(stock > 1 && stock < 100); // false
```

</Right>

**3. Ноль съеден оператором `||`.**

<Wrong>

```js
console.log(0 || 10);
```

</Wrong>

```text
10
```

Ошибки нет, значение по умолчанию просто перебило законный ноль. Замените `||` на `??`.

**4. Смесь `??` и `||` без скобок.**

<Wrong>

```js
const percent = null || 5 ?? 3;
```

</Wrong>

```text
SyntaxError: Unexpected token '??'
```

Языку непонятен порядок, и он отказывается его угадывать. Добавьте скобки: `(null || 5) ?? 3`.

**5. Строки сравниваются как текст.**

<Wrong>

```js
console.log("9" > "10");
```

</Wrong>

```text
true
```

Две строки сравниваются по символам слева направо: `"9"` стоит в таблице символов позже, чем `"1"`. Если значения пришли из формы, сначала превратите их в числа через `Number()`.

**6. Минус перед степенью.**

<Wrong>

```js
console.log(-2 ** 2);
```

</Wrong>

```text
SyntaxError: Unary operator used immediately before exponentiation expression. Parenthesis must be used to disambiguate operator precedence
```

Непонятно, что имелось в виду: «минус от квадрата» или «квадрат от минус двух». Напишите `-(2 ** 2)` или `(-2) ** 2`.

**7. Деление на ноль.** Это не ошибка.

```js
console.log(5 / 0);
console.log(0 / 0);
```

```text
Infinity
NaN
```

Деление на ноль даёт `Infinity` (бесконечность) или `NaN`. Они молча доедут до экрана, как и `NaN` в прошлом уроке. Проверяйте делитель заранее.
