# Разбор

1. Цикл `for` идёт по местам 1–5. На месте 3 срабатывает `continue`: остаток тела пропущен, `seat` не добавляется к строке, но цикл идёт дальше. Получается `"1245"`.
2. `while (paid < 7000)`: после первого прохода `paid` равно 3000, после второго 6000, после третьего 9000. Только тогда условие ложно. Значит, `month` равно `3`.
3. `paid` после цикла равно `9000`: платить пришлось бы три раза по 3000.
4. В `do...while` тело выполняется до проверки условия. `tries` становится 11, потом `11 < 5` ложно, цикл заканчивается. Ответ `11`. В обычном `while` ответ был бы 10.
5. В строке `"A7-K9"` дефис стоит на индексе 2 (A — 0, 7 — 1, дефис — 2). После `break` цикл не идёт дальше. Ответ `2`.
6. Длина строки 5, значит `code.length - 1` равно `4`: индекс последнего символа.
