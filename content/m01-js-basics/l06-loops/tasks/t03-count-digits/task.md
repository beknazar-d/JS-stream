## Контекст

Служба поддержки жалуется: система проверки купонов неверно считает цифры в коде. Для кода «SALE-2025» функция должна находить 4 цифры, а находит 3. От числа цифр зависит, к какому типу акции относится купон.

## Цель

Исправьте функцию `countDigits(code)` в `index.js`. Она считает цифры в строке: для `"SALE-2025"` вернёт `4`. Для не-строки возвращает `0`.

## Критерии приёмки

- `countDigits("SALE-2025")` возвращает `4`.
- Цифра на первой позиции строки тоже считается: `countDigits("7SALE")` возвращает `1`.
- Цифра на последней позиции считается: `countDigits("SALE7")` возвращает `1`.
- Для пустой строки и для строки без цифр возвращает `0`.
- Для `null`, `undefined` и чисел возвращает `0`.

## Ограничения

- Не переписывайте функцию заново: найдите одну ошибку в цикле и исправьте её.
- Не меняйте имя и параметры функции.
