# Разбор

Ошибка была в начале цикла: `let i = 1`. Индексы символов строки идут с нуля, поэтому первый символ `code[0]` ни разу не проверялся. Для `"SALE-2025"` это не видно (первая буква не цифра), а для `"7SALE"` цифра терялась.

Исправление: `let i = 0`. Теперь условие `i < code.length` проходит индексы `0 … length - 1` ровно по разу.

Исходное условие `i <= code.length` тоже было лишним: на последнем проходе `code[code.length]` равно `undefined`. Метод `includes` превращает аргумент в строку `"undefined"` и цифрой не считает, поэтому ошибки не было видно. Но строгое `<` честнее и надёжнее.
