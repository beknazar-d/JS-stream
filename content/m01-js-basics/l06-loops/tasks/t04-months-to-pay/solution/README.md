# Разбор

1. Сначала защита, потом цикл. Все условия, при которых цикл мог бы не закончиться, отсеиваются до него. Если платёж равен 0 или меньше, `rest` не уменьшается (или растёт), условие `rest > 0` остаётся истинным вечно. Если цена бесконечна, вычитание тоже ничего не меняет: `Infinity - 300` это снова `Infinity`.
2. `typeof` отсекает строки, `null` и `undefined`. `Number.isFinite` отсекает `NaN` и `Infinity` (и заодно подтверждает, что значение число).
3. `while (rest > 0)`: на каждой итерации остаток уменьшается на платёж, счётчик растёт. Последний платёж может сделать остаток отрицательным: это нормально, значит, последний платёж был меньше обычного.
4. Для цены 0 или меньше условие ложно сразу, тело не выполняется ни разу, функция возвращает `0`. Поэтому здесь подходит `while`, а не `do...while`.
