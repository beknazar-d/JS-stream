# Разбор

1. `line` — накопитель. Мы начинаем с пустой строки и по ходу цикла приписываем к ней новые куски.
2. Цикл идёт от 1 до `count` включительно. Здесь нужен знак `<=`, потому что нумерация мест начинается с единицы. Для `count` равного 0 условие `1 <= 0` ложно с самого начала, тело не выполняется, и функция возвращает пустую строку.
3. Пробел нужен только между номерами. Проверка `line !== ''` добавляет его перед каждым номером, кроме первого. Поэтому лишнего пробела в начале или в конце нет.
4. `line += seat` приписывает число к строке: плюс с одной строкой склеивает (урок 1.1).
