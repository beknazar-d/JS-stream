## Контекст

В билетной системе на экране выбора места нужна подпись: все свободные номера подряд, через пробел. Для зала на 4 места это «1 2 3 4». Нужна функция, которая строит такую строку.

## Цель

В `index.js` допишите тело функции `seatLine(count)`. Она возвращает строку с номерами мест от 1 до `count`, разделёнными одним пробелом. Используйте цикл `for`.

## Критерии приёмки

- `seatLine(4)` возвращает `"1 2 3 4"`.
- `seatLine(1)` возвращает `"1"`.
- `seatLine(0)` возвращает пустую строку `""`.
- В конце строки нет лишнего пробела, в начале тоже.

## Ограничения

- Не меняйте имя и параметры функции.
- Для `count` равного 0 цикл не должен выполниться ни разу.
