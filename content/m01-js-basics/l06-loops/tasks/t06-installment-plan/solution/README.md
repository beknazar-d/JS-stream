# Разбор

1. Проверка входных данных идёт первой. `Number.isInteger` одновременно отсекает строки, `NaN`, `undefined` и дробные числа: для не-числа он возвращает `false`. Потом проверяем диапазоны.
2. `price % months` — остаток от деления (урок 1.3). Вычитая его из цены, получаем число, которое делится на `months` без остатка. Результат деления `base` целый, дробных рублей нет.
3. Цикл `for` идёт от 1 до `months` включительно: нумерация месяцев с единицы.
4. Для последнего месяца (`month === months`) к платежу добавляется остаток. Для остальных платёж равен `base`.
5. Каждая строка месяца заканчивается переводом строки, поэтому итоговая строка добавляется уже после цикла и перевода строки не имеет. Так в конце нет лишнего пустого перевода.
6. Сумма платежей: `base * (months - 1) + base + rest = base * months + rest = price`. Это проверяет скрытый тест на нескольких ценах.
