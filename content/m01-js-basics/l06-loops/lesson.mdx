## Зачем это в работе

Тикет от отдела продаж. Магазин вводит рассрочку: товар за 12 000 рублей можно оплатить за 4 месяца. Покупателю нужно показать график: в каком месяце сколько платить и сколько ещё осталось.

Можно написать четыре `console.log` подряд. А если срок 6 месяцев? А 12? Копировать строки неудобно, а ошибиться в копии легко.

Для этого есть циклы. Цикл (loop) повторяет один и тот же код столько раз, сколько нужно. В этом уроке мы научимся делать это без бесконечных зависаний и ошибок на единицу.

Массивы мы ещё не проходили. Поэтому цикл будет работать с числами и со строками. Строка — это тоже последовательность: символ за символом.

## Объяснение

Представьте кассира, который пробивает чек. Он берёт товар, пробивает, берёт следующий. Он повторяет одно и то же, пока на ленте есть товары. Цикл — это такая инструкция: «делай это, пока выполняется условие».

В любом цикле есть три части:

- начало: откуда стартуем (счётчик, counter);
- условие: когда продолжать;
- шаг: как меняется счётчик после каждого повторения.

Самый частый цикл — `for`. Все три части записаны в одной строке в скобках:

```js
for (let month = 1; month <= 4; month++) {
  // тело цикла: выполняется на каждом повторении
}
```

- `let month = 1` — начало. Выполняется один раз.
- `month <= 4` — условие. Проверяется перед каждым повторением.
- `month++` — шаг. Увеличивает `month` на 1 после каждого повторения.

Один проход тела называют итерацией (iteration). Здесь их четыре: для `month` равного 1, 2, 3 и 4.

Второй цикл — `while` («пока»). В скобках только условие. Начало и шаг вы пишете сами: начало до цикла, шаг внутри тела. Он удобен, когда заранее неизвестно, сколько раз повторять.

```js
let month = 1;
while (month <= 4) {
  month++;
}
```

Третий, `do...while`, отличается одним: условие проверяется после тела. Значит, тело выполнится хотя бы один раз. Нужен он редко.

```js
let attempts = 3;
do {
  console.log("Попытка", attempts);
  attempts--;
} while (attempts > 0);
```

```text
Попытка 3
Попытка 2
Попытка 1
```

Два слова управляют ходом цикла:

- `break` — выйти из цикла сразу и совсем;
- `continue` — пропустить остаток тела и перейти к следующей итерации.

Обратите внимание: `issued++` стоит после `continue`. Для номера 13 мы до него не дошли, поэтому место не считается выданным. Если поставить `issued++` до проверки, мест выдастся на одно меньше.

Цикл умеет ходить и по строке. У строки есть длина (`length`), а к символу по номеру можно обратиться так: `code[0]` — первый символ, `code[1]` — второй. Номер символа называется индексом (index). Индексы считаются с нуля, поэтому последний символ строки из 12 букв имеет индекс 11.

<Playground example="coupon-chars" />

Правило: цикл по строке идёт от `0` до `i < code.length`. Знак строго «меньше», а не «меньше или равно».

<Wrong>

```js
for (let i = 0; i <= code.length; i++) { /* лишний проход */ }
```

</Wrong>

<Right>

```js
for (let i = 0; i < code.length; i++) { /* ровно length проходов */ }
```

</Right>

## Как это работает

Посмотрите, в каком порядке `for` выполняет свои части.

<Figure src="loop-flow.svg" alt="Схема цикла for. Вверху квадрат «let month = 1» (начало, один раз). Под ним ромб с условием «month меньше или равно 4». Из ромба стрелка «да» вниз к квадрату «тело цикла», затем к квадрату «month++», а оттуда стрелка возвращается к ромбу. Из ромба вправо стрелка «нет» к пунктирному квадрату «выход»." caption="Начало выполняется один раз. Дальше по кругу: проверка условия, тело, шаг. Когда условие ложно, цикл завершён." />

Из схемы следуют правила.

1. Условие проверяется до тела. Если оно сразу ложно, тело не выполнится ни разу. `for (let i = 5; i < 3; i++)` не сделает ни одной итерации.
2. Шаг выполняется после тела, перед следующей проверкой.
3. `continue` в `for` не пропускает шаг: он прыгает прямо к шагу, а потом к проверке. В `while` шага в заголовке нет, поэтому будьте осторожны: если вы пропустили строку со счётчиком через `continue`, цикл может не закончиться.
4. Переменная `let month`, объявленная в заголовке, живёт только внутри цикла. После цикла её нет.

Теперь главная опасность. Что будет, если условие никогда не станет ложным? Цикл не закончится. Это бесконечный цикл (infinite loop). Вот типичная ошибка: забыли шаг.

```js
let attempts = 0;
while (attempts < 3) {
  console.log("Повторяем платёж");
  // забыли attempts++
}
```

`attempts` всегда равно 0, условие всегда истинно. В браузерном редакторе курса это не сломает страницу: код работает в отдельном потоке, и через 5 секунд платформа остановит его и напишет «Код выполнялся слишком долго». В вашей программе на Node.js или в чужом браузере такой защиты нет. Страница зависнет, а программу придётся убивать вручную (в терминале это Ctrl+C).

Поэтому перед запуском цикла задайте себе три вопроса.

- Что меняется на каждой итерации?
- Приближает ли это изменение условие к «ложь»?
- Что если входное число 0, отрицательное или не число?

<Note>

Последний вопрос важен для данных из формы. Цикл `while (rest > 0)`, в котором `rest` уменьшается на платёж, зависнет, если платёж равен 0. Проверяйте входные данные до цикла, а не после.

</Note>

## Типичные ошибки

Все сообщения ниже получены запуском в Node.js 22. Браузер на движке V8 пишет их так же.

**1. Счётчик объявили через `const`.**

<Wrong>

```js
for (const month = 1; month <= 4; month++) {
  console.log(month);
}
```

</Wrong>

```text
TypeError: Assignment to constant variable.
```

Шаг `month++` пытается изменить значение, а `const` менять нельзя. Первая итерация выполнится, ошибка появится на шаге. Счётчик объявляют через `let`.

<Right>

```js
for (let month = 1; month <= 4; month++) {
  console.log(month);
}
```

</Right>

**2. Счётчик используют после цикла.**

<Wrong>

```js
for (let i = 0; i < 3; i++) {}
console.log(i);
```

</Wrong>

```text
ReferenceError: i is not defined
```

Переменная `i` существует только внутри цикла. Если значение нужно после него, объявите переменную до цикла.

**3. Ошибка на единицу в цикле по строке.**

<Wrong>

```js
const code = "AB";
for (let i = 0; i <= code.length; i++) {
  console.log(code[i].toLowerCase());
}
```

</Wrong>

```text
a
b
TypeError: Cannot read properties of undefined (reading 'toLowerCase')
```

У строки из двух символов индексы 0 и 1. Когда `i` стало равно 2, `code[2]` вернуло `undefined`, и у него нет метода `toLowerCase`. Если бы метода не было, ошибка осталась бы тихой, и вы бы получили лишнюю итерацию с `undefined`. Лечится условием `i < code.length`.

**4. Цикл не заканчивается.** Сообщения в консоли нет. Есть только остановка платформы через 5 секунд («Код выполнялся слишком долго»). Смотрите на условие и на шаг: меняется ли то, что стоит в условии?

## Итог

Что вы теперь умеете:

- писать `for` с тремя частями и объяснять, в каком порядке они выполняются;
- выбирать `while`, когда число повторений заранее неизвестно;
- выходить из цикла через `break` и пропускать итерацию через `continue`;
- перебирать строку по индексам от `0` до `i < length`;
- замечать бесконечный цикл по условию и шагу ещё до запуска.

Циклы повторяют код внутри одной программы. Но в магазине одни и те же расчёты нужны в разных местах: рассрочка, доставка, скидка. Копировать цикл в каждое место неудобно. В следующем уроке мы упакуем код в функции: один раз напишем, много раз вызовем.
