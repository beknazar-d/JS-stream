## Контекст

Баг-репорт BUG-2410 от команды витрины.

Шаги:

1. Открыть каталог. В подписях под товарами написано `undefined` вместо «Кроссовки: 4500 ₽».
2. Открыть кабинет оператора, где все заказы оплачены. Баннер «Есть неоплаченные заказы» всё равно горит.

Ожидалось: в подписях название и цена, баннер горит только при неоплаченных заказах.

Фактически: подписи `undefined`, баннер горит всегда.

## Цель

Исправьте функции в `index.js`:

- `priceLabels(products)` возвращает массив подписей вида `"Кроссовки: 4500 ₽"`;
- `hasUnpaid(orders)` возвращает `true`, если есть хотя бы один заказ со статусом, отличным от `"paid"`.

## Критерии приёмки

- `priceLabels([{ name: "Кроссовки", price: 4500 }])` возвращает `["Кроссовки: 4500 ₽"]`.
- Товар с ценой `0` получает подпись `"Подарок: 0 ₽"`.
- `hasUnpaid` возвращает `true`, если неоплаченный заказ есть среди оплаченных.
- `hasUnpaid` возвращает `false`, если все заказы оплачены, и для пустого списка.

## Ограничения

- Менять только тела функций.
- Исходные массивы не меняются.
