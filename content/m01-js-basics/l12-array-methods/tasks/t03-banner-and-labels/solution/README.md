# Разбор

Две разные причины.

**Ценники с `undefined`.** После стрелки в `priceLabels` открыты фигурные скобки. Внутри них колбэк — обычная функция, и ей нужен явный `return`. Без него она возвращает `undefined`, а `map` честно собирает из этого массив. Либо добавьте `return`, либо уберите фигурные скобки: `(product) => product.name + ...`.

**Баннер горит всегда.** Метод `filter` возвращает массив. Любой массив, даже пустой, считается истиной, поэтому `if (orders.filter(...))` срабатывает всегда. Вопрос «есть ли хотя бы один» решает `some`: он возвращает `true` или `false`.

Заодно `some` на пустом списке сам даёт `false`, отдельная проверка не нужна.
