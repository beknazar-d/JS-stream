# Разбор

1. `map` умножает каждую цену на два и возвращает массив той же длины: `[2400, 600, 9000, 1600]`.
2. `filter` оставляет цены больше 1000: `[1200, 4500]`.
3. `find` возвращает первое значение меньше 500. Это `300`, и это само число, а не массив.
4. Цены больше 10000 нет, поэтому `find` возвращает `undefined`.
5. `findIndex` ищет индекс значения `4500`. Оно третье по счёту, индекс `2`.
6. `some`: цена `4500` больше 4000, поэтому `true`.
7. `every`: цена `300` не больше 500, значит подходят не все: `false`.
8. `[].every(...)` даёт `true`: на пустом массиве нет элемента, который нарушил бы условие.
9. Ни один из методов не изменил `prices`, поэтому массив выведен как был.
