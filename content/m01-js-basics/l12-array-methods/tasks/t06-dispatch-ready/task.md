## Контекст

Тикет WH-588 от начальника склада.

Утром нужно понять, какие оплаченные заказы можно отгрузить сразу, а какие ждут товар. Заказ отгружается только целиком: если не хватает хотя бы одной позиции, он ждёт.

Заказ: `{ id: "A-101", status: "paid", lines: [{ sku: "RUN-42", quantity: 2 }, { sku: "CAP-01", quantity: 1 }] }`.
Склад — массив `{ sku: "RUN-42", quantity: 7 }`.

## Цель

Реализуйте `planDispatch(orders, stock)` в `index.js`. Функция возвращает объект `{ ready, blocked }`:

- `ready` — массив номеров (`id`) оплаченных заказов, которые можно отгрузить;
- `blocked` — массив объектов `{ id, missing }` для оплаченных заказов, которые отгрузить нельзя. В `missing` лежат артикулы строк, на которые не хватает остатка, в порядке строк заказа.

## Критерии приёмки

- Рассматриваются только заказы со статусом `"paid"`. Остальные в результат не попадают.
- Строка подходит, если артикул есть на складе и остаток не меньше `quantity` строки.
- Артикул, которого нет на складе, считается недостающим.
- Каждый заказ проверяется независимо: остатки между заказами не резервируются.
- Заказ без строк считается готовым к отгрузке.
- Порядок заказов в обоих списках совпадает с порядком в `orders`.
- Переданные `orders` и `stock` не изменяются.

## Ограничения

- Используйте методы массивов (`filter`, `map`, `find`, `every`), циклы писать не нужно.
- Пример: заказ A-101 из описания при складе из одной позиции `RUN-42` с остатком 7 даст `{ ready: [], blocked: [{ id: "A-101", missing: ["CAP-01"] }] }`.
