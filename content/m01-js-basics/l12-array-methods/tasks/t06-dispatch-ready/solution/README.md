# Разбор

Решение строится из трёх вопросов, и на каждый есть свой метод.

1. **Подходит ли строка?** Вспомогательная функция `lineIsAvailable` ищет товар на складе через `find`. Результат `find` нужно проверить: для неизвестного артикула он равен `undefined`, и читать у него `quantity` нельзя. Условие `item !== undefined && item.quantity >= line.quantity` защищает от этого. Сравнение `>=` включает границу: если нужно 4, а есть 4, строка подходит.
2. **Готов ли заказ?** Заказ готов, если подходят все строки. Это `every`. Для заказа без строк `every` даёт `true`, поэтому он попадает в `ready`. Это то самое поведение пустого массива из урока.
3. **Чего не хватает?** Для заблокированных заказов `filter` оставляет строки без остатка, а `map` превращает их в артикулы.

Сначала отбираем оплаченные заказы, потом работаем только с ними. Все методы создают новые массивы, поэтому `orders` и `stock` остаются нетронутыми.

Остатки не резервируются: два заказа на один и тот же товар проверяются независимо. Это упрощение, о котором сказано в условии.
