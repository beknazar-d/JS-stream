# Разбор

Один `filter`, в нём три независимые проверки. Каждая имеет вид «условие не задано или заказ ему подходит». Поэтому пустой фильтр оставляет все заказы, а сочетание условий работает через `&&`.

- Для `minTotal` проверка именно `=== undefined`, а не «условие ложное». Значение `0` — настоящее условие, и «не задано» оно не означает.
- Граница включена, поэтому `>=`, а не `>`.
- Поиск по имени нечувствителен к регистру: обе строки приводятся к нижнему регистру через `toLowerCase`, потом `includes` ищет подстроку.

`filter` всегда возвращает новый массив, поэтому исходные заказы не изменяются, а для «пустого» фильтра отдельной ветки не нужно.
