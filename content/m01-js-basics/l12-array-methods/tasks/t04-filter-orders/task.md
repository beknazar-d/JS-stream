## Контекст

В кабинете оператора есть список заказов и три поля фильтра: статус, минимальная сумма и поиск по имени клиента. Оператор может заполнить любые поля или не заполнить ни одного.

Заказ имеет вид `{ id: "A-101", status: "paid", total: 4500, customerName: "Ирина Соколова" }`.

## Цель

Реализуйте `filterOrders(orders, filters)` в `index.js`. Параметр `filters` — объект с необязательными полями `status`, `minTotal` и `query`. Функция возвращает массив заказов, которые подходят под все заданные поля.

## Критерии приёмки

- `status`: если задан, остаются заказы с точно таким статусом.
- `minTotal`: если задан, остаются заказы, у которых сумма не меньше `minTotal` (граница включена).
- `query`: если задан, остаются заказы, у которых имя клиента содержит `query`, без учёта регистра.
- Незаданные поля (`undefined`) ничего не отсеивают. Пустой объект `{}` возвращает все заказы.
- Порядок заказов сохраняется. Исходный массив не меняется.
- Результат всегда новый массив, даже если подошли все заказы.

## Ограничения

- Используйте `filter`, цикл писать не нужно.
- Менять только тело `filterOrders`.
