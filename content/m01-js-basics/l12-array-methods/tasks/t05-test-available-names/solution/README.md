# Разбор

В функции три условия, и у каждого есть граница или особый случай. Поэтому тесты разведены по ним.

1. **Цена ровно равна лимиту.** Товар за 1000 при лимите 1000 должен остаться. Только такой тест замечает замену `<=` на `<`.
2. **Нулевой остаток.** Нужен товар с остатком `0` и ценой в пределах лимита, иначе нечем отличить `> 0` от `>= 0`.
3. **Лимит не передан.** Сравнение `price <= undefined` всегда ложно, так что без отдельной проверки на `undefined` список окажется пустым. Тест без второго аргумента ловит потерянную проверку.

Тесты сравнивают только результат с ожидаемым списком названий, поэтому не зависят от того, как функция устроена внутри.
