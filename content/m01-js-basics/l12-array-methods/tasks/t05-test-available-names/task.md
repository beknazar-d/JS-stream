## Контекст

Блок «Успейте купить» на витрине показывает названия товаров, которые есть в наличии и стоят не дороже заданного лимита. Если лимит не передан, показываются все товары в наличии. Тестов у функции `availableNames` нет, а перед следующим релизом её будут переписывать.

## Цель

Напишите тесты в `index.test.js` для функции `availableNames(products, maxPrice)` из `subject/index.js` (код показан под описанием). Функция работает так:

- возвращает названия товаров с остатком больше нуля и ценой не больше `maxPrice`;
- если `maxPrice` не передан, ограничения по цене нет;
- порядок названий совпадает с порядком в каталоге.

## Критерии приёмки

- Все ваши тесты проходят на показанной реализации.
- Тесты падают на каждой из трёх реализаций с ошибкой.
- Тесты проверяют только результат для входных данных, а не устройство функции.
- Названия тестов описывают случай на русском языке.

## Ограничения

- Пишите тесты только в `index.test.js`. Код функции менять нельзя.
- Используйте `describe`, `it` и `expect` без импорта. Из `index.js` импортируйте только `availableNames`.
- Данные для тестов пишите прямо в тестах.
