## Контекст

Каталог витрины — массив товаров вида `{ sku: "RUN-42", name: "Кроссовки", price: 4500, quantity: 3 }`. Для страницы каталога нужны четыре небольших вспомогательных функции. Напишите их по памяти.

## Цель

Допишите в `index.js` четыре функции:

- `productNames(products)` возвращает массив названий товаров;
- `availableProducts(products)` возвращает товары, которых на складе больше нуля;
- `findProduct(products, sku)` возвращает товар с таким артикулом или `undefined`;
- `hasOutOfStock(products)` возвращает `true`, если хотя бы у одного товара остаток равен нулю.

## Критерии приёмки

- `productNames` возвращает названия в порядке каталога.
- `availableProducts` не включает товары с остатком `0` и не меняет исходный массив.
- `findProduct` возвращает сам товар (объект), а не массив.
- `findProduct` для отсутствующего артикула возвращает `undefined`.
- `hasOutOfStock([])` возвращает `false`.

## Ограничения

- Используйте методы массивов, циклы `for` писать не нужно.
- Менять только тела функций.
