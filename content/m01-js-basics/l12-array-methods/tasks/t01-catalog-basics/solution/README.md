# Разбор

Каждая функция — один метод и одна стрелочная функция.

- `map` превращает товар в название. Длина результата та же, что у каталога.
- `filter` оставляет товары с условием `quantity > 0`. Именно строго больше: остаток `0` значит «нет в наличии».
- `find` возвращает первый товар с нужным артикулом. Это сам объект, а если артикула нет, то `undefined`.
- `some` отвечает на вопрос «есть ли хотя бы один». Для пустого каталога он даёт `false`: подходящих нет.

Ни один из методов не меняет исходный каталог.
