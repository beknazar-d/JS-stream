## Контекст

Для печати этикетки склад использует функцию `shippingLabel(order)`. Данные в заказах неполные: у самовывоза нет клиента с адресом, а из внешней системы иногда приходит `address: null`. Тестов у функции нет, а на следующей неделе её собираются переписать.

## Цель

Напишите тесты в `index.test.js` для функции `shippingLabel` из `subject/index.js` (код показан под описанием). Функция работает так:

- для заказа с городом и улицей возвращает `"Казань, Баумана, 12"`;
- если улицы нет, возвращает только город;
- если города нет, вместо него подставляется `"город не указан"`;
- если адреса нет совсем (нет клиента, нет `address` или он равен `null`), возвращает `"Адрес не указан"`.

## Критерии приёмки

- Все ваши тесты проходят на показанной реализации.
- Тесты падают на каждой из трёх реализаций с ошибкой.
- Тесты проверяют только результат для входных данных, а не устройство функции.
- Названия тестов описывают случай на русском языке.

## Ограничения

- Пишите тесты только в `index.test.js`. Код функции менять нельзя.
- Используйте `describe`, `it` и `expect` без импорта. Из `index.js` импортируйте только `shippingLabel`.
