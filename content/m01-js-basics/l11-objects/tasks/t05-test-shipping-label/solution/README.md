# Разбор

Функция читает вложенные данные, значит ломаться она может на каждом уровне. Поэтому каждый уровень получает свой тест.

1. **Нет клиента.** Заказ без `customer` ловит ошибку, когда в коде пропал `?.` перед `address`.
2. **`null` в адресе.** `undefined` и `null` — разные значения. Проверка только на `undefined` пропустит `null`, и функция упадёт на чтении города. Нужен отдельный тест.
3. **Улица.** Тест на полный адрес сравнивает строку целиком и ловит потерянную улицу.

Тесты проверяют только результат: что вернулось для данных. Поэтому они переживут переписывание функции.
