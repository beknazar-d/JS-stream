# Разбор

1. `second = first` не создаёт копию, а даёт объекту второе имя. Статус поменяли через `second`, поэтому `first.status` равно `paid`.
2. `first === second` даёт `true`: это один и тот же объект.
3. `{ id: 1 } === { id: 1 }` даёт `false`: каждый литерал создаёт новый объект, а `===` сравнивает ссылки.
4. `copy` собран вручную и не связан с `first`. Смена статуса в `copy` никак не влияет на `first`, статус остаётся `paid`.
5. `Object.keys(first)` возвращает `["id", "status"]`.
6. У `first` нет поля `customer`, поэтому `first.customer?.address` останавливается на `?.` и даёт `undefined`, а не ошибку.
7. Поля `total` у заказа нет, поэтому `Object.hasOwn` даёт `false`.
