## Контекст

Начальнику склада каждое утро нужна сводка: сколько заказов новых, оплаченных, отправленных и в других статусах. Заказы приходят массивом объектов, статусов может быть больше трёх: бывают отменённые и возвращённые. Иногда оператор забывает проставить статус.

## Цель

Реализуйте `countByStatus(orders)` в `index.js`. Функция принимает массив заказов вида `{ id: "A-101", status: "paid" }` и возвращает объект, где ключ — статус, а значение — число заказов с этим статусом.

Пример: заказы со статусами `new`, `paid`, `new` дают `{ new: 2, paid: 1 }`.

## Критерии приёмки

- Для каждого встретившегося статуса в результате есть ключ со счётчиком.
- Статусов, которых нет в заказах, в результате нет.
- Заказ без поля `status` засчитывается под ключом `"unknown"`.
- Для пустого массива результат — пустой объект `{}`.
- Сам массив заказов не меняется.

## Ограничения

- Заранее известный список статусов в коде использовать нельзя: статусы бывают любыми.
- Менять только тело `countByStatus`.
