# Разбор

Счётчик — обычный объект. Для каждого заказа мы читаем статус и увеличиваем число под этим ключом.

1. Имя ключа лежит в переменной `status`, поэтому нужны квадратные скобки: `counts[status]`. Запись `counts.status` обратилась бы к полю с названием «status».
2. Первый раз ключа ещё нет, и `counts[status]` равно `undefined`. Прибавление к `undefined` дало бы `NaN`. Поэтому `?? 0` подставляет ноль, и первое значение будет `1`.
3. Заказ без статуса получает запасной ключ через `order.status ?? "unknown"`.

Такой приём («счётчик в объекте») пригодится в следующих уроках: тот же шаблон работает для подсчёта товаров, городов и пользователей.
