# Разбор

Решение в три шага.

1. **Копия остатков.** Цикл по `Object.keys(stock)` собирает новый объект `next`. Дальше мы меняем только его. Исходный `stock` читается и не меняется.
2. **Проверка строки.** `Number(line.quantity)` превращает строку из формы в число. Пустая строка даёт `0`, текст даёт `NaN`, `"1.5"` даёт `1.5`. Условие `!Number.isInteger(quantity) || quantity < 1` отсекает все эти случаи сразу: `NaN` и дробные числа не целые, а `0` и отрицательные меньше единицы. Пробелы по краям `Number` убирает сам.
3. **Новый артикул.** Проверяем `Object.hasOwn(next, line.sku)`. Именно `hasOwn`, а не `if (next[sku])`: остаток `0` — это известный артикул. Для нового артикула сначала кладём `0` и добавляем его в `added`, затем прибавляем количество. Так одинаковые артикулы в нескольких строках складываются, а в `added` артикул попадает один раз.

Строки, пропущенные проверкой, не создают артикул вообще: проверка идёт до добавления.
