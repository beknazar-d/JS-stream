## Контекст

Заказ в интернет-магазине — объект вида `{ id: "A-101", status: "new", customer: { name: "Ирина", address: { city: "Казань" } } }`. У заказов самовывоза поля `customer.address` нет. Писать три небольшие функции для работы с такими заказами вы будете по памяти.

## Цель

Допишите в `index.js` три функции:

- `fieldNames(order)` возвращает массив названий полей заказа;
- `hasField(order, field)` возвращает `true`, если у заказа есть собственное поле с таким названием, иначе `false`;
- `deliveryCity(order)` возвращает город доставки или строку `"город не указан"`, если данных нет.

## Критерии приёмки

- `fieldNames({ id: "A-101", status: "new" })` возвращает `["id", "status"]`.
- `hasField(order, "total")` даёт `true`, даже когда значение поля равно `0` или `undefined`.
- `hasField(order, "toString")` даёт `false`: такого поля в заказе нет.
- `deliveryCity` не падает, если нет `customer` или `address`, и возвращает `"город не указан"`.

## Ограничения

- Менять только тела функций.
- Не используйте `try/catch` и цикл: хватит одной строки на функцию.
