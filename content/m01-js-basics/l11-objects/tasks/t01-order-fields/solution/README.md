# Разбор

- `Object.keys` возвращает массив собственных ключей объекта. Для пустого объекта это `[]`.
- `Object.hasOwn(order, field)` проверяет, что поле есть у самого объекта. Значение при этом не важно: `0` и `undefined` не мешают. Оператор `in` здесь хуже, потому что `"toString" in {}` даёт `true`: этот метод есть у любого объекта.
- В `order.customer?.address?.city` каждый `?.` останавливает цепочку, если слева пусто, и результатом становится `undefined`. Оператор `??` заменяет `undefined` запасной строкой.

Не стоит писать `||` вместо `??`: пустая строка или `0` тоже заменились бы запасным значением.
