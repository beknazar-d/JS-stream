# Разбор

Причина бага: строка `const discounted = order` не создаёт копию. В переменную попадает ссылка на тот же объект, поэтому `discounted.total = ...` меняет и заказ в списке.

Исправление: собрать новый объект с теми же полями. Сумму считаем только в нём. Исходный заказ мы теперь только читаем.

Поле `customer` попадает в новый объект по ссылке: клиент у обоих заказов общий. Для этой задачи этого достаточно, потому что мы не меняем клиента.

Что проверить самому: при скидке 0% возвращать `order` нельзя. Обещание функции — «всегда новый объект», иначе вызывающий код получит тот же общий заказ.
