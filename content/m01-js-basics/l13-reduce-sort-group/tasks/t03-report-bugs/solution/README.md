# Разбор

Две отдельные причины.

**`[object Object]900`.** В `reduce` не было начального значения. Тогда первым `sum` становится первая позиция целиком, то есть объект. На втором шаге плюс видит объект и число, превращает объект в строку `"[object Object]"` и склеивает: получается `[object Object]900`. Начальное значение `0` делает `sum` числом с самого начала. Заодно пустая корзина перестаёт падать.

**Переставленная корзина.** `sort` меняет сам массив и возвращает его же. Поэтому `items.sort(...)` в отчёте переставил позиции в корзине покупателя. `toSorted` возвращает копию. Если бы окружение не знало `toSorted`, подошла бы запись `items.slice().sort(...)`.

Порядок равных цен сохраняется сам: сортировка в JavaScript устойчивая, равные элементы остаются в исходном порядке.
