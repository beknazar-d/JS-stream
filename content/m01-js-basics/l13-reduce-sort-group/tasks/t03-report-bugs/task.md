## Контекст

Баг-репорт BUG-2455 от службы поддержки.

Шаги:

1. Положить в корзину кроссовки (4500 ₽ ×1) и носки (300 ₽ ×3).
2. Открыть «Отчёт по корзине».

Ожидалось: итог 5400, а позиции в самой корзине остались в том порядке, в каком их добавили.

Фактически: итог `[object Object]900`, а в корзине позиции переставились: сначала дешёвые.

Корзина — массив позиций вида `{ name: "Носки", price: 300, quantity: 3 }`. Отчёт использует две функции.

## Цель

Исправьте функции в `index.js`:

- `cartTotal(items)` возвращает итог корзины;
- `cheapestFirst(items)` возвращает позиции по возрастанию цены единицы товара.

## Критерии приёмки

- `cartTotal` возвращает число: сумму `price * quantity`. Для пустой корзины это `0`.
- `cheapestFirst` возвращает новый массив по возрастанию `price`.
- Порядок позиций в исходном массиве `items` после вызова не меняется.
- Позиции с равной ценой остаются в исходном порядке.

## Ограничения

- Менять только тела функций.
- Позиции (объекты) не изменять.
