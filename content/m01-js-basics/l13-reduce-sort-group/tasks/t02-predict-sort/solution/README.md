# Разбор

1. `prices.sort()` без компаратора сравнивает числа как строки: `"1"`, `"10"`, `"100"`, `"9"`. Получается `[1, 10, 100, 9]`.
2. `sort` меняет сам массив, поэтому `prices` теперь тоже `[1, 10, 100, 9]`. Именно из-за этого строка 2 такая же, как строка 1.
3. `toSorted` с компаратором `(a, b) => a - b` сортирует как числа и возвращает копию: `[1, 9, 10, 100]`.
4. `prices` после `toSorted` не изменился, поэтому остался в порядке `[1, 10, 100, 9]`.
5. Сумма `1 + 10 + 100 + 9` равна `120`.
6. Массив пустой, колбэк ни разу не вызывается, `reduce` возвращает начальное значение `5`.
7. Максимум из `[3, 1, 2]` начинается с `0`: `3 > 0` даёт 3, остальные не больше. Результат `3`.
