# Разбор

Сводка состоит из трёх независимых частей. Каждую можно писать и проверять отдельно.

1. **Группировка.** `reduce` с начальным значением `{}`. Для нового статуса создаём `{ count: 0, total: 0 }` (проверка через `Object.hasOwn`), потом увеличиваем поля. Колбэк возвращает `groups`, чтобы следующий шаг получил тот же объект. Запасной ключ `"unknown"` берём через `??`.
2. **Выручка.** Сначала `filter` оставляет оплаченные заказы, потом `reduce` с начальным значением `0` складывает суммы. Из-за `0` пустой список оплаченных даёт `0`, а не `TypeError`.
3. **Топ.** `toSorted` сортирует копию оплаченных заказов. Компаратор двухшаговый: сначала `b.total - a.total` (по убыванию), при равенстве `a.id.localeCompare(b.id)`. Потом `slice(0, limit)` берёт нужное число, а `map` оставляет номера.

Исходный `orders` никто не сортирует и не изменяет: `filter` и `toSorted` возвращают новые массивы. Единственное, что мы меняем внутри `reduce`, — объект `groups`, который сами же и создали.
