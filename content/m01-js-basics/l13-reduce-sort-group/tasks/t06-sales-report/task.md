## Контекст

Тикет MGR-77 от руководителя отдела продаж.

Каждое утро нужна сводка по заказам за вчера: сколько заказов и на какую сумму в каждом статусе, какая выручка по оплаченным и какие оплаченные заказы самые крупные. Выгрузка приходит в произвольном порядке. Иногда у заказа нет статуса.

Заказ: `{ id: "A-101", status: "paid", total: 4500 }`.

## Цель

Реализуйте `buildReport(orders, limit)` в `index.js`. Функция возвращает объект с тремя полями:

- `byStatus` — объект вида `{ paid: { count: 2, total: 5700 }, new: { count: 2, total: 1200 } }`: для каждого статуса число заказов и их сумма;
- `paidRevenue` — сумма `total` по оплаченным заказам (`status === "paid"`);
- `top` — массив номеров (`id`) не более чем `limit` самых крупных оплаченных заказов, от большего к меньшему.

## Критерии приёмки

- Заказ без поля `status` попадает в `byStatus` под ключом `"unknown"`.
- Статусы в `byStatus` идут в порядке первого появления в выгрузке.
- При равной сумме в `top` раньше стоит заказ с меньшим номером (по алфавиту, `localeCompare`).
- Если оплаченных заказов меньше `limit`, в `top` все они. При `limit` равном 0 `top` пустой.
- Если оплаченных заказов нет, `paidRevenue` равен `0`, а `top` пустой.
- Пустой список заказов даёт `{ byStatus: {}, paidRevenue: 0, top: [] }`.
- Переданный массив `orders` и его порядок не изменяются.

## Ограничения

- Не используйте `Object.groupBy`: он новый, и группировку нужно написать самим.
- Не сортируйте сам `orders`.
- Пример: заказы A-101 (paid, 4500), A-102 (new, 900), A-103 (paid, 1200), A-104 (new, 300) при `limit` равном 1 дают `{ byStatus: { paid: { count: 2, total: 5700 }, new: { count: 2, total: 1200 } }, paidRevenue: 5700, top: ["A-101"] }`.
