## Контекст

На главной странице магазина есть блок «Хиты продаж». Товары приходят из каталога в произвольном порядке, у каждого есть число проданных штук. Каталог используют и другие части сайта, поэтому менять его порядок нельзя.

Товар: `{ name: "Кепка", sold: 120 }`.

## Цель

Реализуйте `rankProducts(products)` в `index.js`. Функция возвращает новый массив товаров от самых продаваемых к менее продаваемым. Если продажи равны, товары идут по названию в алфавитном порядке (русский алфавит).

## Критерии приёмки

- Товары упорядочены по убыванию `sold`.
- При равных `sold` порядок задаёт название по алфавиту.
- Сортировка работает с числами как с числами: `sold` равное `100` выше, чем `99`.
- Исходный массив не меняется. Результат — другой массив.
- Для пустого массива результат — пустой массив.

## Ограничения

- Не используйте `sort` на самом `products`.
- Менять только тело `rankProducts`.
