# Разбор

Компаратор отвечает на вопрос «кто идёт раньше: `a` или `b`». Здесь два признака, поэтому он работает в два шага.

1. Разница `b.sold - a.sold`. Если у `b` продаж больше, результат положительный, и `b` идёт раньше. Это сортировка по убыванию. Порядок `a - b` дал бы возрастание.
2. Если продажи равны (разница `0`), решает название: `localeCompare` возвращает отрицательное, нулевое или положительное число с учётом русского алфавита.

`toSorted` возвращает копию, поэтому каталог остаётся нетронутым. Такая же запись для старых окружений: `products.slice().sort(...)`.
