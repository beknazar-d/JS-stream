# Разбор

Функция состоит из трёх шагов, и у каждого свой тест.

1. **Какие заказы считаются.** Тест со смесью статусов ловит ошибку, когда сумма берётся по оплаченным, а делится на число всех заказов. Среднее по двум оплаченным из четырёх должно быть 2000, а ошибка даст 1000.
2. **Нет оплаченных заказов.** Деление нуля на ноль даёт `NaN`. Нужны оба случая: пустой список и список без оплаченных.
3. **Округление.** Если сумма всегда делится нацело, потерянное округление не заметить. Нужны данные со средним 1000,5.

Тесты проверяют только результат для данных, а не то, как функция написана.
