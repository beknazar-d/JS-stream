## Контекст

В панели менеджера показан «средний чек»: средняя сумма оплаченных заказов, округлённая до целого рубля. Неоплаченные и отменённые заказы в среднее не входят. Если оплаченных заказов нет, показывается `0`. Тестов у функции `averagePaidTotal` нет, а перед следующим релизом её будут переписывать.

## Цель

Напишите тесты в `index.test.js` для функции `averagePaidTotal` из `subject/index.js` (код показан под описанием). Функция работает так:

- берёт заказы со статусом `"paid"`;
- считает среднюю сумму `total` и округляет до целого;
- если оплаченных заказов нет, возвращает `0`.

## Критерии приёмки

- Все ваши тесты проходят на показанной реализации.
- Тесты падают на каждой из трёх реализаций с ошибкой.
- Тесты проверяют только результат для входных данных, а не устройство функции.
- Названия тестов описывают случай на русском языке.

## Ограничения

- Пишите тесты только в `index.test.js`. Код функции менять нельзя.
- Используйте `describe`, `it` и `expect` без импорта. Из `index.js` импортируйте только `averagePaidTotal`.
- Данные для тестов пишите прямо в тестах.
