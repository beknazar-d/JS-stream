## Контекст

В корзине интернет-магазина нужны три вычисления: сумма цен списком чисел, итог корзины из позиций с количеством и список цен по возрастанию для фильтра. Напишите их по памяти.

## Цель

Допишите в `index.js` три функции:

- `sumPrices(prices)` возвращает сумму чисел в массиве;
- `cartTotal(items)` возвращает сумму `price * quantity` по позициям вида `{ price: 300, quantity: 3 }`;
- `sortPricesAscending(prices)` возвращает новый массив цен по возрастанию.

## Критерии приёмки

- `sumPrices([1200, 300, 4500])` возвращает `6000`, а `sumPrices([])` возвращает `0`.
- `cartTotal([{ price: 300, quantity: 3 }, { price: 1200, quantity: 2 }])` возвращает `3300`, а для пустой корзины `0`.
- `sortPricesAscending([900, 1200, 300])` возвращает `[300, 900, 1200]`.
- Исходный массив цен после `sortPricesAscending` остаётся прежним.

## Ограничения

- Для сумм используйте `reduce` с начальным значением.
- Менять только тела функций.
