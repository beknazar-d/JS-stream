# Разбор

- В обеих суммах второй аргумент `reduce` равен `0`. Он нужен, чтобы пустой список давал `0`, а не `TypeError`. А для объектов он нужен ещё и потому, что без него первым значением `sum` стал бы сам объект.
- В `cartTotal` на каждом шаге к накопленной сумме прибавляется `item.price * item.quantity`.
- В `sortPricesAscending` компаратор `(a, b) => a - b` сравнивает числа как числа. Без него `sort` сравнил бы их как строки. Метод `toSorted` возвращает копию, поэтому исходные цены остаются на местах. Тот же результат даёт `prices.slice().sort((a, b) => a - b)`.
