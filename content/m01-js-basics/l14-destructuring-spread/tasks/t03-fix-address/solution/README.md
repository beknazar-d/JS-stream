# Разбор

В исходном коде было две ошибки.

1. Распаковка в списке параметров `({ city, street, house })` падает, если функцию вызвали без аргумента или с `null`. Ошибка случается ещё до первой строки тела. Поэтому параметр принимаем целиком и проверяем, что адрес есть. Условие `!address` ловит и `undefined`, и `null`.
2. У дома не было значения по умолчанию, и отсутствующее свойство превращалось в слово `undefined` в строке. Запись `house = 'б/н'` подставляет запасное значение.

Вариант с параметром по умолчанию `= {}` кажется быстрым, но молчаливо выдаёт мусорную строку вместо понятного «Адрес не указан». К тому же он не спасает от `null`: значение по умолчанию на `null` не срабатывает.
