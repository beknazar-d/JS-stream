## Контекст

В панели оператора каждая строка списка заказов собирается из пары значений: номер заказа и данные клиента. Рядом в очереди на сборку нужно показать, какой заказ собирать следующим и сколько ждут. Код пишут десятки раз в неделю, поэтому синтаксис распаковки должен быть в пальцах.

## Цель

Напишите по памяти два тела функций в `index.js`. Подсказки в коде нет, шпаргалку урока можно открыть только после попытки.

- `orderLabel(order)` возвращает строку вида `Заказ 1042: Анна Ким, Казань`. Номер, имя и город берутся из заказа вида `{ id, customer: { name, city } }`. Если города нет, вместо него выводится `не указан`.
- `splitQueue(queue)` принимает массив номеров заказов и возвращает объект `{ next, waiting }`: `next` — первый заказ очереди, `waiting` — новый массив с остальными.

## Критерии приёмки

- `orderLabel({ id: 1042, customer: { name: 'Анна Ким', city: 'Казань' } })` возвращает `'Заказ 1042: Анна Ким, Казань'`.
- Без города в строке стоит `не указан`, а не `undefined`.
- `splitQueue([1001, 1002, 1003])` возвращает `{ next: 1001, waiting: [1002, 1003] }`.
- Пустая очередь даёт `{ next: undefined, waiting: [] }`, исходный массив не меняется.

## Ограничения

- Только `index.js`.
- Попробуйте обойтись без обращений вида `order.customer.name` и без `slice`: цель задания в том, чтобы набрать распаковку.
