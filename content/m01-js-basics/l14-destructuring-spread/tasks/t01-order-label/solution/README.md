# Разбор

`const { id, customer: { name, city = 'не указан' } } = order;` делает три вещи сразу: берёт `id`, заходит во вложенный объект `customer` и берёт из него `name` и `city`. Значение после знака равенства используется, только если свойства нет или оно равно `undefined`.

Слово `customer` в этой записи не создаёт переменную. Оно лишь показывает, куда зайти.

`const [next, ...waiting] = queue;` берёт первый элемент в `next`, а три точки собирают всё остальное в новый массив. Для пустой очереди `next` будет `undefined`, а `waiting` — пустой массив, поэтому отдельная проверка не нужна. Исходный массив не меняется.
