# Разбор

1. `status` равен `new`: свойство есть, значение по умолчанию не нужно.
2. `coupon` равен `null`. Значение по умолчанию подставляется только на `undefined` (или отсутствующее свойство). `null` — это намеренное «пусто», его не заменяют. Именно эта ловушка стоит за тикетом про пропавший промокод.
3. `note` равно `undefined`, поэтому берётся `нет`.
4. Свойства `total` в заказе нет, поэтому подставляется `0`.
5. В `copy` поле `status` перезаписано, потому что оно стоит после `...order`. Исходный заказ не изменился: `paid new`.
6. `others` собирает всё, кроме первого элемента: `[20, 30]`.
7. `{ ...base }` копирует только верхний уровень. Объект `address` остаётся общим для обеих переменных, поэтому изменение через `baseCopy` видно и в `base`: `Самара`.
