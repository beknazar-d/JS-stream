## Контекст

Функция `applyPatch(order, patch)` применяет правку оператора к заказу. Через неё идут все изменения: смена статуса, заметка, правка контактов. Раньше в ней уже находили три ошибки, и каждая стоила дня разбирательств. Тестов нет, а завтра функцию будут переписывать.

## Цель

Напишите тесты в `index.test.js` для `applyPatch` из `subject/index.js` (код показан под описанием). Функция работает так:

- возвращает новый заказ: поля заказа плюс поля из правки;
- вложенный объект `customer` из правки сливается с `customer` заказа, а не заменяет его целиком;
- поле `id` менять через правку нельзя, оно игнорируется;
- исходный заказ и правка не меняются.

## Критерии приёмки

- Все ваши тесты проходят на показанной реализации.
- Тесты падают на каждой из трёх версий с ошибкой.
- Тесты проверяют только результат и состояние данных, не устройство функции.
- Названия тестов описывают случай по-русски.

## Ограничения

- Пишите тесты только в `index.test.js`. Код функции менять нельзя.
- Из `index.js` импортируйте только `applyPatch`.
- Подумайте, что должно остаться неизменным после вызова, а не только что должно измениться.
