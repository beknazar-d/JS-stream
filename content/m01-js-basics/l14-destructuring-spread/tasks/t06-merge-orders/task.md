## Контекст

Тикет от службы поддержки магазина. Клиент оформил подряд три заказа на один адрес и просит собрать их в одну коробку. Оператору нужна кнопка «Объединить заказы». Она берёт основной заказ и добавляет к нему позиции из остальных. Если один и тот же товар есть в нескольких заказах, строка в итоге должна быть одна, с суммой количества.

Склад уже сообщал, что после объединения «исчезают» количества в старых заказах: объединение случайно правило исходные строки. Этого повторять нельзя: старые заказы нужны для истории и возвратов.

Заказ выглядит так:

```js
{ id: 1042, status: 'new', lines: [{ sku: 'A-100', name: 'Кофе зерновой 1 кг', price: 1200, qty: 2 }] }
```

## Цель

Реализуйте в `index.js` функцию `mergeOrders(base, ...others)`.

Она возвращает новый заказ: все поля основного заказа `base`, плюс:

- `lines` — позиции основного заказа, затем позиции остальных заказов по порядку; одинаковые `sku` объединяются в одну строку с суммой `qty`, название и цена берутся из той строки, что встретилась первой, порядок — по первому появлению;
- `mergedFrom` — массив номеров (`id`) присоединённых заказов в том порядке, в каком они переданы.

## Критерии приёмки

- `mergeOrders(a, b)` и `mergeOrders(a, b, c, d)` работают одинаково: сколько заказов передали, столько и объединили.
- `mergeOrders(a)` без дополнительных заказов возвращает копию `a` с `mergedFrom: []`.
- Ни `base`, ни остальные заказы не меняются, включая объекты внутри `lines`.
- Статус и прочие поля основного заказа сохраняются.

## Ограничения

- Только `index.js`. Не используйте `arguments`.
- Используйте rest-параметр и spread. Мутации (`push` в чужие массивы, присваивание полей чужих объектов) недопустимы.
