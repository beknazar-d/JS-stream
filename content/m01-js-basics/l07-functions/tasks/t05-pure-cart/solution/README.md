# Разбор

Что было не так в исходной функции:

- она читала и меняла переменную `total` снаружи (побочный эффект);
- печатала в консоль (ещё один побочный эффект);
- возвращала `undefined`, поэтому результат нужно было получать отдельной функцией `getTotal`.

Что сделали:

1. Текущая сумма стала параметром `total`. Всё, что нужно для расчёта, теперь приходит через параметры.
2. Результат отдаётся через `return`. Вызывающий код сам решает, где его хранить и печатать.
3. `quantity = 1` в списке параметров сохраняет удобство: можно не передавать количество, когда берут одну штуку.
4. Переменная модуля и `getTotal` удалены. Теперь можно иметь сколько угодно корзин: у каждой своя сумма в переменной вызывающего кода.

Результат: функция чистая, её тест пишется одной строкой без подготовки.
