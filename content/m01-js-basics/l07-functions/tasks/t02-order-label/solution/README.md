# Разбор

1. `export function orderLabel(number)` — объявление функции с одним параметром. Слово `export` делает её доступной для тестов.
2. `String(number)` превращает число в строку. Метод `padStart` есть только у строк (урок 1.5).
3. `padStart(4, '0')` дополняет строку слева нулями до длины 4. Если строка уже длиннее, она остаётся как есть: `12345` не обрезается.
4. `return` отдаёт готовую подпись вызвавшему коду. Без него функция вернула бы `undefined`.
