## Контекст

В письме покупателю и в чеке номер заказа должен выглядеть одинаково: слово «Заказ», знак номера и номер из четырёх цифр с ведущими нулями. Например, заказ 42 печатается как «Заказ №0042».

## Цель

В `index.js` объявите и экспортируйте функцию `orderLabel(number)`. Она принимает номер заказа (целое число) и возвращает строку вида `Заказ №0042`.

## Критерии приёмки

- `orderLabel(42)` возвращает `"Заказ №0042"`.
- `orderLabel(7)` возвращает `"Заказ №0007"`.
- Номер длиннее четырёх цифр не обрезается: `orderLabel(12345)` возвращает `"Заказ №12345"`.
- Функция возвращает строку через `return`, а не печатает её.

## Ограничения

- Имя функции и параметр должны быть именно такими: `orderLabel(number)`.
- Заготовка пустая: объявите функцию с `export` сами.
