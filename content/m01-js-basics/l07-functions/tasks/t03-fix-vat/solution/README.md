# Разбор

В исходной функции две ошибки.

1. Нет `return`. Выражение `price * (1 + rate)` вычислялось и сразу выбрасывалось, функция возвращала `undefined`. Добавили `return`.
2. Строка `rate = rate || 0.2` заменяет любое ложное значение: `0`, `""`, `NaN`, `null`. Ставка `0` законная, но ложная, поэтому её заменяло на `0.2`. Значение по умолчанию в списке параметров, `rate = 0.2`, срабатывает только когда аргумента нет (`undefined`), и ноль остаётся нулём.

Эту разницу между `||` и значением по умолчанию мы ещё разберём в уроке 1.9.
