## Контекст

Бухгалтерия жалуется: на сайте цены с НДС показываются как пустое место. Функция `withVat` считает цену с налогом, ставка по умолчанию 20%. Для некоторых товаров ставка 0%, и их цена должна оставаться прежней. Функцию писал стажёр, она не работает.

## Цель

Исправьте `withVat(price, rate)` в `index.js`. Она возвращает цену с налогом: `price * (1 + rate)`. Если ставка не передана, используется `0.2`. Если передан `0`, налог не начисляется.

## Критерии приёмки

- `withVat(100)` возвращает `120`.
- `withVat(100, 0.1)` возвращает `110`.
- `withVat(100, 0)` возвращает `100`, а не `120`.
- Функция возвращает число, а не печатает его и не возвращает `undefined`.

## Ограничения

- Не меняйте имя функции и порядок параметров.
- Замените проверку ставки на значение по умолчанию в списке параметров.
