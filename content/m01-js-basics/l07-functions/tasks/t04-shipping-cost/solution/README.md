# Разбор

1. `express = false` в списке параметров: если третий аргумент не передан, экспресса нет.
2. Проверки идут первыми и возвращают `null` для некорректных данных. `Number.isInteger` отсеивает строки, дробные числа и `NaN`. Для расстояния отдельно проверяем тип и `NaN`, потому что дробные значения (12.5 км) допустимы.
3. Дальше расчёт по шагам с накоплением в `cost`. Доплаты строго для значений больше границы: `weightKg > 3` и `distanceKm > 100`.
4. Экспресс применяется последним, к итогу со всеми доплатами.
5. `return cost` стоит в конце, на единственном пути выполнения. Раннее `return null` для плохих данных не мешает: функция всё равно возвращает значение на каждом пути.
6. Функция чистая: результат зависит только от аргументов, ничего снаружи не меняется и в консоль ничего не печатается.
