## Контекст

Тикет: «Единая формула доставки для карточки товара, корзины и письма». Сейчас три экрана считают по-разному. Вместо трёх копий нужна одна функция, которую вызывают все.

Правила тарифа:

- базовая цена доставки 200 рублей;
- вес до 3 кг включительно входит в базу; каждый полный килограмм сверх 3 добавляет 40 рублей;
- если расстояние больше 100 км, добавляется 300 рублей (ровно 100 км ещё без доплаты);
- экспресс-доставка удваивает итоговую стоимость.

## Цель

В `index.js` объявите и экспортируйте функцию `shippingCost(weightKg, distanceKm, express = false)`. Она возвращает стоимость доставки в рублях по правилам выше.

## Критерии приёмки

- `shippingCost(2, 50)` возвращает `200`.
- `shippingCost(5, 250)` возвращает `580`: 200 + 2 × 40 + 300.
- `shippingCost(2, 50, true)` возвращает `400`.
- Граничные значения без доплаты: `shippingCost(3, 100)` возвращает `200`.
- Вес должен быть целым числом не меньше 1, расстояние — числом не меньше 0. Иначе возвращается `null`.
- Функция чистая: не меняет ничего снаружи и не печатает в консоль.

## Ограничения

- Параметр `express` необязательный: по умолчанию `false`.
- Все расчёты в одной функции, без копирования формулы.
