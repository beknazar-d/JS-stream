# Разбор

1. `shippingCost(2, true)`: база равна 200 + 2 × 40 = 280, экспресс включён, значит `return base * 2` даёт `560`.
2. `shippingCost(2)`: `express` получает значение по умолчанию `false`, условие не выполняется. Функция доходит до конца без `return` и возвращает `undefined`. Вывод: `undefined`.
3. `label("Чайник")`: параметр `count` не получил аргумент и равен `undefined`. Шаблонная строка превращает его в слово `undefined`: `Чайник xundefined`.
4. `label("Чайник", 2, 3)`: третий аргумент лишний, ему некуда попасть, он игнорируется. Результат `Чайник x2`.
5. `total(300)`: `quantity` берёт значение по умолчанию 1, результат `300`.
6. `total(300, 0)`: ноль передан явно, значение по умолчанию не подставляется. `300 * 0` равно `0`.
7. `total(300, undefined)`: `undefined` считается «аргумента нет», подставляется 1. Результат `300`.
