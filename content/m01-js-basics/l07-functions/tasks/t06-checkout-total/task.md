## Контекст

Тикет: «Итог заказа на странице оформления». Покупатель вводит цену товара (её подставляет страница), количество и, возможно, процент по купону. Все значения приходят из формы строками. Нужно показать итоговую сумму с учётом скидки и доставки.

Правила:

- скидка по купону в процентах применяется к стоимости товаров;
- доставка стоит 350 рублей, но бесплатна, если сумма товаров после скидки не меньше 5000 рублей;
- процент купона необязательный: по умолчанию 0.

Решено разбить расчёт на три функции, чтобы каждую можно было проверить отдельно и использовать в других местах.

## Цель

В `index.js` объявите и экспортируйте три функции.

- `applyDiscount(amount, percent = 0)` возвращает сумму после скидки: `amount - amount * percent / 100`.
- `shippingFor(amount)` возвращает `0`, если `amount` не меньше 5000, иначе `350`.
- `checkoutTotal(priceText, quantityText, couponPercent = 0)` возвращает итог заказа: стоимость товаров со скидкой плюс доставка, которая считается от суммы после скидки.

## Критерии приёмки

- `applyDiscount(2000, 10)` возвращает `1800`; `applyDiscount(2000)` возвращает `2000`.
- `shippingFor(4999)` возвращает `350`, `shippingFor(5000)` возвращает `0`.
- `checkoutTotal("1200", "2")` возвращает `2750`: товары 2400 и доставка 350.
- `checkoutTotal("6000", "1", 20)` возвращает `5150`: после скидки 4800, доставка платная.
- `checkoutTotal("2500", "2")` возвращает `5000`: товары на 5000 везут бесплатно.
- Цена и количество приходят строками (числа тоже допустимы), пробелы по краям не мешают.
- Цена должна быть числом больше 0, количество — целым числом не меньше 1, процент купона — числом от 0 до 100. Иначе `checkoutTotal` возвращает `null`, а не `NaN`.
- Все три функции чистые: не печатают в консоль и ничего не хранят снаружи.

## Ограничения

- `checkoutTotal` должна вызывать `applyDiscount` и `shippingFor`, а не копировать их формулы.
- Деньги не округляйте: дробные копейки допустимы (в проекте P1 мы вернёмся к округлению).
