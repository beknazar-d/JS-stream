# Разбор

1. `applyDiscount` и `shippingFor` — маленькие чистые функции. Они не знают друг о друге и их легко проверить по отдельности. У `applyDiscount` процент по умолчанию 0: без купона сумма не меняется.
2. `checkoutTotal` сначала превращает строки в числа через `Number()` (урок 1.1) и отсеивает плохой ввод. Пустая строка даёт `0`, поэтому проверка `price <= 0` ловит и пустое поле, а `Number.isFinite` ловит `NaN` и `Infinity`. Количество проверяет `Number.isInteger`: он ловит дроби и `NaN`, а `Number("")` равное 0 отсеивается условием `quantity < 1`.
3. Для процента важна проверка типа: `couponPercent` не проходит через `Number()`, поэтому строку `"10"` мы считаем ошибкой вызывающего кода, а не пытаемся угадать.
4. Только после проверок идёт расчёт. Он состоит из вызовов маленьких функций: сумма товаров, скидка, доставка от суммы **после** скидки.
5. Ни одна функция не печатает и не хранит состояние: все они чистые.
