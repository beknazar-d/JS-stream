## Контекст

Тикет B2B-310. Юридические лица просят счёт, где все суммы указаны в копейках целыми числами: бухгалтерия не принимает дробные копейки. Магазин получает цену за штуку в рублях строкой из формы (`"19.99"`), количество строкой (`"3"`), ставку НДС и стоимость доставки в копейках числами.

## Цель

Реализуйте `invoiceTotal(price, quantity, vatPercent, shippingKopecks)` в `index.js`. Функция возвращает сумму счёта в копейках, целое число.

Порядок расчёта:

1. Переведите цену за штуку в копейки и округлите: `Math.round(Number(price) * 100)`. Умножение `19.99 * 100` даёт `1998.9999999999998`, поэтому округлять нужно сразу.
2. Умножьте на количество. Это сумма без НДС.
3. Посчитайте НДС от суммы без НДС по ставке `vatPercent` процентов и округлите его до целой копейки через `Math.round`.
4. Итог равен сумма без НДС плюс НДС плюс доставка.

Заведите отдельную переменную для каждого шага, чтобы расчёт читался сверху вниз.

## Критерии приёмки

- `invoiceTotal("19.99", "3", 20, 0)` возвращает `7196`: сумма 5997, НДС 1199 (1199,4 округлено), доставки нет.
- `invoiceTotal("10.10", "3", 5, 0)` возвращает `3182`: сумма 3030, НДС 152 (151,5 округлено вверх).
- Доставка прибавляется: `invoiceTotal("19.99", "3", 20, 35000)` возвращает `42196`.
- Ставка 0 процентов даёт сумму без НДС: `invoiceTotal("0.10", "3", 0, 0)` возвращает `30`.
- Числа вместо строк тоже работают: `invoiceTotal(250, 2, 20, 0)` возвращает `60000`.
- Результат всегда целое число.

## Ограничения

- Только арифметика, `Number` и `Math.round`.
- НДС считается от всей суммы без НДС, а не от цены одной штуки, иначе округление копеек накапливается.
