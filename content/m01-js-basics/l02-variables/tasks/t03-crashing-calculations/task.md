## Контекст

Баг-репорт BUG-2107. После рефакторинга три функции интернет-магазина падают с ошибками в консоли:

- `stockAfterSale`: `TypeError: Assignment to constant variable.`
- `priceWithVat`: `ReferenceError: Cannot access 'vat' before initialization`
- `shippingLabel`: `ReferenceError: lable is not defined`

Три разные ошибки, три разные причины. Нужно починить все три.

## Цель

Исправьте функции в `index.js`:

- `stockAfterSale(stock, sold)` возвращает остаток после продажи;
- `priceWithVat(price)` возвращает цену с НДС 20 процентов;
- `shippingLabel(city)` возвращает подпись для этикетки вида `"Доставка: Казань"`.

## Критерии приёмки

- `stockAfterSale(40, 5)` возвращает `35`.
- `priceWithVat(250)` возвращает `300`, `priceWithVat(100)` возвращает `120`.
- Цена может прийти строкой из формы: `priceWithVat("250")` тоже возвращает число `300`.
- `shippingLabel("Казань")` возвращает `"Доставка: Казань"`.
- Ни одна функция не падает с ошибкой.

## Ограничения

- Менять нужно только тела функций.
- Не заменяйте формулы на готовые числа: функции должны работать для любых входных значений.
