# Разбор

1. `stock` было `40`, после `stock - reserved` стало `35`.
2. `backup` получил копию числа `35`. Дальше `stock` уменьшили на 10, но `backup` не изменился, поэтому выводится `35`.
3. `stock` теперь `25`.
4. `let note;` без значения хранит `undefined`.
5. `typeof missingValue` не падает, хотя имени `missingValue` нет: оператор возвращает строку `"undefined"`. Выглядит так же, как в четвёртой строке, но это строка, а не значение.
6. `"SKU-" + reserved` — плюс со строкой склеивает, получается `"SKU-5"`.
