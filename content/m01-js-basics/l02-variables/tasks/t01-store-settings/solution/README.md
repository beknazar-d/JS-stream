# Разбор

Каждая настройка — одна строка: `export const имя = значение;`.

- `const`, потому что настройки в ходе работы программы не меняются.
- Строка пишется в кавычках, числа без кавычек. Число `5000` и строка `"5000"` — разные типы (урок 1.1).
- Имена в camelCase: первое слово с маленькой буквы, остальные с большой, без пробелов и подчёркиваний.
- Теперь, чтобы поменять НДС, достаточно исправить одну цифру в одном месте.
