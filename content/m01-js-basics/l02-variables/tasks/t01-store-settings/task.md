## Контекст

Тикет SHOP-118. В коде магазина порог бесплатной доставки, ставка НДС и лимит позиций в заказе записаны числами прямо в формулах. Команда решила собрать все настройки в одном файле, чтобы менять их в одном месте.

Это разминка: наберите объявления по памяти, без подсказок из урока.

## Цель

Объявите в `index.js` четыре константы и экспортируйте их. Строка выглядит так: `export const имя = значение;`. Слово `export` разрешает другим файлам (в том числе тестам) прочитать константу.

| Имя | Значение |
| --- | --- |
| `storeName` | строка `"ТехноСклад"` |
| `freeShippingFrom` | число `5000` |
| `maxItemsPerOrder` | число `20` |
| `vatPercent` | число `20` |

## Критерии приёмки

- Все четыре имени записаны в точности как в таблице (camelCase).
- `storeName` — строка, остальные три — числа, а не строки в кавычках.
- Значения совпадают с таблицей.

## Ограничения

- Используйте `const`: эти настройки в программе не меняются.
- Других экспортов добавлять не нужно.
