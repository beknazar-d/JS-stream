# Разбор

Остаток меняется по ходу расчёта, поэтому `stock` объявлен через `let`. Каждая строка берёт текущее значение, меняет его и записывает обратно. Слово `let` пишется один раз, в первой строке.

Каждое значение сначала проходит через `Number()`. Без этого `+` склеил бы строки (`"40" + "10"` даёт `"4010"`), как в уроке 1.1. `Number("")` даёт `0`, поэтому пустое поле не ломает расчёт. А `Number("abc")` даёт `NaN`, и он честно доезжает до результата: по условию вызывающая сторона сама решит, что с ним делать.

`parseInt` здесь не подходит: он отбрасывает дробную часть, а остатки в килограммах бывают дробными.
