## Контекст

Функция `finalPrice(price, vatPercent, shippingFee)` считает итоговую цену заказа: цена плюс НДС плюс доставка. Цена приходит из формы, поэтому может быть строкой. Тестов у функции нет, а перед следующим релизом её будут переписывать.

Ваша задача — написать тесты, которые защитят функцию от поломки.

## Цель

Напишите тесты в `index.test.js` для функции `finalPrice` из файла `subject/index.js` (код показан под описанием). Функция работает так:

- берёт цену как число, считает НДС от цены по ставке `vatPercent` процентов;
- возвращает цена плюс НДС плюс `shippingFee`;
- цена может быть числом или строкой с числом.

## Критерии приёмки

- Все ваши тесты проходят на показанной реализации.
- Тесты падают на каждой из трёх реализаций с ошибкой.
- Тесты проверяют только результат для входных данных, а не устройство функции.
- Названия тестов описывают случай по-русски, например `it('прибавляет доставку к цене с НДС', ...)`.

## Ограничения

- Пишите тесты только в `index.test.js`. Код функции менять нельзя.
- Используйте `describe`, `it` и `expect` без импорта. Из `index.js` импортируйте только `finalPrice`.
- Подумайте о трёх вещах: меняется ли результат при другой ставке НДС, учитывается ли доставка, как функция ведёт себя со строкой вместо числа.
