# Разбор

Хорошие тесты проверяют места, где функцию легко сломать. В `finalPrice` три входа, и у каждого своя ошибка:

1. **Ставка НДС.** Если все тесты используют одну ставку, функция может её игнорировать. Нужны две разные ставки: `finalPrice(1000, 10, 0)` и `finalPrice(1000, 20, 0)`.
2. **Доставка.** Если доставка всегда равна нулю, её потеря не видна. Нужен тест с ненулевой доставкой.
3. **Строка вместо числа.** Данные из формы — строки. Тест `finalPrice("1000", 10, 350)` ловит пропущенное `Number()`: без него плюс склеил бы строку с числами.

Тесты проверяют результат, а не устройство, поэтому переживут переписывание функции.
