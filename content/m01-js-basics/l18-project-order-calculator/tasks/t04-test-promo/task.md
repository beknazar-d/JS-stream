## Контекст

Этап 4 проекта P1. До написания модуля скидок принято сначала написать приёмочные тесты: так заказчик и разработчик одинаково понимают правила. Выдержка из ТЗ:

> Промокод SALE10 даёт скидку 10% от суммы. Копейки округляются как в школе: половина вверх. Промокод MINUS500 даёт скидку 500 рублей, но только для заказов от 2 000 рублей. Промокод можно вводить с пробелами и в любом регистре. Пустой промокод означает «без скидки». Неизвестный промокод — ошибка с понятным текстом.

Функция `applyPromo(amount, code)` принимает сумму в копейках и возвращает размер скидки в копейках.

## Цель

Напишите тесты в `index.test.js` для `applyPromo` из `subject/index.js` (код показан под описанием). Реализация уже написана заказчиком в виде образца, ваши тесты станут приёмочными для будущих версий.

## Критерии приёмки

- Все ваши тесты проходят на показанной реализации.
- Тесты падают на каждой из трёх версий с ошибкой.
- Ошибки проверяются через `expect(() => ...).toThrow('текст')`.
- Названия тестов описывают правило по-русски, в духе ТЗ.

## Ограничения

- Пишите тесты только в `index.test.js`. Код функции менять нельзя.
- Из `index.js` импортируйте только `applyPromo`.
- Помните про границы: ровно порог, на копейку ниже порога, половина копейки.
