## Контекст

Этап 2 проекта P1. Заказчик в ТЗ пишет: «Скидка 15% на товар за 19,99 ₽ должна давать ровно ту сумму, которую покажет калькулятор на кассе, до копейки. Бухгалтерия сверяет». Прежде чем писать расчёты, выясним, как JavaScript на самом деле округляет и считает дробные числа. Здесь прячутся все ошибки в копейку.

## Цель

Прочитайте код из `snippet.js`. Запишите в `answer.js` в массив `output` ровно то, что код выведет в консоль, по одной строке на каждый `console.log`. Числа записывайте так, как их показывает консоль: `3`, `299.85`, `0.30000000000000004`. Строку тоже записывайте без кавычек.

## Критерии приёмки

- В массиве `output` ровно девять строк в порядке вызовов `console.log`.
- Каждый элемент — строка.
- Ответ совпадает с реальным выводом кода построчно.

## Ограничения

- Не меняйте `snippet.js`.
- Не запускайте код до ответа: сначала предскажите, потом сверьтесь с проверкой.
