# Разбор

1. `0.1 + 0.2` даёт `0.30000000000000004`: эти дроби в двоичном виде бесконечные, поэтому ответ приближённый.
2. `19.99 * 100` даёт `1998.9999999999998`, а не `1999`. Умножение на сто не убирает хвост.
3. `Math.round` возвращает ближайшее целое: `1999`. Вот почему сумму в копейках получают через `Math.round(x * 100)`.
4. `Math.round(2.5)` даёт `3`, а `Math.round(-2.5)` даёт `-2`: половина округляется вверх, к плюс бесконечности. Для положительных сумм это привычное «половина вверх».
5. `105 / 10` равно `10.5` точно, `Math.round(10.5)` даёт `11`. На этом правиле построены скидки в проекте.
6. `(1.005).toFixed(2)` даёт строку `1.00`, хотя школьное округление дало бы `1.01`. Число `1.005` хранится как `1.00499999999999989...`.
7. По той же причине `Math.round(1.005 * 100) / 100`: произведение `100.49999999999999`, округление даёт `100`, ответ `1`.
8. `1999 * 15 / 100` равно `299.85`. Это 15% от 19,99 ₽ в копейках: `299.85` копейки.
9. `Math.round(299.85)` даёт `300`: скидка 3 рубля ровно.

Вывод для проекта: считаем в целых копейках, округляем одним способом (`Math.round`) и в одном месте.
