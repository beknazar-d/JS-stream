## Контекст

Финальный этап проекта P1. Все детали готовы: деньги, корзина, скидки. Осталось собрать калькулятор заказа и сдать заказчику. Из ТЗ:

> Калькулятор получает корзину и промокод и возвращает полную раскладку заказа. Цены уже включают НДС 20%. Доставка стоит 299 рублей, но бесплатна, если сумма товаров после всех скидок от 3 000 рублей. НДС показываем отдельной строкой для чека, он уже входит в итог и не прибавляется. Пустая корзина — ошибка. Все суммы в копейках, целые, ни одной дробной копейки.

## Цель

Допишите три файла.

`delivery.js`: константы `FREE_DELIVERY_FROM` (`300000`) и `DELIVERY_PRICE` (`29900`) и функция `deliveryCost(goods)`: возвращает `0`, если `goods` не меньше порога, иначе стоимость доставки.

`vat.js`: функция `vatIncluded(amount)`: сколько НДС 20% уже входит в сумму `amount`. Формула: `amount × 20 / 120`, округление до целой копейки по правилу «половина вверх».

`index.js`: функция `calculateOrder(cart, promoCode)`. Если корзина пуста (или не массив), выбрасывает `ValidationError` с текстом `Корзина пуста`. Иначе возвращает объект:

```js
{
  lines: [{ sku, name, price, qty, total }],  // total = price × qty, в порядке корзины
  subtotal,  // сумма корзины без скидок
  volume,    // скидка за количество
  promo,     // скидка по промокоду
  goods,     // subtotal − volume − promo
  delivery,  // стоимость доставки по сумме goods
  vat,       // НДС, входящий в (goods + delivery)
  total,     // goods + delivery
}
```

## Критерии приёмки

- Корзина на 2 999,99 ₽ без промокода: доставка `29900`, на 3 000,00 ₽: доставка `0`.
- Порог бесплатной доставки проверяется по сумме `goods` после скидок, а не по `subtotal`: промокод может вернуть заказ ниже порога.
- `vat` считается от `total` (с доставкой), например `vat` для итога `119999` равен `20000`.
- Ошибки скидок (`Неизвестный промокод: ...`, порог MINUS500) пробрасываются как есть.
- Корзина и ее позиции не меняются. Все суммы в результате — целые числа.

## Ограничения

- Используйте готовые `discountSummary`, `deliveryCost`, `vatIncluded`. Не повторяйте их логику в `index.js`.
- Не меняйте `errors.js`, `money.js`, `cart.js`, `discounts.js`.
