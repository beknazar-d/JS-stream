# Разбор

**Разбор текста.** Регулярное выражение `^\d+(\.\d{1,2})?$` разрешает только цифры, затем необязательные одну-две цифры после точки. Запятую заменяем на точку заранее. Всё остальное (буквы, минус, пробелы внутри, три знака после точки) отсекается одним `if`.

**Копейки как строка.** `'1200.5'.split('.')` даёт `['1200', '5']`. Копейки `'5'` на самом деле 50, поэтому строку дополняют справа: `'5'.padEnd(2, '0')` даёт `'50'`. Без этого получится 5 копеек. Само вычисление на целых: `1200 * 100 + 50`. Никаких дробных рублей, значит, и хвостов нет.

**Форматирование.** Рубли и копейки получаем целочисленным делением и остатком. Копейки дополняем нулём слева (`padStart`), чтобы 7 копеек превратились в `07`. Группы по три цифры ставим при обходе строки: пробел нужен после цифры, если до конца осталось число цифр, при котором оставшаяся часть кратна трём.

**Проверка входа** в `formatMoney` нужна, потому что `Number.isInteger('5')` ложно, а отрицательные суммы в этом проекте означают ошибку выше по цепочке.
