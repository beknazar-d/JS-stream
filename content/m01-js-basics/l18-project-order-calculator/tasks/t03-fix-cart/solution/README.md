# Разбор

**Мутация.** `existing.qty += ...` и `cart.push(...)` меняют данные, которые принадлежат вызывающему коду. История корзины в интерфейсе хранит ссылки на те же массив и строки, поэтому прошлые версии «задним числом» меняются. Решение: возвращать новый массив. Строку, которая меняется, заменяют копией `{ ...line, qty: ... }`, остальные строки переиспользуются как есть.

**Копейки.** Цена уже в копейках, делить её на сто не нужно. Деление превращало целую сумму в дробные рубли (599.97), а касса ждёт целые копейки. К тому же дробные рубли рано или поздно дают хвосты вроде `4.35 * 100`, то есть `434.99999999999994`. Сумма целых чисел всегда целая.

**Проверки.** `Number.isInteger` отсекает дроби, строки и `NaN`. Проверки в начале функции останавливают плохие данные раньше, чем они попадут в корзину. Сообщения написаны так, чтобы их можно было показать покупателю.

**Почему недостаточно `[...cart]`.** Копия массива не копирует объекты внутри. Если потом изменить `line.qty` у общей строки, изменится и старая корзина. Это та же ловушка поверхностной копии из урока про spread.
