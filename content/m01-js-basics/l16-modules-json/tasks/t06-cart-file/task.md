## Контекст

Магазин добавляет кнопку «Сохранить корзину в файл», чтобы покупатель мог отправить корзину коллеге или вернуться к ней с другого устройства. Формат файла уже менялся один раз, и старые файлы лежат у людей в почте.

- Версия 1: `{ "version": 1, "lines": [{ "sku": "A-100", "qty": 2, "price": "1200.50" }] }`. Цена записана строкой в рублях.
- Версия 2 (текущая): `{ "version": 2, "items": [{ "sku": "A-100", "qty": 2, "priceKopecks": 120050 }] }`. Цена хранится целым числом копеек.

Поддержка должна открывать файлы обеих версий. Если файл испорчен или сделан будущей версией сайта, пользователь должен увидеть понятное сообщение, а не «Unexpected token» и не белый экран.

## Цель

Реализуйте три файла заготовки.

`schema.js`:

- `CURRENT_VERSION` — константа, равная `2` (именованный экспорт);
- `migrate(data)` приводит уже разобранные данные к версии 2. Для версии 2 возвращает те же данные как есть. Для версии 1 возвращает `{ version: 2, items }`, где цена в рублях-строке переведена в целые копейки (с округлением до целого). Ошибки: `Файл не похож на корзину` (не объект, нет числовой `version`, для версии 1 нет массива `lines`) и `Неподдерживаемая версия файла: 3` (с номером версии).

`cart-file.js`:

- `exportCart(items)` возвращает строку JSON с отступом в два пробела: `{ version, items }` с текущей версией;
- `importCart(text)` разбирает строку, переносит данные через `migrate` и возвращает массив позиций `{ sku, qty, priceKopecks }` (лишние поля отбрасываются). Ошибки: `Файл повреждён: это не JSON`, если текст не JSON; `Файл не похож на корзину`, если после миграции нет массива `items`; `Позиция 2: некорректные данные` (номер с единицы), если `sku` не непустая строка, `qty` не целое больше нуля или `priceKopecks` не целое неотрицательное.

`index.js`:

- `totalKopecks(items)` — сумма `qty × priceKopecks` по всем позициям;
- `roundTrip(items)` — экспорт и сразу импорт обратно.

## Критерии приёмки

- Файл версии 1 с ценой `"19.99"` даёт `priceKopecks: 1999`, а не `1998.9999999999998`.
- Ошибка миграции (версия 3) доходит до пользователя с её собственным текстом, а не превращается в «это не JSON».
- Обратный путь `importCart(exportCart(items))` возвращает позиции, равные исходным.
- Исходный массив `items` не меняется.

## Ограничения

- Три файла, связанные через `import` и `export`. Не складывайте всё в `index.js`.
- Ловите только то, что умеете обработать: блок `try/catch` нужен вокруг разбора JSON, не вокруг всего подряд.
