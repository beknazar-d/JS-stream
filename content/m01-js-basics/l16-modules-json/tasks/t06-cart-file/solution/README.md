# Разбор

**Слои.** `schema.js` ничего не знает о других файлах: версии и правила переноса. `cart-file.js` импортирует `schema.js` и отвечает за текст. `index.js` импортирует `cart-file.js` и добавляет прикладные функции. Зависимости идут в одну сторону, поэтому циклов нет, а каждый файл можно проверить отдельно.

**Миграция.** Данные старой версии приводятся к текущей один раз, на входе. Остальной код видит только версию 2. Когда появится версия 3, добавится ещё одна ветка в `migrate`, а остальные файлы не изменятся.

**Деньги в копейках.** `Number('19.99') * 100` равно `1998.9999999999998`. Хвост убирает `Math.round`. Целые копейки удобнее дробных рублей: их можно складывать без накопления хвостов.

**Где ловить.** `try/catch` обёрнут вокруг одного `JSON.parse`, потому что только эта ошибка превращается в понятное «это не JSON». Ошибки `migrate` и проверки позиций выбрасываются со своими текстами и идут наверх, как есть. Если обернуть всё, настоящая причина («версия 3») потеряется.

**Проверка позиций.** `item ?? {}` защищает от `null` внутри массива. Деструктуризация сразу отбрасывает лишние поля, потому что возвращается новый объект с тремя ключами.

**Экспорт.** `JSON.stringify(значение, null, 2)` печатает JSON с отступом в два пробела, чтобы файл можно было открыть и прочитать глазами.
