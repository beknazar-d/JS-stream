# Разбор

**Два вида экспорта.** Из файла можно отдать одно главное значение «по умолчанию» (`export default`) и сколько угодно именованных (`export const`, `export function`). Экспорт по умолчанию в файле может быть только один.

**Два вида импорта.** Главное значение подключают без скобок и называют как угодно: `import formatRub from './format.js'`. Именованные берут в фигурных скобках и под теми же именами, под которыми они экспортированы: `import { formatQty, CURRENCY } from './format.js'`. Обе формы можно записать в одной строке: `import formatRub, { formatQty, CURRENCY } from './format.js'`.

**Путь.** `./format.js` значит «файл format.js в этой же папке». Точка и расширение обязательны: без `./` JavaScript решит, что это пакет, а без `.js` Node.js не найдёт файл.

Функция `describeLine` не знает, как устроено форматирование. Она вызывает чужие функции. Когда формат поменяется, правка будет в одном месте.
