## Контекст

Код оформления заказа вырос до трёхсот строк в одном файле, и команда разделила его на модули: склад отдельно, скидки отдельно, сборка заказа отдельно. Теперь каждый файл нужно написать так, чтобы он делал одно дело и отдавал наружу только нужное.

## Цель

Напишите три файла заготовки.

`stock.js` (именованные экспорты):

- `available(stock, sku)` возвращает остаток товара `sku` из объекта вида `{ 'A-100': 5 }`; для товара, которого нет в объекте, возвращает `0`;
- `canReserve(stock, sku, qty)` возвращает `true`, если `qty` не больше остатка.

`discount.js` (один экспорт по умолчанию): функция `discountFor(qty)` возвращает долю скидки: `0.1` при количестве от 10, `0.05` при количестве от 5 до 9, иначе `0`.

`index.js`: функция `quote(cart, stock, prices)`. Корзина: `[{ sku, qty }]`, цены: `{ 'A-100': 1200 }`. Для каждой позиции:

- если товара не хватает: `{ sku, qty, ok: false, total: 0 }`;
- иначе `{ sku, qty, ok: true, total }`, где `total` — цена на количество с учётом скидки, округлённая до копеек (`Math.round(x * 100) / 100`).

Результат: `{ lines, total }`, где `total` — сумма `total` всех позиций, округлённая до копеек.

## Критерии приёмки

- `quote([{ sku: 'A-100', qty: 5 }], { 'A-100': 20 }, { 'A-100': 1200 })` возвращает одну позицию с `total: 5700` (5 × 1200 со скидкой 5%).
- Позиция с нехваткой товара получает `ok: false` и `total: 0` и не входит в общий итог.
- Запрос ровно на весь остаток принимается.
- `stock.js` отдаёт обе функции по имени, `discount.js` отдаёт функцию по умолчанию.

## Ограничения

- Логику склада и скидок держите в своих файлах, а `index.js` только подключает и собирает.
- Входные объекты не меняются.
