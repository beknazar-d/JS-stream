# Разбор

**Что в каком файле.** `stock.js` знает только про остатки. `discount.js` знает только про скидки: это одна функция, поэтому её естественно отдать по умолчанию. `index.js` ничего не считает сам по каждому правилу, а вызывает чужие функции и собирает результат.

**Порядок порогов.** В `discountFor` сначала проверяется большее количество. Если проверить `qty >= 5` раньше, то десять штук получат скидку пять процентов.

**Нулевое слияние.** `stock[sku] ?? 0` возвращает `0` для товара, которого нет на складе, и сохраняет настоящий ноль. Запись `||` здесь тоже сработала бы, но `??` точнее говорит, что мы заменяем только отсутствующее значение.

**Граница.** `qty <= available`: запрос ровно на весь остаток разрешён.

**Деньги.** Цена на количество на множитель `(1 - скидка)` даёт дробь с хвостом из-за двоичных чисел. Округление до копеек делается в одном месте, функцией `roundKopecks`. Общий итог тоже округляется, потому что сумма округлённых чисел снова может дать хвост.

Позиции без остатка получают `total: 0`, поэтому в итог они ничего не добавляют.
