# Разбор

В исходном коде было три ошибки.

1. `import { formatMoney } from './money.js'`: в файле нет экспорта с таким именем, он называется `formatPrice`. Именованный импорт требует точного совпадения имени, поэтому Node.js сообщает: «does not provide an export named 'formatMoney'».
2. `import calcTax from './tax.js'` без скобок означает «возьми экспорт по умолчанию». В `tax.js` его нет, там именованный экспорт, поэтому нужны скобки: `{ calcTax }`.
3. Налог считался от цены одной штуки: `calcTax(price)`, хотя по условию его нужно считать от суммы позиции `sum`.

Как отличать: если в файле написано `export function name`, импортируют `{ name }`. Если `export default`, импортируют без скобок. Сомневаетесь — откройте файл и посмотрите на его экспорты.

Правка в `index.js` безопаснее, чем в чужом файле. Экспорт — это договорённость с другими файлами, и нарушать её нельзя.
