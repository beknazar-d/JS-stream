## Контекст

Тикет из мобильного приложения: «Заказ сохранили в файл и загрузили обратно. Поле даты вдруг не работает как дата, примечание пропало, а сумма превратилась в `null`». Разработчик говорит: «JSON так делает». Давайте выясним, что именно делает JSON и в каких случаях данные меняются при превращении в текст и обратно.

## Цель

Прочитайте код из `snippet.js`. Запишите в `answer.js` в массив `output` ровно то, что код выведет в консоль, по одной строке на каждый `console.log`. Значения, которые не строки, записывайте так, как их показывает консоль: `[1, "2", null]`, `undefined`.

## Критерии приёмки

- В массиве `output` ровно семь строк в порядке вызовов `console.log`.
- Каждый элемент — строка.
- Ответ совпадает с реальным выводом кода построчно.

## Ограничения

- Не меняйте `snippet.js`.
- Не запускайте код до ответа: сначала предскажите, потом сверьтесь с проверкой.
