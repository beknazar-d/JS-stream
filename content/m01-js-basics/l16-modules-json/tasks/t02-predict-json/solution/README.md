# Разбор

1. `JSON.stringify` пропускает свойство `note` (значение `undefined`), заменяет `NaN` на `null`, превращает дату в строку ISO (`toISOString`), а `undefined` внутри массива заменяет на `null`.
2. В JSON `"3"` записано строкой, и `JSON.parse` вернёт строку. Тогда `"3" + 1` склеивает: `"31"`. Тип данных из JSON нужно проверять так же внимательно, как данные из формы.
3. После `parse` поле `created` — обычная строка, `typeof` даёт `string`. Дату нужно создать заново: `new Date(created)`.
4. Массив разобран: `[1, "2", null]`. Строка `"2"` осталась строкой.
5. Строка в JSON всегда в двойных кавычках, поэтому `JSON.stringify('кофе')` вернёт текст `"кофе"` вместе с кавычками.
6. Для `undefined` JSON не умеет записи, `stringify` возвращает не строку, а `undefined`.
7. Число с плавающей точкой записывается так, как оно хранится: `0.1 + 0.2` в JSON — `0.30000000000000004`. С деньгами это ловушка из первого урока, JSON её не исправляет.
