## Контекст

Корзина покупателя сохраняется в браузере строкой в формате JSON. При следующем заходе функция `restoreCart(text)` превращает строку обратно в корзину. Строка может оказаться чем угодно: обрезанной, сохранённой старой версией сайта, испорченной расширением браузера. Если функция упадёт, покупатель увидит белый экран. Если она промолчит и вернёт мусор, сумма заказа будет неверной. Тестов нет, а функцию собираются переписывать.

## Цель

Напишите тесты в `index.test.js` для `restoreCart` из `subject/index.js` (код показан под описанием). Функция работает так:

- принимает строку JSON вида `{"items":[{"sku":"A-100","qty":2}]}`;
- возвращает `{ items }`, где у каждой позиции остаются только `sku` и `qty`, а `qty` — число (из формы оно могло записаться строкой `"2"`);
- если текст не JSON или структура не похожа на корзину (нет массива `items`, вместо объекта число или `null`), выбрасывает `Error` с текстом `Корзина повреждена`.

## Критерии приёмки

- Все ваши тесты проходят на показанной реализации.
- Тесты падают на каждой из трёх версий с ошибкой.
- Ошибки проверяются через `expect(() => ...).toThrow('Корзина повреждена')`, с текстом.
- Названия тестов описывают случай по-русски.

## Ограничения

- Пишите тесты только в `index.test.js`. Код функции менять нельзя.
- Из `index.js` импортируйте только `restoreCart`.
- Входные строки пишите в тестах как обычные строки: `'{"items":[]}'`.
