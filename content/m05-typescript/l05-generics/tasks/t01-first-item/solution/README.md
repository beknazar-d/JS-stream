# Разбор

Параметр типа `T` связывает вход и выход: «массив значений T на входе, значение T или `undefined` на выходе». Компилятор сам подставляет `T` из аргумента, поэтому ни `<Order>`, ни `<string>` писать не нужно.

Результат `T | undefined`, а не просто `T`: для пустого массива `items[0]` равно `undefined`. Если написать `T`, компилятор перестанет напоминать, что очередь может быть пустой.

Заглушка с `unknown` не подходит по другой причине. Она честная, но бесполезная: чтобы прочитать `city`, пришлось бы сужать тип вручную. Параметр типа возвращает вызывающему именно тот тип, который он передал.
