## Контекст

Тикет DEV-512. В диспетчерской «Домотеки» на экране три очереди: заказы на отправку, свободные курьеры, посылки на сортировке. В каждой нужна кнопка «Взять первого». Сейчас у каждой очереди своя копия функции, и правки приходится вносить трижды.

Это задание на память: напишите функцию, не подглядывая в урок. Подсказки остаются под рукой, если застрянете.

## Цель

В `index.ts` замените заглушку `firstItem` обобщённой функцией: она принимает массив любых значений и возвращает первое из них или `undefined`, если массив пуст.

## Критерии приёмки

- `firstItem(orders)` для массива заказов возвращает заказ, а тип результата — `Order | undefined`.
- `firstItem(couriers)` для массива строк возвращает строку, тип результата — `string | undefined`.
- Для пустого массива результат `undefined`.
- Исходный массив не меняется.
- Тип результата не `any` и не `unknown`: тесты типов сверяют его точно.

## Ограничения

- Менять только `firstItem`.
- Без `any` и без приведения типов через `as`.
