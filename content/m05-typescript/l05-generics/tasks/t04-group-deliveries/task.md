## Контекст

Баг-репорт BUG-3107 из отчёта «Доставки по курьерам». Два симптома:

1. В отчёте у каждого курьера ровно одна доставка, хотя у Анны их три. Остальные пропадают.
2. Недавно кто-то написал `byCourier["Анна"][0].adress` (опечатка в `address`). Компилятор промолчал, отчёт показал пустой адрес. Функция `groupBy` возвращает `any[]`, и проверки типов теряются на выходе.

## Цель

Исправьте `groupBy(items, keyOf)` в `index.ts`: она группирует элементы списка по ключу, который возвращает `keyOf`. Результат — объект «ключ → массив элементов».

## Критерии приёмки

- Все элементы с одним ключом попадают в одну группу, порядок внутри группы сохраняется.
- Для `Delivery[]` результат имеет тип `Record<string, Delivery[]>`, а колбэк `keyOf` получает `Delivery`, а не `any`.
- Ключ — всегда строка. Колбэк, который возвращает число, не принимается компилятором.
- Ключи вроде `"constructor"` и `"toString"` работают как обычные: у курьера с таким именем группа создаётся и заполняется.
- Пустой список даёт пустой объект.
- Исходный список не меняется.

## Ограничения

- Менять только `groupBy`.
- Без `any` и без `as`.
