# Разбор

`Page<T>` уже обобщённый, поэтому функция тоже получает `T`: `paginate<T>(items: T[], ...): Page<T>`. Тогда для `Order[]` результат `Page<Order>`, а компилятор подсказывает поля заказа в `page.items`.

Арифметика страниц:

- `totalPages` — `Math.ceil(items.length / size)`. Округление вверх оставляет место для неполной последней страницы. Для пустого списка получается `0 / size`, то есть 0.
- Начало среза — `(page - 1) * size`, потому что страницы нумеруются с 1.
- `slice` не меняет исходный массив и сам возвращает пустой массив, если начало за пределами списка. Отдельная проверка границы не нужна.

В решении нет `any`: тип приходит из аргумента, и результат точный.
