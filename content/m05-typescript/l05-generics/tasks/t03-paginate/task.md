## Контекст

Тикет DEV-524. В личном кабинете курьера три списка: доставки на сегодня, история и штрафы. Каждый показывается по 10 строк на странице. Разработчики трёх экранов написали три почти одинаковые функции разбиения на страницы. Нужна одна.

## Цель

В `index.ts` напишите `paginate(items, page, size)`: обобщённую функцию, которая возвращает страницу списка. Тип `Page<T>` уже объявлен.

## Критерии приёмки

- Страницы нумеруются с 1. `paginate(list, 1, 10)` возвращает первые 10 элементов.
- В результате `items` — элементы страницы, `page` — номер, который передали, `totalPages` — сколько всего страниц.
- Последняя неполная страница возвращает остаток: для 25 элементов и размера 10 на странице 3 пять элементов, `totalPages` равно 3.
- Страница за пределами списка возвращает `items: []`; `page` остаётся тем, что передали.
- Пустой список: `items: []`, `totalPages: 0`.
- Тип результата зависит от типа списка: для `Order[]` результат `Page<Order>`, для `string[]` — `Page<string>`.
- Исходный список не меняется.

## Ограничения

- Менять только `paginate`. Тип `Page<T>` оставьте как есть.
- Без `any`.
