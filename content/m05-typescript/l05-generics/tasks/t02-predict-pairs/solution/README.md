# Разбор

1. `pair("MSK-01", 42)` собирает массив из двух значений. Консоль печатает `["MSK-01", 42]`.
2. `swap(route)` возвращает новый массив с обратным порядком: `[42, "MSK-01"]`.
3. `swap(route)[0]` — число 42, поэтому `typeof` даёт `"number"`. `typeof` смотрит на значение во время выполнения.
4. Явные аргументы типа `<string, number>` ничего не меняют в работе кода. Массив по-прежнему из двух элементов, `.length` равно `2`.
5. `pair(null, undefined)` даёт `[null, undefined]`. Значения `null` и `undefined` здесь обычные данные.
6. `swap(swap(route))` создаёт новый массив. Оператор `===` сравнивает ссылки, поэтому результат `false`, хотя содержимое то же.

Главный вывод: параметры типа `A` и `B` исчезают при компиляции. Всё, что происходит во время выполнения, делают обычные значения.
