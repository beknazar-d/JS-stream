## Контекст

Задача WH-208. На складе «Домотеки» три справочника: товары, ячейки хранения и поставщики. У каждой записи есть числовой `id`. Во всех местах кода повторяется одно и то же: поиск записи по `id` и построение словаря «id → запись» для быстрых обращений.

## Цель

В `index.ts` напишите две обобщённые функции:

- `findById(items, id)` — возвращает запись с этим `id` или `undefined`;
- `indexById(items)` — возвращает словарь `Map` «id → запись».

Обе принимают списки записей любого вида, лишь бы у записи было числовое поле `id`.

## Критерии приёмки

- `findById` возвращает запись с нужным `id`, иначе `undefined`. Тип результата — тип записи списка плюс `undefined`.
- `indexById` возвращает `Map<number, T>`, где `T` — тип записи списка. Все записи доступны по своему `id`.
- Если `id` повторяется, в словаре остаётся последняя запись.
- Список без поля `id` у записей компилятор не принимает (в обеих функциях).
- Записи в результате те же объекты, что и в списке, не копии.

## Ограничения

- Менять только эти две функции.
- Без `any` и без `as`.
