## Контекст

Тикет LOG-362. Партнёр «Ромашка» будет присылать заявки на забор груза в JSON. Вот письмо с примерами двух заявок:

```json
{
  "id": 501,
  "company": "ООО Ромашка",
  "pickup": { "city": "Казань", "street": "Чехова 3", "floor": 4, "intercom": "К1234" },
  "contacts": ["+7 900 111-22-33", "+7 900 111-22-44"],
  "cargo": { "places": 3, "weightKg": 41.5 },
  "comment": "заезд со двора"
}
```

```json
{
  "id": 502,
  "company": "ИП Лис",
  "pickup": { "city": "Самара", "street": "Ленина 1" },
  "contacts": [],
  "cargo": { "places": 1, "weightKg": 7 }
}
```

В письме нет описания формата, есть только эти примеры. Нужно описать типы заявки и написать две функции для диспетчерской панели.

## Цель

В `index.ts` опишите интерфейсы `Cargo`, `PickupPoint` и `PickupRequest` по примерам и реализуйте функции `pickupSummary(request)` и `totalWeight(requests)`.

Правила для `pickupSummary`:

- Формат: `Заявка №{id} ({company}): {city}, {street}[, этаж {floor}][, домофон {intercom}]; мест: {places}, вес: {weightKg} кг`.
- Части в квадратных скобках выводятся, только если значение указано (этаж `0` указан и выводится).

`totalWeight(requests)` возвращает суммарный вес груза по всем заявкам.

## Критерии приёмки

- Обе заявки из письма проходят проверку типов, как они записаны (в виде объектов TypeScript).
- Для заявки 501 `pickupSummary` возвращает `"Заявка №501 (ООО Ромашка): Казань, Чехова 3, этаж 4, домофон К1234; мест: 3, вес: 41.5 кг"`.
- Для заявки 502 `pickupSummary` возвращает `"Заявка №502 (ИП Лис): Самара, Ленина 1; мест: 1, вес: 7 кг"`.
- `totalWeight([])` возвращает `0`, для двух заявок из письма возвращает `48.5`.
- Поля, которые есть в одном примере и отсутствуют в другом, описаны как необязательные; остальные обязательные.

## Неясности

В письме нет ответов на вопросы: бывает ли список контактов пустым (во втором примере он пустой), может ли `comment` быть пустой строкой, в каких единицах вес, если партнёр пришлёт не число, как быть с заявкой без `cargo`. Запишите вопросы и допущения в `assumptions.txt` (строки в этом файле начинаются с `//`, пишите после них) до кода. Тесты проверяют только однозначные случаи из критериев выше.

## Ограничения

- Не используйте `any`, `as` и восклицательный знак после значения.
- Имена интерфейсов должны быть именно `Cargo`, `PickupPoint` и `PickupRequest`: на них ссылаются тесты.
