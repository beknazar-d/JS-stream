## Контекст

Тикет LOG-318. Список курьеров собирали вручную из трёх таблиц. После добавления типа `Courier` проект перестал собираться: компилятор нашёл в данных и в функции три ошибки. Выгрузку телефонов нужно срочно вернуть, диспетчеры работают по ней.

## Цель

Исправьте `index.ts` так, чтобы файл собирался в режиме `strict`. Интерфейс `Courier` менять нельзя: он описывает договорённость с другими командами.

## Критерии приёмки

- Ольга Смирнова ездит на самокате (`"самокат"`): поле `vehicle` у неё заполнено.
- У Петра Лиса телефон записан в поле `phone` без опечатки.
- `contactLine` для курьера с телефоном возвращает `"Иван Петров, тел.: +7 900 000-00-01"`.
- `contactLine` для курьера без телефона возвращает строку с его именем и словом «нет»: `"Мария Орлова, тел.: нет"`.
- В файле нет ошибок типов.

## Ограничения

- Интерфейс `Courier` не меняйте.
- Не используйте `any`, `as` и восклицательный знак после значения (`value!`): они прячут ошибку, но данные остаются неполными.
