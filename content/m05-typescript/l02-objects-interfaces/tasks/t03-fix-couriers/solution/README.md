# Разбор

Три ошибки — три разных сообщения компилятора.

1. `TS2741: Property 'vehicle' is missing...` — у Ольги нет обязательного поля. Правильное исправление — заполнить данные (самокат), а не ослабить интерфейс: другие команды рассчитывают на `vehicle`.
2. `TS2353: ... 'phon' does not exist in type 'Courier'` — опечатка в имени поля. Эту ошибку ловит именно проверка литерала: если бы объект сначала положили в переменную, опечатка прошла бы тихо, а телефон Пётр потерял бы.
3. `TS18048: 'courier.phone' is possibly 'undefined'` — телефон необязательный. Оператор `??` подставляет `"нет"`, когда слева `undefined`.

Почему не `courier.phone!`. Восклицательный знак говорит компилятору «я знаю, что здесь не пусто» и ничего не проверяет. У Марии телефона нет, и вызов упал бы уже у диспетчера.
