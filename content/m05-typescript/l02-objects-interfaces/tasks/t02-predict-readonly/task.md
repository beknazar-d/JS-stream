## Контекст

В коде склада посылка описана как `Parcel` с полем `id` только для чтения. Разработчик уверен, что после создания номер посылки изменить нельзя. Коллега уверен, что можно. Кто прав, покажет запуск, но сначала попробуйте предсказать результат сами.

## Цель

Прочитайте код из `snippet.ts`. Запишите в `answer.ts` в массив `output` шесть строк: то, что код выведет в консоль, по одной строке на каждый вызов `console.log`.

## Критерии приёмки

- В массиве `output` ровно шесть строк в порядке вызовов `console.log`.
- Каждый элемент — строка, например `"99"` или `"без заметки"`.
- Значение `undefined` записывается как строка `"undefined"`.
- Ответ совпадает с реальным выводом кода построчно.

## Ограничения

- Не меняйте `snippet.ts`.
- Помните: `readonly` и `?` существуют только для компилятора. В рантайме остаётся обычный JavaScript.
