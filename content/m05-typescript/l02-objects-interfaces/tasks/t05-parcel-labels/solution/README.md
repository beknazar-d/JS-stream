# Разбор

1. `Summary` — три обязательных числа. Обязательными их делает то, что функция всегда может их вычислить: для пустой партии это нули. Необязательные поля заставили бы каждого, кто читает сводку, проверять `undefined`.
2. Необязательные поля читаем только после проверки. `apartment !== undefined` пропускает номер квартиры, включая возможное `0`, а проверка на истинность выбросила бы его. `fragile === true` отличает «хрупкая» от «не указано» и «нет».
3. Наклейку удобно собирать в массиве частей и склеивать через `join(" — ")`: так нет висящих разделителей, когда части отсутствуют.
4. В `summarize` объект `summary` имеет тип `Summary`: если забыть поле, компилятор напомнит. Менять числа в нём можно, потому что поля не `readonly`.

Компилятор здесь был помощником: он не пропустил чтение `parcel.note.length` без проверки и подсказал, что `Summary` в заготовке не определён.
