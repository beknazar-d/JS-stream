## Контекст

Тикет LOG-301. Заказы в сервисе «Домотеки» ходят между экранами как безымянные объекты, и никто не помнит, какие в них поля. Нужно записать форму заказа в коде. Образец заказа и функция `cityOf` уже есть, но типы `Address` и `Order` пустые.

## Цель

Опишите интерфейсы `Address` и `Order` в `index.ts` по таблице.

| Тип | Поле | Тип поля | Правила |
|---|---|---|---|
| `Address` | `city` | строка | обязательное |
| `Address` | `street` | строка | обязательное |
| `Address` | `apartment` | число | необязательное |
| `Order` | `id` | число | обязательное, только для чтения |
| `Order` | `customer` | строка | обязательное |
| `Order` | `address` | `Address` | обязательное |
| `Order` | `paid` | булево значение | обязательное |
| `Order` | `comment` | строка | необязательное |

## Критерии приёмки

- Файл компилируется в режиме `strict`, образец `sample` проходит проверку.
- Заказ без `comment` и адрес без `apartment` допустимы.
- Заказ без `customer` или без `address` — ошибка типов.
- Присваивание `order.id = 5` — ошибка типов.
- `cityOf(sample)` возвращает `"Казань"`.

## Ограничения

- Используйте `interface`, `?` и `readonly`.
- Не используйте `any` и `as`.
