# Разбор

1. Каждое поле записывается как `имя: тип;`. Обязательное поле просто перечисляется, необязательное получает `?` после имени.
2. Вложенный объект описан отдельным интерфейсом `Address`, а в `Order` поле `address: Address` ссылается на него. Так адрес можно использовать и отдельно.
3. `readonly` ставится перед именем поля: `readonly id: number`. Это запрет на присваивание, который проверяет компилятор.
4. Тип необязательного поля — это `string` или `undefined`. Поэтому при чтении `comment` придётся учесть, что его может не быть.

Образец `sample` в заготовке был «лишним литералом» для пустого интерфейса, поэтому давал ошибку `TS2353`. Когда поля описаны, ошибка пропадает.
