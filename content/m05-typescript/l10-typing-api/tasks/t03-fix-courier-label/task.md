## Контекст

Тикет DEL-212. В карточке заказа показывается подпись курьера, например `Анна (+7 900 000-00-00)`. Вчера служба доставки прислала курьера без поля `phone`, и приложение упало с `TypeError`. В другой раз пришёл пустой ответ с текстом `null`.

Код приводит JSON к типу через `as`, а охранник `isCourier` написан наспех: он пропускает всё, что является объектом.

## Цель

Исправьте `isCourier` и `courierLabel` в `index.ts`. Приведение `as` уберите, вместо него используйте охранник.

## Критерии приёмки

- `isCourier(value)` возвращает `true`, только если значение — объект (не `null`) с полями: `id` — число, `name` — непустая строка, `phone` — строка или `null`. Поле `phone` обязательно: его отсутствие — отказ.
- `courierLabel` возвращает `Имя (телефон)`, а при `phone: null` возвращает `Имя (телефон не указан)`.
- Для сломанного JSON, для JSON-значений `null` и `[]` и для объектов, не похожих на курьера, `courierLabel` возвращает строку `Курьер не определён` и не бросает исключение.
- `isCourier` остаётся охранником типа: после проверки значение имеет тип `Courier`.

## Ограничения

- Интерфейс `Courier` менять нельзя.
- Не используйте `as` и `any` в `courierLabel`.
