## Контекст

Тикет DEL-255. Экран заказа показывает, где сейчас посылка. Данные приходят из API службы доставки. Раньше запрос был в трёх местах, и в каждом по-своему: где-то `catch` глотал ошибку, где-то экран показывал `undefined`.

Нужна одна функция, которая загружает отправление и возвращает типизированный результат: либо надёжный `Shipment`, либо понятная ошибка. Разбор тела уже написан: `parseShipment` лежит в `shipment.ts`. Вам нужен слой запроса.

Реальный `fetch` в учебной среде недоступен, поэтому функция получает его параметром `fetchLike`. В тестах вместо сети стоит заглушка, в браузере будет настоящий `fetch`.

## Цель

Допишите в `index.ts` функцию `loadShipment(fetchLike, id)`, которая возвращает `Promise<Result<Shipment, ApiError>>`.

## Критерии приёмки

- Запрос идёт на адрес `/shipments/<id>`, где идентификатор закодирован через `encodeURIComponent`. Вызов один, с одним аргументом (адресом).
- Успех: ответ `ok`, тело — верное отправление. Результат `{ ok: true, value }`.
- Сеть: если `fetchLike` отклоняет промис, результат `{ ok: false, error: { kind: 'network', message } }`, где `message` — текст ошибки (`error.message` для `Error`, иначе `String(error)`).
- Статус: если `response.ok` равен `false`, результат `{ ok: false, error: { kind: 'http', status } }`. Тело ответа в этом случае не читается.
- Тело: если `json()` отклонён (ответ не JSON), результат `{ kind: 'invalid', problems: ['ответ: не JSON'] }`. Если тело не прошло `parseShipment`, `problems` — это его список ошибок.
- Функция никогда не отклоняет промис.
- `ApiError` — размеченное объединение по полю `kind`: после проверки `kind` компилятор знает остальные поля.

## Неясности

В тикете нет ответа на вопросы: что делать с ответом 204 без тела, нужно ли повторять запрос при 503, и должен ли идентификатор отправления проверяться до запроса. Запишите вопросы и допущения в `assumptions.ts` (в нём только комментарии) до кода. Тесты проверяют только однозначные случаи из критериев.

## Ограничения

- Тип `ApiError` и интерфейс `FetchLike` в заготовке менять нельзя, файл `shipment.ts` тоже.
- Не используйте `any` и приведение `as` к `Shipment`.
