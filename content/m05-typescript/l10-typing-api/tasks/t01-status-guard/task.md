## Контекст

Служба доставки присылает статус отправления строкой: `"in_transit"`, `"delivered"` и так далее. Наш код ждёт тип `ShipmentStatus`, но из сети строка приходит как `unknown`. Нужен охранник типа (type guard): функция, которая проверяет значение и заодно сообщает компилятору, что внутри `if` это настоящий статус.

Это разминка на память: напишите охранник, не подглядывая в урок.

## Цель

Допишите в `index.ts` функцию `isShipmentStatus(value: unknown)` так, чтобы она была охранником типа для `ShipmentStatus`.

## Критерии приёмки

- Для четырёх статусов из списка `SHIPMENT_STATUSES` функция возвращает `true`.
- Для любой другой строки (`"shipped"`, `""`, `"Delivered"` с другим регистром) возвращает `false`.
- Для не строк (`null`, `undefined`, числа, объекты, массивы) возвращает `false`.
- После `if (isShipmentStatus(raw))` значение `raw` имеет тип `ShipmentStatus`: проверка типов принимает такой код.
- Параметр объявлен как `unknown`.

## Ограничения

- Список статусов и тип `ShipmentStatus` менять нельзя.
- Не используйте `any`.
