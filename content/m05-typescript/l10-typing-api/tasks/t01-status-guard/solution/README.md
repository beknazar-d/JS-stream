# Разбор

Охранник типа складывается из трёх частей.

1. **Параметр `unknown`.** Охранник принимает всё, что угодно, потому что проверять нужно именно непроверенные данные.
2. **Проверка `typeof value === 'string'`.** Она отсекает числа, `null`, объекты и массивы. Только после неё строку можно искать в списке.
3. **Предикат `value is ShipmentStatus`.** Это обещание компилятору: если функция вернула `true`, значение имеет этот тип. Без предиката функция возвращает обычный `boolean`, и сужения не будет.

Список из `as const` хранит только четыре литерала, поэтому у `includes` параметр того же узкого типа. Мы приводим список к `readonly string[]`: так можно спросить «есть ли такая строка?». Это безопасное расширение типа, оно не врёт о данных.

Охранник сравнивает строки точно, поэтому `"Delivered"` и `" delivered"` не проходят. Массив `['delivered']` тоже: `typeof` для него возвращает `"object"`.
