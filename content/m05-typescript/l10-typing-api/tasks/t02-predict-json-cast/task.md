## Контекст

Разработчик получил от службы доставки JSON и «типизировал» его через `as`. Код компилируется без единой ошибки. Перед тем как искать, почему на экране пишется `2.52 кг`, надо понять, что именно делает программа.

## Цель

Прочитайте код из `snippet.ts`. Запишите в `answer.ts` в массив `output` семь строк: именно то, что код выведет в консоль, по одной строке на каждый вызов `console.log`. Значения записывайте строками: `"5"`, `"null"`, `"undefined"`.

## Критерии приёмки

- В массиве `output` ровно семь строк в порядке вызовов `console.log`.
- Каждый элемент — строка.
- Ответ совпадает с реальным выводом кода построчно.

## Ограничения

- Не меняйте `snippet.ts`.
- Сначала предскажите ответ, потом сверьтесь с проверкой.
