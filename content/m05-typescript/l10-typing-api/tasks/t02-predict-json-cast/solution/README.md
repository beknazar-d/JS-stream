# Разбор

Главная мысль: типы TypeScript стираются при компиляции. `as` не проверяет и не превращает данные, он только говорит компилятору «поверь мне».

1. `typeof shipment.weightKg` даёт `"string"`. В JSON вес записан в кавычках, и аннотация `number` этого не меняет.
2. `"2.5" * 2` даёт `5`. Умножение превращает строку в число.
3. `"2.5" + 2` даёт `"2.52"`. Плюс склеивает, раз одна сторона строка. Это тот самый баг на экране.
4. `shipment.courier` даёт `null`: так записано в JSON.
5. `shipment.courier?.name` даёт `undefined`: необязательная цепочка останавливается на `null` и возвращает `undefined`, ошибки нет.
6. Поля `status` в JSON нет, поэтому чтение даёт `undefined`. Через `as unknown as` компилятору можно «доказать» что угодно.
7. `typeof JSON.parse('null')` даёт `"object"`: `typeof null` — историческая особенность языка.
