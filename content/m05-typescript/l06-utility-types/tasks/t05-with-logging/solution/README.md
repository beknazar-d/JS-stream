# Разбор

Обёртка должна «выглядеть» как исходная функция. Для этого типы берутся у самой функции:

- `F extends (...args: any[]) => any` — «F — любая функция». Здесь `any` допустим: он нужен, чтобы подошла функция с любыми параметрами. Это единственное место с `any`.
- `Parameters<F>` — кортеж типов параметров `F`. В записи `(...args: Parameters<F>)` остаточный параметр получает ровно эти типы.
- `ReturnType<F>` — тип результата.

Благодаря этому `withLogging(calcDeliveryFee, ...)` возвращает функцию `(zone: string, weightKg: number) => number`. Лишний аргумент или строка вместо числа — ошибка компиляции.

В теле нет `try/catch`: если `fn` бросит ошибку, выполнение прервётся до строки с `log`, и ошибка уйдёт вызывающему как есть. Журнал пишется только после успешного вызова.

Строка журнала собирается через `args.join(', ')`. Для разных типов аргументов это даёт простой читаемый вид.
