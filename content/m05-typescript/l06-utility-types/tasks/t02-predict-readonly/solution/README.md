# Разбор

1. `{ ...base, ...patch }` копирует поля `base`, затем поверх них поля `patch`. В `patch` только `zone`, поэтому зона меняется на «Юг», остальное остаётся.
2. Спред создал новый объект, `base` не изменился: `base.zone` — «Север».
3. У `patch` один собственный ключ. `Partial` не добавляет ключей при выполнении: он лишь говорит компилятору, что ключей может не быть.
4. `base as Courier` снимает запрет на запись для компилятора. Во время выполнения `base` обычный объект, и присваивание `rating = 5` меняет его. Поэтому `base.rating` — `5`.
5. `Object.freeze` — настоящая защита времени выполнения. Запись в замороженный объект в строгом режиме бросает `TypeError`. Модули TypeScript компилируются в строгий режим, поэтому `catch` срабатывает и выводит `true`.
6. Замороженная копия сделана из `base` уже после записи `5`, и значение осталось `5`.

Вывод: `Readonly` помогает ловить ошибки при написании кода, но не защищает данные. Для защиты нужна заморозка или копирование.
