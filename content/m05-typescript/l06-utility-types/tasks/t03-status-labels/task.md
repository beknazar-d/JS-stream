## Контекст

Задача TRK-340. На странице отслеживания посылки нужны две вещи: русская подпись статуса и сводка «сколько посылок в каждом статусе». Месяц назад в `DeliveryStatus` добавили статус `returned`, а подпись для него забыли: покупатель увидел на экране `undefined`.

## Цель

В `index.ts`:

1. Опишите справочник `statusLabels` с типом, который не позволяет забыть ни один статус.
2. Реализуйте `labelOf(status)` и `countByStatus(deliveries)`.

Подписи: `created` — «Создан», `packed` — «Собран», `onTheWay` — «В пути», `delivered` — «Доставлен», `returned` — «Возврат».

## Критерии приёмки

- Тип `statusLabels` — `Record<DeliveryStatus, string>`.
- Если добавить новый статус в `DeliveryStatus` и не добавить подпись, компилятор показывает ошибку.
- `labelOf(status)` возвращает подпись из справочника.
- `countByStatus(deliveries)` возвращает объект типа `Record<DeliveryStatus, number>` со всеми пятью статусами, в том числе с нулями для отсутствующих.
- Исходный список не меняется.

## Ограничения

- Не менять `DeliveryStatus` и `Delivery`.
- Без `any` и без `as`.
