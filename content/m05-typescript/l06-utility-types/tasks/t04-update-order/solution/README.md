# Разбор

**Тип.** `Partial<Omit<Order, "id">>` собирается из `Order` в два шага: убрали `id`, сделали остальные поля необязательными. Теперь патч:

- не принимает `id` и опечатки вроде `adress` (при передаче литерала объекта лишние поля запрещены);
- не принимает статус вне `OrderStatus`, в том числе `"delivered "` с пробелом;
- не требует всех полей сразу.

Поля берутся из `Order`. Добавится новое поле — патч подхватит его сам, а `updateOrder` потребует отдельно решить, как его применять.

**Поведение.** `Object.assign(order, patch)` менял исходный объект. Теперь функция строит новый объект, исходный остаётся прежним.

**undefined.** Запись `patch.city ?? order.city` берёт старое значение, если в патче `undefined` (или `null`). Оператор `??` реагирует только на эти два значения, поэтому `total: 0` сохраняется: `0 ?? 100` даёт `0`. Оператор `||` здесь был бы ошибкой: он заменил бы ноль на старую сумму.
