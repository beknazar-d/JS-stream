## Контекст

Тикет DEV-601. Фронтенду личного кабинета нужны три вида заказа:

- `OrderPreview` — для списка: только `id` и `status`;
- `NewOrder` — для формы создания: всё, что вводит человек. Номер и дату создания ставит сервер;
- `OrderPatch` — для редактирования: любые поля по отдельности, кроме `id`.

Сейчас все три — просто `Order`, поэтому форма требует номер и дату, а патч позволяет подменить `id`. Это задание на память: соберите три типа из `Order`, не переписывая поля.

## Цель

В `index.ts` задайте `OrderPreview`, `NewOrder` и `OrderPatch` через utility types. Затем исправьте `previewOf`: она должна возвращать только поля превью.

## Критерии приёмки

- `OrderPreview` содержит ровно `id` и `status`.
- `NewOrder` содержит `status`, `city`, `total`, `items`. Полей `id` и `createdAt` в нём нет.
- `OrderPatch` содержит те же поля, что `NewOrder`, но все необязательные. Передать `id` в патче компилятор не даёт.
- `previewOf(order)` возвращает новый объект ровно с двумя полями: `id` и `status`.
- Типы получены из `Order`, а не переписаны вручную: поля не дублируются.

## Ограничения

- Менять только три типа и тело `previewOf`.
- `Order` и остальные функции не трогать.
