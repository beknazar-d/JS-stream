# Разбор

Три вида — три разных преобразования:

- `Pick<Order, "id" | "status">` — оставить два поля. Подходит, когда нужно мало полей из многих.
- `Omit<Order, "id" | "createdAt">` — убрать два поля. Подходит, когда нужно почти всё.
- `Partial<NewOrder>` — патч. Он строится от формы, а не от `Order`: так `id` и `createdAt` исчезают из патча автоматически, а `Partial` делает остальное необязательным.

Если в `Order` добавится поле `courierId`, оно появится в `NewOrder` и `OrderPatch` без правок. В `OrderPreview` не появится: он перечисляет поля явно.

`previewOf` нужно исправить отдельно. Типы только описывают данные, но не создают новый объект. Старая версия вернула целый заказ, хотя тип обещает два поля: лишние данные (город, сумма) ушли бы на экран списка. Правильный код собирает объект вручную: `{ id: order.id, status: order.status }`.
