# Разбор

1. У `const orderId = 1042` тип выводится как `1042`: константа не меняется, поэтому тип узкий, как значение. Аннотация `: number` расширяет его до всех чисел.
2. Массивы записываются как тип элемента со скобками: `number[]`, `string[]`.
3. Параметры функции компилятор сам не выводит: в строгом режиме без аннотации это ошибка `TS7006`. Тип результата после скобок (`: string`) можно было бы опустить, но на границах модуля его лучше писать явно.
4. Типы с большой буквы (`Number`, `String`) — это обёртки. Они почти никогда не нужны, пишите примитивы с маленькой.

Типы исчезают при компиляции, поэтому поведение функции не изменилось.
