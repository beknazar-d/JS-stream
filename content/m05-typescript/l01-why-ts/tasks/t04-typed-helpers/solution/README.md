# Разбор

Сначала сигнатуры, потом тела: сигнатура фиксирует контракт.

1. `minutes: number[]` и `: number`. Тип записан явно, потому что у параметров вывода нет. Внутри функции `sum` и `paid` выводятся сами из `0`: аннотация не нужна.
2. Пустой массив проверяется до деления: `0 / 0` даёт `NaN`, а в панели диспетчера это превратилось бы в надпись «NaN мин.».
3. Округление до десятых — `Math.round(x * 10) / 10`. Метод `toFixed` вернул бы строку, а функция обещает число.
4. В `countPaid` сложная логика не нужна: для `boolean[]` хватает `if (flag)`.
5. `formatPrice` возвращает строку: `toFixed(2)` у числа даёт строку с двумя знаками, к ней добавляется код валюты.

Благодаря типам вызов `averageMinutes(["30"])` не соберётся ещё до запуска.
