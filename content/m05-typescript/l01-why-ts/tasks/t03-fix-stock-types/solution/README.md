# Разбор

Каждая ошибка типов здесь указывала на настоящую ошибку в логике.

1. `return raw;` — `TS2322: Type 'string' is not assignable to type 'number'`. Функция обещает число, а возвращает строку. Правильно превратить значение: `Number(raw)`. Приём `as any` заставил бы компилятор замолчать, но строка осталась бы строкой.
2. `count + "1"` — тоже `TS2322`. К числу прибавляли строку, получилась бы склейка (`"01"`, `"011"`), а не счёт. Нужна единица без кавычек.
3. `left.toUpperCase()` — `TS2339: Property 'toUpperCase' does not exist on type 'number'`. Метод есть у строк, у чисел его нет. При склейке со строкой число превращается в текст само, вызов метода не нужен.

Для `parseStock` важно не брать `parseInt`: он обрежет дробную часть.
