# Разбор

Главная мысль: после компиляции типов нет. Конструкция `as Parcel` ничего не преобразует и не проверяет, она только успокаивает компилятор. В рантайме `fromApi` — обычный объект с двумя строками.

1. `typeof fromApi.id` даёт `"string"`: из JSON пришло `"A-17"`.
2. `"2.5" * 2` даёт `5`: умножение превращает строку в число.
3. `"2.5" + 2` даёт `"2.52"`: плюс склеивает, если есть строка.
4. `typeof checked === "number"` даёт `false`: `checked` — строка. Тип `unknown` здесь только скрывает значение от компилятора.
5. `Number("2.5") + 2` даёт `4.5`: явное преобразование, дальше складываются числа.
6. `Number("A-17")` даёт `NaN`, а `Number.isNaN(NaN)` даёт `true`.

Вывод для практики: данные извне (JSON, формы) нужно проверять самим. Аннотация типа гарантий не даёт.
