# Разбор

Перенос на TypeScript — это не «заглушить ошибки», а записать то, что код и так предполагал.

1. Аннотации ставим на границах: параметры функций и константы модуля. Внутри функций типы выводятся сами (`index`, `extraKg`, `price`, `sum`).
2. `zones: string[]` и `baseRates: number[]`: без аннотации выводилось то же самое, но явная запись на границе модуля фиксирует контракт.
3. `weightKg: number`, хотя в форме вес приходит строкой. Функция делает арифметику (`weightKg - 10`), значит, число ей нужно на входе. Строку в число превращают там, где она получена (см. `readWeight` из прошлого задания).
4. Результат `deliveryPrice` — `number`: и `price`, и `Math.round(...)` числа.
5. Тело `receipt` склеивает строки: результат `string`, `orderId` — число, оно превратится в текст при склейке.

Поведение не изменилось, потому что типы стираются при компиляции. Изменилось другое: ошибка вроде `deliveryPrice("центр", "5", false)` теперь находится при сборке.
