# Разбор

Этап небольшой, но на нём заложен каркас всего проекта: данные приходят из API, а страница строит DOM из данных.

1. `formatPrice` вынесена в отдельную функцию. Цена нужна в нескольких местах, а `Intl.NumberFormat('ru-RU')` ставит пробелы между разрядами.
2. `createCard` собирает одну карточку и возвращает её. Названия вставляются через `textContent`: данные приходят с сервера, и разметке из них доверять нельзя.
3. `loadProducts` делает запрос, читает JSON и выводит карточки одним вызовом `replaceChildren`. Он же ставит число найденных товаров.
4. `limit=6` нужно передавать явно. Значение по умолчанию на сервере другое (12).
5. `data.total` — общее число товаров на сервере. `data.items.length` — только то, что пришло на этой странице.

Комментарий про будущее: функции небольшие и разделены по смыслам. На следующих этапах в `loadProducts` добавятся состояния и параметры запроса, а `createCard` почти не изменится.

## Вопросы, которые стоило задать

- Сколько товаров на странице и зависит ли это от экрана?
- Как показывать цену: целые рубли, копейки, скидки, старая цена?
- Что делать с товаром не в наличии: скрыть, показать серым, показать в конце?
- Нужна ли картинка в карточке и откуда она берётся?
- Как сайт должен вести себя на телефоне?

## Допущения в эталоне

Шесть товаров, целые рубли, товар не в наличии остаётся в списке с подписью и серым цветом. Тесты проверяют только то, что описано в критериях.
