## Контекст

Коллега написал пагинацию для каталога и ушёл в отпуск. Тестировщик нашёл баги (задача WEB-655): «Написано „Страница 1 из 24“, хотя страниц четыре. Кнопка „Вперёд“ доезжает до пустой страницы 5, „Назад“ на первой странице уводит на страницу 0. А „Обновить“ почему-то возвращает на первую страницу».

## Цель

Этап 3 из 6. В `script.js` уже есть пагинация (`#prev`, `#next`, `#page-info`). Найдите и исправьте ошибки.

## Критерии приёмки

- Подпись имеет вид `Страница N из M`, где M — число страниц из ответа сервера (`pages`).
- На первой странице `#prev` отключена, на последней отключена `#next`.
- Страницы не выходят за границы: ни при обычных нажатиях, ни при очень частых. Запросов с `page` меньше 1 и больше `pages` не бывает.
- «Обновить» перезагружает текущую страницу, а не первую.
- На каждой странице показаны товары этой страницы (по шесть).

## Ограничения

- Разметку, стили, `data.js` и `api.js` не меняйте.
- Не переписывайте всё заново: исправьте причины.
