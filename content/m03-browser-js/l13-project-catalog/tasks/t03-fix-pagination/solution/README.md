# Разбор

Три причины, пять симптомов.

1. `lastPages = data.total` вместо `data.pages`. Из-за этого «из 24» вместо «из 4», а «Вперёд» не отключалась до 24-й страницы. Одна строка объясняла две жалобы.
2. Границы проверялись неточно: `state.page < 1` никогда не истинно (страница не бывает меньше 1), нужно `<= 1`. Аналогично с последней страницей. К тому же кнопка отключается только после ответа сервера, а клики приходят раньше. Поэтому проверка нужна ещё и в самом обработчике.
3. «Обновить» сбрасывало `state.page` на 1. Это не его работа: перезагрузка не должна менять состояние.

Как искать такие баги: сначала воспроизвести по шагам из тикета, потом смотреть, какая одна строка объясняет несколько симптомов.
