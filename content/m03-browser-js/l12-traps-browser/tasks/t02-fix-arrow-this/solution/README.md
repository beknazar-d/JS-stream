# Разбор

Обе кнопки сломаны одной причиной. В стрелочной функции нет своего `this`, он берётся снаружи. В обычном скрипте снаружи `window`, поэтому `this.dataset` равно `undefined`, а `this.dataset.id` падает с `TypeError: Cannot read properties of undefined (reading 'id')`.

Второй баг коварнее. `this.textContent = '...'` не падает: окну можно присвоить любое свойство. Присваивание проходит молча, а надпись на кнопке не меняется. Такие баги находят только по поведению.

Исправление: параметр `event` и `event.currentTarget`. Это элемент, на котором висит обработчик, независимо от того, стрелка это или обычная функция.

Почему не `event.target`: он указывает на самый глубокий элемент под курсором. В нашей кнопке есть `<span class="icon">`. Если клик пришёлся на значок, `target` — значок, и у него нет `data-id`.
