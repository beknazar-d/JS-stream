## Контекст

Задача WEB-584. В корзине «Домотеки» у каждой позиции кнопки «−» и «+». Тестировщик пишет: «Первый клик по плюсу добавляет одну штуку, второй — две, третий — три. А после нажатия „Обновить“ шаг ещё больше». Консоль чистая.

## Цель

Найдите причину и исправьте `script.js`. Каждый клик по «+» должен менять количество ровно на 1, сколько бы раз ни перерисовывали список.

## Критерии приёмки

- Три клика подряд по «+» у первой позиции увеличивают количество на 3.
- После нескольких нажатий на «Обновить» один клик по «+» добавляет ровно одну штуку.
- Кнопка «−» уменьшает количество на 1, но не ниже 1.
- Итог `#total` («Всего штук: N») всегда равен сумме количеств.
- Количество одной позиции не влияет на другую.

## Ограничения

- Разметку и стили не меняйте.
- Функцию `render` не удаляйте: список по-прежнему должен перерисовываться после каждого изменения.
