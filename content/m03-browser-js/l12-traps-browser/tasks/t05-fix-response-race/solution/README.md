# Разбор

Запросы уходят в порядке нажатий, но возвращаются в порядке готовности ответов. Медленный ответ «Кухни» приходит после быстрого ответа «Уборки» и затирает список. Это гонка ответов (race condition).

Решение — отменять прошлый запрос:

1. `controller` хранится снаружи функции, чтобы новый вызов мог отменить предыдущий.
2. Перед запросом `controller.abort()` обрывает прошлый, а `new AbortController()` создаёт свежий. Его `signal` передаётся в `fetch`. Без `signal` отмена не будет иметь эффекта.
3. Отменённый `fetch` отклоняет промис с `AbortError`. В `catch` его надо распознать и сразу выйти: это не сбой. Если не выйти, устаревший запрос покажет «Не удалось загрузить» поверх нового результата.

Альтернатива — номер запроса и сравнение после ответа. Тогда нужно проверять номер и после успеха, и в `catch`. Отмена проще: лишний запрос не только игнорируется, но и перестаёт тратить трафик.
