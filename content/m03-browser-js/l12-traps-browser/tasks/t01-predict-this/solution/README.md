# Разбор

1. `plain.call(product)`: обычная функция, `this` равен `product`, результат — `Чайник`.
2. `arrow.call(product)`: у стрелки своего `this` нет, а `call` его не меняет. Стрелка записана внутри `createHandlers`, а там `this` равен `cart`. Результат — `Корзина`.
3. `byEvent` не использует `this` вообще: название берётся из `event.currentTarget`. Результат — `Чайник`. Так и надо писать в реальных обработчиках.
4. `plain.call(cart)`: `this` равен `cart`, результат — `Корзина`.
5. `plain.call({})`: `this` — пустой объект, свойства `title` нет, результат — `undefined`.
6. `arrow.call({ title: 'Другой' })`: опять `cart`, поэтому `Корзина`.

Вывод для реальной работы: в обработчике берите элемент из `event.currentTarget`, тогда не важно, обычная функция или стрелка.
