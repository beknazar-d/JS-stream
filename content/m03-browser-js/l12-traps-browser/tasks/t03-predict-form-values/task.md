## Контекст

В форме заказа «Домотеки» поле «Количество» читается как `field.value`. Менеджер жалуется, что то итог «0 ₽», то «NaN ₽», а один раз вместо суммы вышло число с лишними цифрами. Надо понять, что именно делает JavaScript со значением поля, прежде чем писать проверку. Объект `field` повторяет поле формы: у него есть только `value`.

## Цель

Прочитайте код из `snippet.js`. Запишите в `answer.js` в массив `output` шесть строк: то, что код выведет в консоль, по одной на каждый `console.log`.

## Критерии приёмки

- В массиве `output` ровно шесть строк в порядке вызовов `console.log`.
- Каждый элемент — строка, например `"0"` или `"NaN"`.
- Ответ совпадает с реальным выводом кода построчно.

## Ограничения

- Не меняйте `snippet.js`.
- Не запускайте код до ответа: сначала предскажите, потом сверьтесь с проверкой.
