# Разбор

1. `'' * 2490` даёт `0`: пустая строка при умножении превращается в 0.
2. `Number('')` даёт `0`. Это ловушка: пустое поле выглядит как нулевое количество.
3. `'3' + 1` даёт `'31'`. Если у плюса есть строка, он склеивает.
4. `'3' * 2490` даёт `7470`: умножение превращает строку в число.
5. `Number('2 шт')` даёт `NaN`: в строке есть буквы, и число из неё целиком не получить. Умножение `NaN * 2490` остаётся `NaN`.
6. `parseInt('2 шт')` даёт `2`: функция читает число с начала строки и останавливается на пробеле. `Number.isNaN(2)` равно `false`.

Вывод для формы: значение из поля нужно прочитать, обрезать пробелы и проверить отдельно. Пустую строку проверяют до преобразования, а `Number.isNaN` или `Number.isInteger` — после.
