## Контекст

В ленте товаров «Домотеки» картинки должны начинать грузиться чуть раньше, чем доезжают до экрана: тогда покупатель не увидит серую заглушку. Для этого у `IntersectionObserver` есть настройки `rootMargin` (насколько расширить область слежения) и `threshold` (какая доля элемента должна быть видна). Чтобы выбрать их без проб и ошибок, нужно уметь считать, что получится.

## Цель

Прочитайте код из `snippet.js`. В нём упрощённая модель наблюдателя только по вертикали. Запишите в `answer.js` в массив `output` шесть строк: то, что код выведет в консоль, по одной строке на каждый вызов `console.log`.

## Критерии приёмки

- В массиве `output` ровно шесть строк в порядке вызовов `console.log`.
- Каждый элемент — строка, например `"true 0.5"`.
- Ответ совпадает с реальным выводом кода построчно.

## Ограничения

- Не меняйте `snippet.js`.
- Сначала предскажите, потом сверяйтесь с проверкой.
