# Разбор

Во всех вызовах окно высотой 800, область слежения — окно, расширенное на `rootMargin` сверху и снизу.

1. Блок 900–1000 ниже окна (800), отступа нет. Видимая часть нулевая: `false 0`.
2. `rootMargin: 200` расширяет область до 1000. Блок 900–1000 целиком внутри: `true 1`. Именно так картинки начинают грузиться до появления на экране.
3. Блок 700–900 пересекает нижнюю границу окна. Видна половина (700–800): `true 0.5`. Порог по умолчанию 0, достаточно любого пересечения.
4. Тот же блок, порог 0.75. Видна половина, а нужно три четверти: `false 0.5`. Порог измеряет долю элемента, а не пиксели.
5. Блок 1100–1300 при отступе 200 всё равно за пределами области (до 1000): `false 0`.
6. Блок 750–850: видны 50 из 100, доля ровно 0.5. Условие «не меньше порога» выполнено: `true 0.5`.

Для настоящего наблюдателя действуют те же идеи, но с двумя уточнениями: он учитывает и горизонталь, и вложенные прокручиваемые контейнеры, а `rootMargin` записывается строкой с единицами: `'200px 0px'`.
