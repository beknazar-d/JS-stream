# Разбор

`IntersectionObserver` («наблюдатель за пересечением») сообщает, когда элемент входит в область видимости или выходит из неё. Работает он так.

1. Конструктору передают колбэк. Браузер вызывает его с массивом записей `entries` и самим наблюдателем.
2. У каждой записи есть `target` (элемент) и `isIntersecting` (виден ли он сейчас).
3. `observer.observe(img)` начинает слежение, `observer.unobserve(img)` заканчивает его для одного элемента.

Две важные детали.

- **`isIntersecting` проверять обязательно.** Браузер вызывает колбэк сразу после `observe` для каждого элемента, даже невидимого: с `isIntersecting: false`. Без проверки все картинки загрузятся мгновенно.
- **Записей может быть несколько.** Если за один кадр на экран попали две картинки, они придут в одном вызове. Поэтому цикл `for...of`, а не `entries[0]`.

`unobserve` после загрузки нужен, чтобы колбэк не вызывался снова за картинкой, которая уже загружена.
