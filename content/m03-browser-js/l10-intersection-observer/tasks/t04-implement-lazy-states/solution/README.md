# Разбор

## Загрузка заранее

Второй аргумент конструктора — объект настроек.

- `rootMargin: '200px 0px'` расширяет область слежения на 200 пикселей сверху и снизу (формат как у `margin` в CSS: «вертикаль горизонталь»). Картинка получает «зелёный свет», пока ещё в 200px от экрана, и успевает загрузиться.
- `threshold: 0` означает «достаточно любого пересечения». Это значение по умолчанию, его можно не писать.

`rootMargin` обязательно строка с единицами (`px` или `%`). Число `200` браузер не принимает: `SyntaxError: Failed to construct 'IntersectionObserver': rootMargin must be specified in pixels or percent.`

## Состояния

Событие `load` приходит, когда картинка загрузилась, `error` — когда нет. Обработчики навешиваются до присвоения `src`: загрузка не мгновенна, но если событие уже произошло, поздний обработчик его не увидит.

`classList.replace('is-loading', 'is-loaded')` заменяет один класс другим за одно действие.

## Порядок действий в колбэке

1. Проверить `isIntersecting`.
2. Навесить обработчики и класс `is-loading`.
3. Перенести адрес и убрать `data-src`.
4. `unobserve`.

Удаление `data-src` нужно не только для чистоты разметки: повторный вызов `initLazyImages()` (например, после добавления новых карточек в каталог) выберет по селектору `img[data-src]` только ещё не загружаемые картинки и не запустит загрузку повторно.
