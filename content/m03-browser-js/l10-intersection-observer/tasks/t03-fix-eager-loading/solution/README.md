# Разбор

Ошибка: колбэк не смотрит на `entry.isIntersecting`.

Наблюдатель устроен так: сразу после `observe` браузер сообщает о текущем состоянии элемента, даже если тот далеко за экраном. Такое первое уведомление приходит с `isIntersecting: false`. Колбэк из заготовки принимает любую запись за сигнал «пора грузить», и все шесть картинок загружаются при открытии страницы.

Исправление в одну строку:

```js
entries.forEach((entry) => {
  if (!entry.isIntersecting) return;
  ...
});
```

Почему не `intersectionRatio > 0.5`: доля показывает, сколько элемента видно. Для ленивой загрузки нужно «начать как можно раньше», а не «когда почти целиком виден». Порог настраивают в `threshold` наблюдателя, а условие `isIntersecting` уже учитывает его.

Совет на будущее: когда ленивая загрузка «не работает», откройте сетевую панель и сразу после загрузки страницы посмотрите на запросы картинок. Если все они уже там, значит, колбэк действует на каждую запись.
