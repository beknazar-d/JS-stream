## Контекст

Каталог «Домотеки» пока показывает пустой список: товары живут на сервере, а страница о них ничего не знает. Backend-разработчик уже выложил метод `GET /api/products`, он возвращает JSON со списком товаров. Нужно подключить страницу к нему.

## Цель

Наберите по памяти в `script.js` функцию, которая запрашивает товары, разбирает ответ и выводит их списком в `#products`. Она вызывается при загрузке страницы и по кнопке «Обновить».

## Критерии приёмки

- При загрузке страницы выполняется один запрос `GET /api/products`.
- Для каждого товара в `#products` появляется элемент `li` с текстом вида `Чайник K-200 — 3490 ₽`: название, тире, цена и знак рубля.
- Кнопка `#reload` повторяет запрос и заменяет список. Дубликатов нет: после обновления в списке столько же элементов, сколько товаров.
- Функция объявлена как `async`, внутри использованы `await fetch(...)` и `await response.json()`.

## Ограничения

- Не меняйте `index.html`.
- Не используйте `.then(...)`: тренируем `async` и `await`.
- Не пишите `innerHTML` для данных с сервера.
