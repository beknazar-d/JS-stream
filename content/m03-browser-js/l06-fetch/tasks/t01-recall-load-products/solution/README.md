# Разбор

1. `async function` позволяет использовать внутри `await`. Слово `await` приостанавливает только эту функцию, страница продолжает работать.
2. `await fetch(url)` возвращает объект ответа `Response`, когда сервер ответил. Тело ответа ещё не разобрано.
3. `await response.json()` читает тело и превращает JSON-текст в обычный массив. Это тоже обещание, поэтому нужен второй `await`.
4. Перед выводом очищаем список: `list.textContent = ''`. Иначе при повторном вызове товары добавятся к старым.
5. Строку собираем через `textContent`: данные пришли с сервера, и в названии может оказаться разметка.
6. Последняя строка вызывает функцию при загрузке страницы. Кнопке тот же обработчик.

Проверки `response.ok` здесь нет намеренно: её вы добавите в следующих заданиях.
