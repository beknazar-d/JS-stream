# Разбор

1. `ok` истинно, если код ответа от 200 до 299. У `200` это `true`.
2. `201` (создано) — тоже успех: `true`.
3. `404` (не найдено) — `false`. Важно: `fetch` на 404 не выбрасывает ошибку, нужно проверять `response.ok` самому.
4. `503` (сервис недоступен) — `false`.
5. `204` (нет содержимого) тоже успех: `true`.
6. `JSON.parse` превращает текст в объект. `1042 + 1` равно `1043`.
7. `encodeURIComponent` кодирует символы, которые ломают строку запроса: пробел становится `%20`, амперсанд — `%26`. Дефис остаётся как есть.
8. Разметка вместо JSON не разбирается: `JSON.parse` выбрасывает `SyntaxError`, поэтому срабатывает `catch`. Так бывает, когда сервер вместо данных вернул страницу ошибки.
9. и 10. Тело `async`-функции выполняется сразу, пока не встретится `await`. Поэтому `load: начало` выводится первым. Результат вызова — всегда `Promise`.
