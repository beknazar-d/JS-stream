# Разбор

1. **Отправка.** Второй аргумент `fetch` — объект настроек. `method: 'POST'` задаёт способ, `headers` сообщает серверу формат, `body` — строка. Объект в строку превращает `JSON.stringify`. Без заголовка `Content-Type` сервер не узнает, что внутри JSON.
2. **Типы.** Из `FormData` все значения — строки. Количество переводим в число через `Number`, имя очищаем через `trim()`.
3. **Успех.** Если `response.ok`, читаем тело и берём номер заказа.
4. **Ошибка с причиной.** Сервер может прислать понятный текст в поле `error`. Его и показываем.
5. **Ошибка без JSON.** При сбое сервер часто отвечает не JSON, а текстом или HTML-страницей. Вызов `response.json()` тогда выбросит `SyntaxError`. Чтобы не потерять сообщение, чтение тела обёрнуто в `try/catch`, а причина по умолчанию содержит статус.

Заметьте, что `try/catch` стоит не вокруг всей функции, а только вокруг того, что может упасть из-за формата тела. Так видно, какую именно ошибку мы ждём.
