## Контекст

Форма быстрого заказа на странице товара уже проверяет поля. Теперь её нужно подключить к серверу. Метод `POST /api/orders` принимает JSON и отвечает так:

- `201` и тело `{ "id": 1042 }`, если заказ создан;
- `422` и тело `{ "error": "Количество должно быть от 1 до 10" }`, если данные не прошли проверку на сервере;
- другие коды (например, `500`), при этом тело может быть вообще не JSON, а текстом или страницей ошибки.

## Цель

Допишите `script.js`: при отправке формы отправьте заказ на сервер и покажите результат в `#status`.

## Критерии приёмки

- Страница не перезагружается при отправке.
- Запрос: `POST /api/orders`, заголовок `Content-Type: application/json`, тело — JSON `{ "name": "Анна", "qty": 2 }`. Имя очищено от пробелов по краям, `qty` — число, а не строка.
- Если заказ создан, в `#status` выводится `Заказ №1042 принят` (номер берётся из ответа).
- Если сервер ответил ошибкой и в теле есть поле `error`, выводится `Не удалось оформить заказ: ` и текст из `error`.
- Если сервер ответил ошибкой, а тело не является JSON или в нём нет `error`, выводится `Не удалось оформить заказ (500)`, где в скобках статус.

## Ограничения

- Не меняйте `index.html`.
- Данные формы читайте через `FormData`.
- Используйте `async/await`, не `.then`.
