## Контекст

Тикет DOM-244 от менеджера «Домотеки»:

> Каталог должен брать товары с сервера, а не из разметки. Выводите карточками: название, цена. Нужен переключатель «Только в наличии», чтобы покупатели не смотрели на то, что нельзя купить. Цену покажите красиво. Если товаров нет, скажите об этом. Кнопка «Обновить» нужна, чтобы подтянуть свежие остатки.

Сервер: `GET /api/products` возвращает массив объектов вида `{ "id": 1, "title": "Чайник K-200", "price": 3490, "inStock": true }`.

Разметка готова: чекбокс `#only-in-stock`, кнопка `#reload`, абзац `#status` для сообщений и список `#products`.

## Неясности

В тикете осталось несколько мест, которые заказчик считает очевидными.

- Что значит «красиво» для цены: разделитель тысяч, знак рубля, копейки?
- Нужно ли показывать на карточке, что товара нет в наличии, если переключатель выключен?
- Переключатель «Только в наличии» фильтрует уже загруженный список или заново запрашивает сервер?
- Что делать, если сервер недоступен? В тикете об этом ни слова.
- Остаётся ли переключатель включённым после нажатия «Обновить»?

Перед кодом откройте `assumptions.txt` и запишите 2–3 вопроса менеджеру и свои допущения. Тесты проверяют только то, что в тикете сказано однозначно: состав карточек, фильтр по наличию, пустой ответ, безопасный вывод названий.

## Цель

Допишите `script.js`: загрузка каталога из API, вывод карточек, фильтр и кнопка «Обновить».

## Критерии приёмки

- При загрузке страницы выполняется запрос `GET /api/products`.
- Для каждого товара в `#products` создаётся элемент `li.product`. Название товара находится в `h3` внутри карточки, рядом видны цифры цены (формат на ваше усмотрение).
- Пока чекбокс `#only-in-stock` снят, показаны все товары. Когда отмечен, показаны только товары с `inStock: true`. Переключение мгновенно меняет список.
- Кнопка `#reload` запрашивает товары заново и заменяет список.
- Если сервер вернул пустой массив, карточек нет, а в `#status` выводится непустое сообщение.
- Название товара вставляется как текст: разметка в нём не становится элементами.

## Ограничения

- Не меняйте `index.html`.
- Используйте `async/await`, проверяйте `response.ok`.
- Не пишите `innerHTML` для данных с сервера.
