# Разбор

Три ошибки в одной функции.

1. **Нет `await` перед `fetch`.** `fetch` возвращает обещание. Без `await` в `response` лежит обещание, у него нет метода `json`, и код падает: `TypeError: response.json is not a function`.
2. **Нет проверки `response.ok`.** `fetch` не считает ошибкой ответ 404 или 500: промис выполнен, сервер ведь ответил. Решать, успешен ли ответ, нужно самому. Если не проверить, код попытается разобрать тело ошибки как список. Правильно: `if (!response.ok)`, сообщение со статусом и `return`.
3. **Список не очищается.** Каждый вызов добавляет элементы к уже имеющимся. Перед выводом очищаем: `list.textContent = ''`. Сообщение об ошибке тоже очищаем при успехе.

Порядок важен: список очищаем только после того, как данные успешно получены. Если очистить раньше, то при ошибке сервера покупатель увидит пустую страницу вместо старого списка.
