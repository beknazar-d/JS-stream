## Контекст

Баг из поддержки: «каталог пустой, а в консоли какая-то ошибка». Список товаров не показывается совсем. Когда разработчик быстро поправил первую ошибку, всплыли две другие: если сервер отвечает ошибкой, страница молчит, а по кнопке «Обновить» товары удваиваются.

## Цель

Исправьте `script.js`, чтобы каталог загружался, понятно сообщал об ошибке сервера и корректно обновлялся.

## Критерии приёмки

- При загрузке страницы в `#products` выводятся три товара в формате `Чайник K-200 — 3490 ₽`.
- Кнопка `#reload` повторно запрашивает товары, список после этого заменяется, а не дополняется.
- Если сервер ответил ошибкой (статус не 2xx), в `#status` выводится `Не удалось загрузить товары (500)`, где в скобках статус ответа. Список при этом не меняется.
- После успешной загрузки `#status` очищается.
- Если сервер вернул ошибку, тело ответа не разбирается как список товаров.

## Ограничения

- Не меняйте `index.html`.
- Не заменяйте `async/await` на `.then`.
- Выводите данные через `textContent`.
