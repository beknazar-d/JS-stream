# Разбор

1. Один обработчик на список (делегирование): `event.target.closest('.check')` находит кнопку, даже если клик пришёл по вложенному элементу. Затем `button.closest('.card')` даёт карточку. Артикул берём у неё из `dataset.sku`.
2. Адрес собираем строкой и кодируем значение через `encodeURIComponent`. Для `K-200` ничего не изменится, но артикул с пробелом или `&` не сломает запрос.
3. После `await fetch(...)` порядок проверок важен. Сначала особый случай `404`: он значит «артикула нет», это не поломка. Потом общий `!response.ok`: склад недоступен. Только после этого читаем тело через `await response.json()`.
4. `data.left > 0` отделяет «есть» от «нет». Проверка «поле существует» не годится: `0` — это тоже существующее значение.
5. Текст пишем в `.stock` той карточки, на которую нажали, а не в первую попавшуюся.

Здесь нет `try/catch`. Он нужен, если сеть недоступна совсем: тогда `fetch` не возвращает ответ, а выбрасывает ошибку. Этим мы займёмся в уроке про состояния загрузки.
