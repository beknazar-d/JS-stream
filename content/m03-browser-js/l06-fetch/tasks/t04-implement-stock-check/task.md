## Контекст

В карточках каталога «Домотеки» нужна кнопка «Проверить наличие». Склад отвечает по адресу `GET /api/stock?sku=<артикул>`:

- `200` с телом `{ "sku": "K-200", "left": 3 }`, где `left` — сколько штук осталось;
- `404` с телом `{ "error": "..." }`, если такого артикула нет на складе;
- другие коды, если склад недоступен.

Артикул карточки записан в её атрибуте `data-sku`. Сообщение выводится в абзац `.stock` внутри той же карточки.

## Цель

Допишите `script.js`: по клику на кнопку карточки запросите остаток и покажите результат в этой карточке.

## Критерии приёмки

- Клик по кнопке «Проверить наличие» отправляет ровно один запрос `GET /api/stock` с параметром `sku`, равным артикулу именно этой карточки.
- Если `left` больше нуля, в `.stock` этой карточки выводится `В наличии: 3 шт.` (с настоящим числом).
- Если `left` равен нулю, выводится `Нет в наличии`.
- Если склад ответил `404`, выводится `Артикул не найден`.
- Для остальных неуспешных ответов выводится `Не удалось проверить наличие (503)`, где в скобках статус.
- Остальные карточки не меняются.

## Ограничения

- Не меняйте `index.html`.
- Используйте `async/await` и проверку `response.ok` или `response.status`.
- Артикул подставляйте в адрес через `encodeURIComponent`.
