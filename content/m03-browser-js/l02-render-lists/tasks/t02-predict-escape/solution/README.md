# Разбор

1. `&` заменяется на `&amp;`: `Хлеб &amp; соль`.
2. `<` заменяется на `&lt;`: `5 &lt; 7`.
3. Теги `<b>` и `</b>` теряют скобки: `&lt;b&gt;Скидка&lt;/b&gt;`. Для браузера это текст, а не элемент.
4. Строка `&lt;` уже содержит амперсанд. Он тоже заменяется, получается `&amp;lt;`. Браузер покажет на экране ровно `&lt;`. Поэтому экранируют один раз, перед вставкой, а не по нескольку раз подряд.
5. `reviewHtml` экранирует автора и текст, а теги `li` и `b` пишет сама. Получается `<li><b>Олег</b>: &lt;i&gt;Супер&lt;/i&gt;</li>`.
6. В строке два открывающих тега, `li` и `b`. Экранированные скобки у `i` не считаются.
7. Для отзыва без тегов результат тот же: два тега, свои.
