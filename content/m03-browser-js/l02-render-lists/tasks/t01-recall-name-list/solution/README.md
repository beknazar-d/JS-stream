# Разбор

1. `list.replaceChildren()` без аргументов убирает всех детей. Благодаря этому повторный вызов не дублирует позиции.
2. Для каждого названия создаём `li`, записываем текст через `textContent` и добавляем `append`. Строка с тегами останется текстом.
3. Класс задаём через `className`: у нового элемента других классов нет, затирать нечего.
4. Счётчик берём из `names.length`, поэтому пустой массив даёт `Позиций: 0`.
