# Разбор

1. Перед отрисовкой `list.replaceChildren()` убирает прежние карточки. Из-за этого функцию можно вызывать сколько угодно раз.
2. `empty.hidden = products.length > 0` одним выражением включает и выключает сообщение в обе стороны.
3. `template.content` — фрагмент с заготовкой. Мы клонируем его через `cloneNode(true)`, чтобы шаблон остался чистым и пригодился на следующий товар. Без клонирования `append` перенёс бы узлы из шаблона.
4. Клон — `DocumentFragment`, у него нет `dataset` и `classList`. Поэтому нужную карточку достаём через `fragment.querySelector('.card')`.
5. Данные пишем только через `textContent` и `dataset`. Название с тегами остаётся текстом.
6. `toggle(имя, условие)` ставит или снимает класс, а `disabled = isOut` делает то же для кнопки. Так клонирование не наследует состояние.
