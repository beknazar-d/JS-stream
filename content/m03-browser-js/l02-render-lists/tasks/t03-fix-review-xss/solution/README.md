# Разбор

Причина — строка `'<span ...>' + review.author + '</span>'` и присваивание её в `innerHTML`. Всё, что внутри `review.author`, браузер читает как разметку. Имя `<img src=x onerror=...>` создаёт настоящую картинку, которая не загружается, и срабатывает `onerror`.

Исправление: строим элементы через `createElement` и пишем данные в `textContent`. Тогда браузер не разбирает строку, а просто показывает её.

Что не сработало бы.

- Экранировать только текст отзыва: имя автора тоже пришло от пользователя.
- Заменять только `<` и `>`: строка `&quot;` превратится при разборе в кавычку, и текст изменится.
- Вырезать теги регулярным выражением: пропадёт честное слово в скобках, а хитрые обходы останутся.

Бонус: цикл с `list.innerHTML +=` ещё и пересоздаёт все предыдущие элементы на каждом шаге. `append` этого не делает.
