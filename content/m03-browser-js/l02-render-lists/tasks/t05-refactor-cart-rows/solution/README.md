# Разбор

Что было плохого в `innerHTML +=`: выражение `list.innerHTML += s` читает всю разметку списка в строку, дописывает к ней `s` и разбирает заново. Все старые узлы выбрасываются и создаются новые. Фокус, выделение, введённый текст и обработчики пропадают. Ещё название, склеенное в строку, превращается в разметку.

Что стало.

1. Строка строится из элементов: `li` и два `span`. Данные идут через `textContent` и `dataset`.
2. `list.append(row)` добавляет только новую строку. Старые остаются теми же узлами.
3. Счётчик считает `list.children.length`, поэтому он правильный после любого количества добавлений.

Тест на фокус показывает практическую пользу: поле или строка, на которых стоит пользователь, не сбрасываются при добавлении.
