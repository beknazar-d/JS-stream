# Разбор

1. Основной код выполняется сверху вниз, таймеры ждут. Поэтому первыми идут `ввод: ч`, `ввод: чай` и `конец скрипта`.
2. Вызов `onInput('чай')` делает `clearTimeout(timer)`. Таймер от `'ч'` ещё не сработал, поэтому он отменён и строки `поиск: ч` не будет.
3. Таймер с задержкой 0 не выполняется «прямо сейчас»: он ждёт, пока закончится основной код. Но срабатывает раньше таймера на 10 мс, поэтому `нулевая задержка` идёт перед `поиск: чай`.
4. Через 30 мс срабатывает `onInput('чайник')`: сначала `ввод: чайник`, потом через ещё 10 мс `поиск: чайник`. К этому моменту предыдущий таймер уже отработал, отменять нечего.

Итого семь строк. Это дебаунс в миниатюре: из двух быстрых вводов поиск получил только последний.
