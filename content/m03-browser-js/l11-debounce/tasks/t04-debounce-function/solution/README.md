# Разбор

1. `timer` объявлена внутри `debounce`, но снаружи возвращаемой функции. Это замыкание: все вызовы одной «дебаунснутой» функции делят один таймер, а у двух разных `debounce(...)` таймеры свои.
2. Каждый вызов сначала отменяет таймер (`clearTimeout`), потом запускает новый. Поэтому `fn` срабатывает только после паузы.
3. `...args` собирает все аргументы вызова, а `fn(...args)` передаёт их дальше. В таймер попадают аргументы именно последнего вызова: каждый следующий перезаписывает ожидание.
4. `cancel` вызывает `clearTimeout(timer)` и не запускает новый таймер. Если ожидающего вызова нет, ничего не происходит.

Функция-стрелка тут подходит, потому что `this` нам не нужен. С `this` в обработчиках мы разберёмся в следующем уроке.
