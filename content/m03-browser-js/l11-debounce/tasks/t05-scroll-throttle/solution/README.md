# Разбор

Троттлинг ограничивает частоту, а не ждёт тишины.

1. `lastCall` хранит момент последнего выполнения. `wait` — сколько ещё нужно подождать, чтобы выдержать интервал.
2. Если `wait` не больше нуля, интервал выдержан: выполняем сразу. Так первое событие после паузы не ждёт.
3. Иначе откладываем вызов на `wait` мс. Перед этим `clearTimeout` убирает прежний отложенный вызов, чтобы остался только последний. Он нужен затем, чтобы не потерять финальную позицию прокрутки: на ней пользователь и остановился.
4. `throttle(updateBackToTop, 100)` вызывается один раз, при подключении. Если вызвать его внутри обработчика, на каждое событие появится новая функция со своим `lastCall`, и ограничение пропадёт.

На 20 событиях за 300 мс получается около четырёх выполнений: в начале, примерно на 100, 200 и 300 мс.
