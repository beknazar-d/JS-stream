# Разбор

1. Сообщение показывается сразу: `saved.textContent = 'Сохранено'`.
2. Убирается позже: `setTimeout(функция, 300)`. Функция передаётся без скобок, её вызовет браузер.
3. Номер таймера хранится в переменной `hideTimer` снаружи обработчика. Это важно: при втором нажатии нужно отменить таймер от первого, иначе он сотрёт сообщение слишком рано.
4. `clearTimeout(hideTimer)` перед новым `setTimeout` — это уже заготовка дебаунса: событие откладывает действие, а следующее событие отодвигает его ещё раз.

Если таймер ещё не создан, `clearTimeout(undefined)` ничего не делает и ошибки не даёт.
