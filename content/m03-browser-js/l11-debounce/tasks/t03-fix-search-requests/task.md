## Контекст

Задача WEB-527. В поиске «Домотеки» на каждую букву уходит запрос: покупатель набирает «чайник» и вызывает шесть обращений к серверу. Администратор просит: «Пусть запрос уходит один, когда человек закончил печатать».

## Цель

Исправьте `script.js`: поиск должен запускаться не на каждое нажатие, а один раз после паузы в 300 мс. Пока человек печатает без длинных пауз, запросов нет.

## Критерии приёмки

- Если ввести «ч», «чай», «чайник» с паузами по 50 мс, уходит один запрос с `q=чайник`.
- Сразу после ввода запроса нет. Он уходит примерно через 300 мс после последней буквы и не позже чем через 500 мс.
- Результаты поиска выводятся в `#results` по одному элементу `li` на товар.
- Два отдельных поиска с паузой между ними дают два запроса, и на экране остаётся результат второго.

## Ограничения

- Разметку и стили не меняйте.
- Адрес запроса и вывод результатов оставьте как есть: меняется только момент вызова `loadResults`.
