# Разбор

Ошибка в том, что `loadResults` вызывается прямо из обработчика `input`. Событие приходит на каждую букву, и на каждую букву уходит запрос.

Исправление — дебаунс:

1. `let timer;` объявлена снаружи обработчика, поэтому все нажатия видят один и тот же таймер.
2. `clearTimeout(timer)` отменяет таймер от предыдущей буквы.
3. `setTimeout(() => loadResults(search.value), 300)` запускает новый. Значение поля читается внутри таймера, поэтому в запрос попадает то, что написано в поле на момент срабатывания.

Типичная неточность: поставить `setTimeout`, но забыть `clearTimeout`. Тогда запросы не пропадают, а лишь откладываются.
