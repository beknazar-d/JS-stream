## Зачем это в работе

Менеджер «Домотеки» пишет тикет: у товаров, которых нет на складе, нужна пометка «Нет в наличии», а кнопка «В корзину» должна стать серой и не нажиматься. Данные о наличии уже лежат в разметке. Остаётся прочитать их из страницы и поменять сами элементы.

До сих пор вы писали JavaScript, который считал и возвращал значения. Теперь он будет менять страницу. Для этого браузер даёт программе доступ к документу. Он называется DOM (Document Object Model, «объектная модель документа»).

В этом уроке вы научитесь находить элементы, менять их текст, классы и атрибуты и читать `data`-значения. Весь код синхронный: данные приходят сразу вместе со страницей. Загрузку с сервера мы разберём позже, в уроке про `fetch`.

## Объяснение

Браузер читает HTML и строит из него дерево. Каждый тег становится узлом (node) дерева, вложенные теги становятся детьми. Дерево лежит в памяти, и JavaScript работает именно с ним, а не с исходным текстом HTML. Поэтому после изменения дерева текст файла не меняется, а страница на экране меняется сразу.

Аналогия: HTML-файл — это чертёж квартиры. DOM — сама квартира, в которой можно подвинуть шкаф. Чертёж при этом остаётся прежним.

Работа с DOM состоит из двух шагов: найти элемент и изменить его.

**Поиск.** Метод `document.querySelector(селектор)` принимает такой же селектор, как в CSS, и возвращает первый подходящий элемент. Если ничего не нашлось, вернётся `null`. Метод `document.querySelectorAll(селектор)` возвращает список всех подходящих элементов. Он называется `NodeList` и устроен как массив для чтения: по нему можно идти циклом `for...of`. Если совпадений нет, список пустой, а не `null`.

**Изменение.**

- `element.textContent` — текст внутри элемента. Присвоили строку, и текст заменился.
- `element.classList` — набор классов. Методы `add`, `remove`, `toggle` и `contains` не трогают остальные классы.
- `element.getAttribute(имя)` и `element.setAttribute(имя, значение)` — любые атрибуты. У частых атрибутов есть готовые свойства: `link.href`, `input.value`.
- `element.dataset` — атрибуты вида `data-*`. Атрибут `data-product-id` читается как `dataset.productId`. Значение всегда строка.
- `element.hidden` — скрыть элемент или показать.

## Пример

Разметка карточки с данными о наличии.

```html
<article class="card" data-product-id="k200" data-stock="0">
  <h3 class="card__title">Чайник K-200</h3>
  <p class="card__stock">В наличии</p>
  <button class="card__buy">В корзину</button>
</article>
<script src="script.js"></script>
```

Скрипт читает наличие и обновляет карточку.

```js
const card = document.querySelector('.card');
const stock = Number(card.dataset.stock);

if (stock === 0) {
  card.querySelector('.card__stock').textContent = 'Нет в наличии';
  card.classList.add('card--out');
  card.querySelector('.card__buy').disabled = true;
}
```

Обратите внимание на две детали. Во-первых, `dataset.stock` — строка `'0'`, и мы превратили её в число через `Number`. Во-вторых, искать внутри карточки удобнее через `card.querySelector`: метод есть у любого элемента и ищет только среди его потомков.

Теперь сравним два способа поменять класс.

<Wrong>

```js
// затирает все классы: card и card--featured пропадут
card.className = 'card--out';
```

</Wrong>

<Right>

```js
// добавляет один класс, остальные остаются
card.classList.add('card--out');
```

</Right>

Схема показывает, как фрагмент HTML превращается в дерево.

Так выглядит дерево в виде вложенных отступов. Каждый узел знает своих детей, и поиск идёт по ним сверху вниз.

<Playground example="tree" />

Правила, которые стоит запомнить.

1. **Скрипт должен видеть элементы.** Браузер читает HTML сверху вниз. Скрипт в начале `body` запустится раньше, чем появятся элементы ниже, и `querySelector` вернёт `null`. Ставьте `script` в конец `body` или в `head` с атрибутом `defer`: он отложит запуск до конца разбора HTML.
2. **`null` нужно ожидать.** Опечатка в селекторе или нет такого элемента: результат `null`, а следующая строка упадёт.
3. **`querySelectorAll` возвращает не массив.** У `NodeList` есть `forEach` и итерация, но нет `map` и `filter`. Нужен массив: `Array.from(список)` или `[...список]`.
4. **Присваивание свойства коллекции ничего не меняет.** Список не элемент: `querySelectorAll('.card').textContent = 'x'` молча создаст свойство у списка, а страница не изменится.
5. **`hidden` работает по наличию.** Атрибут `hidden="false"` всё равно скрывает элемент. Пишите `element.hidden = false`: браузер уберёт атрибут сам.
6. **Данные в `dataset` — строки.** Значение `'0'` в условии истинно. Сначала `Number`, потом сравнение.

<Note>

Откройте DevTools (клавиша F12) и вкладку Elements: это живое DOM-дерево. В консоли можно сразу пробовать `document.querySelector('.card')`.

</Note>

## Типичные ошибки

Сообщения ниже получены в Chromium. В консоли браузера они выглядят так же.

**1. Элемент не найден.** Селектор написан без точки или скрипт запущен раньше разметки.

```text
TypeError: Cannot set properties of null (setting 'textContent')
TypeError: Cannot read properties of null (reading 'classList')
```

Проверьте, что в селекторе есть точка перед классом, а `script` стоит в конце `body`.

**2. Неверный селектор.** Значение атрибута без кавычек или две точки подряд.

```text
SyntaxError: Failed to execute 'querySelector' on 'Document': '[data-id=5]' is not a valid selector.
```

Пишите `[data-id="5"]`.

**3. Метод списка у одного элемента и наоборот.** Вызвали обработчик у списка, а не у элемента.

```text
TypeError: document.querySelectorAll(...).addEventListener is not a function
```

Пройдите по списку циклом `for...of` или возьмите один элемент через `querySelector`.

**4. Пробел в имени класса.** Метод `add` принимает по одному имени.

```text
InvalidCharacterError: Failed to execute 'add' on 'DOMTokenList': The token provided ('a b') contains HTML space characters, which are not valid in tokens.
```

Передайте два аргумента: `classList.add('a', 'b')`.

**5. Опечатка в свойстве.** `textcontent` вместо `textContent` не выдаёт ошибки. Просто ничего не происходит. Это самая коварная ошибка: смотрите на регистр букв.
