# Разбор

В скрипте четыре проблемы.

1. `querySelector('product-title')` ищет тег `product-title`, которого нет. Результат `null`, и строка ниже падает с `Cannot set properties of null`. Исправление: точка перед классом.
2. В документе два элемента с классом `product-title`. Первый стоит в блоке «Похожие товары», и `querySelector` вернёт его. Селектор `main .product-title` ищет только внутри `main`.
3. `classList.add('.visible')` добавляет класс с точкой в имени. Такой класс не совпадает с `.visible` в CSS. В `classList` точку не пишут.
4. `textcontent` с маленькой буквой не существует. JavaScript молча создаёт новое свойство у объекта, ошибки нет, текст не меняется.

Привычка: после правки сразу смотрите в консоль и на страницу. Каждая ошибка видна только после исправления предыдущей.
