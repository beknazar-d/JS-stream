# Разбор

Меняем по строке старого кода на современный аналог.

1. `getElementsByClassName` + счётчик → `querySelectorAll('.card')` + `for...of`. Читается проще, а `NodeList` не меняется на ходу.
2. `getAttribute('data-new') == 'true'` → `dataset.new === 'true'`. Строгое сравнение со строкой нужно, потому что значение `'false'` тоже строка и сама по себе истинна.
3. `className = className + ' card--new'` → `classList.add('card--new')`. Метод не дублирует класс и не требует следить за пробелами.
4. `style.display = 'none'` → `hidden = true`. Атрибут `hidden` — признак состояния, а не оформление: его можно переопределить в CSS и прочитать в тестах и программах чтения с экрана.

Рефакторинг не меняет то, что видит человек. Именно поэтому после каждой замены стоит проверять страницу.
