# Разбор

1. Каждый элемент находим один раз через `document.querySelector` и кладём в переменную. Имена классов взяты из разметки.
2. `textContent` заменяет текст. Это безопасный способ: строка остаётся текстом, а не разбирается как HTML.
3. `badge.hidden = false` убирает атрибут `hidden`. Строка `'false'` не подойдёт: она истинна, и атрибут останется.
4. `classList.add('badge--sale')` добавляет класс и не трогает `badge`. Присваивание в `className` затёрло бы оба.
5. `setAttribute('href', ...)` записывает адрес, а `dataset.productId` превращается в атрибут `data-product-id`.
