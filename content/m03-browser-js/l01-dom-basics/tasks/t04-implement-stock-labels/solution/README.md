# Разбор

1. `card.dataset.stock` — строка или `undefined`, если атрибута нет. Отдельная проверка `raw === undefined` важна: `Number(undefined)` даёт `NaN`, и сравнения с ним всегда ложны.
2. Число получаем через `Number`. Не пишите `if (card.dataset.stock)`: строка `'0'` истинна.
3. Элементы внутри карточки ищем через `card.querySelector`. Метод `document.querySelector('.stock')` вернул бы первую подпись на странице.
4. `classList.toggle('card--out', isOut)` с вторым аргументом работает в обе стороны: включает класс при `true` и выключает при `false`. Так же `button.disabled = isOut`. Из-за этого повторный вызов после пополнения склада возвращает карточку в норму.
5. Порядок веток: сначала «нет данных» и ноль, потом граница `<= 5`, остальное — «В наличии».

Вопрос на будущее: «Что показывать при отрицательном остатке?» Сейчас он попадёт в ветку «Осталось: -2 шт.». В реальной задаче это стоило бы уточнить у склада.
