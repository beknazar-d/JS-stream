# Разбор

Функция задаёт состояние страницы целиком, а не «добавляет» к нему. Поэтому её можно вызывать сколько угодно раз.

1. Тексты: `textContent` для заголовка, крошки и цены, `document.title` для вкладки.
2. Скидка. Условие `oldPrice > price` вычисляется один раз. Если `oldPrice` не передан, сравнение `undefined > число` ложно, ошибки нет. Оба элемента получают `hidden = !hasDiscount`, а их текст очищается в ветке «нет скидки».
3. Наличие. `classList.toggle(имя, условие)` с вторым аргументом сам включает или выключает класс, поэтому `p-stock--ok` и `p-stock--out` не накапливаются. Кнопка: `disabled = !inStock`.
4. Доступность. У кнопки в разметке написано только «В корзину». Без `aria-label` невидящий пользователь не поймёт, какой товар он покупает. Картинке нужен `alt`; если отдельного описания нет, берём название через `??`.
5. `data-product-id` записываем через `dataset.productId`, чтобы позднее найти товар по кнопке.

Проценты округляем `Math.round`, как требует тикет: 39,76 превращается в 40.
