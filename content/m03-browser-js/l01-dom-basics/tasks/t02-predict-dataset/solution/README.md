# Разбор

1. `data-product-id`: после удаления `data-` остаётся `product-id`, дефис перед `i` превращается в заглавную `I`. Получается `productId`.
2. `data-old-price-rub`: два дефиса, обе замены выполняются из-за флага `g`. Получается `oldPriceRub`.
3. `stockLeft`: перед заглавной `L` ставится дефис и буква становится строчной. Получается `data-stock-left`.
4. `id`: заглавных букв нет, остаётся `data-id`.
5. Значение атрибута всегда строка: `typeof` даёт `string`.
6. `Boolean('0')` — `true`: непустая строка истинна. Это причина багов вида `if (card.dataset.stock)`.
7. `Number('0') > 0` — `false`: число получено явно, и сравнение работает как ожидается.
8. `'0' + 1` — склейка строк, получается `'01'`, а не `1`.
