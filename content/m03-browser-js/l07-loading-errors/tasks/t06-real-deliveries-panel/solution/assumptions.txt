Вопросы:
1. Какие тексты показывать для загрузки, ошибки, пустого списка? Есть ли утверждённые формулировки?
2. Оставлять старый список при неудачном обновлении или очищать? Может ли быть важно видеть последние известные данные?
3. Показывать пользователю код ошибки или достаточно общего сообщения? Нужен ли автоматический повтор?

Допущения:
1. Тексты: «Загружаем доставки…», «Сервер отвечает слишком долго», «Нет соединения с сервером», «Не удалось загрузить доставки», «Доставок на сегодня нет».
2. При новой загрузке старый список очищается, чтобы не показывать устаревшие данные под сообщением об ошибке.
3. Код ошибки добавляю в скобках для статуса сервера, чтобы поддержке было проще разбираться. Автоповтора нет: повторяет только человек по кнопке.
