# Разбор

1. `new AbortController()` создаёт пульт отмены. Его `signal` передаётся в `fetch` вторым аргументом. Когда вызывают `controller.abort()`, `fetch` немедленно завершается ошибкой.
2. Таймер `setTimeout(() => controller.abort(), TIMEOUT_MS)` нажимает на этот пульт через полсекунды.
3. Ошибка отмены имеет имя `AbortError`. По нему `catch` отличает таймаут от сбоя сети (`TypeError`). Две разные ситуации требуют разных сообщений: «подождите, сервер медленный» и «проверьте интернет».
4. `clearTimeout(timer)` стоит в `finally`. Если запрос завершился вовремя, таймер нужно остановить, иначе он сработает позже и отменит уже не нужный запрос (а в плохом решении ещё и выведет ложное сообщение).
5. Проверка статуса остаётся: ответ 503 — не таймаут и не сеть.

Блок `finally` выполняется в любом случае: после успеха, после ошибки и после `return` внутри `try`. Поэтому сброс таймера удобно держать там.
