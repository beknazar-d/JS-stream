# Разбор

Первые четыре строки — выбор состояния.

1. Идёт загрузка: `loading`. Проверка загрузки стоит первой.
2. Есть ошибка и старые данные: `error`. Ошибка проверяется раньше списка, поэтому остатки прошлой загрузки её не скрывают.
3. Ошибки нет, списка нет: `empty`.
4. Всё хорошо и есть элементы: `list`.

Дальше `AbortController`.

5. Пока `abort()` не вызван, `signal.aborted` равно `false`.
6. После `abort()` — `true`.
7. Если причину не указали, `signal.reason` — ошибка с именем `AbortError`. Именно это имя приходит в `catch`, когда отменённый `fetch` завершается ошибкой. По нему отличают отмену от сетевого сбоя.
8. и далее. Обработчик события `abort` вызывается синхронно, прямо внутри `abort()`. Поэтому порядок: `до abort`, `отмена получена`, `после abort`.
