# Разбор

Две части: разметка и скрипт.

**Живая область.** Скринридер читает сообщения вслух, только если знает, что элемент меняется. Это называется живой областью (live region). Её делают атрибутом `aria-live="polite"` или `role="status"`. Слово `polite` значит «вежливо»: сообщение прочитается, когда человек закончит текущую фразу. Атрибут должен стоять на элементе до того, как в нём появится новый текст, поэтому его правят в `index.html`, а не из скрипта в момент ошибки.

**`aria-busy`.** Пока список обновляется, ставим `aria-busy="true"`. Скринридер понимает, что содержимое сейчас меняется. Снимаем в блоке `finally`: он выполняется и после успеха, и после `return` в ветке ошибки, и после `catch`. Так не получится забыть про одну из веток.

**Фокус.** После ошибки человек с клавиатурой должен сразу оказаться на кнопке «Повторить». Но у скрытого элемента (`hidden`) фокус получить нельзя: `focus()` просто ничего не сделает. Поэтому сначала `retry.hidden = false`, затем `retry.focus()`. Для двух видов ошибки (статус и сеть) выделена функция `showError`, чтобы не дублировать эти строки.

**Пусто.** Пустой массив — отдельный исход с понятным сообщением. Иначе зрячий видит пустую страницу, а незрячий не слышит вообще ничего.
