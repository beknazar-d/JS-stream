# Разбор

Три ошибки.

1. **`addEventListener('click', loadOrders())`.** Скобки вызывают функцию прямо сейчас, а в обработчик попадает то, что она вернула (обещание). Результат: запрос уходит при подключении обработчика и ещё раз в конце файла, а нажатие на кнопку не делает ничего. Передавать нужно саму функцию: `loadOrders`.
2. **Кнопка не показывается.** В `catch` стоит `retry.hidden = true`. Нужно `false`: в состоянии ошибки кнопка должна быть видна.
3. **«Загрузка…» не убирается при успехе.** В начале функции мы пишем это сообщение, но нигде его не очищаем. Добавляем `status.textContent = ''` в успешную ветку.

Совет на будущее: после каждого исхода запроса (успех, ошибка, пусто) проверяйте три вещи: что написано в статусе, видна ли кнопка, что в списке.
