## Контекст

Баг из поддержки: «Раздел «Мои заказы» ломается так. Страница открывается, сервер отвечает ошибкой 503, кнопки «Повторить» нет. А если какими-то путями дойти до успеха, наверху остаётся надпись «Загрузка…». Ещё разработчики заметили в логах сервера, что при открытии страницы приходит два запроса вместо одного».

Страница делает запрос `GET /api/orders`. Сервер в тестовой среде сначала отвечает `503`, на втором запросе — списком из трёх заказов.

## Цель

Исправьте `script.js`, чтобы состояния и кнопка «Повторить» работали, а при открытии страницы уходил ровно один запрос.

## Критерии приёмки

- При открытии страницы выполняется ровно один запрос `GET /api/orders`. Пока он идёт, в `#status` `Загрузка…`, а кнопка `#retry` скрыта.
- После ответа `503` в `#status` `Не удалось загрузить заказы`, кнопка `#retry` показана.
- Нажатие на `#retry` делает ещё один запрос (всего два). Заказы выводятся в `#orders`, по одному `li` на заказ.
- После успешной загрузки `#status` пуст, а кнопка `#retry` скрыта.

## Ограничения

- Не меняйте `index.html`.
- Не убирайте `try/catch` и не заменяйте `async/await` на `.then`.
