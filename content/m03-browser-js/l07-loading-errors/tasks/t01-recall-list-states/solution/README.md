# Разбор

У списка, который приходит с сервера, не одно состояние, а четыре. Хороший тон — показывать каждое.

1. **Загрузка.** Перед запросом пишем «Загрузка…» и прячем кнопку: человек видит, что страница работает.
2. **Ошибка ответа.** Сервер ответил, но с плохим статусом. Проверяем `response.ok` и показываем статус. Здесь же показываем кнопку «Повторить».
3. **Ошибка сети.** Ответа нет вообще, `fetch` выбрасывает ошибку. Её ловит `catch`. Без него функция молча падает и надпись «Загрузка…» остаётся навсегда.
4. **Пусто.** Пустой массив — не ошибка. Нужно отдельное сообщение, иначе человек решит, что страница сломалась.
5. **Список.** Перед выводом очищаем `list.textContent = ''`, иначе при «Обновить» заказы задвоятся.

Обратите внимание: каждая ветка сама устанавливает и сообщение, и видимость кнопки. Так не бывает «ошибка, но кнопки нет» или «загрузка, а кнопка ещё видна».
