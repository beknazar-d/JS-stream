# Разбор

Ошибка в одной строке функции `save`:

```js
localStorage.setItem(KEY, cart); // было
localStorage.setItem(KEY, JSON.stringify(cart)); // стало
```

Хранилище умеет хранить только строки. Когда в `setItem` попадает массив объектов, браузер вызывает `String(cart)` и записывает `"[object Object],[object Object]"`. Данные потеряны, а при следующем запуске `JSON.parse` падает или возвращает мусор. Тостер из прошлого визита загрузился, потому что он был записан раньше в нормальном виде, но первое же сохранение его затёрло.

Как искать такую ошибку: после действия откройте `localStorage.getItem('cart')` в консоли. Если вместо `[{"id":...` вы видите `[object Object]`, в запись попал не JSON.

Очистка уже вызывала `save()` и работает, как только `save` исправлена: в хранилище остаётся `[]`. Удалять ключ через `removeItem` здесь не стоит: другие страницы читают корзину без запасного значения.
