## Контекст

Тикет из поддержки: «Положил в корзину три товара, обновил страницу, а там только один». Корзина «Домотеки» хранится в `localStorage`, и при загрузке страница показывает число товаров. Товары, которые лежали с прошлого визита, на месте. Но всё, что покупатель добавил на этой странице, после перезагрузки пропадает.

## Цель

Найдите и исправьте ошибку в `script.js`, чтобы корзина сохранялась в `localStorage` целиком и в правильном виде.

## Критерии приёмки

- В хранилище по ключу `cart` лежит JSON-массив позиций. После добавления товара в нём на одну позицию больше, прежние позиции не потеряны.
- Позиция имеет вид `{ id, title, price }`, где `id` и `price` — числа.
- Кнопка «Очистить корзину» оставляет в хранилище `[]`: другие страницы читают корзину без запасного значения и не должны упасть.
- Число товаров рядом с корзиной совпадает с длиной массива.
- Данные пишутся в `localStorage`, а не в `sessionStorage`.

## Ограничения

- Не меняйте `index.html`.
- Не переписывайте скрипт с нуля: ошибка в одном месте.
