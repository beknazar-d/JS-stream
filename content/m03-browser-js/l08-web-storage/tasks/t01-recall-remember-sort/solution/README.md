# Разбор

Хранилище работает с парами «ключ — строка». Здесь две операции.

1. `localStorage.getItem('sort')` возвращает сохранённую строку или `null`, если ключа ещё нет. Поэтому перед присваиванием стоит проверка `if (saved)`: при первом визите список остаётся как есть.
2. `localStorage.setItem('sort', sortSelect.value)` на событии `change` записывает выбранное значение. Значение у `select` уже строка, поэтому `JSON.stringify` не нужен. Если записать `JSON.stringify('rating')`, в хранилище окажется `"rating"` с кавычками, и присваивание в список не сработает.

Почему не `sessionStorage`: он очищается при закрытии вкладки. Предпочтение пользователя должно пережить визит, значит, нужен `localStorage`.
