# Разбор

Главное правило: хранилище превращает любое значение в строку через `String(value)`.

1. `typeof storage.getItem('qty')` даёт `"string"`. Число `3` при записи стало строкой `"3"`.
2. `storage.getItem('qty') + 1` даёт `"31"`. Слева строка, поэтому плюс склеивает. Чтобы посчитать, нужен `Number(...)`.
3. Массив `[4, 7]` при записи превращается в `"4,7"`. Это не JSON, и обратно массив уже не собрать.
4. Объект при записи превращается в `"[object Object]"`. Данные потеряны. Для объектов нужен `JSON.stringify`.
5. Для отсутствующего ключа `getItem` возвращает `null`, а не `undefined` и не пустую строку.
6. `JSON.stringify` и `JSON.parse` сохраняют структуру: после `parse` поле `inStock` снова настоящее `true`.
