## Контекст

Разработчик «Домотеки» сохраняет в `localStorage` число товаров, список номеров и данные покупателя. После перезагрузки страницы числа ведут себя странно: `qty + 1` даёт `"31"`, а объект превращается в непонятный текст. Чтобы понять причину, нужно знать правило хранилища: оно хранит только строки.

## Цель

Прочитайте код из `snippet.js`. В нём простая модель хранилища с тем же правилом, что у настоящего `Storage`. Запишите в `answer.js` в массив `output` шесть строк: то, что код выведет в консоль, по одной строке на каждый вызов `console.log`.

## Критерии приёмки

- В массиве `output` ровно шесть строк в порядке вызовов `console.log`.
- Каждый элемент — строка, например `"31"` или `"null"`.
- Ответ совпадает с реальным выводом кода построчно.

## Ограничения

- Не меняйте `snippet.js`.
- Сначала предскажите, потом сверяйтесь с проверкой.
