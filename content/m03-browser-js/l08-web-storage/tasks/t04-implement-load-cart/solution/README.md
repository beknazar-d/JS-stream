# Разбор

Данные из хранилища нельзя считать правильными: их могла записать другая версия сайта, расширение или сам человек в консоли. Поэтому `loadCart` проверяет всё по цепочке.

1. **Разбор JSON в `try/catch`.** `JSON.parse` бросает `SyntaxError` на любом неверном тексте, например `{oops`. В `catch` возвращаем пустую корзину. Если ключа нет, `getItem` вернёт `null`, а `JSON.parse(null)` даёт `null`, поэтому отдельная проверка на отсутствие ключа не нужна.
2. **Проверка формы.** После успешного разбора это может быть что угодно: `null`, число, объект. `Array.isArray` оставляет только массивы.
3. **Проверка каждой позиции.** `filter` отбрасывает `null`, позиции без `qty`, с `qty` строкой, дробным или нулевым. `item &&` в начале защищает от `null` внутри массива.

`saveCart` проще: `JSON.stringify` превращает массив в строку, `setItem` записывает.

Почему здесь `filter`, а не проверка «весь массив или ничего»: одна повреждённая позиция не должна стоить покупателю всей корзины.
