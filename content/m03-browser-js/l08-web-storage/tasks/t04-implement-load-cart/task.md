## Контекст

Корзина «Домотеки» лежит в `localStorage` под ключом `cart`. Раньше её писали старые версии сайта, расширения браузера и тестовые скрипты. В хранилище попадает всякое: пустое значение, обрезанный JSON, объект вместо массива, позиции с количеством `"2"` строкой. Из-за этого у части покупателей страница падает на загрузке, а у части в корзине показывается `NaN`.

## Цель

Допишите в `script.js` функции `loadCart()` и `saveCart(cart)`. Корзина — массив позиций вида `{ id, qty }`. Функция `loadCart` не должна падать ни на каких данных и всегда возвращает массив.

## Критерии приёмки

- Ключа `cart` нет: `loadCart()` возвращает `[]`.
- Значение не разбирается как JSON (например, `{oops`): возвращается `[]`, ошибка наружу не выходит.
- JSON разобран, но это не массив (`null`, число, строка, объект): возвращается `[]`.
- Из массива остаются только корректные позиции: `id` и `qty` — целые числа, `qty` больше нуля. Остальные элементы отбрасываются, порядок оставшихся сохраняется.
- `saveCart(cart)` записывает массив в `cart` как JSON-строку.
- Число рядом со значком корзины `#cart-count` — сумма `qty` по корректным позициям. Оно считается при загрузке страницы.

## Ограничения

- Не меняйте `index.html`.
- Функции должны называться `loadCart` и `saveCart` и быть объявлены на верхнем уровне скрипта: тесты вызывают их напрямую.
- Не используйте `eval` и регулярные выражения для разбора JSON.
