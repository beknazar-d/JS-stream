## Контекст

Менеджер «Домотеки» хочет слать клиентам ссылки на готовые подборки: «чайники в наличии, сначала дешёвые». Для этого состояние фильтров каталога должно жить в адресе страницы: `/catalog?category=kettles&sort=price-asc&inStock=1`. Нужны две функции: одна превращает адрес в фильтры, другая фильтры в адрес. Дальше ими воспользуются страницы каталога.

Ссылки приходят из рассылок, закладок и мессенджеров, поэтому адрес может быть любым: с лишними параметрами, с опечатками, с якорем или пустым.

## Цель

Допишите в `index.js` функции `parseFilters(url)` и `buildUrl(filters)`.

## Критерии приёмки

- `parseFilters(url)` принимает полный адрес, путь с параметрами (`/catalog?sort=rating`), только строку запроса (`?category=kettles`) или пустую строку. Возвращает объект `{ category, sort, inStock }`.
- Допустимые значения: `category` из `CATEGORIES`, `sort` из `SORTS`. Любое другое значение или отсутствие параметра даёт значение по умолчанию из `DEFAULTS`.
- `inStock` равно `true` только при `inStock=1`. Для `0`, пустого значения и отсутствия параметра — `false`.
- Лишние параметры и якорь (`#...`) игнорируются. Если параметр повторён, берётся первое значение. Функция никогда не бросает ошибку, даже на мусорном адресе.
- `buildUrl(filters)` возвращает `/catalog` и строку запроса. Параметры идут в порядке `category`, `sort`, `inStock`. Значения по умолчанию, недопустимые значения и отсутствующие поля в адрес не попадают. Если параметров нет, адрес равен `/catalog` без знака вопроса.
- Для `inStock` пишется `inStock=1`.
- Цикл `parseFilters(buildUrl(f))` возвращает нормализованные фильтры `f`.

## Ограничения

- Не используйте `location`: функции получают адрес строкой, так их можно проверить в тестах и вызвать в любом месте приложения.
- Строку запроса не режьте вручную по `&` и `=`: используйте `URL` и `URLSearchParams`.
