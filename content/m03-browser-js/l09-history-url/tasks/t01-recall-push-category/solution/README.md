# Разбор

`history.pushState(state, title, url)` добавляет в историю новую запись и меняет адрес, не перезагружая страницу.

1. `state` — любой объект, который можно скопировать. Он вернётся в `event.state`, когда покупатель вернётся к этой записи.
2. `title` — устаревший аргумент, браузеры его игнорируют. Передают пустую строку.
3. `url` — новый адрес. Относительный `?category=kettles` заменит только строку запроса.

Адрес собираем через `URLSearchParams`: он сам кодирует пробел, амперсанд и русские буквы. `'?' + params` вызывает `params.toString()`. Склейка строк `'?category=' + value` ломается на любом значении с `&`, `=`, `#` или пробелом.

Отличие `replaceState` от `pushState`: первый заменяет текущую запись, второй добавляет новую. Для выбора фильтра, к которому надо уметь вернуться, нужен `pushState`.

В настоящем браузере вы бы увидели новый адрес в строке и могли прочитать его через `location.search`. В тренажёре `location` не меняется, поэтому тесты читают адрес хелпером `currentUrl()`.
