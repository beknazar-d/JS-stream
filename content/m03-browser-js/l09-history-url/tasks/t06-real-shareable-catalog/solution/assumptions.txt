Вопросы:
1. Как упорядочивать товары с одинаковым числом продаж: по цене, по названию, как придёт из API?
2. Что показывать при загрузке и при ошибке API: заглушку, сообщение, повторить запрос?
3. Запоминать ли фильтры между визитами, если человек открыл каталог без параметров в адресе?

Допущения:
1. При равенстве продаж порядок остаётся как в ответе API (сортировка в JavaScript стабильна).
2. Пока товары грузятся, список пуст и показывается «Ничего не найдено». Это временное решение, пока нет макета загрузки.
3. Между визитами фильтры не запоминаем: адрес страницы и есть память, ссылку можно отправить.
