# Разбор

1. `params.get('category')` даёт `kettles`. Начальный знак `?` конструктор отбрасывает сам.
2. `get('sort')` при двух параметрах с одним именем возвращает первое значение: `price-asc`.
3. `getAll('sort')` возвращает массив из двух значений, длина `2`.
4. Параметра `page` нет, `get` возвращает `null`.
5. После `set('page', 2)` и `delete('sort')` остаются `category` и `page`. `toString` даёт строку без знака `?`: `category=kettles&page=2`. Число `2` превратилось в строку `"2"`.
6. `URL` хранит адрес в закодированном виде: русские буквы стали последовательностями `%D1%87...`, пробел стал `%20`.
7. `url.searchParams.get('q')` раскодирует значение обратно: `чайник Bosch`.

Вывод для практики: читать параметры нужно через `URLSearchParams`, а не резать строку руками. Кодирование и раскодирование он делает сам.
