# Разбор

`pushState` вызывается в `applyFilters`, а `applyFilters` вызывал и обработчик выбора, и обработчик `popstate`. Возврат по истории сам записывал новую запись. А новая запись стирает всё, что было «впереди» текущей, поэтому «Вперёд» становилась недоступной.

Правило: **`pushState` вызывается только в ответ на действие человека**, не в ответ на сам переход по истории.

Исправление: обработчику `popstate` нужны два действия, показать значения в элементах управления и перерисовать список.

```js
window.addEventListener('popstate', (event) => {
  const filters = event.state || DEFAULTS;
  showControls(filters);
  render(filters);
});
```

Две детали.

1. У самой первой записи истории `state` равен `null`. Поэтому `event.state || DEFAULTS`: без этого возврат к началу упадёт с `TypeError`.
2. При загрузке тоже вызывается только `render`: страница открылась, новой записи не нужно.
