## Зачем это в работе

Покупатель нажимает «В корзину», и счётчик в шапке растёт. Печатает в поиске «чай», и список сам сокращается. Нажимает Enter в поле промокода, и форма не перезагружает страницу. Всё это события.

Событие (event) — это сообщение браузера, что что-то случилось: клик, нажатие клавиши, ввод текста, отправка формы. Страница не опрашивает кнопку каждую секунду. Она один раз говорит браузеру: «Когда на этой кнопке щёлкнут, вызови вот эту функцию».

В этом уроке вы научитесь вешать такие функции, читать объект события и отменять действия браузера по умолчанию. Код синхронный: никаких запросов к серверу.

## Объяснение

Функция, которую браузер вызывает при событии, называется обработчиком (event handler, listener). Подключается она методом `addEventListener`:

```js
element.addEventListener('click', handler);
```

Первый аргумент — имя события, второй — функция. Скобок после `handler` нет: мы передаём саму функцию, а не результат её вызова. Вызывать её будет браузер.

Браузер вызывает обработчик и передаёт ему объект события. У него полезные свойства:

- `event.type` — имя события, например `'click'`;
- `event.target` — элемент, на котором событие случилось;
- `event.currentTarget` — элемент, на котором висит обработчик (чаще всего тот же самый);
- `event.key` — какая клавиша нажата, для событий клавиатуры (`'Enter'`, `'Escape'`);
- `event.preventDefault()` — отменить действие браузера по умолчанию.

Основные события страницы:

- `click` — щелчок или нажатие Enter и пробела на кнопке;
- `input` — значение поля изменилось, срабатывает на каждый символ;
- `change` — ввод завершён: для текстового поля это уход с поля, для флажка и списка — сразу;
- `keydown` — клавиша нажата;
- `submit` — форма отправляется (по кнопке или по Enter).

Действие по умолчанию есть у многих событий. Клик по ссылке открывает адрес. Отправка формы перезагружает страницу. Если страница должна обработать это сама, обработчик вызывает `event.preventDefault()`.

Аналогия: звонок в дверь. Вы вешаете звонок один раз и объясняете, что делать на звонок: открыть дверь, посмотреть в глазок. Когда гость нажмёт кнопку, сработает ваша инструкция. А `preventDefault` — это «не отправлять курьера по умолчанию, я сам разберусь».

Обработчик можно снять: `removeEventListener`. А если он нужен ровно один раз, добавьте третий аргумент `{ once: true }`.

## Пример

Разметка: кнопка, счётчик, ссылка и форма поиска.

```html
<button id="add">В корзину</button>
<p id="count">Корзина: 0</p>
<a id="details" href="#specs">Подробнее</a>
<form id="search">
  <input id="q" type="text">
  <button>Найти</button>
</form>
<script src="script.js"></script>
```

Скрипт.

```js
let count = 0;
const add = document.querySelector('#add');
const counter = document.querySelector('#count');

function onAdd() {
  count += 1;
  counter.textContent = `Корзина: ${count}`;
}
add.addEventListener('click', onAdd);

document.querySelector('#details').addEventListener('click', (event) => {
  event.preventDefault();
  console.log('Открываем характеристики в окне, а не переходим по адресу');
});

const search = document.querySelector('#search');
search.addEventListener('submit', (event) => {
  event.preventDefault();
  const query = document.querySelector('#q').value.trim();
  console.log('Ищем: ' + query);
});
```

Что здесь важно. Счётчик `count` лежит вне обработчика, поэтому помнит значение между кликами. Ссылка и форма получили `preventDefault`: страница не переходит и не перезагружается. Проверка поиска висит на `submit` формы, а не на клике по кнопке: так срабатывает и Enter в поле.

Теперь сравним два способа подключить обработчик.

<Wrong>

```js
// функция вызывается сразу, при загрузке страницы
add.addEventListener('click', onAdd());
```

</Wrong>

<Right>

```js
// браузер вызовет функцию сам, когда будет клик
add.addEventListener('click', onAdd);
```

</Right>

## Как это работает

Путь события на схеме.

<Figure src="event-flow.svg" alt="Слева направо четыре блока со стрелками: человек нажал кнопку, браузер создаёт объект события, вызывается ваш обработчик, затем выполняется действие по умолчанию, например отправка формы или переход по ссылке. Из обработчика идёт пометка: preventDefault отменяет то, что справа." caption="Обработчик получает событие до действия по умолчанию. Вызов preventDefault отменяет это действие." />

Правила, которые стоит запомнить.

1. **Обработчик — это функция, а не её вызов.** `handler`, а не `handler()`. Со скобками функция выполнится один раз при загрузке, а на клик подпишется результат вызова.
2. **`preventDefault` вызывают со скобками.** Запись `event.preventDefault;` ничего не делает: это просто чтение свойства.
3. **Форму ловят на `submit`.** Клик по кнопке не заметит Enter в поле. А `submit` сработает в обоих случаях.
4. **`input.value` — всегда строка.** Для числа нужно `Number(...)`, для сравнения с границами проверка на `NaN`. Иначе `'5' + 1` даёт `'51'`.
5. **`event.key` зависит от регистра.** `'Enter'` и `'Escape'` начинаются с заглавной буквы. Строка `'enter'` никогда не совпадёт.
6. **Снять обработчик можно только той же функцией.** Две стрелочные функции с одинаковым текстом — разные объекты, и `removeEventListener` не найдёт нужную. Поэтому обработчик, который снимают, объявляют отдельно и называют.
7. **Один раз — `once: true`.** Не нужно заводить для этого переменную-флаг.
8. **`target` и `currentTarget` могут различаться.** Если внутри кнопки есть значок `span`, клик по значку даст `target`, равный `span`, а `currentTarget` останется кнопкой. Данные кнопки читайте через `currentTarget`. Подробнее об этом в следующем уроке.

Правило про снятие обработчика проверим на модели: две одинаковые стрелки — это две разные функции.

## Типичные ошибки

Сообщения получены в Chromium.

**1. Вместо функции передали строку.**

```text
TypeError: Failed to execute 'addEventListener' on 'EventTarget': parameter 2 is not of type 'Object'.
```

**2. Забыли обработчик.**

```text
TypeError: Failed to execute 'addEventListener' on 'EventTarget': 2 arguments required, but only 1 present.
```

**3. Элемент не нашёлся.** Скрипт запущен раньше разметки или в селекторе опечатка.

```text
TypeError: Cannot read properties of null (reading 'addEventListener')
```

**4. Повесили обработчик на список элементов.**

```text
TypeError: document.querySelectorAll(...).addEventListener is not a function
```

Обойдите список циклом `for...of` и вешайте обработчик на каждый элемент.

**5. Скобки после имени функции.** Ошибки нет, но обработчик отрабатывает при загрузке, а клик ничего не делает. Если счётчик стал единицей до первого клика, ищите скобки.

**6. `event.preventDefault;` без скобок.** Ошибки нет, страница перезагружается. Смотрите на скобки.

**7. `event.key === 'enter'`.** Ошибки нет, ветка не выполняется. Проверьте регистр.
