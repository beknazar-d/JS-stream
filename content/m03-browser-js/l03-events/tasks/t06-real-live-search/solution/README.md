# Разбор

Главная идея: состояние страницы целиком определяется строкой запроса. Поэтому есть одна функция `applyFilter(raw)`, а все остальные места лишь вызывают её.

1. `input` вызывает `applyFilter(input.value)` на каждый символ. Поле при этом не трогаем.
2. Запрос подготавливаем: `trim()` убирает пробелы по краям, `toLowerCase()` убирает зависимость от регистра. Названия приводим к нижнему регистру так же.
3. Для сравнения достаточно `includes`: он ищет подстроку как есть, поэтому скобки не требуют экранирования. `new RegExp(query)` на `(` упал бы с `SyntaxError`.
4. Каждому `li` пишем `hidden = !match`. Это работает в обе стороны, поэтому не нужно отдельно «показывать обратно».
5. Счётчик и сообщение считаются тут же, после цикла: они всегда соответствуют списку.
6. `submit` формы отменяем: поле остаётся в странице, перезагрузки нет. Мы ловим именно `submit`, а не клик по кнопке, потому что Enter в поле тоже отправляет форму.
7. Escape и ссылка «Сбросить» вызывают `reset`: очищают поле и применяют пустой фильтр. У ссылки отменяем переход.
