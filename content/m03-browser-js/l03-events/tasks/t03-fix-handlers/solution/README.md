# Разбор

Три ошибки, и все они не дают сообщения в консоли.

1. `addEventListener('click', addItem())` вызывает функцию сразу. Счётчик показывает единицу при загрузке, а в подписку уходит результат вызова (`undefined`), поэтому клики ничего не делают. Нужно передать саму функцию: `addItem`.
2. `event.preventDefault;` — чтение свойства без вызова. Переход по ссылке остаётся. Нужны скобки: `event.preventDefault()`.
3. `event.key` для клавиши Enter равно `'Enter'` с заглавной. Строка `'enter'` никогда не совпадёт, и ветка не выполняется.

Как искать такие ошибки: проверьте состояние страницы сразу после загрузки, затем выполните каждое действие по очереди и сравните с ожидаемым. В консоли разработчика можно посмотреть `event.key`, выведя его в `console.log`.
