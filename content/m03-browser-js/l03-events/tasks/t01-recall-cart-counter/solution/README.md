# Разбор

1. Счёт хранится в переменной `count` вне обработчиков. Если объявить её внутри функции, при каждом клике она начиналась бы заново.
2. Функция `render` собирает текст в одном месте. Оба обработчика сначала меняют `count`, затем зовут `render`. Так число в переменной и на странице не расходятся.
3. В `addEventListener` передаём функцию, а не её вызов: `addEventListener('click', handler)`. Скобки вызвали бы функцию сразу.
4. Очистка обнуляет саму переменную. Если бы мы меняли только текст, следующий клик продолжил бы старый счёт.
