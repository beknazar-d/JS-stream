# Разбор

Вся логика держится на двух маленьких функциях.

1. `parseQty(value)` превращает строку в допустимое число. `Number('')` даёт 0, `Number('abc')` даёт `NaN`, `Math.trunc` отбрасывает дробную часть. Проверка `NaN` отдельная, потому что сравнения с `NaN` всегда ложны: без неё `Math.min` и `Math.max` вернули бы `NaN`.
2. `setQty(qty)` пишет число в поле и рисует сумму. Поле всегда получает строку.
3. Событие `input` срабатывает при каждом символе. Если человек ещё печатает (пусто, `abc`, `500`), поле не трогаем: исправление на каждый символ мешало бы вводу. Сумму обновляем только для допустимых чисел.
4. Событие `change` означает «ввод закончен». Здесь поле исправляется на допустимое значение.
5. Кнопки берут число через `parseQty(input.value)`, то есть работают и с только что введённым текстом, и добавляют единицу как число, а не как строку. Иначе `'5' + 1` даёт `'51'`.

Константы `MIN` и `MAX` собраны наверху, чтобы границы не повторялись по файлу.
