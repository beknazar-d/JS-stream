# Разбор

1. Из разметки убраны все `onclick`. Идентификатор товара живёт в `data-id` и читается в скрипте. Разметка описывает страницу, скрипт — поведение.
2. Обработчик `onBuyClick` один на все кнопки. Его подключаем циклом по `querySelectorAll('.buy')`: у списка элементов нет `addEventListener`, поэтому цикл обязателен.
3. Идентификатор берём из `event.currentTarget`. Кнопка содержит значок `span`. При клике по значку `target` равен значку, а у него нет `data-id`. `currentTarget` всегда тот элемент, на котором висит обработчик.
4. Флаг `promoApplied` не нужен. Параметр `{ once: true }` сам снимет обработчик после первого срабатывания. Меньше состояния — меньше ошибок.
5. Функция `addToCart(id)` больше не нужна глобально: обработчик не зависит от имени, которое надо знать разметке.
