## Контекст

Страница каталога «Домотеки» написана в старом стиле: у кнопок в разметке стоят атрибуты `onclick="addToCart('k200')"`. На ревью указали на проблемы. Идентификатор товара вшит в текст атрибута и дублируется в скрипте, JavaScript смешан с разметкой, а для промокода автор завёл переменную-флаг, чтобы скидка не применялась дважды.

Поведение страницы должно остаться прежним.

## Цель

Перепишите `index.html` и `script.js`: уберите все `onclick`, подключайте обработчики через `addEventListener`, идентификатор товара храните в `data-id`, повторное применение промокода запретите средствами самого события.

## Критерии приёмки

- На странице нет атрибутов `onclick`.
- У каждой кнопки `.buy` есть `data-id` с идентификатором товара (`k200`, `b50`, `t2`).
- Клик по кнопке (в том числе по значку `.buy__icon` внутри кнопки) увеличивает общее число в `#summary` (`В корзине: N шт.`) и записывает в `#last` название товара: `Последний товар: Чайник K-200`.
- Кнопка `#promo-btn` применяет промокод один раз: `#promo-status` показывает `Скидка: 10%`, повторные клики ничего не меняют.

## Ограничения

- Не меняйте `styles.css`.
- Название товара берите из объекта `titles` в `script.js`, не из текста на странице.
- Не вводите переменную-флаг для промокода: используйте параметр самого `addEventListener`.
