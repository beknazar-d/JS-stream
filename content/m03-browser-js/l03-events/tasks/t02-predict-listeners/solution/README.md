# Разбор

1. Первый `fire`: вызываются все три обработчика по порядку добавления: `a click`, `b click`, `c click`. Обработчик `b` с `once: true` перед вызовом удаляется.
2. Второй `fire`: `b` уже снят. Остаются `a` и `c`: `a click`, `c click`.
3. `off(a)` снимает `a`. Затем `on(() => ...)` добавляет стрелочную функцию. Вторая запись `() => console.log('x')` в `off` — другая функция, хоть и с тем же текстом. Сравнение идёт по ссылке, и `off` ничего не находит.
4. Последний `fire` с событием `input`: сначала `c`, потом остался `x`: `c input`, `x`.

Вывод для практики: обработчик, который собираетесь снимать, объявляйте отдельной функцией с именем.
