# Разбор

Две причины, и обе решает делегирование.

1. **Значок.** При клике по `span.add__icon` значение `event.target` — значок, а не кнопка. Проверка `target.classList.contains('add')` ложна. `event.target.closest('.add')` поднимается от значка к кнопке и находит её.
2. **Новые карточки.** Цикл `for` подключал обработчик только к тем кнопкам, что существовали при загрузке. Карточка из `addProduct` появилась позже, и обработчика у неё нет. Обработчик на `#catalog` слышит клики по любым потомкам, включая будущие.
3. **Проверка `null`.** Если клик пришёл на название или на пустое место, `closest` вернёт `null`. Без `if (!button) return` счётчик рос бы при любом клике по каталогу.

Функцию `addProduct` менять не пришлось: она создаёт карточки и ничего не знает про обработчики. Так и должно быть при делегировании.
