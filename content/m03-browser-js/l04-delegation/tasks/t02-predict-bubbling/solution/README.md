# Разбор

1. Первый `dispatch(icon)`. У значка обработчиков нет. Дальше событие поднимается: `button <- icon` (слушает кнопка, случилось на значке), затем `item <- icon`, затем `list <- icon`. Слева `currentTarget` меняется, справа `target` остаётся значком.
2. Печатается разделитель `---`.
3. Второй `dispatch(icon)`. На кнопке теперь два обработчика, они вызываются в порядке добавления: сначала `show` (`button <- icon`), потом новый (`stop on button`), который вызывает `stopPropagation`. Остальные обработчики той же кнопки отработали бы, но выше событие не пойдёт: `item` и `list` ничего не выведут.
4. Третий `dispatch(item)`. Цель теперь строка. Обработчики кнопки и значка не затрагиваются, потому что путь идёт вверх от строки: `item <- item`, `list <- item`.
