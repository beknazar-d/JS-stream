## Контекст

В корзине «Домотеки» у каждой строки кнопка «×». Строки добавляются кодом при выборе товара, поэтому вешать обработчик на каждую кнопку нельзя: новые строки останутся без него. Делегирование через `closest` — основа этого урока, наберите его по памяти.

## Цель

Допишите `script.js`: один обработчик на список `#cart-list` удаляет строку по кнопке `.remove` и обновляет счётчик.

## Критерии приёмки

- Клик по кнопке `.remove` или по значку `.remove__icon` внутри неё удаляет её строку `li.cart-row`.
- Клик по названию товара или по свободному месту строки ничего не удаляет.
- `#count` содержит `Позиций: N`, где N — число строк, и обновляется после удаления.
- Строки, добавленные в список после загрузки страницы, удаляются так же.

## Ограничения

- Не меняйте `index.html` и `styles.css`.
- В скрипте ровно один вызов `addEventListener` на список. Обработчики на отдельные кнопки не вешайте.
