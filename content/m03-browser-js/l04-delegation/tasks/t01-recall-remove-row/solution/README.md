# Разбор

1. Один обработчик висит на списке. Клики по любому потомку всплывают к нему.
2. `event.target.closest('.remove')` находит кнопку, даже если нажали на значок внутри неё. Если клик пришёл на название или на пустое место, результат `null`, и мы выходим.
3. `button.closest('.cart-row')` поднимается от кнопки к строке. Это надёжнее, чем `parentElement`: разметка внутри строки может измениться.
4. Строки, добавленные позже, обслуживаются тем же обработчиком. На них ничего подключать не нужно.
5. Счётчик берётся из `list.children.length`, поэтому всегда совпадает с реальным списком.
