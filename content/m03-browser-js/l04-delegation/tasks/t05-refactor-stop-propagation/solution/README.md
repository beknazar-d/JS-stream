# Разбор

Раньше «клик по сердечку не выбирает карточку» держался на `stopPropagation`: событие не доходило до обработчика карточки. Побочный эффект: оно не доходило и до всех остальных, в том числе до счётчика на документе.

Теперь решение принимает один обработчик, который сам разбирается, куда попал клик.

1. Сначала проверяем сердечко: `event.target.closest('.heart')`. Если нашли, переключаем избранное и выходим через `return`.
2. Иначе ищем карточку: `event.target.closest('.card')`. Если нашли, выбираем.
3. Событие никто не останавливает, оно спокойно всплывает до документа. Счётчик кликов видит все клики.
4. Обработчик висит на списке, поэтому карточки, добавленные позже, работают без подключения.

Порядок проверок важен: сердечко лежит внутри карточки, поэтому `closest('.card')` нашёл бы карточку и для клика по сердечку. Раньше проверяем более специфичный элемент и выходим.

Общее правило: если хочется написать `stopPropagation`, сначала подумайте, нельзя ли проверить условие в обработчике выше.
