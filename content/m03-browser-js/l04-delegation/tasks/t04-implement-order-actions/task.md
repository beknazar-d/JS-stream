## Контекст

Тикет ADM-58. В панели менеджера «Домотеки» таблица заказов. В каждой строке три кнопки: «Подтвердить», «Отменить», «Удалить». Новые заказы подгружаются в таблицу из кода, поэтому обработчики на отдельные кнопки вешать нельзя. У кнопки «Отменить» есть значок внутри.

## Цель

Допишите `script.js`: один обработчик на `tbody#orders` выполняет действия по атрибуту `data-action` кнопки.

## Критерии приёмки

- `confirm`: у строки `data-status` становится `confirmed`, а ячейка `.status` получает текст `Подтверждён`.
- `cancel`: `data-status` становится `cancelled`, текст — `Отменён`.
- Заказ в статусе `cancelled` подтвердить нельзя: `confirm` для него ничего не меняет. Отменить можно любой заказ.
- `delete` удаляет строку целиком, в любом статусе.
- Нажатие на значок внутри кнопки действует как нажатие на кнопку.
- Нажатие на ячейки и пустое место таблицы ничего не меняет.
- `#summary` показывает `Новых: N`, где N — число строк со статусом `new`, и обновляется после каждого действия.
- Строки, добавленные после загрузки, работают так же.

## Ограничения

- Не меняйте `index.html` и `styles.css`.
- Один вызов `addEventListener` на `#orders`.
