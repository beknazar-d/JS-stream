# Разбор

1. Один обработчик на `tbody`. Все кнопки всех строк, в том числе будущих, всплывают к нему.
2. `event.target.closest('[data-action]')` находит кнопку, даже если нажали на значок. Если кнопки нет (ячейка, пустое место), выходим.
3. Данные читаем с найденной кнопки: `button.dataset.action`. Строку находим от кнопки: `button.closest('tr')`.
4. Правило «отменённый нельзя подтвердить» встроено в условие ветки `confirm`: `row.dataset.status !== 'cancelled'`.
5. Смена статуса вынесена в `setStatus`: она обновляет и атрибут, и текст, так что они не расходятся.
6. `updateSummary()` вызывается в конце обработчика, а не внутри каждой ветки: пересчёт нужен после любого действия, включая удаление.
