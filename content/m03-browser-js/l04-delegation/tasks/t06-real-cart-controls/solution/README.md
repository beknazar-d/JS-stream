# Разбор

Главное решение: корзина живёт в массиве `cart`, страница рисуется из него функцией `render`. Обработчик не правит DOM руками, а меняет данные и зовёт `render`.

1. **Один обработчик на `#cart`.** Список не пересоздаётся (`render` очищает его детей, но сам список остаётся), поэтому обработчик работает после любого числа перерисовок. Обработчики на кнопки пропадали бы вместе с кнопками.
2. **`closest('[data-action]')`** находит кнопку, даже если нажали на значок. Если клик пришёл на название или свободное место, результат `null`, и мы выходим.
3. **Товар ищем по данным.** Идентификатор строки лежит в `row.dataset.id`, по нему `find` возвращает объект из `cart`. Это надёжнее, чем индекс строки.
4. **Границы.** `Math.min(99, …)` и `Math.max(1, …)` держат количество в диапазоне. Для `dec` на единице количество остаётся единицей.
5. **`addToCart`** сначала ищет товар. Если он есть, увеличиваем, иначе добавляем с количеством 1. Копируем только нужные поля, а не вставляем чужой объект целиком.
6. После любого изменения вызывается `render`. Итог и сообщение «пусто» рисуются там же, поэтому всегда согласованы с данными.
