# Разбор

1. Обработчик вешаем на форму и на событие `submit`. Оно срабатывает и при клике по кнопке, и при Enter в поле.
2. `event.preventDefault()` отменяет отправку на сервер и перезагрузку страницы.
3. `new FormData(form)` собирает поля с атрибутом `name`. Метод `get('sku')` возвращает строку (или `null`, если поля с таким именем нет), поэтому оборачиваем в `String`.
4. `trim()` убирает пробелы по краям. Пустую строку после очистки считаем ошибкой и выходим из обработчика через `return`.
5. Результат записываем через `textContent`: текст пользователя не станет разметкой.
