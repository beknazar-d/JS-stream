# Разбор

1. `data.get('qty')` возвращает `"2"`. Это строка, `console.log` печатает её без кавычек: `2`.
2. `typeof` строки даёт `string`.
3. `"2" + 1` склеивает строки: `21`.
4. `Number("2") + 1` складывает числа: `3`.
5. Поля `color` нет, `get` возвращает `null`.
6. `getAll('gift')` возвращает оба значения по порядку: `["on", "wrap"]`.
7. `Object.fromEntries` перебирает пары по порядку. Ключ `gift` встречается дважды, поэтому остаётся последнее значение `wrap`. Если в форме есть несколько полей с одним именем (например, группа флажков), берите `getAll`.
8. После `delete('gift')` ключа нет, `has` возвращает `false`.
9. `keys()` возвращает оставшиеся ключи: `title` и `qty`.

Главный вывод: всё, что приходит из формы, — строки. Число из строки делайте явно через `Number`.
