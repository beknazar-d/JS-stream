# Разбор

Три ошибки.

1. **Нет `event.preventDefault()`.** Без него браузер отправляет форму и перезагружает страницу. Ответ появляется на долю секунды и пропадает.
2. **У поля количества нет `name`.** `FormData` берёт только поля с этим атрибутом. `id` и `label` не помогают. Без `name` вызов `get('qty')` возвращает `null`, а `Number(null)` равен `0`. Исправление в `index.html`: `name="qty"`.
3. **Флажок сравнивается с `true`.** Значение выбранного флажка — строка `on`, а не логическое `true`. Невыбранный флажок в `FormData` вообще не попадает. Надёжная проверка: `data.has('gift')`. Можно и `data.get('gift') !== null`, но не `undefined`: отсутствующее поле даёт `null`.
