# Разбор

- `later` ставит колбэк в очередь задач через `setTimeout` с задержкой 0. Он выполнится после синхронного кода и всех микрозадач.
- `soon` ставит колбэк в очередь микрозадач через `queueMicrotask`. Он выполнится сразу, как только опустеет стек, раньше любого таймера.
- В `scheduleReminder` идентификатор таймера лежит в локальной константе `id`. Поэтому у каждого напоминания своя функция отмены, и два напоминания не мешают друг другу. Переменная на уровне модуля сломала бы это.
- `clearTimeout` с уже сработавшим или несуществующим идентификатором ничего не делает, поэтому повторная отмена безопасна.

Передавайте в таймер саму функцию (`send`), а не её вызов (`send()`).
