# Разбор

1. Сначала выполняется весь синхронный код: `старт` и `конец`. Таймер и микрозадачи при этом только ставятся в очереди.
2. Стек опустел, и event loop опустошает микрозадачи. `queueMicrotask` был поставлен первым, поэтому `журнал` идёт первым. Следом идёт первый `then`: `склад`.
3. Первый `then` завершился и поставил в очередь второй. Он тоже микрозадача, поэтому выполняется сразу: `курьер`. Микрозадачи не заканчиваются, пока очередь не пуста.
4. Только теперь event loop берёт задачу из очереди задач: `таймер`.

Итог: `старт, конец, журнал, склад, курьер, таймер`. Место таймера в файле ничего не меняет: задачи всегда идут после микрозадач.
