## Контекст

Тикет SHOP-4412. На странице корзины скидка по промокоду всегда показывает 0%, хотя `SPRING` должен давать 10%. Функция `loadDiscount` пока читает таблицу в таймере (позже здесь будет запрос к серверу), и интерфейс ждёт результат через колбэк `onReady`.

## Цель

Исправьте `loadDiscount(code, onReady)` в `index.js`: колбэк `onReady` должен получать процент скидки для промокода.

## Критерии приёмки

- `loadDiscount("SPRING", onReady)` вызывает `onReady(10)`, `loadDiscount("VIP", onReady)` вызывает `onReady(20)`.
- Для неизвестного промокода приходит `0`.
- `onReady` вызывается ровно один раз.
- `onReady` не вызывается синхронно, внутри `loadDiscount`: результат всегда приходит позже, как будто он загружен с сервера.

## Ограничения

- Таблицу `DISCOUNTS` не меняйте.
- Сигнатура `loadDiscount(code, onReady)` остаётся прежней.
- Функция по-прежнему использует `setTimeout`.
