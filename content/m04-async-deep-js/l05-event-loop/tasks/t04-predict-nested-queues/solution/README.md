# Разбор

Ведём две очереди.

1. Синхронный код: `начало`, `конец`. После него очередь задач содержит таймер 1, таймер 2 и таймер 3, очередь микрозадач содержит первый `then`.
2. Микрозадачи: `then 1`. Он ставит в очередь задач ещё один таймер и завершается, из-за чего в очередь микрозадач попадает второй `then`. Он выполняется сразу: `then 2`.
3. Очередь микрозадач пуста. Берём одну задачу, таймер 1: `таймер 1`. Он создал микрозадачу, и она выполняется до следующей задачи: `then в таймере 1`.
4. Следующая задача — таймер 2: `таймер 2`.
5. Затем таймер, поставленный из `then 1`: `таймер из then`. Он пришёл в очередь позже двух первых, поэтому и выполняется позже.
6. Через 20 мс срабатывает последний таймер: `таймер 3 (20 мс)`.

Главное правило: между любыми двумя задачами event loop опустошает микрозадачи.
