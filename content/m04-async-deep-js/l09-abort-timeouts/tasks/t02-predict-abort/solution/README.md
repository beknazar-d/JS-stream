# Разбор

1. `signal.aborted` до отмены — `false`.
2. `controller.abort()` синхронно вызывает все подписанные обработчики. Первым выводится «событие abort», ещё до следующей строки кода. Второй обработчик вызывает `reject`, но реакция на отказ (`catch`) попадёт в очередь микрозадач.
3. После `abort()` `signal.aborted` равно `true`.
4. Если не указать причину, `signal.reason` — это `DOMException` с именем `AbortError`.
5. Код доходит до конца файла и выводит «конец». Таймер ждёт своей очереди.
6. Синхронный код закончился, выполняются микрозадачи: срабатывает `catch` и выводит «отказ: AbortError».
7. Потом срабатывает таймер. Второй `abort` с другой причиной игнорируется: сигнал можно отменить только один раз, `reason` остаётся `AbortError`.

Правило: отмена — синхронное событие, а реакция промиса на отказ всегда асинхронная.
