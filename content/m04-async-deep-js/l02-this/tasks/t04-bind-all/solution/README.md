# Разбор

Алгоритм: пройти по ключам, найти среди значений функции и заменить каждую привязанной.

Главная тонкость — как узнать, что в свойстве функция. Запись `typeof obj[key]` читает свойство, а у getter чтение — это вызов функции. Побочные эффекты выполнятся, а при ошибке внутри getter упадёт сам `bindAll`. Поэтому используется `Object.getOwnPropertyDescriptor`: он описывает свойство, не обращаясь к значению. У обычного свойства в дескрипторе есть `value`, у getter — `get`, а `value` равно `undefined`. Проверка `typeof descriptor.value === 'function'` выбирает только методы.

Остальные детали:

- `bind(obj)`, а не `bind(this)`: `this` внутри обычной функции `bindAll` равен `undefined`.
- Объект меняется на месте и возвращается, поэтому `bindAll(cart)` можно написать отдельной строкой или обернуть конструктор: `const cart = bindAll({ ... })`.
- Привязанный метод хранит ссылку на объект, а не его копию, и поэтому видит изменения состояния.
- Повторный вызов безопасен: функция привязывается ещё раз, но результат тот же (`this` уже фиксирован первым `bind`).
