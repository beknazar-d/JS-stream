## Контекст

Тикет UI-540. Панель оформления заказа передаёт методы объекта корзины в обработчики кнопок: `button.onclick = cart.clear`. Каждый раз кто-то забывает обернуть вызов, и метод падает, потеряв `this`. Команда хочет вызвать одну функцию при создании объекта, и после этого любой метод можно передавать как угодно.

## Цель

Реализуйте в `index.js` функцию `bindAll(obj)`. Она заменяет каждый метод объекта функцией, привязанной к этому объекту, и возвращает тот же объект.

## Критерии приёмки

- После `bindAll(cart)` метод можно достать и вызвать отдельно: `const { total } = cart; total()` работает и видит состояние `cart`.
- Привязанный метод видит изменения состояния после привязки: добавили позицию и вызвали `total()` — позиция учтена.
- `bindAll(obj)` возвращает сам `obj` (`bindAll(obj) === obj`), а не копию.
- Свойства, которые не функции (числа, строки, массивы), остаются как были.
- Getter (свойство, значение которого вычисляется функцией при чтении, например `get status() { ... }`) не вызывается и остаётся getter-ом: счётчик его обращений после `bindAll` равен `0`, а чтение свойства по-прежнему считает значение.
- Повторный вызов `bindAll(obj)` ничего не ломает.

## Ограничения

- Обрабатываются только собственные перечисляемые свойства с строковыми ключами (то, что возвращает `Object.keys`).
- Только встроенные возможности языка.
