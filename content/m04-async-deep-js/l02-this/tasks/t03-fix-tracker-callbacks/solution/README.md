# Разбор

Обе ошибки одного рода: `markShipped` передан как значение, и в момент вызова слева от точки нет объекта. Метод получает `this`, равный `undefined`, и падает на `this.shipped`.

1. **`markAll`.** `orders.filter(tracker.markShipped)` отдаёт `filter` голую функцию. Лечится стрелкой-обёрткой: `(order) => tracker.markShipped(order)`. Внутри обёртки вызов снова идёт через точку, и `this` равен `tracker`. Заодно обёртка передаёт методу только заказ, а не индекс и массив, которые добавляет `filter`.
2. **`makeMarker`.** Функция должна вернуть колбэк, который помнит трекер. Подходит `tracker.markShipped.bind(tracker)` или стрелка `(order) => tracker.markShipped(order)`. Оба варианта работают и в `forEach`, и в отдельной переменной.

Метод `markShipped` менять не нужно: он написан верно. Ошибка в местах, где его вызывают.
