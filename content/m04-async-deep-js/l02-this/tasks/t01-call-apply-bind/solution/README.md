# Разбор

Все три метода задают `this`. Различие в том, когда вызывается функция и как передаются аргументы.

| Метод | Вызывает сразу | Аргументы |
|---|---|---|
| `call(thisValue, a, b)` | да | по одному |
| `apply(thisValue, [a, b])` | да | массивом |
| `bind(thisValue, a)` | нет, возвращает новую функцию | можно зафиксировать первые |

`bindTo` возвращает функцию, которая навсегда помнит заказ. Префикс она получает при вызове: `bind` пробрасывает аргументы дальше. Повторный `call` или `bind` на такой функции `this` уже не меняет.

Привязанная функция хранит ссылку на объект, а не его копию. Если заказ поменялся, привязанная функция увидит новое состояние.
