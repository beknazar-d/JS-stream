## Контекст

В «Домотеке» функция `printOrder` печатает строку для накладной. Она не принадлежит ни одному объекту, а нужные данные берёт из `this`. Разные части системы вызывают её по-разному: с готовыми аргументами, с массивом аргументов, в виде заготовки для подписи.

## Цель

Допишите в `index.js` три функции. Функцию `printOrder` менять не нужно.

- `viaCall(order, prefix)` вызывает `printOrder` для заказа `order` с префиксом `prefix` и возвращает результат. Используйте `call`.
- `viaApply(order, args)` делает то же, но аргументы приходят массивом `args`. Используйте `apply`.
- `bindTo(order)` возвращает новую функцию, в которой `this` навсегда равен `order`. Префикс этой функции передают при её вызове.

## Критерии приёмки

- `viaCall({ id: "ORD-1", status: "новый" }, "Заказ ")` возвращает `"Заказ ORD-1: новый"`.
- `viaApply(order, ["№ "])` возвращает то же, что `viaCall(order, "№ ")`.
- `bindTo(order)` возвращает функцию, а не строку. Вызов `bindTo(order)("Заказ ")` возвращает строку для `order`.
- Привязанную функцию нельзя переключить на другой заказ: `bindTo(a).call(b, "Заказ ")` печатает заказ `a`.

## Ограничения

- Не меняйте `printOrder`.
- Не копируйте тело `printOrder` в свои функции.
