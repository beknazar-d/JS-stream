## Контекст

Тикет UI-612. Строка поиска на сайте отправляет запрос на каждую букву. Нужен `debounce`: он откладывает вызов функции и сбрасывает ожидание, если вызвали снова. В модуле 3 вы писали его для обработчика-функции. Теперь его хотят применять к методам объектов, например `searchBox.onInput`, и для них важен `this`.

## Цель

Реализуйте в `index.js` функцию `debounce(fn, delay)`. Она возвращает новую функцию. Вызов новой функции откладывает вызов `fn` на `delay` миллисекунд. Если за это время новую функцию вызвали снова, прошлый вызов отменяется, и ожидание начинается заново.

## Критерии приёмки

- Серия вызовов подряд приводит к одному вызову `fn` через `delay` мс после последнего.
- `fn` получает аргументы последнего вызова серии.
- `fn` вызывается с тем же `this`, с которым вызвали обёртку: если обёртка лежит в объекте как метод, `this` внутри `fn` равен этому объекту.
- До истечения `delay` `fn` не вызывается.
- У результата есть метод `cancel()`: после него отложенный вызов не происходит.
- Два вызова, между которыми прошло больше `delay`, приводят к двум вызовам `fn`.

## Ограничения

- Используйте `setTimeout` и `clearTimeout`.
- Возвращаемое значение `fn` не передаётся наружу: обёртка возвращает `undefined`.
