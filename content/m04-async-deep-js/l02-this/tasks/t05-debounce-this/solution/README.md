# Разбор

Здесь встречаются сразу две темы урока: замыкание и `this`.

1. **Замыкание.** `timerId` объявлен в `debounce` и живёт столько же, сколько возвращённая функция. Каждый вызов обёртки видит ту же переменную и может отменить прошлый таймер. Поэтому вызов `debounce` создаёт независимое состояние: у каждой обёрнутой функции свой таймер.
2. **`this`.** Возвращаемая функция объявлена через `function`, чтобы получить `this` от способа вызова. Если её положили в объект как метод и вызвали `obj.method()`, `this` равен `obj`. Колбэк таймера написан стрелкой: у неё нет своего `this`, она берёт `this` и `args` из `debounced`. Если бы колбэк был обычной `function`, `this` внутри потерялся бы.
3. **`apply`.** `fn.apply(this, args)` вызывает исходную функцию с нужным `this` и всеми аргументами последнего вызова.
4. **`cancel`.** Просто сбрасывает текущий таймер. Следующий вызов обёртки начнёт всё заново.

Ошибка, которую легко сделать: написать `const debounced = (...args) => {...}`. Тогда `this` внутри берётся не от вызова, а снаружи `debounce`, и методы объектов ломаются.
