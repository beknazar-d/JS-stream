## Контекст

Тикет DLV-905. Табло в диспетчерской, SMS-уведомления и журнал должны реагировать на события службы доставки: `delivered`, `delayed`, `cancelled`. Сейчас каждый модуль вызывает друг друга напрямую. Решено сделать простой хаб событий: модули подписываются и получают сообщения.

Подписчиками часто бывают методы объектов, например `board.onDelivered`. Им нужен их объект в роли `this`, поэтому при подписке можно передать контекст. Хаб будут использовать и так: `const { on, emit } = createEventHub()`.

## Цель

Реализуйте в `index.js` функцию `createEventHub()`. Она возвращает объект с методами:

- `on(event, handler, context)` — подписывает `handler` на событие `event`. Контекст необязателен. Возвращает функцию `off`, которая отменяет именно эту подписку.
- `emit(event, ...args)` — вызывает обработчики события в порядке подписки, передавая им `args`. Каждый обработчик вызывается с `this`, равным его `context` (если контекст не передали, `this` равен `undefined`). Возвращает число вызванных обработчиков.
- `listenerCount(event)` — сколько подписок сейчас у события.

## Критерии приёмки

- Обработчики вызываются в порядке подписки и получают все аргументы `emit`.
- `emit` события без подписчиков возвращает `0` и не падает.
- Метод объекта, подписанный с `context`, работает с `this` равным этому объекту.
- Методы хаба работают, если достать их из объекта: `const { on, emit, listenerCount } = createEventHub()`.
- `off()` убирает подписку; повторный вызов `off()` ничего не ломает и не снимает чужие подписки.
- Если одна и та же функция подписана дважды, `off` снимает только ту подписку, которую он вернул.
- Обработчик может отписать сам себя во время `emit`. Остальные обработчики при этом всё равно получают событие.
- Разные события не влияют друг на друга. Два хаба независимы.

## Неясности

В тикете нет ответов на несколько вопросов: что делать, если обработчик выбросил ошибку, будут ли вызваны обработчики, подписанные во время `emit`, что с обработчиком, который отписали другим обработчиком до его очереди, нужна ли подписка «один раз». Запишите вопросы и допущения в `assumptions.txt` до кода (строки в этом файле начинаются с `//`, пишите после них). Тесты проверяют только однозначные случаи из списка выше.
