# Разбор

1. `courier.greet()` — вызов как метод, `this` равен `courier`. Результат `Курьер Иван`.
2. `other.greet()` — та же функция, но слева от точки `other`. Результат `Курьер Ольга`.
3. `copy()` — функцию вынули из объекта, слева от точки ничего нет. В строгом режиме `this` равен `undefined`, а `this.name` падает с `TypeError`. `catch` печатает имя ошибки.
4. `bound` создана через `bind`, поэтому `this` навсегда равен объекту с Петром. Вызов `bound.call(courier)` `this` не меняет. Результат `Курьер Пётр`.
5. В `greetLater` колбэк `map` — стрелка. Своего `this` у неё нет, она берёт `this` метода, то есть `courier`. Результат `Иван`.
6. `copy.call({ name: 'Анна' })` — явное задание `this`. Функция та же, что в строке 3, но теперь контекст есть. Результат `Курьер Анна`.
