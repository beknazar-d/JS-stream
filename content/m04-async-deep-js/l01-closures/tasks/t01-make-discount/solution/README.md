# Разбор

`makeDiscount` получает `percent` и сразу возвращает стрелочную функцию. Эта функция не получает процент как параметр. Она берёт его из окружения, в котором создана: это и есть замыкание.

Каждый вызов `makeDiscount` создаёт новое окружение со своим `percent`. Поэтому купоны `makeDiscount(10)` и `makeDiscount(50)` живут рядом и не мешают друг другу.

Цена округляется через `Math.round`: заказ считается в целых рублях.
