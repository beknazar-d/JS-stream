# Разбор

Кэш нужен не для того, чтобы менять ответы, а чтобы вызывать исходную функцию реже. Поэтому главный инструмент теста — мок-функция `fn` и проверка `toHaveBeenCalledTimes`.

Три ошибки, три теста.

1. **Проверка через истинность.** `if (cache.get(arg))` не отличает «нет в кэше» от «в кэше лежит 0». Ловит тест с функцией, которая возвращает `0`, пустую строку или `undefined`: они должны вызываться один раз.
2. **Кэш на одно значение.** Ловит только чередование аргументов: `2, 3, 2`. Серия одинаковых вызовов не покажет разницы.
3. **Общий кэш.** Ловит только тест, где две разные мемоизированные функции получают один и тот же аргумент.

Тесты проверяют ответы и число вызовов, а не то, как устроен кэш внутри, поэтому переживут переписывание реализации с `Map` на объект.
