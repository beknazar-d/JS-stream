# Разбор

Список `lines` объявлен внутри `createCart`, а наружу уходит объект с пятью методами. Все методы создаются в одном вызове фабрики, поэтому делят один список. Снаружи списка нет: ни `cart.lines`, ни другого пути к нему.

Две детали, на которых спотыкаются чаще всего.

1. **`items()` возвращает копию.** Если вернуть `lines` как есть, внешний код получит ссылку на тот же массив и сможет его менять. Копировать нужно и массив, и каждую строку: `lines.map((line) => ({ ...line }))`. Копия только массива не спасёт: `snapshot[0].qty = 100` изменит строку корзины.
2. **Состояние на экземпляр.** `lines` создаётся при каждом вызове `createCart`, поэтому две корзины независимы. Вынесенный в модуль массив стал бы общим для всех.

`remove` переприсваивает `lines`, поэтому переменная объявлена через `let`. Замыкание держит саму переменную, а не её значение: методы видят новый массив.
