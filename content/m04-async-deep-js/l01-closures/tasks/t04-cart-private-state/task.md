## Контекст

Тикет DOM-311. Корзина покупателя хранится в переменной на странице, и любой скрипт (виджет отзывов, аналитика) может случайно записать в неё лишнее. Нужна корзина, в которой список позиций нельзя изменить иначе, чем через её методы.

## Цель

Реализуйте в `index.js` функцию `createCart()`. Она возвращает объект с методами:

- `add(sku, price, qty)` — добавляет товар. Если артикул уже есть в корзине, увеличивает количество и не создаёт вторую строку. Возвращает количество этого товара в корзине после добавления.
- `remove(sku)` — удаляет строку целиком. Возвращает `true`, если строка была, и `false`, если артикула нет.
- `items()` — возвращает массив строк вида `{ sku, price, qty }` в порядке добавления.
- `total()` — сумма `price * qty` по всем строкам.
- `count()` — общее количество штук (сумма `qty`).

## Критерии приёмки

- Две корзины независимы: товар из одной не виден в другой.
- Изменение массива, который вернул `items()`, и изменение его элементов не меняет корзину.
- У корзины нет свойств, через которые можно добраться до списка: `cart.lines`, `cart._lines`, `cart.items` как массив.
- Повторное `add` с тем же артикулом даёт одну строку: `add("kettle", 2500, 1)` и ещё раз `add("kettle", 2500, 2)` дают `qty` равное 3.
- Пустая корзина: `items()` возвращает `[]`, `total()` и `count()` равны `0`.

## Ограничения

- Без классов: состояние хранится в замыкании.
- Проверять входные данные (отрицательное количество, нечисловая цена) не нужно.
