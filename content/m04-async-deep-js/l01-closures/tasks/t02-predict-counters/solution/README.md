# Разбор

Вызовов `makeCounter` три, значит окружений три: у `byOne` (шаг 1), у `byTen` (шаг 10) и у временного счётчика в последней строке.

1. Первый вызов `byOne()` даёт `1`.
2. Второй даёт `2`.
3. Первый вызов `byTen()` даёт `10`: у него своя переменная `value`.
4. Третий вызов `byOne()` даёт `3`, второй вызов `byTen()` даёт `20`. Сумма `23`.
5. `alias` — второе имя той же функции, а не новый счётчик. Четвёртый вызов даёт `4`.
6. `makeCounter(1)()` создаёт новое окружение. Его первый вызов даёт `1`.
