## Контекст

Разработчик склада сделал счётчики для двух потоков операций: приёмка считает по одной коробке, паллеты считаются по десять штук. Перед тем как использовать код в отчёте, нужно понять, что он выведет.

## Цель

Прочитайте код из `snippet.js`. Запишите в `answer.js` в массив `output` шесть строк: именно то, что код выведет в консоль, по одной строке на каждый вызов `console.log`.

## Критерии приёмки

- В массиве `output` ровно шесть строк в порядке вызовов `console.log`.
- Каждый элемент — строка, например `"1"`, а не число.
- Ответ совпадает с реальным выводом кода построчно.

## Ограничения

- Не меняйте `snippet.js`.
- Сначала предскажите ответ в уме, потом проверьте.
