# Разбор

Ошибка в одной строке: `let last = 0` стояла внутри `nextNumber`. Локальная переменная создаётся заново при каждом вызове функции, поэтому после `last = last + 1` всегда было `1`.

Исправление — перенести объявление в `createNumbering`. Тогда `last` лежит в окружении фабрики и создаётся один раз на каждый вызов `createNumbering`. Функция `nextNumber` берёт её из своего рюкзака и накапливает значение между вызовами.

Выносить `last` в модуль не нужно: тогда заказы и возвраты делили бы один счётчик.

`padStart(4, '0')` дополняет строку нулями слева до четырёх символов. Если число длиннее, строка остаётся как есть, поэтому `ORD-10000` не обрезается.
