## Контекст

Тикет TOOLS-77. Для отчёта «из чего состоит проект» нужна функция, которая разбирает вывод `ls -la`: сколько в папке папок и файлов, как они называются и сколько байт занимают файлы. Вывод команды приходит текстом, как его видит пользователь в терминале.

Реальный вывод команды в папке проекта `shop` (macOS и Linux, а также Git Bash на Windows):

```text
anna@vm:~/shop$ ls -la
total 36
drwxr-xr-x 5 anna anna 4096 Oct  9 14:05 .
drwxr-xr-x 3 anna anna 4096 Oct 11 08:29 ..
-rw-r--r-- 1 anna anna   11 Oct  2 09:00 .env
-rw-r--r-- 1 anna anna   18 Oct  1 11:20 .gitignore
-rw-r--r-- 1 anna anna    7 Oct  9 14:05 README.md
drwxr-xr-x 2 anna anna 4096 Oct  9 14:05 docs
-rw-r--r-- 1 anna anna   58 Sep 30 09:41 hello.js
drwxr-xr-x 2 anna anna 4096 Mar  3  2026 price lists
drwxr-xr-x 2 anna anna 4096 Oct  9 13:00 src
```

Как читать строку: первый символ первого поля — тип записи. `d` значит папка, `-` значит обычный файл. Пятое поле — размер в байтах. Последние поля, начиная с восьмого, — имя. В имени может быть пробел, как в `price lists`.

## Цель

Допишите функцию `parseLs(output)` в `index.js`. Она принимает текст вывода `ls -la` и возвращает объект:

```js
{ folders: ["docs", "price lists", "src"], files: [".env", ".gitignore", "README.md", "hello.js"], totalBytes: 94 }
```

## Критерии приёмки

- `folders` — имена папок в порядке вывода, `files` — имена всех остальных записей в порядке вывода.
- `totalBytes` — сумма размеров только файлов (числом).
- Строка `total ...`, пустые строки и записи `.` и `..` не попадают ни в какой список.
- Имена с пробелами сохраняются целиком: `price lists`.
- Скрытые файлы (имя начинается с точки), например `.env`, попадают в `files`.
- Пустая папка (в выводе только `total`, `.` и `..`) даёт `{ folders: [], files: [], totalBytes: 0 }`.
- Лишние пробелы между полями (выравнивание колонок) не мешают.

## Ограничения

- Только формат `ls -l` для macOS, Linux и Git Bash. Вывод `dir` на Windows сюда не входит.
- Не используйте регулярные выражения.
- Менять только тело `parseLs`.
