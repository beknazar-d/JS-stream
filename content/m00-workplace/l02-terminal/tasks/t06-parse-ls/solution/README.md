# Разбор

Вывод `ls -la` — таблица, записанная текстом. Колонки выровнены пробелами, поэтому разбирать её нужно аккуратно.

1. **Строки.** `output.split("\n")` режет текст на строки. Последняя строка после завершающего перевода строки пустая, она отсеется на следующем шаге.
2. **Поля.** `line.split(" ")` режет строку по каждому пробелу. Выравнивание даёт подряд идущие пробелы, а значит, и пустые куски. Цикл оставляет только непустые, получается чистый список полей.
3. **Что пропустить.** Строка `total 36` содержит два поля, пустая строка — ноль. В строке с файлом всегда минимум девять полей, поэтому условие `fields.length < 9` отсеивает лишнее и не требует проверять слово `total`.
4. **Имя.** Имя начинается с восьмого поля (нумерация с нуля) и может состоять из нескольких слов. `fields.slice(8).join(" ")` собирает его обратно. Записи `.` и `..` — это ссылки на текущую папку и на папку выше, их пропускаем по имени.
5. **Тип.** Если первое поле начинается с `d`, это папка. Остальные записи считаем файлами.
6. **Размер.** Пятое поле (`fields[4]`) — размер в байтах, строка. Для файлов его превращают в число и прибавляют к сумме. Размер папки (обычно 4096) — это размер служебной записи, а не содержимого, поэтому в сумму он не входит.

Заметьте: функция не зависит от формата даты. Месяц, число и время (или год) занимают ровно три поля в любом случае.
