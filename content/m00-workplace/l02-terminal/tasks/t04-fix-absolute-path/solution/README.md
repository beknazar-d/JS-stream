# Разбор

Старый код знал один признак: путь начинается с `/`. Для Windows этого мало. Путь `C:\Users\anna` начинается с буквы, а не с косой черты, и функция принимала его за относительный.

Новая проверка состоит из двух частей.

1. **macOS и Linux.** Начинается с `/`. Проверка осталась.
2. **Windows.** Три условия вместе:
   - первый символ — буква от `A` до `Z` (после `toUpperCase()`, чтобы `d:` тоже подошло);
   - второй символ — двоеточие;
   - третий символ — косая черта, прямая или обратная.

Все три нужны. Только двоеточие недостаточно: имя `notes:draft.txt` — обычный относительный файл. Без третьего условия путь `C:file.txt` (в Windows он значит «файл в текущей папке диска C») тоже ошибочно стал бы абсолютным.

Для пустой строки `slice` возвращает пустые строки, сравнение с буквой даёт `false`, и функция честно отвечает `false`.
