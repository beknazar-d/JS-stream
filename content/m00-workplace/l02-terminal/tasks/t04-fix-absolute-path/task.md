## Контекст

Баг-репорт BUG-2210 от пользователя Windows. Скрипт установки спрашивает путь к проекту. Пользователь ввёл `C:\Users\anna\shop`. Скрипт решил, что путь относительный, и дописал к нему текущую папку. Получился адрес `D:\work\C:\Users\anna\shop`, которого не существует.

Причина в функции `isAbsolutePath(path)`: она знает только про путь, который начинается с косой черты.

## Цель

Исправьте `isAbsolutePath(path)` в `index.js`. Функция возвращает `true` для абсолютного пути и `false` для относительного. Поддерживаются два вида абсолютных путей:

- macOS и Linux: начинается с `/`;
- Windows: буква диска, двоеточие и косая черта (прямая или обратная): `C:\Users`, `d:/data`.

## Критерии приёмки

- `isAbsolutePath("/home/anna/shop")` возвращает `true`.
- `isAbsolutePath("C:\\Users\\anna\\shop")` возвращает `true` (диск C, обратные косые черты).
- `isAbsolutePath("D:/data")` и `isAbsolutePath("d:\\data")` возвращают `true`: любая буква диска, любой регистр, любая из двух косых черт.
- `isAbsolutePath("src/index.js")`, `isAbsolutePath("./src")`, `isAbsolutePath("../docs")`, `isAbsolutePath("")` возвращают `false`.
- Относительное имя с двоеточием, например `"notes:draft.txt"`, возвращает `false`.
- Буква диска без косой черты (`"C:file.txt"` — файл в текущей папке диска C) тоже относительный путь: `false`.

## Ограничения

- Менять только тело `isAbsolutePath`.
- Не используйте регулярные выражения.
