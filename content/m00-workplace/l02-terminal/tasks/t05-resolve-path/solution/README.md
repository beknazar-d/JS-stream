# Разбор

Идея: идём по частям пути слева направо и ведём список папок, в которых мы сейчас находимся (`stack`, «стопка»).

1. **Откуда считать.** Абсолютный `target` (начинается с `/`) берётся как есть. Иначе склеиваем текущую папку, косую черту и `target`.
2. **Пустая часть и точка** пропускаются. Пустые части возникают от начальной косой черты, двойных `//` и косой черты в конце. Одна точка значит «эта же папка».
3. **Две точки** убирают последнюю папку: `stack.pop()`. Если список пуст (мы в корне), `pop` ничего не делает. Так выполняется правило «выше корня не подняться».
4. **Остальное** — обычное имя, его добавляем в конец: `stack.push(part)`. Три точки `...` тоже обычное имя.
5. **Результат.** `stack.join("/")` склеивает папки, `"/"` в начале делает путь абсолютным. Для пустого списка получается ровно `"/"` — корень.

Заметьте, что `continue` пропускает остаток тела цикла и переходит к следующей части. Так не нужна вложенная цепочка `else`.
