# Разбор

- `pwd` — print working directory, «где я».
- `ls` — list, «что здесь лежит». На Windows в cmd это `dir`, а в PowerShell работают оба варианта.
- `mkdir reports` — make directory, создать папку. Имя идёт отдельным словом через пробел.
- `cd ..` — change directory на уровень выше. Пробел между `cd` и `..` обязателен: `cd..` терминал macOS и Linux не поймёт.
- `node src/index.js` — программа `node`, и файл, который она запустит. Путь относительный: он считается от текущей папки.
