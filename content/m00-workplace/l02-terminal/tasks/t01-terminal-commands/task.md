## Контекст

Вы готовитесь к первому пэйр-программированию, где придётся показывать команды в терминале. Чтобы не открывать шпаргалку каждый раз, пора выучить пять самых частых команд наизусть.

## Цель

В файле `index.js` каждая константа содержит пустую строку. Впишите в неё команду для терминала:

- `showCurrentFolder` — напечатать текущую папку;
- `listFiles` — показать содержимое текущей папки;
- `makeFolder` — создать папку `reports`;
- `goUp` — подняться на уровень выше;
- `runScript` — запустить Node.js-скрипт `src/index.js`.

## Критерии приёмки

- Каждая из пяти констант содержит команду без лишнего текста.
- Команды для macOS и Linux (на Windows в PowerShell они те же). Для `listFiles` подойдёт также `dir`.
- Команды написаны строчными буквами, как в уроке.

## Ограничения

- Не меняйте имена констант и слово `export`.
- Менять нужно только текст между кавычками.
