# Разбор

`"/home/anna/shop/src".split("/")` даёт пять частей: пустая строка, `home`, `anna`, `shop`, `src`. Пустая часть появляется потому, что перед первой косой чертой ничего нет.

1. `parts.length` — `5`.
2. `parts[0] === ""` — `true`: первая часть пустая. Это признак пути, который начинается с `/`.
3. `parts[parts.length - 1]` — последний элемент, `src`. Номер последнего элемента всегда на единицу меньше длины.
4. `parts.slice(0, 3)` берёт части с номерами 0, 1, 2: пустую, `home`, `anna`. `join("/")` склеивает их через косую черту: `/home/anna`. Пустая часть даёт косую черту в начале.
5. `"src/index.js".split("/")` — две части: `src` и `index.js`. Длина `2`.
6. В `"../docs/guide.md".split("/")` первая часть — две точки, `..`.
