# Разбор

1. **Один разделитель.** В Windows части пути разделены обратной косой чертой, в macOS и Linux — прямой. Проще сначала привести всё к одному виду: `path.split("\\").join("/")` заменяет каждую `\` на `/`. В строке JavaScript обратная косая черта пишется удвоенной: `"\\"`.
2. **Нарезка.** `split("/")` даёт массив частей. Косая черта в начале и в конце даёт пустые части, а пустая строка вообще даёт массив из одной пустой строки.
3. **Последняя непустая часть.** Цикл идёт по всем частям и запоминает каждую непустую. После цикла в `last` лежит последняя из них. Для корня и пустой строки непустых частей нет, и остаётся начальное значение `""`.

Берём именно последнюю непустую часть, а не последний элемент массива: иначе косая черта в конце сломает результат.
