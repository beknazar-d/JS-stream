## Зачем это в работе

Первый рабочий день. Тимлид пишет в чат: «Склонируй репозиторий и запусти отчёт по складу: `node scripts/stock-report.js`». Вы открываете терминал, вводите команду и видите:

```text
bash: node: command not found
```

Отчёт не запустился, и вы не понимаете почему. Так случается, когда рабочее место не настроено.

Этот урок про то, как настроить его за двадцать минут. Вы установите Node.js и редактор, запустите свой первый файл и поймёте, как устроен курс.

## Объяснение

JavaScript — язык программирования. Сам по себе он только текст. Чтобы текст превратился в действия, нужна программа, которая его читает и выполняет.

Представьте рецепт. Рецепт — это ваш код. Кухня — место, где по рецепту готовят. У JavaScript две кухни:

- браузер: код запускают страницы сайтов;
- Node.js: код запускают прямо на вашем компьютере, без браузера.

Node.js — это среда выполнения (runtime): программа, которая умеет запускать JavaScript вне браузера. Через неё работают серверы, скрипты и инструменты разработчика. В этом курсе мы начнём с Node.js: он проще всего показывает, что делает ваш код.

Вместе с Node.js ставится npm (Node Package Manager, «менеджер пакетов»). Он скачивает готовые библиотеки, чтобы вам не приходилось писать всё с нуля. Пока он нужен только для проверки установки. Подробно мы займёмся им в модуле про Node.

Третий инструмент — редактор кода. Мы используем VS Code (Visual Studio Code): он бесплатный и подходит и новичкам, и профессионалам. В нём есть встроенный терминал (terminal): окно, в которое вы вводите команды текстом.

### Установка

1. Откройте сайт `nodejs.org` и скачайте версию LTS. LTS (Long Term Support) — версия с долгой поддержкой. Она стабильная, её и берут в работе. Версию Current не берите.
2. Запустите установщик и оставьте настройки по умолчанию.
3. Откройте `code.visualstudio.com`, скачайте и установите VS Code.
4. Закройте все окна терминала и откройте новое. Без этого система не увидит свежеустановленный Node.js.

### Проверка

Откройте терминал и введите две команды. Знак доллара в начале строки — это приглашение терминала, его вводить не нужно.

```text
$ node -v
v22.22.0
$ npm -v
10.9.4
```

Ваши цифры могут отличаться. Для курса достаточно, чтобы первое число в ответе `node -v` было не меньше 22. Если вы видите версию, значит, Node.js установлен.

### Встроенный терминал VS Code

В VS Code откройте меню «Терминал» → «Создать терминал» или нажмите `Ctrl` и обратный апостроф (клавиша слева от цифры 1, на ней же буква «ё»). Терминал откроется внизу окна сразу в папке вашего проекта. Это удобнее, чем отдельное окно: файл и команда рядом.

<Note>

Задания с кодом удобнее решать на компьютере: там есть клавиатура и место для двух окон. Уроки читать и карточки повторять можно и с телефона. Установку и терминал всё равно придётся делать на компьютере.

</Note>

Затем карточки повторения вернут вам старые темы, пока вы не забыли. Чем больше вы пишете сами, тем лучше: практики в курсе больше, чем чтения.

Ни регистрации, ни аккаунта нет. Ваш прогресс хранится в самом браузере (в хранилище IndexedDB). Отсюда два правила:

- прогресс живёт в том браузере и на том устройстве, где вы занимались;
- если очистить данные сайта, прогресс пропадёт.

Поэтому время от времени используйте экспорт: он сохраняет прогресс в файл. Импорт вернёт его в другой браузер или на другой компьютер.

## Типичные ошибки

Сообщения ниже получены запуском в Node.js 22 в терминале bash. В Windows тексты первой ошибки другие, но смысл тот же.

**1. Терминал не знает команды `node`.** Здесь команда набрана с опечаткой `nodee`, поэтому сообщение именно такое.

```text
$ nodee -v
bash: nodee: command not found
```

Фраза «command not found» значит «команда не найдена». Причин три: опечатка, Node.js не установлен или терминал открыт до установки. Сначала проверьте написание, затем закройте терминал и откройте новый.

**2. Файл не найден.**

<Wrong>

```text
$ node helo.js
```

</Wrong>

```text
node:internal/modules/cjs/loader:1386
  throw err;
  ^

Error: Cannot find module '/home/anna/shop/helo.js'
    at Function._resolveFilename (node:internal/modules/cjs/loader:1383:15)
    ...
    at node:internal/main/run_main_module:36:49 {
  code: 'MODULE_NOT_FOUND',
  requireStack: []
}

Node.js v22.22.0
```

Многоточие мы поставили сами, чтобы сократить вывод. Главное — строка `Cannot find module '/home/anna/shop/helo.js'`: Node.js не нашёл файл по этому пути. Сравните имя файла в команде с именем в проводнике. Проверьте и папку: терминал должен быть открыт там, где лежит файл. Об этом следующий урок.

<Right>

```text
$ node hello.js
```

</Right>

**3. Опечатка в имени команды внутри кода.**

<Wrong>

```js
console.Log("Привет");
```

</Wrong>

```text
/home/anna/shop/typo.js:1
console.Log("Привет");
        ^

TypeError: console.Log is not a function
    at Object.<anonymous> (/home/anna/shop/typo.js:1:9)
    ...

Node.js v22.22.0
```

В JavaScript заглавные и строчные буквы — разные. Метод называется `log`, а `Log` не существует. Сообщение «is not a function» значит: «это не функция, вызвать нельзя». Вторая строка вывода показывает файл и номер строки (`typo.js:1`), а стрелка `^` указывает место в строке.

<Right>

```js
console.log("Привет");
```

</Right>

**4. Команда npm запущена не в папке проекта.**

```text
$ npm run hello
npm error code ENOENT
npm error syscall open
npm error path /home/anna/shop/package.json
npm error errno -2
npm error enoent Could not read package.json: Error: ENOENT: no such file or directory, open '/home/anna/shop/package.json'
```

Скрипты `npm run` ищут файл `package.json` в текущей папке. Его нет, поэтому `ENOENT` («нет такого файла или папки»). Перейдите в папку проекта или создайте файл командой `npm init -y`.

## Итог

Что вы теперь умеете:

- объяснить, чем Node.js отличается от браузера, и зачем нужен npm;
- проверить установку командами `node -v` и `npm -v`;
- создать файл в VS Code и запустить его командой `node имя-файла.js`;
- понять по `command not found` и `Cannot find module`, что именно не так;
- пользоваться курсом: урок, задания, повторение, экспорт прогресса.

Дальше нужно научиться уверенно ходить по папкам. Именно из-за не той папки чаще всего не находится файл. Следующий урок — про терминал: пути, `cd`, `ls` и `pwd`.
