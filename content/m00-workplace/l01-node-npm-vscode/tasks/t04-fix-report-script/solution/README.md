# Разбор

В скрипте три разные проблемы, и они проявляются по очереди.

1. **Строка 7, `ReferenceError: shiped is not defined`.** Имя написано с опечаткой: объявлено `shipped`, а используется `shiped`. `ReferenceError` значит «такого имени нет». Первое, что стоит проверить, — написание.
2. **Строка 8, `TypeError: console.Log is not a function`.** Эта ошибка была скрыта первой: скрипт останавливался раньше. Метод называется `log`, с маленькой буквы.
3. **Строка 9, тихая ошибка в тексте.** Сообщения нет, но в выводе «Всего движений:19» без пробела. Такие ошибки находят только сверкой с ожидаемым результатом.

Общий вывод: после каждого исправления запускайте скрипт снова. Node.js останавливается на первой ошибке, остальные видны не сразу.
