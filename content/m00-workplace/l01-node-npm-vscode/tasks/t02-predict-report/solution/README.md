# Разбор

1. `console.log("Заказов в обработке:", processing)` печатает два значения через пробел: `Заказов в обработке: 12`.
2. `processing + shipped` — оба числа, плюс складывает: `12 + 5` даёт `17`. Строка `"Всего:"` идёт отдельным значением, поэтому вывод `Всего: 17`.
3. `"Всего: " + processing + shipped` вычисляется слева направо. Сначала `"Всего: " + 12` даёт строку `"Всего: 12"`. Потом к строке приклеивается 5: `Всего: 125`. Это та же ловушка, что в тикете «вместо 15 показывается 123». Чтобы сложить числа, их нужно взять в скобки: `"Всего: " + (processing + shipped)`.
4. Три значения через запятую печатаются через пробел, поэтому `Осталось 7 шт.`: `12 - 5` посчитано как число.
5. `12 / 4` даёт `3`. Дробной части нет, потому что результат целый.
6. Два плюса склеивают три строки: `Склад Центральный`.
