# Разбор

Один вызов `console.log` печатает одну строку. Три строки вывода — три вызова.

Во второй строке есть два значения: текст и число. Если перечислить их через запятую, `console.log` напечатает их через пробел: `"Заказов в обработке:", 12` даёт `Заказов в обработке: 12`. Тот же результат получится, если написать `"Заказов в обработке: " + 12`, но с запятой короче и безопаснее: ничего не склеивается случайно.

Ёлочки « и » — обычные символы внутри строки, JavaScript их не трогает.
