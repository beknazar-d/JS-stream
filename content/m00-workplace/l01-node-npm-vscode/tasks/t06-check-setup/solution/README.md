# Разбор

Функция состоит из двух независимых проверок. Каждая добавляет сообщение в общий массив `problems`. В конце массив возвращается целиком.

**Почему нет `return` внутри проверок.** Если вернуть результат сразу после первой проблемы, вторая проверка не выполнится. Разработчик исправит Node.js и только потом узнает про npm. Накопление в массиве даёт полную картину за один запуск.

**Проверка Node.js.** Вывод после `trim()` должен начинаться с `v`, а часть до первой точки — превращаться в число. Если нет, мы считаем, что в строке не версия, а ошибка терминала: «bash: node: command not found» разбирается в `NaN`. Только если версия найдена, её сравнивают с минимумом. Сравнение идёт числами, не строками: у строк `"8"` больше `"22"`.

**Проверка npm.** У `npm -v` нет буквы `v`: вывод выглядит как `10.9.4`. Поэтому часть до точки превращается в число сразу. Пустая строка даёт `0` при `Number("")`, поэтому её нужно проверить отдельно: пустой вывод — тоже «не найден».

Сообщения собираются сложением строк: `"Node.js " + nodeMajor + " устарел..."`. Число превращается в текст само, потому что рядом строка.
