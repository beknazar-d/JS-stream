# Разбор

Хорошие тесты проверяют не «функция работает», а места, где она может сломаться. Для `isSupportedNode` таких мест три.

1. **Граница.** Версия ровно равная минимуму должна подходить. Ошибка «больше» вместо «не меньше» ловится только тестом `isSupportedNode("v22.22.0", 22)`.
2. **Тип сравнения.** Если сравнивать текст вместо чисел, то по алфавиту `"8"` оказывается больше `"22"`. Старый Node.js 8 сочтут подходящим. Ловит такую ошибку только тест с однозначной версией против двузначного минимума.
3. **Грязный вывод.** Вывод терминала бывает с пробелами и переводом строки. Тест с пробелом в начале ловит потерянный `trim()`. Заметьте: перевод строки в конце сам по себе эту ошибку не выдаёт, потому что `split(".")` отрезает его вместе с хвостом. Значит, нужен именно пробел в начале.

Тесты проверяют результат и не лезут в устройство функции, поэтому переживут её переписывание.
