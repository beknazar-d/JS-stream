## Контекст

В скрипте проверки окружения есть функция `isSupportedNode(versionOutput, minMajor)`: она получает вывод команды `node -v` и минимально допустимую мажорную версию, а возвращает `true` или `false`. Тестов у неё нет, а в пятницу её будут переписывать.

Ваша задача — написать тесты, которые защитят функцию от поломки.

## Цель

Напишите тесты в `index.test.js` для функции `isSupportedNode` из файла `subject/index.js` (код показан под описанием). Функция работает так:

- берёт из строки вида `v22.22.0` первое число после буквы v;
- возвращает `true`, если оно не меньше `minMajor`;
- иначе возвращает `false`;
- вывод может содержать пробелы и перевод строки по краям;
- если вместо версии пришёл любой другой текст (например, «command not found»), результат `false`.

## Критерии приёмки

- Все ваши тесты проходят на показанной реализации.
- Проверка находит каждую из трёх реализаций с ошибкой: тесты должны падать на каждой.
- В тестах нет проверок, которые зависят от того, как функция написана внутри: проверяется только результат для входных данных.
- Названия тестов описывают случай на русском языке.

## Ограничения

- Пишите тесты только в `index.test.js`. Код функции менять нельзя.
- Используйте `describe`, `it` и `expect` без импорта. Из `index.js` импортируйте только `isSupportedNode`.
- Подумайте о границах (ровно минимум), об однозначных версиях и о «грязном» вводе.
