# Разбор

Вывод терминала — это обычная строка. Её разбирают по шагам.

1. `trim()` убирает пробелы и перевод строки по краям. Без него лишние символы попадают в разбор. Копируя вывод из терминала, их легко прихватить вместе с версией.
2. `slice(1)` отрезает первый символ — букву `v`. Остаётся `"22.22.0"`.
3. `split(".")` режет строку на части по точке: `"22"`, `"22"`, `"0"`. Нужна первая, `parts[0]`.
4. `Number("22")` превращает текст в число `22`. Без этого шага функция вернула бы строку, а сравнивать версии как строки опасно: текст `"8"` по алфавиту больше текста `"22"`.

Порядок шагов важен: сначала `trim`, потом `slice`.
