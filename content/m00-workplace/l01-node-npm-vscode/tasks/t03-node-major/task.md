## Контекст

Скрипт проверки окружения должен убедиться, что у разработчика стоит свежий Node.js. Команда `node -v` печатает версию в виде строки, например `v22.22.0`. Из неё нужно достать первое число — мажорную версию (major): именно её сравнивают с минимально допустимой.

## Цель

Допишите функцию `nodeMajor(versionOutput)` в `index.js`. Она принимает строку — вывод команды `node -v` — и возвращает мажорную версию числом.

```text
$ node -v
v22.22.0
```

Для такой строки функция вернёт число `22`.

## Критерии приёмки

- `nodeMajor("v22.22.0")` возвращает `22`, `nodeMajor("v20.11.1")` возвращает `20`.
- Результат имеет тип «число» (`number`), а не строка.
- Работает с однозначной мажорной версией: `nodeMajor("v8.17.0")` возвращает `8`.
- Пробелы и перевод строки по краям не мешают: `nodeMajor("  v18.19.0\n")` возвращает `18`.

## Ограничения

- Менять только тело `nodeMajor`.
- Не используйте регулярные выражения. Хватит `trim`, `slice`, `split` и `Number`.
