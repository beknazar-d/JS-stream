# Разбор

1. **Кадры.** Идём по строкам и берём только те, что начинаются с `at ` (после `trim()`). Заголовок ошибки, исходная строка кода и указатель `^` пропускаются.
2. **Место.** Если кадр заканчивается на `)`, место стоит внутри последних скобок: `lastIndexOf("(")` находит открывающую. Иначе место — всё, что после `at `. Функцию `Function.executeUserEntryPoint [as runMain]` скобки не ломают, потому что берутся именно последние.
3. **Внутренние кадры** (`node:...`) пропускаем: нас интересует ваш код.
4. **Числа с конца.** Режем место по двоеточию. В пути двоеточия бывают (`file:///`, `C:\`), поэтому столбец — последняя часть, строка — предпоследняя, а остальное склеивается обратно через двоеточие. Если числа не получились (`<anonymous>` даёт `NaN`), кадр пропускаем.
5. **Префикс** `file://` снимаем, чтобы вернуть обычный путь.
6. Если подходящего кадра нет, цикл заканчивается и возвращается `null`.
