# Разбор

- `ReferenceError` — такого имени нет (`is not defined`): обычно опечатка.
- `TypeError` — имя есть, значение есть, но действие с ним невозможно: вызвать не функцию (`is not a function`) или прочитать свойство у `undefined`.
- `SyntaxError` — код записан неправильно, и программа даже не запускается (`missing )`, `Unexpected token`).
- `debugger` — слово, которое в коде ставит точку останова, если открыты DevTools.
