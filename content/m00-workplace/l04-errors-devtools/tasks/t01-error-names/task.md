## Контекст

Коллега читает сообщения ошибок вслух и хочет, чтобы вы называли тип сразу, не заглядывая в шпаргалку. Проверим, что вы помните имена типов и слово для точки останова.

## Цель

В файле `index.js` впишите между кавычками:

- `undefinedVariable` — тип ошибки для сообщения `totl is not defined`;
- `notAFunction` — тип ошибки для сообщения `price.toFixed is not a function`;
- `readOfUndefined` — тип ошибки для сообщения `Cannot read properties of undefined (reading 'name')`;
- `brokenSyntax` — тип ошибки для сообщения `missing ) after argument list`;
- `breakpointWord` — слово, которое, будучи написанным в коде как `слово;`, ставит точку останова при открытых DevTools.

## Критерии приёмки

- Каждая из пяти констант содержит одно слово, написанное точно, с учётом регистра.

## Ограничения

- Не меняйте имена констант и слово `export`.
- Менять нужно только текст между кавычками.
