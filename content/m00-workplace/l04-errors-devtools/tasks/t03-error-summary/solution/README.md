# Разбор

1. `trim()` убирает пробелы и перевод строки по краям, чтобы они не попали в результат.
2. `indexOf(": ")` возвращает номер первого вхождения. Нужен именно первый разделитель: после него идёт текст, и в нём могут быть свои двоеточия.
3. Если вхождения нет, `indexOf` возвращает `-1`. Без проверки `slice(0, -1)` молча отрежет последний символ. Проверка отдельного случая делает функцию надёжной.
4. Тип — всё до разделителя (`slice(0, at)`), текст — всё после (`slice(at + 2)`: два символа разделителя пропускаем).

Разрезать `split(": ")` и взять два первых куска нельзя: всё после второго разделителя пропадёт.
