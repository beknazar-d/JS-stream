# Разбор

Сначала JavaScript вычисляет аргументы внешнего `console.log`. Для этого вызывается `finalPrice`, и она печатает свои отладочные строки. Только когда функция вернула значение, внешний `console.log` печатает «Итого».

1. `finalPrice(2000, 15)`: `price: 2000`, `percent: 15`, `discount: 300` (2000 · 15 / 100), возвращает 1700. Затем `Итого: 1700`.
2. `finalPrice(500)`: второй аргумент не передан, поэтому `percent` равен `undefined`. Лог печатает `percent: undefined`. `500 * undefined` даёт `NaN`, и `discount: NaN`. Результат `500 - NaN` тоже `NaN`: `Итого: NaN`.

Ошибки нет, программа не упала. Но по логам сразу видно, откуда взялся `NaN`: параметр не передали. Это и есть отладка логами.
