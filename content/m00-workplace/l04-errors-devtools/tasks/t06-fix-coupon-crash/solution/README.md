# Разбор

**Как искать.** Стектрейс читают сверху вниз. Верхний кадр, `parsePercent` на строке 2, показывает, где упало: `text.replace` вызвали у `undefined`. Нижний кадр со своим кодом, `main.js` строка 4, показывает причину: туда передали `undefined` вместо купона. Мы исправляем место, где решается судьба значения без купона: `parsePercent` должна уметь принимать «ничего».

**Что исправлено.**

1. Проверка `undefined` и `null` до вызова `replace`: отсутствие купона даёт скидку `0`.
2. `trim()` убирает пробелы, чтобы `" 10% "` разбиралось.
3. `Number.isNaN` ловит текст, который не получилось превратить в число. Без этого `"abc"` дал бы `NaN`, а он молча дошёл бы до итога заказа (ошибки нет, а сумма сломана). Тот же `NaN` вы видели в уроке про типы.
4. Пустая строка превращается в `0` сама: `Number("")` равно `0`, отдельная проверка не нужна.

**Что не стоило делать.** Проглатывать ошибку молча или возвращать `0` вместо итога: без скидки нужно взять полную цену.
