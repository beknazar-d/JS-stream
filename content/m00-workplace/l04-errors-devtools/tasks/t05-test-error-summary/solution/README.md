# Разбор

Для `errorSummary` три места, где легко сломать функцию.

1. **Двоеточие в тексте.** Нужно делить только по первому `": "`. Тест `Error: Failed: timeout` ловит реализацию, которая режет по каждому разделителю и теряет хвост.
2. **Пробелы и перевод строки.** В логах строки приходят с отступами. Тест с пробелами в начале и переводом строки в конце ловит потерянный `trim()`.
3. **Строка без разделителя.** Здесь возвращается имя `Error` и вся строка. Без отдельной проверки `indexOf` вернёт `-1`, и получится мусор. Только тест `connection lost` это показывает.

Тесты проверяют результат функции и не зависят от её устройства.
