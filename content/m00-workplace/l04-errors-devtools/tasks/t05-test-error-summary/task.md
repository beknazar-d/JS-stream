## Контекст

В системе мониторинга есть функция `errorSummary(line)`: из первой строки сообщения об ошибке она достаёт тип и текст. Тестов у неё нет, а на неделе её будут переписывать. Её вы уже писали в одном из заданий этого урока.

Ваша задача — написать тесты, которые защитят функцию от поломки.

## Цель

Напишите тесты в `index.test.js` для функции `errorSummary` из файла `subject/index.js` (код показан под описанием). Функция работает так:

- убирает пробелы и перевод строки по краям;
- делит строку по первому `": "`: слева тип, справа текст;
- если в строке нет `": "`, возвращает имя `Error` и всю строку как текст.

## Критерии приёмки

- Все ваши тесты проходят на показанной реализации.
- Проверка находит каждую из трёх реализаций с ошибкой: тесты должны падать на каждой.
- Проверяется только результат для входных данных, а не устройство функции.
- Названия тестов описывают случай на русском языке.

## Ограничения

- Пишите тесты только в `index.test.js`. Код функции менять нельзя.
- Используйте `describe`, `it` и `expect` без импорта. Из `index.js` импортируйте только `errorSummary`.
