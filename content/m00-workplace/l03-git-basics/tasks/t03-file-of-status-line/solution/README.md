# Разбор

Формат строки `git status --short` постоянный: два символа кода, один пробел, имя. Поэтому имя всегда начинается с индекса 3, и `line.slice(3)` достаёт его для любого кода: ` M`, `A `, `??`, `MM`.

Если в имени есть пробел, Git берёт имя в двойные кавычки. Они нужны Git, чтобы показать границы имени, и в самом имени файла их нет. Поэтому убираем их, но только когда кавычки стоят с обоих краёв: `startsWith` и `endsWith` вместе.

`slice(1, -1)` отбрасывает первый и последний символ.

Нельзя разрезать строку по пробелам: тогда имя `price lists/may 2026.csv` развалится на куски, а коды вида `A ` дадут пустой элемент между буквой и именем.
