## Контекст

Команда `git status --short` печатает по строке на каждый изменённый файл:

```text
$ git status --short
 M src/order.js
M  src/cart.js
A  src/utils.js
?? notes.txt
 M "price lists/may 2026.csv"
```

Скрипту предкоммитной проверки нужно имя файла из такой строки, чтобы сверить его со списком запрещённых файлов.

## Цель

Допишите функцию `fileOf(line)` в `index.js`. Она принимает одну строку вывода `git status --short` и возвращает имя файла без кода и без кавычек.

## Критерии приёмки

- `fileOf(" M src/order.js")` возвращает `"src/order.js"`.
- `fileOf("A  src/utils.js")` и `fileOf("?? notes.txt")` возвращают `"src/utils.js"` и `"notes.txt"`: код из двух символов не мешает.
- Если имя взято в двойные кавычки (в нём есть пробел), кавычки убираются: `fileOf(' M "price lists/may 2026.csv"')` возвращает `price lists/may 2026.csv`.
- Папка с косой чертой в конце остаётся как есть: `fileOf("?? reports/")` возвращает `"reports/"`.

## Ограничения

- Переименования (`R  старое -> новое`) в этом задании не рассматриваются.
- Не используйте регулярные выражения.
- Менять только тело `fileOf`.
