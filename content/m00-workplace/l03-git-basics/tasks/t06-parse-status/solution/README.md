# Разбор

Функция идёт по строкам и для каждой решает три вопроса: как называется файл, что с ним в индексе и что с ним в рабочей папке.

1. **Имя.** Оно начинается с индекса 3 (два символа кода и пробел). Если в записи есть ` -> `, это переименование: нужна часть после стрелки, `slice(arrow + 4)` (длина ` -> ` равна четырём). Затем снимаем кавычки, если они стоят с обоих краёв.
2. **Неотслеживаемые.** Код `??` означает, что в индексе и в рабочей папке сравнивать не с чем: файл новый. Он идёт только в `untracked`.
3. **Индекс и рабочая папка — две отдельные проверки.** Первый символ кода отвечает за `staged`, второй — за `unstaged`. Это два `if`, а не `if / else`: файл с кодом `MM` должен попасть в оба списка.
4. **Пустые строки** (в том числе после последнего перевода строки) пропускаем в начале цикла.

Порядок имён в списках — тот же, что в выводе Git: в его порядке строки и приходят.

Код возврата — обычный объект с тремя массивами.
