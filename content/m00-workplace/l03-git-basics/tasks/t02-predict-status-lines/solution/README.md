# Разбор

Цикл разбирает каждую строку на код (первые два символа) и имя (с четвёртого символа, потому что третий — пробел). Переменная `staged` истинна, если первый символ кода — не пробел и не `?`: то есть файл уже в индексе.

1. `" M src/cart.js"`: код ` M`, первый символ пробел. Файл изменён, но не в индексе. Вывод `src/cart.js false`.
2. `"A  src/utils.js"`: код `A ` — добавлен в индекс. Вывод `src/utils.js true`.
3. `"?? notes.txt"`: первый символ `?`, новый неотслеживаемый файл. Вывод `notes.txt false`.
4. `"MM src/stock.js"`: первый символ `M`, часть изменений в индексе. Вывод `src/stock.js true`.
5. `lines[3].slice(0, 2) === "MM"` даёт `true`.
6. `"[" + " M" + "]"` даёт `[ M]`. Пробел из кода остаётся внутри скобок.

Вторая буква кода в цикле не проверялась, поэтому у `MM` результат `true`: в коммит войдёт версия, лежащая в индексе.
