# Разбор

- `git init` создаёт репозиторий. Ключ `-b main` называет ветку `main`, но он необязателен.
- `git status` — главная команда: она говорит, что происходит.
- `git add .` кладёт в индекс всё в текущей папке (кроме игнорируемого через `.gitignore`).
- `git commit -m "подпись"` фиксирует содержимое индекса. Без `-m` Git не поймёт, что кавычки — это подпись, и воспримет текст как имя файла.
- `git log --oneline` печатает историю, каждый коммит одной строкой.
- `git push -u origin main` отправляет ветку `main` в удалённый репозиторий `origin` и запоминает связь, чтобы дальше хватало `git push`.
