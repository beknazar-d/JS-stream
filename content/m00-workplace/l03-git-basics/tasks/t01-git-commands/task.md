## Контекст

Вы настраиваете первый репозиторий на новой работе и не хотите каждый раз открывать шпаргалку. Выучите шесть команд, которыми начинается любой проект.

## Цель

В файле `index.js` каждая константа содержит пустую строку. Впишите в неё команду Git:

- `initRepo` — создать репозиторий в текущей папке;
- `showStatus` — показать состояние файлов;
- `stageAll` — положить в индекс все изменения текущей папки;
- `makeCommit` — сделать коммит с любой понятной подписью;
- `showHistory` — показать историю коммитов по одной строке на коммит;
- `firstPush` — первый раз отправить ветку `main` в удалённый репозиторий `origin` и запомнить связь.

## Критерии приёмки

- Каждая константа содержит команду, начинающуюся со слова `git`.
- Подпись в `makeCommit` не пустая и взята в кавычки.
- Лишние пробелы по краям и между словами тест игнорирует, регистр не игнорирует.

## Ограничения

- Не меняйте имена констант и слово `export`.
- Менять нужно только текст между кавычками.
