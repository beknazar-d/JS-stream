## Контекст

Тикет GIT-55. Предкоммитная проверка должна показывать список «Войдёт в коммит». В отчёте тестировщика сказано: в списке оказался файл, который в индекс не добавляли, а настоящий файл из индекса пропал.

Вот что показывает `git status --short` на проекте тестировщика:

```text
 M src/order.js
M  src/cart.js
A  src/utils.js
?? notes.txt
```

Ожидалось: `src/cart.js` и `src/utils.js` (они в индексе). Фактически: `src/order.js` и `src/utils.js`.

## Цель

Исправьте функцию `stagedFiles(statusLines)` в `index.js`. Она принимает массив строк вывода `git status --short` и возвращает массив имён файлов, которые войдут в следующий коммит, в том порядке, в каком они пришли.

## Критерии приёмки

- Для четырёх строк выше результат — `["src/cart.js", "src/utils.js"]`.
- Файл с кодом, у которого первый символ — `M`, `A`, `D` или `R`, считается находящимся в индексе (включая `MM`).
- Файл с пробелом на месте первого символа (` M`, ` D`) в коммит не войдёт.
- Файлы с кодом `??` в коммит не войдут.
- Пустой массив строк даёт пустой массив.

## Ограничения

- Менять нужно только условие внутри `stagedFiles`.
- Имена файлов в этом задании простые: без пробелов и переименований.
