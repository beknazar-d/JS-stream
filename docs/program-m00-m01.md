# Программа модулей 0 и 1 (этап 2)

Цель этапа по ТЗ: модули 0–1 целиком, около 20 уроков и 120 заданий.
Здесь 22 урока и 132 задания: 6 заданий на урок (3 разминки, 2 основных, 1 реальная).

Принципы порядка:

- один урок — одна идея, термин вводится до использования;
- старые темы возвращаются в новых заданиях (типы → в функциях → в массивах → в проекте);
- после трудных тем — урок «разбор ловушек» с заданиями на предсказание результата;
- сквозной контекст модуля 1 — интернет-магазин и склад: корзина, остатки, заказы,
  доставка. В конце модуля из этих кусков собирается проект P1.

## Модуль 0. Рабочее место (1 неделя, 4 урока)

| № | Урок | Что умеет после | Задания в браузере |
|---|---|---|---|
| 0.1 | Как устроен курс. Node.js, npm и VS Code | Установил Node.js и редактор, запустил `node file.js` | Разминки на `console.log`, предсказать вывод скрипта |
| 0.2 | Терминал: папки, пути, команды | Ходит по папкам, создаёт файлы, запускает скрипты | Разобрать путь к файлу, найти ошибку в команде по сообщению терминала |
| 0.3 | Git: первый репозиторий и коммит | `init`, `add`, `commit`, `log`, `.gitignore`, публикация на GitHub | Прочитать вывод `git status` и ответить, что будет закоммичено |
| 0.4 | Чтение ошибок и DevTools | Читает стектрейс, находит строку с ошибкой, ставит точку останова | Отладка по логам: по сообщению и стектрейсу найти и починить баг |

| № | Урок | Ключевое |
|---|---|---|
| 1.1 | Значения, типы и преобразования ✓ готов | `typeof`, `Number()`, `NaN`, `===` |
| 1.2 | Переменные: `let` и `const` | Объявление, присваивание, имена, почему не `var` |
| 1.3 | Операторы | Арифметика, остаток, `+=`, сравнение, `&&`, `\|\|`, `!`, `??` |

| 1.8 | Область видимости и стрелочные функции | Блочная область, вложенные функции, `=>`, первое знакомство с замыканием |

Повторение старых тем: с урока 1.7 каждое реальное задание использует функции; с 1.12 —
списки заказов; в 1.15–1.17 возвращаются строки, даты из формы и `NaN` из урока 1.1.

## Что нужно от платформы для этапа 2

- Модуль 0: терминал и Git не запускаются в браузере. Решение: в браузере —
  задания на чтение вывода терминала, `git status` и стектрейсов (проверяются тестами),
  а практика на своём компьютере — чек-лист самопроверки в уроке, который не засчитывается
  как задание (компонент `<Checklist>` в MDX).
- Урок 1.17: тесты с датами работают с фиксированными датами, которые передаются в функцию
  (без `Date.now()` внутри), отдельная поддержка в раннере не нужна.
- Проект P1: многофайловая заготовка уже поддерживается; чек-лист самопроверки — тот же `<Checklist>`.
