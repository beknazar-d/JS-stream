# Принятые решения и допущения

Решения, принятые при разработке без отдельного согласования (по правилу из CLAUDE.md).

## Платформа

- **Третье неверное решение.** В CLAUDE.md три неверных решения: частичное, с гонкой,
  без краевого случая. Пока в модуле нет асинхронности (модули 0–3), гонку заменяет
  «типичная ошибка» (`kind: common-mistake`).
- **Изоляция JS-заданий.** Код выполняется в одноразовом Web Worker, у которого
  удалены IndexedDB, Cache, fetch, WebSocket, вложенные Worker и postMessage.
- **Изоляция заданий на страницу.** iframe `sandbox="allow-scripts allow-forms"` без
  `allow-same-origin`: у страницы непрозрачный источник, данные платформы недоступны.
  Поэтому `localStorage`, `sessionStorage` и `history.pushState` заменены совместимыми
  реализациями в памяти, а `location` не меняется. Надёжнее — отдельный домен для
  страниц учащихся (как у онлайн-песочниц); отложено до появления бесплатного поддомена.
- **Бесконечные циклы на странице.** Worker здесь не подходит (нужен DOM), а iframe
  работает в том же потоке, что и сайт. Поэтому в циклы скриптов страницы при запуске
  вставляется проверка времени (1 с). Скрипты внутри `<script>` в `index.html` не
  защищены — в заданиях код пишется в `script.js`.
- **Сравнение со скриншотом.** Вместо попиксельного сравнения тесты вёрстки проверяют
  геометрию элементов с допуском (`box()`), вычисленные стили и доступность. Это
  устойчиво к различию шрифтов в системах. Попиксельное сравнение — при необходимости
  позже.
- **Проверка вёрстки в CI** — headless Chromium через playwright (бесплатно).
