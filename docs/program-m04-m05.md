# Программа модулей 4 и 5 (этап 4)

25 уроков, по 6 заданий. Сквозной контекст: сервис доставки «Домотеки» — заказы,
курьеры, склады, платёжный шлюз и нестабильные внешние API (служба доставки,
курсы валют, остатки поставщика). Задания с неясностями продолжаются (раздел
«## Неясности», `assumptions.txt`), минимум одно в уроке.

С модуля 4 третье неверное решение — снова «с гонкой» (`kind: race`) там, где тема
асинхронная; в синхронных уроках — `common-mistake`.
